# Generated plugins: AI through Prologue

Design what materials the model reads, the result, where it is shown/saved and when the person confirms. A button-triggered command calls `model.generate`, declared in its effects; a query never calls it automatically. Follow the actual capability catalog, no provider HTTP, key settings or fixed model. No model, timeout, empty/invalid answer and cancellation keep inputs and prior results with a clear retry. Do not fake success. The capability is one text completion, not tools, a streaming conversation or images. Check the catalog before promising those. Supply required inputs in the form and return a declared error if missing; the sandbox cannot ask questions, emit questionnaire cards, or return `needs_input` for the Host to continue.

In the operation file declare literal `export const prompts = [{ id: 'summary', title: 'Summarize', purpose: 'Extract what the reader needs later', body: 'Summarize the decisions and actions using the note. Do not invent missing facts.' }] as const`. Use a unique lowercase id of letters, digits and hyphens. `await sdk.capability.call('model.generate', { prompt: 'summary', input: originalText })` returns `{text}`. Use a literal ID, put all changing data in `input`, never concatenate it into instructions or pass an `instructions` field. G4 refuses undeclared/computed IDs and obsolete inputs. Describe actual useful output, and verify any length or structure imposed by the product. Empty/invalid output is a declared failure with original data available for recovery. Save only an accepted result.

Installed calls use the exact installed declaration and then the person's edited prompt if present; trial uses the current build's prompt. Another project or release cannot fill a missing declaration. Do not send a project, installation, alternate body or language in business input. Host chooses the round language; a user request for a specific output language belongs to the task, not a plugin's guess. A selected target of a translation feature stays explicit.

Sandbox → authorized broker → this Home's Prologue Runtime. Host owns identity, authority, credentials, cancellation and budget and rechecks before dispatch and delivery. Sandbox has no `caller.beforeEffect()`; native concurrent actions have their own checks. Reuse a stable request identity across retries; do not assume a paid operation is idempotent. Automated checks use stand-ins, proving wiring, schema, saves and refusals; trial can use the configured model, and installation checks actual quality, user overrides and recovery. Do not infer model quality from a scripted response.

Signed role/method material reaches consumers as attributed, untrusted JSON. It cannot grant agent execution, directories, MCP, tools or child Agents, or become system/role instructions or inline methods.
