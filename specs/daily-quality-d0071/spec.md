# D0071：MCP 客户端独立连接凭据

状态：实施中（2026-11-08 用户批准高优先级自动修复，并明确采用独立凭据、旧接入重新连接）；验证和 PR 结果随日评记录更新。

## 方案与边界

报告建议客户端身份不可从输入读取，归位宿主的动作网关与授权服务。采纳这个方向；主控制令牌不能安全换取任意身份的子令牌，故按用户决定改为显式接入时创建独立凭据。职责仍在 apps/local-host，实验 Server 管理员入口只调用其公开注册函数；插件和 SDK 不增加身份分支。可信安装 Home 由装配注入，目标账户 Home 由现有路由确定，不从动作输入选择。

连接凭据仅存安装 Home 的私有文件，当前格式第 1 版。用户确认接入 Runtime 时生成，失败或取消只按 CAS 回滚本次凭据；移除接入撤销。MCP 进程用其注册凭据签名短时证明，目标 Home、Host 实例和客户端绑定在签名内。服务端从验证后的注册记录取得 actor，不读取请求体 client_id。Home 主令牌、Origin 和一次性请求键的现有门仍适用；当前凭据在业务提交前复核。短时证明只在接纳时检查到期，已接纳长调用仍遵守当前连接及权限；撤销连接后不得迟到提交。

账号切换保持已有拒绝语义，不以安装根身份访问其他账户；凭据不导出或恢复到另一台机器，恢复后明确重连。不声称隔离能以同一个 OS 用户读取整个 Home 的本机进程。无新 UI 页面或页面资源，无动作、Manifest 或 SDK schema 变化，不建立历史读取路径。

## 验收

1. **D0071-01** 仅持主令牌并在正文声明客户端的请求拒绝，不产生业务或调用记录。
2. **D0071-02** 有效客户端不能在正文冒充他人；伪造签名、跨 Home、过期和已撤销凭据都拒绝；内部 Agent 身份不能注册。
3. **D0071-03** 凭据路径链接、宽权限、损坏或不匹配版本拒绝，凭据不被返回或改写。
4. **D0071-04** 预览不创建凭据；显式接入创建；失败、取消回滚本次凭据且不覆盖之后的注册；已有配置缺凭据被提示重新接入。
5. **D0071-05** 快照排除客户端私钥，仍保留用户业务数据；原凭据不变。
6. **D0071-06** 移除连接时，已进入处理器的旧调用在提交检查处被拒绝，业务表不新增行；Host 实例变化拒绝旧证明。

测试分别位于 security-invariants-gateway、runtime-integration-ownership、home-snapshot-computer-mcp-files 与 action-gateway。先证明原网关的主令牌冒充请求返回 200，再验证修复后的拒绝（原失败日志仅在隔离本机，不含真实凭据）。本机点名相关用例，CI Full 覆盖其余消费者。

## 开工前检查与交付

- 小修／安全边界；用户明确批准接入变化，旧接入重新连接。身份和撤销归宿主，业务授权沿现有动作服务，不在插件、SDK 或 UI 另存授权。
- 事实主人、依赖方向、单一模型入口、声明注册、生命周期、错误模型与现行合同逐项通过；不新增插件名单、不绕过 beforeEffect、不读业务 owner 的表、不新增错误类。无界面定样或页面资源变化。
- 删除请求体身份路径；不提供旧身份兜底或任意换证接口。新私钥目录进入同一 Home store 登记，普通卸载保留、purge 清除，快照省略。
- 安全边界变更对应 S-07 拒绝测试；新文件从格式第 1 版开始，不改原文件版本或迁移机制。对调用方的变更写入 MCP 手册、合同变更说明及 Unreleased 升级须知。
- 在途 PR 已复核，宿主出口只加本项公开方法，不重排聚合文件。独立凭据经本机可信注册，不以主令牌重新签发任意身份。
- 本机整体 build、boundary 与相对 origin/main 的 health 验证；相关定向测试结果和 CI Full 最终结果在 PR 更新，不把定向通过等同于全量通过。未操作真实 Home，未合并或发布。
