# 56 · 提醒通知、文字复核与 N22 收口

[执行目录](../../spec.md#execution-batches) · 阶段 2：个人工作完整可用 · [上一批 55](55.md) · [下一批 57](57.md) · [执行规则](../execution-rules.md)

## 给人讲清楚

作为进入「阶段 2 总验收（第 57 批）」前的收口批，这一批按**三条互不卡脖子的独立轨道**完成三件事：

1. **到点提醒唤醒、应用角标与系统通知（`56-1`，单独一个功能 PR）**：把「稍后提醒 / 到点提醒」真正接通——后台只看全局到期简表，哪条真到点了才按需叫醒对应空间向主人插件核实它还在不在，不会空转唤醒所有休眠项目；提醒遵守克制分级原则：只有**你亲手设了到点 / 稍后提醒**或**卡住推进、需要你拍板的事项**才弹 macOS 系统横幅并计入 Dock 图标角标（支持设置里一键静音系统弹窗并尊重系统专注 / 勿扰模式），后台常规同步、自动整理完成等知会消息只安静收进左下角账户条通知铃；纯网页模式不主动讨要浏览器弹窗权限，只更新标签页与左下角铃铛。不管当前停在哪个页面，点开通知都会自动切回对应的「个人空间」或具体项目并直达那条内容。
2. **阶段 2 新页面中 / 英 / 日三语文案与术语总复核（`56-2`，单独一个收尾 PR）**：等阶段 2 全部新增界面（含 `43`、`45`、`46`、`48`、`52`～`55`、`91B` 及 `56-1` 通知界面）合入后，统一按中 / 英 / 日（`zh`/`en`/`ja`）三语与零二元语言分支标准过筛，清零缺键、硬编码文字、公文冷词与内部黑话，并跑通「中 → 英 → 日 → 中」原地切换不断流验证。
3. **动作输入类型自动推导收口（`56-3` N22，按模块分片独立小 PR + 防回潮门禁 PR）**：在 `111`（统一工作分区）与 `112`（Jelly 瘦身分表、删掉旧 `JellyCommand` 大泥球特例）稳定后，把全仓剩余动作处理器（现测 91 个文件 223 处处理器强转、47 个文件 352 处手写动作输入类型）按模块分片迁到从输入说明自动推导类型，删掉重复手写校验，最后开启绝对门禁 `N22-G` 并删掉过渡计数。

需要你做的：在 `56-1` 开工前看一次通知铃弹层、右下角卡叠「以后再说」、Dock 角标与点开直达的轻量样稿并定下。
