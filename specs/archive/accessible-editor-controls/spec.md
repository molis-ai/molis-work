# 插件编辑控件的可访问名

> 归档（2026-11-23）：判定为**已实现**。插件名称和标签已由第 27 批合入，本次补齐项目设置及组件板，隔离 Home 的无障碍树与键盘回归通过。

状态：本地实现与定向验证完成（2026-11-23）。目标为功能可用，以隔离 Home 的浏览器无障碍树和键盘实操验收。

本次结清 [清点 F-17](../../visual-ui-experience/copy-help-inventory.md#54-第二轮新增的跨页面问题)（BL-1038）。从开工时最新的 `origin/main`（`5bfd52b87b`）建立独立工作树。核对[认领板 #1743](https://github.com/molis-ai/molis-work/issues/1743) 和 [#2010](https://github.com/molis-ai/molis-work/pull/2010)，第 27 批已给六个插件补齐本项清点的名称和表单标签。项目设置由 [#1999](https://github.com/molis-ai/molis-work/pull/1999) 并行调整，实际页面仍需给插件行补充可访问名。在途核查包含共享样式的 [#2258](https://github.com/molis-ai/molis-work/pull/2258)，该 PR 随后合入。

沿用各插件的翻译、原生表单标签与工作台的项目插件清单。项目设置的整行仍用原生 `summary` 展开，名称说明是哪个插件的详情，版本及状态可随描述一起读取。组件板图标按钮用 SDK `renderButton` 已经必填的 `label`，以类型检查锁定要求，并用现有的双语控制词给标本命名。范围为清点列出的控件、对应编辑状态和组件板标本，不新增持久数据、动作、授权或样式。

## 验收标准

1. **AEC-01** Forms 的题目操作、选项删除及标题有名称。Dataset 用三列四行核对九个图标按钮及标题。PPT 的返回、移动、删除、关闭等五个操作及两个标题有名称，三组色板的十二个选项在中文和英文均能读到用途及色名。
2. **AEC-02** Inbox 的返回及关闭、Feed 的添加来源及立即拉取等操作有名称。Jelly 新建事项的起止时间和备注有真实表单标签。对应视图的按钮以 Chrome 无障碍树扫查空名。
3. **AEC-03** 项目设置的项目和个人空间清单，每个插件的展开控件都有含插件名的双语名称，描述保留版本及状态。键盘打开同一行时浏览器报告展开状态。
4. **AEC-04** TypeScript 拒绝给组件板图标按钮省略 `label`。组件板的图标按钮标本在中英文均以给定的动作名进入浏览器无障碍树。

用锁定版本运行 `pnpm build`，用独立 Chrome for Testing、隔离 Home 和 `node scripts/run-tests.mjs --jobs 1` 验收编辑器、Form、组件板和项目插件设置。第 27 批的保存、键盘、颜色回显与窄窗断言继续执行。核对双语词、页面资源预算与门禁，验证通过后删除待办并在 `docs/backlog-removed.md` 留证据。
