状态：方向原型，不是定样（2026-11-12）。用户看过第二版并认可「一条线」的方向，看过第三版后弹窗定了四项（[`specs/work-line/spec.md`](../../../specs/work-line/spec.md) §12）。正式定样随路线书第 32 批第 3 项做，按组件板实件重做，三种宽度、中英文、深浅色、异常状态都要有。产品没有实现；页面里全是演示数据，不连 Home、不调模型，进展靠定时器模拟。

需求出处：[`specs/work-line/spec.md`](../../../specs/work-line/spec.md)。

## 和定样差在哪

- **没有用组件板的实件。** 单文件，自带一套颜色、圆角和动效数值，不是 `docs/design/kit/` 的 `mw-*`。定样时全部换掉，不从这里抄数值。
- **只有中文、只细看过深色。** 浅色能切，英文没做。
- **没有 390 宽。** 窄到 1100 以下只是把名字收起来。
- **没有异常状态。** 排队、失败、断线后核对、读不到都没画。
- **安放是假的。** 「放到哪」靠几个关键词判断，只为演示两拍的样子。

## 打开

```bash
python3 -m http.server 4410 --bind 127.0.0.1 --directory docs/design
```

再打开 `http://localhost:4410/work-line/`。右上角三个按钮：侧边、深浅色、重置。

## 可以试的路径

1. **说一件事。** 在输入框写两三行（⇧↵ 换行）：框向上长，主区的下边跟着让，线的高度不变。发送：框上方先出一句回应，接着写出「放到：发布 v2 › 新工作」和「改」；线上多一个进行中的节点。
2. **看它办。** 节点上的字跟着步骤变；侧边「浏览器」页会亮一下。几秒后它变成「等你」，自己移到中间展开：交办的原话、拆解的四步（各标着插件）、要改的两处。点「同意」，它办完变成结果。
3. **在结果上接着说。** 点结果节点，卡里是预览，过程折叠着；在下面写一句「语气再口语一点」发出去，对话记在这个节点上。「打开」把它开成顶部的一个标签。
4. **点着办。** 点「发布前检查」，勾掉最后一项；点「设计评审会」，「让助理准备材料」。
5. **和这条线无关的事。** 回到现在，发一句「提醒我周五订会议室」：回应写「不归事项 · 在后台任务里」，线上不多节点。点「改」能把它放回这条线。
6. **后台任务。** 点线最右端的按钮：上面是这条线上的，下面是其他——「整理评审反馈」里在办的一件、不归事项的两件。点别的事项的那件会切过去并聚焦；点不归事项的，卡开在侧边。
7. **切事项。** 点线最左端的按钮，切到「整理评审反馈」：线、标签一起换。
8. **停到侧边。** 任一张卡右上角的侧边按钮：卡搬到侧边「对话」页，可以一边在主区做事一边点它。
9. **手边。** 输入框左边的「＋」：Shelf、灵光、资料，点一项附到这句话上；图钉把它钉到侧边。主区条目悬停时的「放到 Shelf」会飞进侧边。
