## 打开样张

从本工作树根目录起静态预览。

~~~sh
python3 -m http.server 4436 --bind 127.0.0.1 --directory docs/design
~~~

打开 [项目资料原型](http://127.0.0.1:4436/batch-06-materials/)。用上方控制条切方案、状态、宽度、语言和外观。也可在新标签页直接打开 [A 的品牌指南](http://127.0.0.1:4436/batch-06-materials/?view=reader)、[B 的品牌指南](http://127.0.0.1:4436/batch-06-materials/?scheme=b&view=reader) 或 [A 的选择器](http://127.0.0.1:4436/batch-06-materials/?view=picker)。重开保留当前标签页的阅读位置、目录展开和任务草稿。重置恢复该链接的初始设置。

## 两案的区别

| | A 就地预览 | B 主区阅读 |
| --- | --- | --- |
| 侧栏 | 资料列表在侧栏里翻到阅读器，返回回到原行。可把长文带到主区。 | 资料列表留在侧栏。正文在主区单独开一个标签，返回原来的任务或列表。 |
| Coding 文件 | 点文件后在侧栏预览，任务、文件区与输入框仍在主区。手机上用底部窗格。 | 点文件后用主区完整宽度阅读，回到任务恢复之前的工作目录和文件区。 |
| 选择器 | 宽屏并排显示资料与正文，窄屏逐页。 | 各宽度逐页，返回资料列表保留筛选和位置。 |
| 取舍 | 适合对照任务快速摘录，读长段落时可扩到主区。 | 长文和代码有更宽的空间，回看任务要切一次位置。 |

A 作为样张的默认入口。它把查看几行代码或摘一句文案的操作留在原任务里，长读仍有明确的主区入口。

## 走一遍

1. 在「项目资料」打开 `brand-assets` 的《品牌指南》，浏览到「按钮怎么写」。拖选一段后点「引用选区」，或用该按钮打开段落列表，用方向键和 Enter 选取。点「加入任务」，输入框上显示文件名、出处和选区；点提示里的「撤销」或引用末尾的 ×。
2. 从任务输入框打开「选择资料」，选《品牌指南》并点「固定快照」，再加入任务。切控制条到「文件有更新」并刷新正文。点任务引用可查看取用时的旧版本。
3. 在 Coding 文件区打开 `Hero.tsx`，引用其中的行。用文件区抬头临时查看 `brand-assets`，文件树随浏览位置切换，Coding 的执行位置仍是 `website`；「回到工作目录」恢复该树。手机收起文件区后仍在任务顶端显示本轮位置。
4. 控制条切「参考访问撤回」「参考目录丢失」。当前文件和新引用被拦在原处；历史固定引用仍可打开并显示原出处。用阅读器或资料来源行进同一个「输入与输出」恢复，再回到文件。切「工作目录丢失」可以看发送被阻止的情形。
5. 切「大文件截断」，先引用可见的日志行，或读取剩余内容后固定整份文件。切「空项目」或「仅项目内容」试导入及使用 Pages 等已有内容。保留一条引用，点「重开」，查看阅读位置与未发送的草稿。

## 共用组件与样张边界

样张直接加载 [组件板实件](../kit/README.md) 和图标表。按钮用 `renderButton`，目录角色与异常用 `renderBadge` 和 `renderAlert`，资料菜单用 `renderMenu`、`renderMenuItem` 和 `renderPopover`，工作区标签用 `renderTabs`，导入文件类型用 `renderFileKind`。键盘可用 Tab、方向键、Enter 和 Esc，关闭时焦点回到触发位置。系统开启减少动态效果时取消位移。

**组件板新增组合**为可展开文件树、带来源和取用栏的阅读器、树与阅读器组成的选择器。树沿用 `mw-dir-row`，取用和恢复用现有按钮与提示。新增的是这些控件的组合、滚动与返回方式。定样后将采用的共用组合补为组件板标本。

文件内容、路径、任务、恢复和固定版本都是示例。PDF 样本展示两页的解析文本，代码用示例着色。原型在同一标签页的会话存储里演示重开。恢复访问只更新样本；固定引用可读性按其独立授权仍有效来展示。产品侧的实际授权、读写、迁移和重启验证在隔离 Home 中进行，验收见 [WMD-01、WMD-04～06、WMD-10](../../../specs/product-flow-governance/workspace-and-materials-design.md#7-验收与当前进展)。

## 走查结果

独立测试浏览器走完了 A、B 的 1440／1024／390 宽度、中英文和浅深色，共 24 个阅读器与 24 个选择器组合。检查了文字与按钮布局、方向键和 Enter、Esc 恢复焦点、鼠标拖选原文、搜索返回、加入和撤销、文件更新前后的固定版本、访问撤回与恢复、大文件读完、空项目导入、手机 Coding 返回工作目录，以及在当前标签页重开时保留引用和草稿。

这份证据达到可交互定样。采用哪套布局、产品内的真实文件与授权行为、迁移后回读分别由用户确认和实现阶段验收。
