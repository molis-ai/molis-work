# 风险解决依据主题颜色修复

> 归档（2026-10-01，合入后梳理）：判定为**已被取代**。待决定页已退役。没有剩余事项。

完成等级：3（功能可用）

## 背景与目标

待决定页选择“已处理，不再阻塞”后，会显示“解决摘要 / 证据引用 / 剩余缺口”三项解决依据。暗色主题下，输入框已经使用暗色 token，但三项字段的外层容器仍保留旧的浅色背景，形成刺眼白块，并让浅色标签几乎不可读。

目标是让这组条件字段与同一表单中的“决定理由”以及 Goal 详情使用同一套表面色、边界和文字颜色，同时保持浅色主题与现有交互不变。

## 范围与非目标

- 在暗色主题中为 `.risk-resolution-fields` 应用现有决策表单的语义表面 token。
- 增加样式回归断言，并实际检查明暗主题和窄屏布局。
- 不调整字段、文案、校验、提交行为或风险状态语义。
- 不重做待决定页或 Goal 详情的信息结构。

## 方案与边界

- 复用 `.decision-reason` 已采用的 `Quiet Line` 与 `Rail / Paper` 混合表面，不新增颜色值或局部主题系统。
- 修改边界：`src/web/visual-foundation.ts`、`tests/web.test.ts` 与本 spec。

## 验收标准

1. 暗色主题下三字段容器不再出现白底，标签、占位文本、边框和输入内容均清晰可读。
2. 容器色与同一表单中的“决定理由”属于同一表面层级。
3. 浅色主题外观不发生意外变化。
4. 窄屏单列布局没有横向溢出。

## 验证

- 定向运行 `tests/web.test.ts`。
- 浏览器检查暗色、浅色，以及窄屏三种状态。
