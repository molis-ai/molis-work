## 1. 背景

来源：MISC「T-188 二审 建议」。T-188（#1472）把 Goals 插件里几处按 UTF-16 单元截标题的地方改成按整字截，Feed 里同一类的两处没进那一单。`plugins/native/feed/src/goal-promotion.ts:88-91`（约；开工先核）：

```ts
const sourceTitle = item.title.trim().replace(/[\u0000-\u001f\u007f]/gu, " ").slice(0, 104) || "未命名内容";
const itemTypeLabel = "Feed Item";
const intent = {
  title: `处理 ${itemTypeLabel}：${sourceTitle}`.slice(0, 120),
```

`.slice(0, 104)` 和 `.slice(0, 120)` 都按单元：条目标题第 104 个单元落在 emoji 等两单元字的两半之间时，Goal 标题里留下半个字（落单的代理字符）。之后这个标题写进 Goal，显示、搜索、JSON 都可能出问题。T-188 的写法可作范本（`[...text].slice(0, N).join("")`，先用 `slice` 把要展开的量限住，因为条目标题没有上限）。

注意两个上限的关系：Goal 标题（`goals.create` 的 `title`）在 Goals 合同里的上限是多少、按什么数（Ajv 的 `maxLength` 按字数数），以 `plugins/native/goals/src/contract/goal-actions.ts` 里的 schema 为准；这里 120 的意思必须与它一致，不能出现“Feed 截到 120 个单元却被 Goals 按字数拒”或相反。

## 2. 目标

1. `sourceTitle` 按整字截到 104 个字；整个 `title` 按整字截到 120 个字。含两单元字的标题，Goal 标题里不留落单的代理字符，且比改前多保留的是整字。
2. 不展开整段条目标题：先 `slice` 到 2×上限个单元，再展开（条目标题没有上限）。
3. 全部是 ASCII/汉字的标题，结果和改前逐字一致（两种数法在这里相同）。
4. 用例（见第 7 节）。

## 3. 不做

- 不改 `itemTypeLabel`、`outcome`、`why`、`business_logic`、`priority` 等其他字段，不改幂等键的写法。
- 不改 Goals 的合同和 `goals.create`；不改 Feed 其他地方的 `.slice`（本单只管标题这两处；发现别的同类处记到【交接】，不顺手改）。
- 不加兼容或迁移逻辑；库里已存的旧标题不动。

## 5. 做法

先在当时的 main 上核第 1 节的行。把两处改成（形状，名字自定）：

```ts
/** At most `max` whole characters; only the first 2×max units are spread, since a title has no upper bound. */
const wholeCharacters = (text: string, max: number) => [...text.slice(0, 2 * max)].slice(0, max).join("");
```

`sourceTitle` 用 `wholeCharacters(清理后的标题, 104)`；`title` 用 `wholeCharacters("处理 Feed Item：" + sourceTitle, 120)`。照 `tests/feed-goal-promotion.test.ts` 第 41 行那条用例的做法起一个 Feed + Goals 的宿主，造条目。先读 `plugins/native/goals/src/contract/goal-actions.ts` 里 `goals.create` 的 `title` schema，确认 120 的口径（第 1 节最后一段），把核对结果写进【方案】。

## 6. 验收

- `RAC-2299`：条目标题是 `"x".repeat(103) + "🙂" + "尾"`时（第 104 个单元落在 🙂 的两半之间，改前会留下半个字），升成的 Goal 标题里没有落单的代理字符，`sourceTitle` 恰是 `x×103 + 🙂`（104 个字，整个 🙂 保留；改前是 `x×103` 加半个字）。
- 同一条用例里另一个条目：标题 130 个 emoji（260 个单元）——Goal 标题恰是 `处理 Feed Item：` 加上若干个整个 emoji，总字数不超过 120，没有半个字。
- 全 ASCII 的长标题（如 200 个 `a`）结果和改前一样：`sourceTitle` 104 个、`title` 120 个字符。
- 先红：`RAC-2299` 的第一部分在改源码前红（落单代理）。
- `tests/feed-goal-promotion.test.ts` 其余用例不变。
