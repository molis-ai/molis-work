## 给人讲清楚

第 34 批已经让你能看到各个外部 AI 工具里的会话记录，这一批让你能真正接着管它们，分**两步（两个串行 PR）**稳扎稳打交付：

1. **直接控制与运行中换人交接（`60-1`）**：在 Molis 里直接恢复某个外部工具会话、给它发下一句指令、或者叫停它；如果原工具正在干活，你想换另一个外部工具、或者交给 Molis 自己的助理 / Coding 接着干，界面会让你选**「先停掉原工具再接手」**或**「原工具继续跑、新工具并行接着做」**，并自动把原任务背景、已定决定、已有成果和未完事项带过去。凡官方开放了正式命令 / 协议接口的工具真刀真枪接通直控；对官方没开放外部控制接口的第三方 IDE 或云端工具，绝不黑进对方私有数据库伪造续接，而是诚实说明限制，提供**「一键唤起原工具窗口定位」+「带上下文交接给 Molis 助理或 Coding 接着做」**。
2. **持续跟进汇入简报与国内外主流工具全表收口（`60-2`）**：开启持续跟进后，你在外部工具继续推进的新进展会自动增量汇入工作记录、项目概览和第 52 批的每日简报（断线或重启绝不重复记功）；同时补齐其余开放公开接口或可读本地格式的国内外主流 AI 开发工具适配，逐个入口把「发现、读原文、直控恢复、交接、限制缺口」列成诚实透明的全景表。

需要你做的：在 `60-1` 开工前看一次对话栏 + 信息栏上的「控制与运行中交接选择」轻量样稿并定下。

## 11-18 复查与 11-25 路线校准（[决定 52](../decisions.md#decision-52)、[决定 66](../decisions.md#decision-66)、2026-11-25 拍板）

对照 main `horizontal/sessions` 实况与前序已拍板批次校准后改的地方；改动已写进上面各处：

- **拆分为 `60-1`（直接控制与运行中交接）+ `60-2`（持续跟进汇入简报 + 其余厂商适配与全表收口）两个串行 PR**，解决单 PR 跨合同、存储、UI、简报与十余个适配器体量失控问题。
- **钉死外部控制安全红线与第三方工具诚实边界**：读取权绝不推导控制权（严防绕过 `105` 命令审批）、CLI 参数数组化防注入与本人目录核验、Clean v1 机制表零原文落库；未开放控制接口的 IDE／云端工具严禁逆向篡改私有库伪造续接，统一提供「唤起原工具 + 带上下文交接给 Molis 助理／Coding」。
- **厘清个人空间与项目分区的列表口径**，并要求交接弹层按需懒加载以守住 `91B` 首屏预算。

**与底栏第十三版及 `91B` 壳层的衔接（[决定 53](../decisions.md#decision-53)）**：「交接选择与控制」按统一对话栏 + 信息栏出样，不另起平行面板。
