# 原型验证记录

2026-09-21。对象为本目录的静态交互 Demo，不是生产 Molis Work。

## 已直接操作的主线

| 场景 | 实际观察 |
| --- | --- |
| 新反馈留到下轮，再重新考虑并采用 | 延期保留原要求；采用后进入原稿第二段，带入新写作依据，正文没有被自动改写 |
| 修改第二段，保存草稿并刷新 | 输入内容恢复；仍是工作稿，未产生已提交成果 |
| 保存为成果 v2，记录已阅；修改后保存 v3 | v3 仍显示“记录已阅”；回 v2 可以看到它自己的已阅记录 |
| 针对 v3 第二段写意见，切到第三段再切回 | 意见仍留在第二段，第三段为空，没有被重新绑定 |
| 带着意见继续修改 | 聚焦原稿第二段，保留现有正文；侧栏显示针对 v3 的原意见 |
| 修改后保存 v4，并刷新 | v4 正文和依据恢复；回看 v3 仍有原段落意见；v4 没有继承旧版意见或已阅状态 |
| 从首页、Inbox 和成果入口打开当前成果 | 承诺打开最新版的入口使用同一动作，避免曾看旧版后误开旧版 |
| Feed 保存资料 | 进入项目资料视图；已读与保存去向分别呈现 |
| 个人置物架处理样例 | 保留原件并出现文字副本；个人范围明确，没有自动加入项目 |
| 原有范围决定 | 失败保留选择与说明；重试后记录实际选择，刷新可恢复 |
| 搜索与目标 | 新建本地目标后可以搜索、打开并在刷新后保持同一身份 |

这些操作由浏览器工具实际执行并观察可见反馈，使用代表性中文样例。它们验证原型交互，不证明真实 Agent、真实应用或团队链路可用。

## 视觉与窗口

- 直接查看了普通桌面下 A 的首页／变化面、B 的成果对照／文稿面，以及个人置物架；浅深色均观察过。
- 返工时原先依据栏随正文滚走，已调整桌面栏的停留方式；手机和矮窗口保持普通文流。
- 原先段落意见输入远在页面底部，已移至所选本版段落下方，并检查点击后输入可达。
- 1024×400 CSS 视口：根宽 1024、根高 400，正文在内部滚动，已阅动作可操作。发现并修复隐藏标签定位造成的根页面额外高度。
- 390×844 CSS 视口：根宽 390、根高 844，内容无横向溢出；通过抽屉导航进入成果，段落按先后版顺序排列，意见输入可达。设备模拟截图存在工具画布缩放异常，因此不据该截图确认真实手机的视觉质感。
- 临时设备模拟已清除。原型没有安装浏览器扩展、修改系统外观或生产应用设置。
