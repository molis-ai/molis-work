# WI9 Pages 对齐 Notion：块操作、链接、光标

完成等级：**3 功能可用 → 4 内部完整**（按轮次推进）。不宣称可发布。

depends_on: `08-visual-polish`

## 背景目标

WI8 把阅读面和 hover/拖拽做到能看了，但作为 Notion 式文档工具还缺基本动作：写不了超链接，块菜单只有上移/下移/备注，卡片/分隔线前后落不了光标。这条 WI 是长程目标「Pages 达到 Notion 的质感、功能和顺畅度」的执行容器，按轮次补齐并逐条留证据。

## 当前行为与问题证据

- `plugins/native/pages/src/schema.ts` 的 marks 只有 strong/em/underline/strike/code/comment，没有 `link`：选中文字没有任何入口能加超链接，粘贴 URL 也只是纯文本。`styles.ts` 里已有 `.ProseMirror a` 规则，但永远匹配不到。
- 块手柄菜单只渲染「上移 / 下移 / 备注」三项，没有转换为、复制、删除；换块型只能删掉重敲。
- 插件列表里没有 `prosemirror-gapcursor` / `prosemirror-dropcursor`：文末是 `task_card`、`calendar`、`toc`、`horizontal_rule` 这类 atom 时，键盘走不到它后面，只能靠鼠标点别处。
- Backspace 在标题或列表项行首走 `baseKeymap`，直接和上一块合并，而不是先脱一层格式。
- 没有选块键：Esc 只被 Slash 菜单用掉，选不中整块。

## 范围与非目标

做（本轮）：

1. `link` mark：格式条按钮 + `Mod-k` + 弹层编辑/移除，点击链接新窗口打开，粘贴 URL 到选区自动加链，`href` 只收可导航协议。
2. 块菜单补齐：转换为（段落/H1–H3/无序/有序/清单/Callout/Toggle/代码，两级菜单）、复制、删除，保留备注/上移/下移。
3. `gapCursor()` + `dropCursor()`：atom 块前后能落光标，原生拖放有插入线。
4. 键盘：`Mod-d` 复制当前块、Esc 选中整块、行首 Backspace 先脱一层（标题→段落，列表/清单/Callout/Toggle→提出）。

做（第三轮）：

5. 文字颜色与背景高亮：两个 mark（`font_color` / `highlight`），格式条「A」按钮开双排色板，取值限定在设计系统 hue 白名单。
6. 嵌套：Tab / Shift-Tab 对待办列表同样生效；三层以内的无序/有序列表用不同 marker 区分层级。
7. 空态占位：整篇空白时不必聚焦也显示「输入 / 插入块，或直接写」。
8. 键盘：`Mod-a` 渐进全选（先当前块，再整篇）。

做（第四轮）：

9. 占位覆盖到所有空块：空标题显示「标题 N」，列表项 / 待办 / Callout / Toggle 里的空段落各给自己的词，表格单元格不给。
10. 块菜单加「颜色」二级面板，对整块上色 / 清色。
11. 动效补齐：块 hover 底色和阴影带过渡、块手柄淡入、全局 `prefers-reduced-motion` 兜底。

做（第五轮）：

12. 代码块：上方常驻语言选择条 + 悬停出现的复制按钮，13 种语法的高亮，语言名走别名折叠与白名单。

做（第六轮）：

13. Callout：图标与颜色解耦，点左侧图标开选择器；颜色接到同一套九色板；四个旧色调（info/warn/success/plain）渲染保持不变。

做（第七轮）：

14. 拖拽改层级：握把对准光标下的那一行（含列表项、Callout / Toggle 里的子块）；落点线跟着横向偏移，右移一档嵌进上一个能装子块的容器，左移提出来。原地放下不改文档。

做（第八轮）：

15. 多块选择：握把点一下选中该行，Shift 再点或选中后 Shift+↑/↓ 把连续的行扩进去。删除、复制、拖拽作用在整组上。选区里如果包含父块，子块跟着走，不单独再处理一次。

做（第九轮）：

16. 上移 / 下移对任意一行生效，不只顶层块：菜单和 `Cmd+Shift+↑/↓` 在同级兄弟之间换一位。已经在最上或最下就不动。多块选区如果是同一级的连续兄弟，整组一起挪，选区跟着落到新位置。

做（第十轮）：

17. 段落里只敲 `---`、`***` 或 `___` 变成分隔线，后面留一个空段落接着写。只敲 ``` 或 ``` 加语言名变成代码块，语言名走现有白名单。列表项里的段落套不进分隔线或代码块时，这几个字符留在原地。代码块末尾按 ↓、开头按 ↑ 能走出块；末尾后面没有块时补一个空段落。

做（第十一轮）：

18. 在空段落里粘贴一段 Markdown：标题、无序/有序/待办列表、分隔线、代码围栏和行内的加粗、斜体、删除线、行内代码、安全链接会变成对应的块和 mark。没有这些结构的普通多行、光标不在空段落、或父块装不下（例如列表项里的标题）时，走原来的粘贴。

做（第十二轮）：

19. 表格：在右下角那个格子按 Tab 会在下面加一行空行，光标进到新行第一格。块菜单对表格多出「加一行」「加一列」「删行」「删列」。从表头加出来的新列仍是表头。删到只剩一行或一列时，整张表换成一个空段落。

做（第十三轮）：

20. 引用：空行敲 `> ` 变成引用块，光标在里面接着写。连续以 `> ` 开头的粘贴行合成同一块引用，行内加粗保留。列表项装不下引用时字符留在原地。块菜单和 `/` 可以转成引用，再转回段落时正文还在。行首 Backspace 脱掉引用或 Callout，正文留下。引用里最后一行是空的时按回车，空行挪到引用外面。折叠块还有内容时，标题那一行的退格不会把标题拆出去。
做（第十四轮）：

21. 空行粘贴 GFM 表格：第一行在有 `| --- |` 分隔行时是表头，分隔行不进格子，后面是正文。格子里的 `**加粗**` 还在。只有一列的 `| 只有一格 |` 不当成表。

做（第十五轮）：

22. 斜杠换块换的是光标下这一行，不是它所在的整张列表或整个 Callout。列表中间一项换成标题时，前后两项各自留成列表。Callout 里只换当前那段。`Cmd+D` 和块菜单「转换为」同样只动这一行，列表项转成标题时文字还在。

做（第十六轮）：

23. 行内快捷输入：打完 `**甲**`、`*乙*`、`~~删~~`、`` `码` `` 变成加粗、斜体、删除线、行内代码，记号本身消失。`**甲**` 不会被斜体规则吃掉。代码块里这些记号保持原文。打完 `[文档](molis.ai/docs)` 只留下带链接的「文档」；网址后面打一个空格，网址变成链接、空格还在。`javascript:` 不会变成链接。

做（第十七轮）：

24. 代码块里按 Tab 插入两个空格，Shift-Tab 删掉光标前最多两个空格；段落和划了选区时不触发。折叠块箭头走 click 切换 `open`，标题和内文不动。

做（第十八轮）：

25. 斜杠不限最外层段落。列表项、Callout、写到一半的句子里，光标前的 `/查询` 都会打开同一份菜单。整行只有这个标记时，选中的块换掉这一行；前面还有字时，字留下，新块插在这一行后面。折叠块标题上的斜杠不会把里面的正文一起换掉。代码块和表格格子里的 `/` 保持原文。

做（第十九轮）：

26. 行首加号：空的正文、标题、列表项、Callout 里直接写入 `/`，斜杠菜单就地打开。这一行已经有字时，在下面新开一行并写入 `/`；列表里新开的是同级一项，已勾选的待办不会被带过去。块与块之间的缝也是在下面插入带 `/` 的段落，不会把上一行的空段落填上。代码块下面新开的是正文，代码本身不动。

做（第二十轮）：

27. 块颜色跟着握住的那一行，不再把整张列表或整个 Callout 一起铺上。列表里只给当前项上色，加粗还在，旁边的项不动。Callout 里只给当前段上色，色调图标不动；握住 Callout 本身时，里面的段落一起上色。多选几行时，只给选中的那几行上色。代码块不接收颜色。不在色板里的名字不会写成标记。

做（第二十一轮）：

28. 多选连续几行后可以一起「转换为」。三段正文变成一张列表，加粗还在；变成标题时仍是三段标题。两段正文合成一个代码块时用换行接起来。列表里只转中选中的几项，其余项留在列表里。Callout 里的几段合成一张列表时，Callout 的颜色和图标不动。选区跨出 Callout，或里面夹着表格时，文档不动。

做（第二十二轮）：

29. 标题里按回车：写到一半时，左边留在标题，右边变成正文，行内样式跟着右边走。光标在标题末尾时，下面是空段落。光标在标题开头时，上面插入空段落，标题整段还在。划掉标题里的一段字再回车，这段字消失，后面是空段落。已勾选的待办写到一半按回车，前一条仍勾选，新的一条不勾选。普通段落不走这两条命令。

做（第二十三轮）：

30. 目录里的每一条都能点。点第一条跳到第一个标题，两个标题都叫「甲」时点第二条跳到后面那个。标题藏在关着的折叠块里时，先把折叠块打开再把光标放进去；套了两层就两层都打开。Callout 里的标题同样能跳到，颜色和图标不动。没有那么多标题时不动。

做（第二十四轮）：

31. 斜杠、提及、块菜单、格式条和各种小弹层靠近屏幕边缘时翻到放得下的一边，并留在视口里。块菜单优先出现在握把右边，右边不够就到左边。格式条优先在选区上方，上方不够就到下方。斜杠和提及菜单里，键盘移到的那一项滚进菜单自己的滚动区。

做（第二十五轮）：

32. 键盘换块：`Mod-Alt-0` 到 `3` 把当前行转成正文或一到三级标题，`Mod-Shift-8` 无序列表，`Mod-Shift-7` 有序列表，`Mod-Shift-9` 待办。`Mod-Enter` 只翻转光标下那一条待办。代码块最后一行是空的时按回车，空行收掉，光标走到下面的新段落；最后一行还有代码时回车仍留在块里。空代码块按回车变成空段落。

做（第二十六轮）：

33. 空段落粘贴一个网址，变成书签卡：标题是站点名（去掉 `www`），点开会在新标签打开。选中「文档」再粘贴网址，字还是「文档」，只加上链接。写到一半的句子末尾粘贴，网址接在后面变成链接，不换成卡片。列表项装不下卡片时，网址留在这一项里。Callout 的空行可以换成书签，颜色和图标不动。代码块、`javascript:` 和普通句子不接手。坏地址不会渲染成可点击链接。

做（第二十七轮）：

34. 块与块之间的提示线点下去只出现空白，文档先不变。没打字就点走、按 Esc 或按回车，这一行不存在。打了字，或往空白里粘贴了内容，才在这个位置插入。单独一个网址变成书签。`Cmd/Ctrl+C` 复制、`Cmd/Ctrl+X` 剪切、`Cmd/Ctrl+Z` 撤销、`Cmd/Ctrl+Shift+Z` 和 `Cmd/Ctrl+Y` 重做。粘贴仍走编辑器自己的粘贴处理，不把普通文字吃掉。格式条上的无序、有序、清单：再点同一种会取消，换一种只转当前项。

做（第二十八轮）：

35. `Cmd/Ctrl+F` 在文中查找。大小写不敏感，匹配不跨过换行。回车到下一处，Shift+回车到上一处，到头绕回。Esc 关掉。`Shift+Enter` 在段落里插入换行，块还是同一块；在代码块里插入一个换行，语言名不动。

做（第二十九轮）：

36. 空行粘贴 `https` 图片地址（png、jpg、gif、webp、svg、avif）变成图片块，按宽度缩进页面，替代文字用文件名。普通网址仍是书签。`http` 图片和 `javascript:` 不会变成图片。选中文字再粘贴图片地址，字还在，只加链接。Callout 空行可以放图片，颜色和图标不动。坏地址渲染出来不是 `img`。

做（第三十轮）：

37. 从剪贴板粘贴 png、jpeg、gif、webp 截图，嵌成图片块。空段落被这张图换掉；段落里已经有字时，图排在这一段后面，字还在。提示线的空白里粘贴同样会插入。svg 数据、超过约 1.5MB 的数据地址和 `javascript:` 不会变成图片。

做（第三十一轮）：

38. 斜杠选「分栏」得到左右两栏，每栏一个空段落，占位是「这一栏」。块菜单「加一栏」再加一列，光标进新栏。「取消分栏」去掉栏框，各栏正文按从左到右留下。窄屏时栏上下叠放。

做（第三十二轮）：

39. 光标在栏的最边上时，左方向键走到左边那一栏的末尾，右方向键走到右边那一栏的开头。已经是最左或最右时，再按就离开分栏，到上面或下面那一块。上方向键在栏的第一行离开整组分栏，下方向键在栏的最后一行离开，不会横着跳到旁边那一栏。栏中间的方向键仍在栏里走。分栏上面或下面没有块时，方向键留在原地。

做（第三十三轮）：

40. 分栏里的每一段都有自己的握把，握把落在这一栏左侧留出的空位里，不盖住字，也不盖住旁边那一栏。栏外的段落可以拖进某一栏，加粗还在。把一栏里仅有的一段拖出去，这一栏留下空行，分栏还在。整组分栏不能拖进自己里面。握住栏里的一段，菜单里仍能加一栏或取消分栏。

做（第三十四轮）：

41. 把一段往右拖到另一段旁边，松手后两段并成左右两栏，左边是原来那一段，右边是拖过去的那一段，加粗留着。落点是一条竖线，贴在左边那段的右侧。平着拖仍然只换上下位置。已经在栏里的块、Callout 和列表的右移嵌套不变。

做（第三十五轮）：

42. 已经有左右两栏时，把栏外的一段再往右拖过右栏，会在右边多出第三栏，加粗留着。竖线贴在这一栏的右缘。拖到和栏里文字对齐的位置，仍掉进这一栏，不新开栏。拖到左栏右侧，新栏插在中间。从这一栏自己里面往右拖，不会多出一栏，落点退回普通换位：这一栏留下空行，那段排到分栏下面。

做（第三十六轮）：

43. 一栏里只剩一个空块时，按退格收掉这一栏。三栏里收掉中间的空栏，左右两栏还在，光标落到左边那段的末尾。只剩两栏时，分栏框也拆掉，留下另一栏的正文。空栏在左边时，光标落到留下那段的开头。栏里还有别的块，或这一栏里有字，退格不收栏。

做（第三十七轮）：

44. 查找条可以填「替换为」。替换只换当前这一处，然后跳到下一处。全部把每一处换掉，换出来的字里再出现要找的词也不会继续换。加粗的字换完还是加粗。换成一样的字等于没换。留空是删掉这一处。代码块里能换字，语言名不动，也不会带上加粗。在替换框按回车换当前这一处，按 Cmd/Ctrl+回车换全部。

做（第三十八轮）：

45. 选中图片，拖右缘改变宽度，松手才写进文档。宽度小于 120 像素时收到 120，大于 1600 时收到 1600。拖到接近整行就恢复满宽。地址和替代文字不动。不是图片的位置不能改宽度。写出的样式只有 `width: Npx`。不是纯数字的宽度被丢掉，不会写进样式。

做（第三十九轮）：

46. 拖表格某一列的右缘，这一列的表头和下面每一格一起变宽，旁边的列不动。窄于 80 像素收到 80，宽于 640 收到 640。设成 0 恢复自动平分。不是表格、或列号对不上，不会改。写出的样式只有 `width: Npx`。不是纯数字的列宽被丢掉。

做（第四十轮）：

47. 光标在格子的最边上时，左方向键到左边那一格的末尾，右方向键到右边那一格的开头。上方向键到同一列上一格的末尾，下方向键到同一列下一格的开头。一行的开头再按左，到上一行最后一格。已经是表格第一格时，再按上或左就离开表格。最后一格再按下或右，到表格下面。格子中间的方向键仍留在这一格里。表格上下没有别的块时，方向键留在原地。

做（第四十一轮）：

48. 普通点击链接只把光标放进字里，不打开新标签。按住 Command 或 Control 再点才在新标签打开。光标停在链接里时，上方出现站点名，以及「打开」和「编辑」。Shift 或 Alt 加 Command 不打开。

做（第四十二轮）：

49. 选中几个字写评论，字还在，评论盖在这几个字上。光标停在评论里，下方出现评论原文和「编辑」。把评论留空就去掉高亮，字还在。没选中字、光标也不在评论里时，不能写评论。

做（第四十三轮）：

50. 拖两栏之间的缝，左边变宽、右边变窄，两边加起来还是原来的总宽。窄的一边最少留 0.2。已经是最后一栏，或位置不是分栏，不能拖。窄屏幕仍改成上下排列。不是数字的宽度按相等处理。

做（第四十四轮）：

51. 块菜单「表头行」把第一行从标题格收成普通格，再点一次变回去。格子里的字、加粗和列宽留着，下面的行不动。不是表格的位置不会改。

做（第四十五轮）：

52. 光标在表格某一格里，按 `Cmd/Ctrl+Shift+↑` 或 `↓` 只挪这一行，不挪整张表。字、加粗、表头和列宽跟着这一行走。已经是第一行再往上，或最后一行再往下，表格不动。光标不在表格里时，这个键仍按原来的方式挪块。

做（第四十六轮）：

53. 光标在表格某一格里，按 `Cmd/Ctrl+Alt+←` 或 `→` 只挪这一列。每一行里这一列和旁边那列对调。字、加粗、表头和列宽跟着这一列走。已经是最左再往左，或最右再往右，表格不动。光标不在表格里时，这个键没有反应。

做（第四十七轮）：

54. 选中带样式的字，按 `Cmd/Ctrl+\` 去掉加粗、斜体、下划线、删除线、行内代码、文字颜色、背景色、链接和评论。字还在，选区外面的样式不动。本来就没有样式时，这个键没有反应。只把光标放着、下一段要继承加粗时，按一下后接下来打的字是普通字。

做（第四十八轮）：

55. 光标在表格格子的开头按退格，走到左边那一格的末尾，这一格的字不删。在格子末尾按删除键，走到右边那一格的开头。光标在格子中间时，退格和删除仍按原来的方式删字。

做（第四十九轮）：

56. 斜杠选「图片」打开本机文件。png、jpeg、gif、webp 且转成数据地址后不超过约 1.5MB 才会嵌进文档。svg、空文件和更大的文件不读。拖一张符合的图到正文里，图落在松手的位置。取消选择时斜杠字被清掉，不插入空块。

做（第五十轮）：

57. 整块被选中时打字，这一块换成刚打出来的那段普通文字，原来的加粗不带过去，旁边的块不动。光标停在新字后面。光标还在字里面时，打字不走这条。退格或删除在整块被选中时删掉这一块；文档只剩这一块时，留下一个空段落。

做（第五十一轮）：

58. 选中图片后，图下面出现说明。写下的字只留一行，换行变成空格，超过 200 字被截断。地址、替代文字和宽度不动。没选中且没有说明时，这一行不出现。有说明时，读出来的页面在图下显示这句话。

做（第五十二轮）：

59. 整块被选中时，下方向键选中下一块，上方向键选中上一块。已经是第一块再往上，或最后一块再往下，选中不动。左方向键把光标放进这块文字的开头，右方向键放到末尾。选中的是图片时，左方向键回到左边那段的末尾，右方向键进到右边那段的开头。回车在这块下面新开一个空段落，光标进去。光标还在字里面时，这些键仍按原来的方式走。

做（第五十三轮）：

60. 从网页贴进空行时，标题、列表、表格、加粗、斜体和安全链接会留下来。`javascript:` 链接只留文字。脚本不进文档。贴到一句已经写了的话里，如果网页只是一段，就替换选中的字并留下样式。代码块里不接手。纯文本已经是 Markdown 标题、列表、引用、表格、代码围栏或分隔线时，仍按 Markdown 解析，不用网页结构盖掉。

做（第五十四轮）：

61. 点书签卡片不会打开网页。按住 Command 或 Control 再点地址才在新标签打开。选中卡片后可以改名称。名称只留一行，换行变成空格，超过 120 字被截断。地址不动。把名称清空后，卡片重新显示站点名。

做（第五十五轮）：

62. 同时选中多块再复制，剪贴板里按顺序带上每一块，不只是最后点中的那一块。从下往上选，顺序仍是从上到下。只选一块时，复制仍走原来的选区。剪切会把这些块剪走。列表里选中相邻两项，复制的是这两项，不会把整份列表再套一层。

做（第五十六轮）：

63. 把复制出来的列表项贴回空行，它们重新收成一份列表，不会散成普通段落。中间隔着一段字时，前后各自成一份列表。待办项贴回去仍是待办，勾选还在。整份有序列表贴回去仍是有序列表。整份待办列表贴回去仍是待办列表。

做（第五十七轮）：

64. 同时选中多块再打字，这些块收成一段普通文字，原来的加粗不带过去。没选中的旁边那块还在。从下往上选，结果一样。只选一块时，不走这条，仍按单块替换。

做（第五十八轮）：

65. 复制一块或几块时，纯文本带上 Markdown 记号。标题还是 `#`，加粗还是 `**`，链接还是 `[字](地址)`，待办是 `- [x]` 或 `- [ ]`，代码块带语言围栏。本机图片不把一长串数据地址写进纯文本。把 `- [x] 完成` 贴回空行，仍是勾选的待办。`[] 待办` 这种旧写法还能贴。

做（第五十九轮）：

66. 从网页贴进来的下划线还在。文字颜色只收设计系统里的颜色，以及红、蓝、黄、绿这几个常见写法；对不上的颜色丢掉，字还在。`<mark>` 没有指定颜色时用黄底。带这些样式的网页片段，即使旁边的纯文本像 Markdown，也按网页结构贴，颜色不会被盖掉。复制出去的纯文本里，下划线写成 `<u>`。

做（第六十轮）：

67. 选中的字里只有一部分已经是这个颜色时，再点这个颜色会把选区铺满，不会把已有的颜色清掉。整段选区都是这个颜色时，再点一次才取消。换一种颜色仍是整段换成新颜色。

做（第六十一轮）：

68. 加粗、斜体、下划线、删除线和行内代码也一样。选区里只有一部分有这个样式时，再按一次会铺满。整段都有时，再按一次才去掉。代码块里按加粗没有反应。

做（第六十二轮）：

69. 选中同一层相邻的几条列表再按 Tab，它们一起嵌到上一条下面。勾选跟着走。再按 Shift-Tab，这几条回到原来那一层。选区从第一条开始时，Tab 不会把第一条塞进自己里面，列表保持原样。只选一条时，仍按原来的方式缩进。

做（第六十三轮）：

70. 选中连续几段再点标题，这几段都变成那个级别的标题，加粗还在。旁边没选中的段不动。这几段已经是同一级标题时，再点一次变回段落。选中连续几段再点无序列表，它们收成一份列表。已经是这份列表时，再点一次变回段落。只把光标放在一段里时，仍只改这一段。

做（第六十四轮）：

71. 单独一行 `![图](地址)` 贴回空行会变成图片，替代文字是方括号里的名字。单独一行 `[名称](地址)` 会变成书签。句子里的链接仍是行内链接，不会变成书签。`javascript:` 不会变成图片或书签。从编辑器复制出去的图片和书签，纯文本贴回去还是原来的块。

做（第六十五轮）：

72. 目录里，光标正停着的那一级标题会标出来。光标在标题里面，或在它后面、下一个标题之前的正文里，都算这一级。还没到第一个标题时，目录里没有当前项。

做（第六十六轮）：

73. 选中连续几段，用块菜单「转换为」引用、代码或折叠，这几段收成一块。引用里的加粗还在。代码把这几段收成一个代码块，中间换行。没选中的段不动。只把光标放着时，仍只转这一段。选区里夹着表格时不转。

做（第六十七轮）：

74. 格式条上的标题按钮会亮。光标在二级标题里，或选中的几段都是二级标题时，H2 亮着。选区里夹着段落或其他级别时，三个标题按钮都不亮。光标在普通段落里也不亮。

做（第六十八轮）：

75. 格式条上的列表按钮也一样。光标在无序列表里，或选中的几条都在同一份无序列表里时，无序列表亮着。选区伸进列表外面的段落时，三个列表按钮都不亮。光标在普通段落里也不亮。

做（第六十九轮）：

76. 空的代码块会提示「写代码」。写了字以后提示消失。表格格子里仍然不提示。

做（第七十轮）：

77. 格式条上的加粗、斜体、下划线、删除线、行内代码和链接，只有整段选区都有这个样式时才亮。只选中已经加粗的那几个字会亮。选区里还有没加粗的字时不亮。没选中字时不亮。

做（第七十一轮）：

78. 在 Callout 里按 Esc，先选中光标所在的那一段，再按一次才选中整个 Callout。第三次没有更外层的块，不再改选区。列表里按 Esc 只选中这一条，不会把整份列表选进去。折叠块的标题行本身不是单独一块，按 Esc 直接选中折叠块；里面的正文先选那一段，再按一次才选中折叠块。`Cmd+A` 也是先选当前这段字，再选包着它的容器，最后才选中整篇。顶层普通段落仍是第一次选这段字，第二次选中整篇。

做（第七十二轮）：

79. 斜杠菜单开着时，回车或 Tab 选中当前这一项，不会把 `/代码` 拆成下一行。上下键只移动高亮，不移动光标。没有匹配的块时，回车和 Tab 留在原地，不插入空行。Esc 仍清掉斜杠字。引用文档的菜单同样用回车或 Tab 选中。菜单关着时，回车仍是换行。

做（第七十三轮）：

80. 块菜单开着时，上下键在菜单项之间移动高亮，到头以后绕回第一项或最后一项。回车执行当前高亮的那一项，例如「转换为」会打开下一层，再回车才真正转换。Esc 关掉菜单。这些键不会改文档里的选区。菜单关着时，方向键仍在正文里移动。打字仍会替换已经选中的整块。

做（第七十四轮）：

81. 加号和握把跟着光标所在的块，不用先把鼠标移上去。鼠标停在另一块上时，握把让到那一块；鼠标离开后回到光标那一块。光标自己移动时，握把跟着走，不再停在上次鼠标经过的地方。跟着光标时握把稍淡，鼠标放上去就恢复清楚。

做（第七十五轮）：

82. 一整段都选中时，再按 Shift+↓ 会把下一块一起选上，Shift+↑ 则带上上一块。到头就停住。只选中半句，或只是一个光标，方向键仍按文字选，不会突然变成整块。已经选中几块时，Shift 加方向键继续加块；不按 Shift 则只移到旁边那一块。

做（第七十六轮）：

83. 选中连续几块之后，退格或删除会把这几块一起去掉，旁边没选中的还在。只剩这一组时，删完留下一个空段落。`Cmd+D` 把这一组作为一份复制到后面，不是只复制最后一块。只选中一块时，退格和复制仍只动那一块。

做（第七十七轮）：

84. 选中连续几块再按加粗，这几块里的字一起变成加粗，没选中的旁边那块不动。只有一部分已经是加粗时，再按一次会铺满。整组都是加粗时，再按一次才去掉。只选中一块时，仍按原来的方式加粗。斜体、下划线、删除线和行内代码也一样。

做（第七十八轮）：

85. 按住 Shift 再粘贴，只把文字贴进来。`# 标题` 还是这几个字，不会变成标题。网址不会变成书签，网页上的加粗和颜色也不会带过来。光标正停在加粗里时，贴进来的第一行也是加粗；后面另起的行是普通段落，光标后面原来的字留在最后一行，原来的加粗还在。代码块里仍是代码，换行也留在代码里。普通粘贴不变。

做（第七十九轮）：

86. 选中连续几块再按标题或列表快捷键，这几块一起变。两段变成二级标题后，再按一次同一级，变回段落。变成无序列表时收成一份列表，旁边没选中的段还是段落。`Cmd+\` 清掉这一组上的加粗和链接，没选中的那块格式还在。只选中一块时，仍只改那一块。

做（第八十轮）：

87. 链接、评论、块备注和写作菜单开着时，按 Esc 关掉，不保存刚才改的字，光标回到正文。菜单关着时，Esc 仍是选中当前块。查找条自己的 Esc 不受影响。

做（第八十一轮）：

88. 选中一条待办再按空格，或按 `Cmd+Enter`，只切换这一条的勾选，文字还在。选中好几条待办再按空格，有任何一条没勾就全部勾上；已经全勾了再按，全部取消。旁边没选中的待办不动。选区里夹着普通段落时，空格不拿来勾选。光标停在待办文字里时，空格仍是输入空格，`Cmd+Enter` 仍只翻转这一条。

做（第八十二轮）：

89. 块菜单开着时，右方向键在「转换为」或「颜色」上会打开那一层，和回车一样。在普通项上，右方向键留在菜单里，不改文档。左方向键在下一层里回到上一层；在第一层留在菜单里。这两项后面有一个小箭头。

做（第八十三轮）：

90. 在文档标题里按回车，光标落到正文第一段的开头。正文第一块是图片时，落到图片后面的文字里。正在用输入法组字时，回车不抢走。标题本身不会换行。

做（第八十四轮）：

91. 光标在全文最后、而且已经在这一段的末尾时，按 ↓ 会在文档下面多出一个空段落，光标落进去。最后一块是图片并且整块选中时也一样。光标还在句子中间，或者下面还有别的块，↓ 不新开段落。Callout 里的最后一段按 ↓，空段落开在 Callout 外面。

做（第八十五轮）：

92. 光标在全文最前、而且已经在这一段的开头时，按 ↑ 会在文档上面多出一个空段落，光标落进去。第一块是图片并且整块选中时也一样。光标还在句子中间，或者上面还有别的块，↑ 不新开段落。Callout 里的第一段按 ↑，空段落开在 Callout 外面。

做（第八十六轮）：

93. 光标在一段的末尾按 → 或 ↓，下一块如果是图片或横线，会先选中那一块，而不是跳过去。光标在一段的开头按 ← 或 ↑，上一块是横线或图片时也先选中它。光标还在句子中间，或者旁边是普通段落，方向键仍在文字里走。

做（第八十七轮）：

94. 点待办前面的勾选框，只翻转这一条，文字还在。已经勾上的再点一次会取消。点到段落上不会误当成待办。勾选框按下时不再交给浏览器自己切换，否则选区会跳走、勾选也不会写进文档。

做（第八十八轮）：

95. 点正文最后一块下面的空白，光标落到那里的一个空段落里。最后一块已经是空段落时，只把光标移进去，不再多开一段。最后一块是图片或 Callout 时，空段落开在它外面。点在文字旁边或文字中间时，仍按原来的方式放光标。

做（第八十九轮）：

96. 鼠标移到斜杠菜单、引用文档菜单或块菜单的某一项上，高亮跟着这一项走。接着按回车，执行的是鼠标指着的那一项，不是刚才方向键停过的那一项。鼠标还停在同一项上时，菜单不重新画。移到菜单外面的空白，高亮不动。

做（第九十轮）：

97. 在段落开头打 `[] `、`[ ] ` 或 `[x] `，这一行变成待办。`[x] ` 和 `[X] ` 是勾上的，另外两种不勾。记号后面已经有的字留在待办里，加粗也留着。光标落在这些字的开头。句子中间的同样几个字不变。列表项里不拆开原列表。Callout 里的待办留在 Callout 里面。

做（第九十一轮）：

98. 在段落开头打 `> `，这一行变成引用。记号后面已经有的字留在引用里，加粗也留着，光标落在这些字的开头。整行只有 `> ` 时，引用里是空段落。句子中间的 `> ` 不变。列表项里不拆开原列表。Callout 里的引用留在 Callout 里面。

做（第九十二轮）：

99. 在正文里按 `Cmd+/` 或 `Ctrl+/`，打开光标所在这一块的块菜单。再按一次，菜单关掉。斜杠菜单或引用文档菜单开着时，这个键不抢。普通 `/` 仍是打字。按住 Shift 或 Alt 时也不打开。光标在 Callout 里的一段上时，菜单对着这一段，不是整个 Callout。在普通段落、代码块或列表外面按 Tab 或 Shift+Tab，焦点留在编辑器里，不会跳到页面上别的控件。表格、代码块和列表里的 Tab 仍按原来的方式换格、缩进或插入空格。

做（第九十三轮）：

100. 用鼠标从一块的开头划到后面几块的末尾，这几块按整块选中，和 Shift+方向键选中的是同一批。接着删除、复制或加粗，动的是这几块。只划过半句，或只盖住单独一块，仍是文字选区。列表里划过相邻两条的全部文字，选中的是这两条。Callout 里划过里面的几段，选中的是这几段，不是整个 Callout。

做（第九十四轮）：

101. 在段落开头打 ` ``` ` 或 ` ```ts `，这一行变成代码块。`ts` 会收成 TypeScript，不认识的语言名留空。记号后面已经有的字留在代码里，光标落在这些字的开头。整行只有围栏时，代码块是空的。句子中间的围栏不变。列表项里不拆开原列表。Callout 里的代码块留在 Callout 里面。

做（第九十五轮）：

102. 斜杠菜单或引用文档菜单开着时，把光标点到这段记号外面，菜单关掉，开头的 `/代码` 或 `@标题` 也从正文里去掉。光标还在这段记号里面时不删。正在打字、按空格或按 Esc 清斜杠时，不重复删一次。旁边的段落不动。

做（第九十六轮）：

103. 页面滚动时，格式条、链接预览、评论预览、斜杠菜单和引用文档菜单跟着光标走，不再停在屏幕上的旧位置。菜单自己内部滚动时，位置不动。块菜单在页面滚动时关掉，握把跟着当前块。窗口变大小时，格式条也重新靠到选区上。

做（第九十七轮）：

104. 选中连续几块再按回车，这几块留在原地，空段落开在最后一块下面，光标进去。只选中一块时，仍按原来的方式在那一块下面开一段。Callout 里选中里面的几段再按回车，空段落开在 Callout 里面，外面的段落不动。

做（第九十八轮）：

105. 选中连续几块再按 Shift+回车，不删这几块，在最后一块的末尾换一行，光标落在这一行。最后一块是代码时，换行留在代码里，语言名不动。只选中一块时，仍按原来的方式在光标处换行。

做（第九十九轮）：

106. 选中连续几块再粘贴，这几块换成贴进来的内容。`# 标题` 加一行正文会变成标题和段落，后面没选中的块还在。按住 Shift 粘贴时，`# 标题` 仍是普通文字。什么都没贴时不改文档。选区跨出 Callout 时不替换，避免把容器拆坏。只选中一块时，仍按原来的方式贴。

做（第一百轮）：

107. 在段落开头打 `---`、`***` 或 `___`，这一行变成横线，记号后面已经有的字留在横线下面的段落里，加粗也留着，光标落在这些字的开头。整行只有记号时，横线下面仍是空段落。句子中间的记号不变。列表项里不拆开原列表。Callout 里的横线留在 Callout 里面，外面的段落不动。

做（第一百零一轮）：

108. 三击一段文字，选中这一整块，中间的换行也算在里面。三击第二行，选区仍是整块，不是只有这一行。三击图片，选中这张图片。三击图片后面的字，选中的是这段字，不是图片。

做（第一百零二轮）：

109. 拖握把时按住 Alt（macOS 上是 Option），松手后在落点留下一份复制，原来的块还在原地。拖「甲」到「乙」后面，顺序变成甲、乙、甲、丙。一起拖「甲」和「乙」到文末，文末多出甲、乙，开头的甲、乙还在。不按 Alt 仍是搬走。落点对不上时不复制。拖的过程中按住 Alt，落点预览也是复制，原来的块还留在预览里；松开 Alt 预览又变回搬走。复制时拖影左上角有一个加号。

做（第一百零三轮）：

110. 已经选中一块时，按住 Shift 再点另一块的文字，选区扩到那一块，中间的块一起选上。点在自己这一块上，选区收成这一块。点在 Callout 里面时，选中的是整个 Callout，不是里面单独一段。已经选中 Callout 里的一段，再点里面另一段，扩的是这两段，外面的段落不动。点到另一层、或点在块与块之间对不上的位置，选区留在原地。光标还在字里面、没有整块选中时，Shift+点击仍是拉文字选区。

做（第一百零四轮）：

111. 光标在一块里按 Tab，这一块收进上一块。上一块是普通段落时，它变成打开的折叠块，标题是原来的段落，这一块进到里面，加粗留着。上一块已经是折叠块时，这一块接在里面，关着的折叠块会打开。上一块是 Callout 或引用时，这一块进到里面，颜色和图标不动。一起选中连续两块再按 Tab，两块都进去。第一块、标题下面、折叠块自己的标题上按 Tab，文档不动。列表里的 Tab 仍是缩进列表项。按 Shift+Tab，把这一块从折叠块、Callout 或引用里提出来，放到容器后面。折叠块只剩标题时，再按一次 Shift+Tab，标题变回普通段落。标题下面还有内容时，Shift+Tab 不把标题抽走。

做（第一百零五轮）：

112. 光标在折叠块标题末尾按回车，标题留着，里面多一个空段落，光标进去。折叠块关着时会先打开，新行能看见。光标在标题中间按回车，前半留在标题，后半进到里面，加粗留在后半，关着的同样会打开。光标在标题开头、标题里还有字时按回车，折叠块上面多一个空段落，标题、里面的内容和开关都不动。标题是空的、里面没有别的块时，回车仍退出成空段落。光标在折叠块里面的正文按回车，不走这条。

不做（至今）：`@` 人和空间、接真模型、发布、提交。

## 使用场景

1. 选中一段字按 `Cmd+K`，填 `molis.ai/docs`，回车 → 变成带下划线的链接；再点它在新标签打开；重新 `Cmd+K` 可改或「移除链接」。
2. 复制一个 URL，选中「文档」两个字粘贴 → 「文档」变成指向该 URL 的链接，而不是被替换成一串地址。
3. 划过一行点手柄 → 菜单里选「转换为 → 清单」，三行无序列表变成三条待办，加粗等行内样式保留。
4. 手柄菜单里「复制」在下面插一份同样的块；「删除」删掉这一块，文档只剩一块时退化成空段落而不是非法文档。
5. 文末是月历卡时按 ↓，光标落到卡后面，敲字就是新段落。
6. 在 `## 标题` 行首按 Backspace → 先变成段落；再按才和上一块合并。列表项行首 Backspace → 提出为段落。
7. 选中一句话点格式条「A」→ 上排选「红」文字变红，下排选「黄」加上黄底；再点一次同一个色块取消。光标不选中时先点颜色再打字，新字就是该颜色。
8. 光标放在待办列表第二条按 Tab → 这条缩进成子任务、勾选状态不丢；Shift-Tab 退回原位。三层无序列表的 marker 依次是 `•` `◦` `▪`，有序列表是 `1.` `a.` `i.`。
9. 新建一篇空文档，不点正文就能看到「输入 / 插入块，或直接写」的灰字提示。
10. 光标在某段中间按 `Cmd+A` → 只选中这一段；再按一次 → 选中整篇。
11. 光标落在空的 `## ` 行 → 提示「标题 2」；落在空的待办项 → 提示「待办事项」；落在 Callout 的空行 → 提示「想强调的话」。表格空单元格不出提示。
12. 手柄菜单选「颜色 → 黄」，整块（含列表所有项）铺上黄底；再进去选「默认」还原。整块是代码块时不受影响。
13. 系统开了「减弱动态效果」时，浮层不再上浮淡入、块 hover 不再过渡、gapcursor 不闪。
14. 敲一个代码块，上方的下拉里选 TypeScript → 关键字、字符串、数字、注释立刻分色；改成 Python 立刻重新上色。悬停时右上出现复制按钮，点一下变绿表示已复制。存成 `sh` 的旧文档打开后下拉显示 Shell 并按 bash 高亮；存成没注册的语言名时退回纯文本，不报错。
15. 点 Callout 左侧的图标 → 弹出「图标」十二宫格和「颜色」九色板；换图标不动颜色，换颜色不把图标钉死（没选过图标时仍跟着颜色走默认）。老文档里的 info / warn / success / plain 四种 Callout 打开后和改版前长得一样。
16. 拖一段文字到 Callout 最后一行的下半，再往右偏大约一个缩进 → 蓝线右移，松手后这段进了 Callout，色调不变。拖到无序列表最后一项的右侧 → 变成它的子项，加粗还在。再把子项往左拖出列表 → 变回普通段落，列表里没了空壳。代码块对齐列表项时不会被硬塞成一项，再往右一档才会进到该项里面。待办项拖到列表开头，勾选状态不丢。
17. 点第一段的握把，再按住 Shift 点第三段的文字（或选中后按 Shift+↓）→ 这几行一起铺上选中底色。光标还在字里时，Shift+点击仍是拉文字。按删除，它们一起消失。按 `Cmd+D`，这几行作为一组出现在选区后面，而不是每行后面各插一份。拖其中一行，整组跟着走。选区从 Callout 盖到它里面的段落时，删的是整个 Callout。
18. 光标在第二段按 `Cmd+Shift+↑` → 它和第一段对调；再按 `Cmd+Shift+↓` 两次，它落到文末。已经是第一段时再往上按，文档不变。待办列表里把下面那项上移，勾选状态留在各自的文字上。选中连续两段再下移，两段一起挪到下面那块的后面，选区还圈着这两段。
19. 在空行敲 `---` 再打最后一个 `-` → 这一行变成一条横线，光标落到下面的空段落。敲 ```ts → 变成 TypeScript 代码块，光标在块里面。在列表项里敲 `---`，字符还在，不会把列表拆坏。代码块写到最后一行按 ↓，光标走到下一块；已经是文末时下面多出一个空段落。光标在代码中间按 ↓，还在这一行里。
20. 在空行粘贴一段带标题、列表、`---` 和 ```ts 的 Markdown → 各自变成对应的块；`**乙**` 是加粗，`[文档](https://molis.ai/docs)` 是链接，`javascript:` 链接留成原文。粘贴 `hello` 换行 `world` 这种没有标记的文字，仍按原来的方式拆成段落。光标停在「写到一半」里粘贴标题，标题不会把这句换掉。
21. 在表格右下角按 Tab → 下面多一行空行，光标在新行第一格。表头那一列右边「加一列」，新出来的仍是表头；正文行右边加出来的是普通格子。删掉正文行后只剩表头；再删这一行，表格变成空段落。
22. 在空行粘贴 `| 甲 | 乙 |`、分隔行、`| 1 | **2** |` 再加一句「说明」→ 一张两列表，表头是甲乙，正文第二格是加粗的 2，说明仍是段落。`| 只有一格 |` 还是普通文字。
23. 在代码块里 `a|b` 按 Tab → 变成 `a  b`，语言名不变。再把光标放回两个空格后面按 Shift-Tab → 回到 `ab`。段落里按 Tab 仍是缩进列表，不会塞空格。点折叠块的箭头，标题和内文都还在，只是收起或展开。
24. 在列表第二项里敲 `/代码` 再选代码 → 前后两项还是列表，中间变成代码块。在 Callout 里敲 `/标题` → 只换这一段，色和图标不动。在「写到一半 /标题」里选标题 → 前面留下「写到一半」，下面多出一个空标题。折叠块标题上这样做，里面的正文还在。代码块和表格里敲 `/码`，菜单不出现。
25. 空段落上点行首加号 → 这一行变成 `/`，菜单打开。在「甲」上点加号 → 「甲」还在，下面多出一行 `/`。列表第二项「乙」上点加号 → 甲、乙、`/`、丙。空的列表项上点加号 → 还是一项，里面是 `/`。已勾选的「做完」下面多出一条未勾选的 `/`。Callout 里的「留下」下面多一段 `/`，颜色和图标不动。代码块下面多出的是正文 `/`。两段之间的缝点一下，是在缝里插入 `/`，不会把旁边的空行填掉。
26. 握住列表第二项选「颜色 → 黄」→ 只有「乙」有黄底，「甲」没有，乙上的加粗还在。握住 Callout 里的第二段上色，第一段仍是普通字，Callout 的颜色和图标不动。同时选中第一段和第三段上色，中间那段不动。代码块选颜色，代码原样。
27. 选中连续三段「甲」「乙」「丙」，转换为无序列表 → 一张列表三项，甲上的加粗还在。转换为标题 2 → 三个二级标题。只选甲和乙转成代码 → 代码块里是「甲」换行「乙」，丙还是段落。列表里选乙和丙转成标题 1 → 甲留在列表里，乙和丙变成标题。Callout 里两段转成列表，颜色和图标不动。从 Callout 里面选到外面的段落，或者选中段落加表格，文档不变。
28. 二级标题「甲乙」光标在中间按回车 → 标题留下「甲」，「乙」变成正文，乙上的加粗还在，光标在乙里。光标在末尾按回车 → 标题不动，下面是空段落。光标在开头按回车 → 上面多一个空段落，标题还是「甲乙」。划掉「乙」再回车 → 标题留下「甲」，下面是空段落。已勾选的「甲乙」中间回车 → 「甲」仍勾选，「乙」不勾选。未勾选的拆开后两条都不勾选。
29. 文档里有两个都叫「甲」的标题，目录点第二条 → 光标在后面那个二级标题里。点一条藏在折叠块里的标题 → 折叠块打开，光标在那条标题上，标题文字还在。套了两层折叠块时两层都打开。Callout 里的标题点进去，颜色和图标不动。
30. 光标靠近窗口底部时打开斜杠菜单，菜单翻到光标上方。光标在中间时，菜单仍在下方。菜单靠近右边缘时，左边被推进来，不会伸出窗口。块菜单在握把右边；右边放不下就到握把左边。格式条在选区贴着窗口顶时，改到选区下面。键盘把高亮项移出菜单可见范围时，只滚动菜单，不滚动整页。
31. 代码块里写完 `const a` 再回车出一行空行，再按一次回车 → 空行消失，光标在代码下面的新段落里，语言名还在，后面的「后」还在。空代码块按回车变成空段落。光标停在 `const a` 末尾或中间时，这条命令不接手。已勾选的「甲」旁边，未勾选的「乙」上按 `Mod-Enter` → 乙变成勾选，甲不动；再按一次乙回到未勾选。正文里按这个键没有反应。
32. 空行粘贴 `https://www.molis.ai/docs` → 一张书签，标题是 molis.ai，地址仍是带 www 的原链接。选中「文档」粘贴同一地址 → 字不变，链到该地址。在「见」后面粘贴 → 正文变成「见」加这段网址，只有网址带链接。空的列表项里粘贴，仍是列表项里的链接。Callout 空行变成书签，橙色和 star 还在。代码块、`javascript:`、「不是网址」都不变。存进文档的 `javascript:` 书签渲染出来不是链接。
33. 甲和丙之间点提示线，不打字 → 文档还是甲、丙。打出「乙」→ 中间多一段乙，光标在乙里。粘贴一个网址 → 中间是书签，甲和丙还在。空白和只有空格都不插入。格式条把「甲」变成无序列表，再点一次回到段落。列表里的「乙」转成有序列表时，甲和丙还是无序列表。
34. 「甲乙甲」和「甲乙」里查找「甲」有三处，查找「甲乙」有两处。`AbC` 用 `abc` 能找到，取出来仍是 `AbC`。甲和乙中间有换行时，「甲乙」找不到。光标在第一处再往后，到第二处；在最后一处再往后，回到第一处。`Shift+Enter` 把「甲乙」拆成同一段里的两行。代码块里则变成 `a` 换行 `b`。
35. 空行粘贴 `https://molis.ai/cover.png` → 图片，替代文字是 `cover.png`。粘贴 `https://molis.ai/docs` 仍是书签。`http://molis.ai/cover.png` 也是书签，不会嵌进页面。选中「文档」再粘贴图片地址，字不变。Callout 空行粘贴 `a.webp`，颜色和图标不动。提示线提交 `封面.png` 的地址，甲和丙还在，替代文字是「封面.png」。`javascript:` 不会变成 `img`。
36. 空段落放入一张 png 数据图 → 整段换成图片，替代文字是「图片」。光标在「见」里粘贴，字还在，图在下一段，替代文字可以用「截图」。Callout 空行同样能放，颜色和图标不动。提示线提交这张图，甲和丙还在。svg 数据、超长数据和 `javascript:` 都不会变成 `img`。
37. 空行用斜杠换成两栏，光标在第一栏，提示是「这一栏」。再加一栏变成三栏。两栏里分别是「甲」「乙」，取消分栏后变成上下两段。不是分栏的位置不能加栏。
38. 左栏是「甲」「乙」，右栏是「丙丁」，上面是「上」，下面是「下」。光标在「丙丁」开头按左，落到「乙」末尾；在「乙」末尾按右，落到「丙丁」开头。在「丙丁」开头按上，落到「上」末尾，不进左栏。在「乙」末尾按下，落到「下」开头。光标在「丙丁」两个字中间、或在「乙」开头、「甲」末尾，这条命令不接手，方向键仍在栏里走。分栏是文档唯一内容时，在「甲」开头按上或左，光标不动。
39. 左右两栏分别是「甲」和「乙」，下面是加粗的「丙」。把「丙」拖到「甲」前面，左栏变成「丙」「甲」，加粗还在，右栏仍是「乙」。把「乙」拖到文末，右栏留下空行，「丙」和「乙」在分栏下面。整组分栏拖到「乙」那一行的位置，文档不变。
40. 「甲」「乙」「丙」三行，乙是加粗。把乙往右拖到甲旁边，变成左栏甲、右栏乙，加粗还在，丙仍在下面。把甲往右拖到乙旁边，变成左栏乙、右栏甲。同一位置平拖，文档不变。
41. 左右已经是「甲」「乙」，下面是加粗的「丙」。把丙往右拖过乙，变成三栏甲、乙、丙。拖到和乙对齐的高度，丙掉进右栏，还是两栏。往右拖过甲，顺序变成甲、丙、乙。把乙自己往右拖，右栏留下空行，乙排到分栏和丙之间。

## 方案与关键决策

- `href` 归一化放 `plugins/native/pages/src/link.ts` 的 `safePagesHref`：只放行 `http:` / `https:` / `mailto:` 和 `#`/`/` 开头的站内地址，裸域名补 `https://`，其余（含 `javascript:`、`data:`）归零。schema 的 `toDOM` 再走一遍，坏 href 降级成 `<span>`，保证导出 HTML 也不带可执行链接。这是外部输入进可点击 DOM 的信任边界，必须在两端都过。
- 块型转换放 `plugins/native/pages/src/convert.ts` 的 `convertedBlocks(id, node)`，纯函数、不碰 DOM，Node 侧可直接测。按「行」语义：列表每项一行、Callout/Toggle 每个子文本块一行，转段落/标题时一行一块，转列表/Callout/Toggle 时合成一块。代码块用 `textContent`（schema 里 `marks: ""`，不能带行内样式）。
- 转换为做成同一个 `pages-block-menu` 的第二层（顶部「返回」），不新开子菜单浮层，避免再写一套定位。
- `gapCursor()` 放在 `keymap(baseKeymap)` 之后（和 `prosemirror-example-setup` 一致），gapcursor 的 CSS 写进 `PAGES_STYLES`，不引第三方 css 文件（内核是 esbuild IIFE，不走 css loader）。`dropCursor` 传 `color: false`，颜色交给 `.pages-native-drop` 用 `--plugin-pages`。
- 行首 Backspace 用 `chainCommands(unwrapAtStart, baseKeymap.Backspace)`：先尝试脱层，脱不动再走原行为，不改 baseKeymap 语义。
- Esc 选块的 keymap 挂在 plugins 末尾，让 Slash / mention 先吃掉 Esc。
- 颜色不存 CSS 值，只存色名，白名单在 `plugins/native/pages/src/tone.ts` 的 `safePagesTone`（9 个 hue，对齐 `MW_HUES`）。样式由 `PAGES_STYLES` 按色名生成 `var(--hue-x)` / `var(--hue-x-soft)`，深浅色主题自动跟随，文档里写任何别的值在 `toDOM` 一侧降级成普通 `span`——和 `href` 同样的双端约束，理由也一样：文档正文是外部输入，不能让它决定 DOM 上的样式。
- Tab 嵌套用 `chainCommands(sinkListItem(list_item), sinkListItem(task_item))`：原来只挂了 `list_item`，待办列表按 Tab 无反应。`unwrapAtStart` 早就两种都处理了，这里只是把缺的一半补齐。
- `Mod-a` 的第一段判断是「选区是否已经盖满当前 textblock」，盖满或空块直接 `selectAll`，避免在空段落上按一次没反应。
- 占位文案由 `plugins/native/pages/src/placeholder.ts` 的 `blockPlaceholder($pos)` 纯函数决定，只看块型和它的直接容器，不碰 DOM，Node 侧可直接测；`chromePlugin` 只负责把它挂成 `Decoration.node`。整篇空白时不看焦点也挂，其余情况只挂在光标所在的空块上——和 Notion 一致，不然每个空行都挂提示会很吵。
- 块级上色复用选区的 `font_color` / `highlight`，不引入块级属性：`setBlockTone` 对整块范围先 `removeMark` 再 `addMark`，代码块因为 schema 里 `marks: ""` 天然收不到，不需要额外判断。
- 代码高亮拆成两个模块，因为它们的加载代价差一个量级：`code-language.ts` 只有白名单和别名表，零依赖，给 `schema.ts` 和 Node 侧用；`code-highlight.ts` 才 import `lowlight` + 13 份 highlight.js 语法，只有编辑器 bundle 会碰它。若把两者合一，宿主进程 `import` 插件包就会连带加载整个 highlight.js。测试通过新增的 `./code-highlight` 导出路径直接取，不用把它拉进主入口。
- `highlightRanges` 返回的是相对代码文本的 UTF-16 偏移，不是 DOM 片段：这样既能直接转成 `Decoration.inline`，也能在 Node 里断言「切出来的子串是不是这个 token」。中文注释在前是最容易串位的场景，已单独断言。
- 高亮只在 `tr.docChanged` 时重算并缓存在插件 state 里，不在每次 `decorations` 调用时重跑 lowlight。
- 语言条做成代码块上方的真实一行（flex column），不是浮在代码上的 overlay：不遮第一行内容，不悬停也能看到当前语言。复制按钮才是悬停出现。
- Callout 用设计系统 sprite 里的图标，不引 emoji：整个 GoalBoard 都在用这套 sprite，掺 emoji 会是视觉语言上的断层。颜色也复用文字色那九个 hue，而不是给 Callout 另造一套语义色名——产品里只该有一套颜色概念。
- 兼容靠一层折叠而不是数据迁移：`safePagesCalloutTone` 把 info/warn/success/plain 映射到 cyan/orange/green/gray，`calloutIconFor` 在没选过图标时回落到该色调历来隐含的那个图标。结果是旧文档和十份模板一个字不用改，渲染完全一致；`icon` 留空表示「跟着颜色走」，只有用户主动选过才写值。
- CSS 从 `.pages-callout--{tone}` 四条手写规则改成按 `[data-pages-callout="{hue}"]` 生成九条，和文字色共用同一份 hue 生成逻辑。
- 拖拽层级不改 schema。能装子块的只有 Callout、Toggle、列表项和待办项；普通段落右边没有下一档，落点线不往右跳。列表本身不是一行，握把落在光标下的那一项上，所以拖的是一项而不是整张列表。提出文档顶层时，列表项拆回它的正文（段落），不留一个只有一项的新列表；拖进 Callout 时仍包成列表，圆点还在。最后一项被拖走或删掉时，空列表一起去掉；Callout 的最后一块被拖走时留下一个空段落，避免 `block+` 变空。
- 落点先算「缝」（垂直方向上，行中线以上算插到这行前），再按指针相对上一行左缘每 24px 一档算缩进，档位超出容器能力就往回退，直到有一档真的改得了文档。原地（同一父级、同一位置或紧挨自己后面）返回 `null`，文档不动。
- 嵌套行的块菜单只有复制和删除。转换为、上色、备注、上下移仍只对顶层块，因为那些命令按顶层下标工作；一项一转换留到后面。
- 多块选择不另造选区类型，记在 hover 插件 state 的 `anchor` / `head`（两个行位置）上，用 `is-block-selected` 画出来。父块和它的子块同时落在选区里时，`spanRoots` 只留父块，子块跟着走。复制是整组插到最后一行后面；删除从后往前摘，这样前面的位置不会被后面的删除带偏。一组的拖拽复用单行的落点计算，只是一次搬走所有根。多块时菜单只留复制、删除和上下移。
- 上移 / 下移不再用顶层下标。`nudgeSpan` 在拖拽行里找同父级、同缩进的邻居，上移插到它前面，下移插到它（含子行）后面。没有邻居就返回 `null`，不把行提出去——提出去已经有往左拖。挪完用节点引用找回新位置，选区贴在同一批行上，所以可以连续按。
- Markdown 快捷输入只认「这一段刚好是标记」：`markdownBlock` 先问父容器 `canReplace`，列表项要求第一个孩子是段落，塞不进分隔线或代码块就返回 `null`，字符留在原地。语言名复用 `safePagesLanguage`，不另造一份别名表。代码块里的方向键只在光标贴着块的头或尾时才走出，中间的 ↓ 仍是块内移动。
- 粘贴只在空段落上接手，而且这段文字里得真有标题、列表、分隔线或代码围栏。普通换行仍走 ProseMirror 原来的按行拆段。父容器 `canReplace` 失败就放弃，避免把列表项拆成非法结构。行内只认 `**`、`*`、`~~`、反引号和安全链接；`javascript:` 链接留成原文。下划线不拿来做斜体，免得 `snake_case` 被拆开。
- 表格不加按钮浮在格子上。右下角按 Tab 才长出一行，和 Notion 一样；菜单里的加行、加列给握把一条显式路径。新行一律是正文格，新列跟着当前格：表头旁边加出来的还是表头。删到只剩一行或一列时整张表换成空段落，避免留下 `table_row+` 不成立的空表。
- `highlight.js` 必须写进 `dependencies`——它虽然是 lowlight 的传递依赖，esbuild 能穿透 pnpm 的软链解析到，但 Node 在 strict node_modules 下解析 `dist/code-highlight.js` 会直接 `ERR_MODULE_NOT_FOUND`。这个差异让 build 绿而测试红，实际踩到过。
- 代码块的 Tab 排在表格换格和列表缩进前面：`insertCodeIndent` 只认 `spec.code` 且选区为空，其它情况返回 false，后面的列表缩进照常接手。Shift-Tab 只删光标前连续空格，最多两个，字母和行首不动。折叠开关用 `setToggleOpen` 改 `open`，不重建子块；箭头的 `mousedown` 只保住选区，真正翻转走 `click`，键盘的 Enter/Space 也能点到。
- 斜杠是否打开由 `slashSession` 看光标前的 `/查询`，不再要求这一段在文档最外层、也不再要求整段都以 `/` 开头。整行就是这个标记时走 `replaceEnclosingRow`；前面还有字，或这一行还包着别的正文（折叠块的内文）时，先删掉 `/查询` 和它前面的那一个空格，再把新块插到这一行后面。列表装不下就切开，当前项留在前半。代码块和表格格子直接返回 null，避免把整张表换成一块。
- 加号和块间缝都走 `insertSlashBelow`。`auto` 只在这一行没有任何文字、而且能放进一个正文光标时，把 `/` 写进当前行；否则在后面插同级的新行。列表的同级是列表项，待办的同级是未勾选的待办项，这样不会把一段正文硬塞进只装列表项的父级。缝使用 `after`，所以它总是往下插，空行留在原地。光标落在 `/` 后面，下一帧 `slashSession` 就能打开菜单。
- 块菜单的颜色改走 `setRowsTone`，按握住的行或当前多选的根上色，不再用顶层下标把整块列表铺满。色名仍过 `safePagesTone`，空字符串和色板外的名字都是去掉这一层标记。代码块的 schema 不收 mark，上色后文档不变。嵌套行和多选菜单都有「颜色」，和顶层块同一块色板。
- 多选转换走 `turnSpanInto`。只处理同一父级里首尾相接的行；父级装得下就原地替换，列表装不下标题这类块时把列表切开，选中项前面和后面的项各自留成列表。几行合成列表、引用、Callout、代码时是一块，合成标题时仍是一行一块。代码块把各行文字用换行接上。组里有表格，或选区跨了两个父级，返回 null，避免把中间的块吃掉。多选菜单里的「转换为」和单行用同一份目标列表。
- 标题回车用 `splitBlockAs`：不在末尾时，拆出去的那一块指定为段落，所以中间回车不会再长出一个同级标题。开头和末尾仍交给默认拆分，分别在上面或下面得到段落。待办回车仍用 `splitListItem`，拆完若光标落在一条已勾选的新待办上，只把这一条改成未勾选，前一条的勾选不动。
- 目录跳转用 `revealHeading`，按下标而不是按标题文字，避免两个同名标题跳到同一个。沿光标的祖先把 `open: false` 的折叠块改成打开，不重建子块。目录项是按钮，鼠标按下只保住选区，真正跳转走点击，键盘也能激活。
- 浮层位置用 `placeFloating`。先试偏好的那一边，放得下就停；放不下再试对面；两边都不够就选空位更大的一边，最后再夹进 8px 边距。块菜单用 `beside`，格式条用 `above`，斜杠和弹层用 `below`。当前项滚动只改菜单的 `scrollTop`，不用会连带滚动页面的 `scrollIntoView`。
- 键盘换块直接走已经按行工作的 `turnRowInto`，所以列表里只转当前项。`Mod-Enter` 沿祖先找到待办项，只改它的 `checked`。代码块回车先看是不是停在块尾的空行：整块是空的就换成段落；前面还有代码就删掉最后一个换行，再在块后面插入段落。最后一行还有字时返回 false，交给原来的块内换行。
- 网址粘贴走 `pasteUrl`。地址先过 `safePagesHref`。空段落且父级装得下书签时，整段换成 `bookmark`，标题用 `bookmarkLabel`（站点名，去掉 `www`；邮件链用邮箱）。父级装不下，或光标在已有文字中间，就插入带 link mark 的地址。已有选区时不改字，只加链接。`toDOM` 再过一遍地址，坏地址输出 `div`，避免把 `javascript:` 放进 `href`。
- 提示线只记下「要在第几块后面写」，用 `setMeta` 打开空白，不改文档。空白里的输入法组字结束或出现非空文字时才 `commitGap`。空文本、纯空格、Esc、空回车都关掉空白。复制和剪切在有选区时调用浏览器的 `execCommand`，这样系统剪贴板能拿到编辑器里选中的字；粘贴不拦截，继续进 `handlePaste`。撤销重做仍走 history。格式条列表用 `applyList`：已经是这种列表就 `liftListItem` 提出来，否则只转当前行。
- 查找只扫文本节点，所以硬换行两边的字不会连成一个匹配。大小写先折掉再比，取出的仍是原文。下一处用 `hit.from > 光标`，没有就回到第一处。`Shift+Enter` 在普通文本块插入 `hard_break`，代码块插入换行字符，不拆成两块。
- 图片只收 `https` 且路径以 png、jpg、gif、webp、svg、avif 结尾的地址，先过 `safePagesHref` 再认扩展名。剪贴板截图另外收 `data:image/png|jpeg|gif|webp;base64,` ，长度不超过 150 万字符，这样一张普通截图能进文档，svg 和超大图进不去。`toDOM` 再验一次，坏地址输出 `div`。空段落被图片换掉；段落里已有字时，图插在这一行后面。提示线提交同一条校验。
- 分栏是 `column_list` 里至少两栏 `column`，每栏 `block+`。斜杠插入两栏空段落。`addColumn` 在列表结束前再插一栏。`unwrapColumns` 按栏从左到右把里面的块放回父级，父级装不下就返回 null。窄于 760px 时改成一列，避免两栏挤在手机上。整组分栏仍是一个拖拽行，栏里的块再各算一行，父级是那一栏。拖走栏里唯一一块时留下空段落，避免 `block+` 被掏空。分栏不能再拖进栏里。每栏左侧留 48px，栏内握把用 4px 间距贴在这段空位里，不压字。顶层块多一档右移：`columnWrap` 为真时，`wrapColumns` 把这一块和拖来的块收成两栏，左边留原块。栏内、列表项和容器不走这一档，避免把已经能嵌套的右移改成分栏。落点线在这种放下时改成竖线，贴在原块右侧。栏里的普通块再多一档 `columnSplit`：往右拖是在这一栏右边插入新栏，拖来的块若就在这一栏里则拒绝，避免掏空后再留下一个空栏。对齐栏内文字的那一档仍是插进这一栏。`collapseEmptyColumn` 接在退格最前面：这一栏只有一个空文本块时删掉该栏；只剩两栏就把分栏换成另一栏里的块。栏里还有别的块时不接手，交给原来的退格。`column` 保持 `isolating`，避免退格把两栏并成非法结构；方向键到栏边时由 `moveColumnEdge` 把光标送到邻栏或分栏外，栏内仍交给原来的方向键。

- `plugins/native/pages/tsconfig.json` 把 `src/editor-browser.ts` 排除在 tsc 之外，这个文件（约 1700 行、编辑器全部行为）从来没被类型检查过，改坏了也照样 build 成功。新增 `tsconfig.editor.json`（`noEmit`）并接进 `build` / `typecheck`，首次跑出 34 个错误，已全部修掉。
- mention 插件的 `apply` 里 `slashKey.getState(tr)` 传的是 `Transaction` 而不是 `EditorState`，取不到 slash 状态，所以 Slash 菜单开着时 mention 从来没被抑制。改成 `apply(tr, value, _old, next)` 用 `next`。
- 手柄、块菜单项、格式条原先只听 `pointerdown` / `mousedown`，键盘激活按钮（Enter/Space 只发 `click`）没有任何反应。改成 `mousedown` 只 `preventDefault` 保住选区、动作走 `click`，拖拽结束用 `suppressClick` 吃掉尾随的那次 click。
