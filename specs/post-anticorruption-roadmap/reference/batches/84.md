## 给人讲清楚

Coding 还差一批进阶功能：会话分叉、受控导出、边做边插问一句、命令行和外部工具接入、结构化结果输出、跟进 GitHub 评论、浏览器余项；再做一个可以交互的计划页，用公共的页面能力来做。记忆相关的仍按暂停。需要你做的：看会话操作、交互计划和接续的样子并定下。

## 交付与前置

- **阶段／类型**：4；产品线（Coding）；体验与效果
- **需求来源**：[Coding 下一阶段 C／D／E7][CN]、[Memory][MEM]
- **前置／待决**：35、37、65～67；C3 记忆沿原暂停
- **可并行项**：85 的现代化计划／进度设计
- **UI 要求**：先定样：会话操作、交互计划与接续
- **粒度**（批内子分支怎么分，全批仍是一个 PR；开工建议，执行时按[开发流程第 8.4 节](../development-workflow.md#batch-grouping)判断）：C／D 期余项按路径分子分支；交互计划页一个子分支。
