# 70 · 第三批插件功能

[执行目录](../../spec.md#execution-batches) · 阶段 3：持续工作与创作 · [上一批 69](69.md) · [下一批 71](71.md) · [执行规则](../execution-rules.md)

## 给人讲清楚

和第 55 批一样，这一批集中交付 **10 项分属不同主人的实用内容与插件能力**，按模块主人拆成 **5 个互不干等的独立 PR**，哪组前置就绪就独立轻量定样、独立评审合入：

1. **全平台本机规则脱敏（`PR A`：`70-1`，安全独立审）**：把散在注入清洗、判断规则、记忆过滤和密钥扣留里的规则脱敏收拢成平台共用的一份（不在置物架 `modules/shelf` 里另写）。
2. **连接器内容增强：Gmail 全文附件 + YouTube 纯文本字幕轨（`PR B`：`70-2 + 70-3`）**：Gmail 读取完整正文（剥离脚本与追踪像素）和真实受控附件（限大小、只存受控附件库并走安全纯文本提取，绝不自动运行可执行文件）；在统一 `rss` 驱动里提取 YouTube 视频自带的纯文本字幕轨（**严守延续 `112-1` 的零音视频下载原则：没有自带字幕轨的视频诚实标注「该视频未提供字幕，仅收标题与简介」，绝不下载音视频流或引回语音转写包袱**）。
3. **文稿与演示增强（`PR C`：`70-4 + 70-5 + 70-6 + 70-9`）**：PPT 支持图片与图表（消费 `43-2` 规范化 `dataset_rows` 行表）；Pages 个人模板存在个人空间并通过版本化推送或引用给各项目用；支持比较两个固定版本的逐段差异；在后端侧用轻量结构支持导出 Word（`.docx`）与指定历史固定版本（严禁把重型导出库塞进浏览器前端脚本涨首屏字节）。
4. **可追溯出处与材料更新结论重看（`PR D`：`70-7 + 70-8`）**：AI 生成内容放进 PPT、待办等落点时保留可追溯出处且标记可编辑；Cognia 底层参考材料更新后，自动列出需要重看的结论只读清单。
5. **规划方法系统技能扩充行业覆盖（`PR E`：`70-10`）**：在 `packages/system-skills/planning-methods/` 补齐更多行业规划模板，并同步更新中 / 英 / 日（`zh`/`en`/`ja`）三语词包。

需要你做的：只有涉及新增界面状态的分组（如 `PR C`、`PR D`），在该组开工前单独看一次轻量样稿确认即可，不用等 10 项攒齐。
