## 给人讲清楚

Coding 联网搜索、跑有风险的命令、下载依赖时，需要一套统一、清楚的规则。这一批做：统一的搜索和按项目、按任务的联网设置；受限命令、依赖下载、长期规则，以及可选的「低风险的由 AI 批」；已经许可过的直接复用；Hooks（Coding 在特定时刻自动运行的脚本）第一次启用或改动要你确认，能停用，重启后恢复。需要你做的：看权限、规则、审批来源和 Hooks 的样子并定下。

**65-2 的命令安全与防注入护栏**（2026-11-20，[决定 57](../decisions.md#decision-57) ③；拒绝都要在 `docs/system/SECURITY-INVARIANTS.md` 登记，每条有断言拒绝本身的测试）：

- **按解析结果判，不按字符串判。** 命令先解析成程序与参数；`;`、`&&`、`||`、管道、`$()`、反引号、重定向、行首环境变量赋值、`eval`／`sh -c`／`bash -c` 包一层的，按组合命令拆开逐段判，取最高风险的那段。解析不了的一律按高风险，要人批。
- **AI 低风险审批只批单条、普通的命令。** 组合命令、重定向、写项目输出目录以外的地方、联网、装包、改 Git 远端或凭据的，都不进 AI 审批，只能人批。
- **许可只来自人和可信上下文。** 文件内容、网页、工具输出、模型自己写的话里出现「已批准」「可以跑」之类，一律不算许可（AGENTS.md「可信身份从调用上下文来」）；AI 审批的判断输入里标明哪些是外部内容。
- **许可绑在确切的命令上。** 「只为这次放行」和跨重启的有限许可都绑程序、参数、工作目录和联网范围；改了任何一项就要重新批。长期规则按程序加参数模式匹配，不按子串匹配，也不能由模型生成后自动生效。
- **执行仍只走 SDK 命令路径**（决定 51 ①），宿主不另起进程；被拒、撤权或取消的调用不再写业务记录（AGENTS.md 硬约束）。
