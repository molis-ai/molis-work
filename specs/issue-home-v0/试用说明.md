# Issue 试用说明

状态：首期体验重构（ISSUE-35 至 ISSUE-41）的试用路径；工程、实际操作与用户验收的结论以 [规格与验收记录](spec.md) 为准。

## 三步记一条

1. 在 Molis Work 里任何地方按 **⌘⇧I**（其他系统 Ctrl+Shift+I），或点右上角「Issue」。侧栏打开，直接开始打字。
2. 写一句话：在哪里、做了什么、出了什么问题。截图用电脑自己的工具截，复制后在输入框里粘贴，或拖进来。
3. 按 **⌘↵**。输入框马上空出来，可以接着记下一条；这条以「整理中」出现在下面，几秒后变成助理起好的标题和类型，并提示「已记录 · 撤销」。

不用等它：按 Esc 或再按 ⌘⇧I 收起侧栏，继续干活。整理中右上角「Issue」带铜色点，需要你处理时是琥珀色点。

## 看和改

- 「我的 Issue」按时间倒序列出你记过的全部问题：标题、类型、时间、截图数。多了点「加载更多」。
- 点开是只读详情，写着记录于哪个页面、怎么整理的。「编辑」可以改标题、类型、描述和截图；「删除」要再确认一次。Esc 回到列表。
- 标题或类型不对，直接编辑；刚记的这条整个不要，点提示里的「撤销」，原文会放回输入框。

## 需要你处理的时候

这些情况会留在列表顶部，写着原因，点开就是带原文原图的编辑器：

| 情况 | 你可以 |
| --- | --- |
| 助理需要补充信息（比如只写了「111」） | 补一句后点「重新整理」 |
| 模型不可用 | 写个标题、选类型后「保存」；或点提示里的「模型设置」 |
| 整理超时、多次没整理好 | 「重新整理」或手动「保存」 |
| 你在能力设置里要求这类保存每次确认 | 标题类型已填好，核对后「保存」 |
| 不想要了 | 「放弃」 |

## 其他入口

- 在底部助理输入框里说「记个 issue：切换项目后侧栏草稿丢了」，助理直接记下，工作里可以撤销。
- 也可以打开整页 `/plugins/issues`，内容和侧栏一样。
- 外部客户端按 Work 的 [MCP 接入说明](../../docs/mcp.md) 接入同一 Home，在「能力 → 对外接入」逐客户端授予 `issues.list`、`issues.read`、`issues.create`、`issues.update`、`issues.delete`；编辑和删除先读取当前版本。

所有入口和项目共用同一份个人 Issue，没有项目也能用。每条最多 6 张 PNG/JPEG/WebP，大图会先压缩。没发出去的文字留在这台电脑上，换页面也在；截图只在当前页面里。

## 请帮忙验收

| 场景 | 看什么 |
| --- | --- |
| 真实模型连续记 10 条（纯文字、图文、只有截图） | 标题是否说清了在哪里出了什么问题，类型是否对 |
| 桌面版里在各个页面、编辑器、终端里按 ⌘⇧I | 是否都能唤起、再按收起 |
| 中文输入法打字时按 ⌘↵ | 候选词不被吃掉，发出的是你确认的文字 |
| 从截图工具、浏览器、Finder 粘贴或拖入 | 图片都进来，类型不对时有提示 |
