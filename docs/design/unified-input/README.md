# 统一输入框定样

状态：方案已定（用户 2026-11-04，七块都照推荐），记入 [`specs/unified-input-voice/spec.md`](../../../specs/unified-input-voice/spec.md) §10。产品没有实现；整页是模拟，不连 Home、不调模型，回复、回执和状态都是假的。

需求出处：[统一输入体验](../../../specs/unified-input-voice/spec.md) §3～§5、§8、UIV-01～17；[输入回执 §4.1](../../../specs/ai-input-receipts/spec.md)（三种送达方式）；[视觉体验](../../../specs/visual-ui-experience/spec.md) VUX-16～18；路线书[第 10 批](../../../specs/post-anticorruption-roadmap/reference/batches/10.md)的本批核账与统筹 2026-11-04 定下的五条；H4 用词。现状盘点见[输入框盘点](../../../specs/unified-input-voice/input-inventory.md)。

## 打开

```bash
python3 -m http.server 4433 --bind 127.0.0.1 --directory docs/design
```

再打开 `http://localhost:4433/unified-input/`。顶部斜纹条是原型控制：入口（助理、Coding、创作台、项目讨论）、用词（H4 三个方案）、中英文、深浅、重置。左边目录的字母是每块当前选的方案。

## 七块要定的

每块 2～3 个方案，点方案卡切换，样张跟着变。推荐项标「推荐」，用户 2026-11-04 全部选了推荐项。

| 块 | 定什么 | 已定（＝推荐） |
| --- | --- | --- |
| 1 编辑器层 | 附件放在哪（框里、底行、框外），恢复草稿时怎么说 | A：附件在框里，恢复的草稿一行说明加「清空」 |
| 2 对 AI 的送达菜单 | 补充、打断并改向、下一轮再做放在哪 | A：发送按钮带 ▾ 菜单（[输入回执 §4.1](../../../specs/ai-input-receipts/spec.md) 的原样） |
| 3 新键位的一次提示 | 助理、项目讨论、创作台改成 Enter 换行后怎么提醒 | C：按老习惯回车时才提醒，用 ⌘↵ 发过一次就不再出现 |
| 4 发给谁 | 「发给：对象」放在哪 | A：框上方一行（03 定样已用） |
| 5 状态 | 发送中、运行中、失败、待确认、被丢弃、离线写在哪 | A：框里、发送键上方一行 |
| 6 插件扩展的入口 | 插件加进来的资料、方法、关联对象放在哪 | A：左下角一个 + 菜单，按来源分组；/ 和 @ 都能用 |
| 7 H4 用词 | 工作／任务／子任务三个方案，加三条小决定 | 方案一；下一轮再做；发给；turn |

几处要注意：

- 第 2 块：统筹 11-04 第 3 条写「创作台另加明确的『打断并改向』按钮」，需求 §4 允许按钮或菜单；用户 2026-11-04 选定创作台和别处一样走 ▾ 菜单。
- 第 7 块的小决定 2 推荐「发给」，和盘点时写的「发到」不同：03 已定的连续对话样张和 PWA-130 用的是「发给」，项目讨论现在写「发到」。
- 带虚线下划线的词随 H4 变；顶上的「用词」会把整页换掉。

## 建议走一遍

1. 第 1 块：点「加两个附件」「填一段长文」，看长高到上限后在框里滚动；拖一个文件进框；点「模拟刷新或切回来」看草稿恢复；点「模拟输入法选词」（或者直接用中文输入法打字，选词时按 Enter 不会发）。
2. 第 2 块：写一句按 ⌘↵（补充，回执从「已收到」变「已用上」），再写一句按 ⌘⇧↵（排到下一轮，可撤回）；从 ▾ 选「打断并改向」再发。关掉「AI 正在运行」看平时的样子。
3. 第 3 块：点「模拟刚升级」，写一句后像以前那样按 Enter。
4. 第 4 块：切换发送对象，看标签和 × 回到助理。
5. 第 5 块：六种状态并排；切换方案看三种写法。
6. 第 6 块：点 +，或在框里打 / 或 @；Esc 只关菜单。
7. 入口切到「项目讨论」：没有送达菜单和停止，标题栏有关闭；切到「创作台」「Coding」看场景选项的位置。
8. 换 EN、深色，窗口缩到 1024 和手机宽度。

## 模拟的部分

- 回复、回执的变化、附件读取都是定时器演的；「停止」只把「AI 正在运行」关掉。
- 状态块里的按钮（重试、查看、放回输入框）只弹一条提示。
- 语音按钮只占位置，语音在第 53 批。
- 控件是原型自己的样式，不是 `mw-*` 组件；做产品前换成组件板里的控件（`data-fit`、`molisDropZone`、输入回执）再核对一遍。
- 状态存在浏览器 localStorage（键 `molis-proto.unified-input.v1`），「重置」清掉。
- 样式里的设计令牌（`base.css`）从第 03 批的 `workbench-shared-paths/styles.css` 拷来，因为那一批还没合入 main；两边合入后可以改成引用同一份。
