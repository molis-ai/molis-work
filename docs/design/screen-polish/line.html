底栏第五版 · 可点原型

25 · 底栏第五版：左边办完的，中间现在，右边接下来；输入框只问一句话

可以直接点。点两边的任何一件、点输入框上面的页签、点事项名、点 ＋、在输入框里打字回车（输入 @ 或 / 试试），或者用上面的按钮让它发生一件事。「演示一遍」按顺序走完一件事的一生。

现在静止的样子。中间是事项「发布 v2.3」和输入框；左边是这件事里办完的，右边是接下来的。
位置就是状态左边是办完的，输入框上面是现在（在办的、该你的），右边是接下来的。一件事只按「右 → 中 → 左」走，不因为着急或被点了而出现在第三个地方。
长相只有三种两翼是字：图形、名字、时间。中间是页签：图形、名字、状态词。输入框是唯一的盒子。颜色只出现在中间那一排。
动法只有两种事件沿着线走；中间这一列向上长（一行，再到对话框）。没有悬停小卡、没有留在原地的空位、没有另起的凸起。
事项和事件事项是第一个页签，后面的页签是它正在进行的事件，两翼是它的过去和将来。换事项，整条线一起换。

输入框：只问一句话

收起时只有三样＋、一句话、发送。对谁说、关于什么，看输入框上面亮着的页签，框里不再放「发给」的片。
只有一扇门要带上东西、换个对象、换种方式，都从 ＋ 进；打字时输入 @ 或 / 是同一个面板，直接到那一段。
选了才出现选过的东西是这句话上面的一排小片，一样的长相，都能点 × 拿掉。它还在办的时候再说一句，才多出一枚「怎么送达」。
一条动线说一句 → 上面长出一行回应 → 要细看就展开成对话框 → Esc 收回。反馈、报错、它的提问都在这一行，不另起别的行。
默认看得见的现在这一版
收起的输入框里4–5 个：＋、「发给」的片（带 ×）、输入、发送；有改动时再加「更多」3 个：＋、输入、发送
输入框外面上面四行（这次带上的、下一步、提醒、状态），旁边一个铃上面一行，没事时不出现
发送键发送；跑着的时候是「补充」加一个 ▾（三种送达方式），旁边另有暂停、停止发送；它在办而你没打字时是停止；打了字才多出一枚「怎么送达」
