# 项目首页：日期、快捷方式与待开放 Agent 入口

状态：2026-09-13 用户已确认本方向，随后完成生产实现与本机更新。本文保留当时的设计预览约定；最终行为与验收以 [spec.md](./spec.md) 为准。前一轮 A / B / C 已被用户否定，不再作为视觉依据。

## 已明确的结构

- 保留主体的中性灰、克制紫色与真实项目导航。取消上一轮的诗意大标题、工作活动叙事与名言控制条。
- 上方是一组日期和小月历：本地当天日期清晰可见，月历标记今天、可前后翻月。日历暂不承载没有接通的日程或任务数量。
- 名人名言自动轮换，无上一句/下一句/暂停按钮。参考 Adeptify `adeptify-next/client-app-adeptify/pc/shell/src/pages/login/BrandPanel.tsx`：5 秒轮换、约 0.5 秒淡入淡出、衬线字与稳定高度。普通悬停/聚焦可暂缓阅读，页面隐藏时不推进；减少动态效果时直接换文而不移动内容。仅借播放机制，不照搬未核实的名言归属；本预览使用 Molis Work 已有三段有出处的古典名言。
- 快捷方式位于输入框上方。首次为空，只显示“添加快捷方式”；可填写名称与地址，添加后显示小图标和名称，支持编辑、移除。预览仅保存在本次展示的本地状态；正式版建议按项目保存，新增项即时生效，取消不会修改已有项。
- 输入框采用 Google 的简洁轮廓与 Claude 的单行横向布局，默认靠下。整个输入与发送按钮原生 disabled，明确“Agent 尚未开放”；不接收输入、不保存假草稿、不模拟回复。待自研 Agent Harness 接入后再启用。

## 体验与边界

宽屏保留既有左侧项目导航，上方日期/名言与右侧小月历形成一组；下方快捷方式与输入形成一组，中间留出思考空间。窄屏收起侧栏、日期和月历纵向排列，输入完整可见。首页没有数据卡片、装饰性大口号或虚构的日程。

设计预览提供两项轻量比较：输入区靠下 / 居中，初始空快捷方式 / 示例快捷方式。日历和快捷方式可以本地操作，页面导航仅作真实产品结构的视觉上下文；不在设计稿内连接真实 Molis Work 数据。

设计预览本身为完成等级 2；后续生产实现达到等级 3，快捷方式已按项目持久化在当前浏览器或桌面端的 localStorage。生产沿用 Workbench 外观偏好与项目路由，只接受无凭据的有效 http/https 地址，名称作为普通文本渲染；Agent 运行、超时、重启和结果接管仍属于后续 Harness 接入范围。
