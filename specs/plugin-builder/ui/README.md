# 插件 Builder 高保真交互演示 · V3

用户已批准 [视觉基准图](design/approved-comp.png)：“可以，这个路子对了，按这个出高保真”。V3 将这张图落实为可操作的浏览器页面：左侧保留需求、设计依据、三张方案小样和共享主线，右侧始终展示当前方案的实际插件预览。视觉约束见 [视觉基准](design/视觉基准.md)。

当前场景为「灵感库」。模型解析、Jev 选择和 Agent 调度是 Mock；录入校验、本地保存、搜索筛选和 CSV 导出由实际浏览器代码执行。独立使用页仍是浏览器本地演示，尚未接入 Molis Work 正式插件运行时。生成图片仅作为示例封面，页面文字与控件均由 DOM 呈现。

入口：[插件 Builder](http://127.0.0.1:4199/)。[独立使用页](http://127.0.0.1:4199/plugin/materials) 需先在工作台保存独立版本。


## 如何体验

1. 没有 V3 草稿时，首次打开停在第 8 步，呈现已批准图对应的构建现场；已有草稿则恢复。点击「继续构建」推进，或「从空画布重播构建」从空开始播放 13 步，完整过程约 39 秒；也可暂停、单步推进。
2. 在左侧比较「阅读 / 整理 / 灵感」三张小样，右侧直接切换实际预览。打开「主线设计」可修改名称、目标及是否保留批量选择与导出。顶部「从新需求开始」进入预设的需求解析流程。
3. UI Agent 逐个放入容器、标题、搜索、筛选和素材卡片，功能 Agent 跟进数据、保存、搜索与导出。两只具名鼠标定位页面元素，已连接的行为在对应位置显示勾；鼠标动作与状态推进共用同一条演示时间线。
4. 添加入口出现后即可输入。保存未接通时明确提示且保留内容；接通后才写入本地。构建模式下点击内容区域可打开组件检查，切换「试用」后直接操作；可替换列表、表格、卡片而保留素材数据。
5. 完成构建后，点击「打开插件」，再选择「保存并独立打开」。独立页共用已保存素材；「编辑新草稿」复制已保存设计到新的草稿地址。该页面仍需要本地预览服务运行。

右侧零件池只包含 UI 组件。「本步选择」解释 Mock 选择结果与约束；扩展到团队协作、云端同步等需求会说明当前演示边界，不伪装成已实现能力。13 步播完只代表预设装配完成。

## 本地存储与版本边界

以下键名已对照 `app.ts` 与 `material-preview.ts` 核对：

| 对象 | V3 存储键 |
| --- | --- |
| 默认草稿 | `molis-builder-draft-v3` |
| 独立新草稿 | `molis-builder-draft-v3:<draft-id>` |
| 已保存的独立使用版本 | `molis-builder-release-v3` |
| 素材库 | `molis.plugin-builder.inspiration-library.demo.v3` |

V3 使用独立键，不读取或覆盖 V1/V2 演示数据。不同 V3 草稿和独立使用页共用素材库；设计草稿与已保存使用版本分开保存，只有显式保存独立版本才更新使用版本。素材保存前会重新读取并合并有效数据，遇到无效数据时暂停保存，避免覆盖。

关闭页面后浏览器数据保留，清理本站数据会移除它。本地演示版本与正式插件安装、Host 权限和正式运行时持久化没有接通。
