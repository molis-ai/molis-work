# 76 · 全平台与主动效果验收

## 给人讲清楚

主动助理、记忆自动整理（Dreaming）、智能操作面组合、主线建议、写代码质量核验和本机用量统计全都做出来以后，这一批做整个**阶段 3 的收官总验收**：真刀真枪检查建议准不准、没事的时候有没有忍住不烦人、拼出来的操作面好不好采用和纠正、跨项目与「个人空间」边界严不严、失败和未知有没有老实交代。还要重点核对：提前准备和发通知是不是分开管的、影子观察试用是不是真的零副作用、在完全没装 Goals 的项目和「个人空间」里后台任务能不能一样跑通、初始技能包能不能开箱即用。

同时在隔离的新版干净环境里做**跨周再办长效演练**：第 1 周交办周报、做人工纠正、撤回一个数据源、彻底遗忘一条内容并重启；接着换第 2 周新数据和不同读者重跑——看上次纠正有没有继续生效、被遗忘的内容有没有从聊天原文里偷偷复活、常驻记忆有没有变臃肿、后台整理费用有没有守住每日预算上限，并在图形化的「`设置 › 评测`」后台和「`75-A` 本机用量统计」面板里双向对账。走查抓出的跨模块缺陷、提示词或阈值调优（必须附独立验证集不倒退的实验账本证据）与最终验收报告**全部放在本批同一个 PR 里一次性修完合入**；你本人的多天日常实操体验与阶段 4 并行观察，在 `83`／`90` 收官对账前签字结项，不卡后续批次开发。

## 交付与前置

- **阶段／类型**：3（真人日常观察可跨阶段并行，至 `83`／`90` 前签结）；体验与效果；横向能力收官验收
- **需求来源**：[主动助理 §14／§16][PAST]、[观测采集 §5～6][OCL]、[Harness R12][CHO]、[智能呈现][IUI]、[主线][MLN]、[视觉][VUX]、[PWA-141～147（#1730）][PAEXT]、[Memory §15][MEM]
- **前置／待决**：`52`、`63`（`63-1`／`63-2` 含图形化「`设置 › 评测`」后台）、`63A`、`64`、`66`、`67`、`71`、`75-A`；按[决定 66](../decisions.md#decision-66)与 [`112`](112.md) 前置等 [`111`](111.md)：全平台与主动效果验收统一在 Clean v1 统一工作分区（含 `"personal"` 个人空间默认仅开 `Schedule`、按需启用 `112-2` 瘦身后 `Jelly` 日历与极简笔记、零 `jelly-whisper`）、零醒睡 `overview_projection` 与 20 个平等内置插件终态上执行，全程使用隔离 `MOLIS_WORK_HOME`，绝不触碰真实 `~/.molis-work`。
- **可并行项**：本批隔离环境跨周演练与工程收官 PR 合入后，`77`～`86` 中满足各自依赖的项照常推进（`79`～`81` 已移到服务端批）；你本人的多天日常使用观察与阶段 4 并行累计，`83` 与 `90` 收官对账前须拿到对应真实观察结论，工程模拟与真人日常体验分开记账、不混充
- **UI 要求**：复用已定界面（含 `63-2`「`设置 › 评测`」管理后台与 `75-A` 本机用量统计面板）；新增或生成表面的帮助引导文案在隔离 Home 中核对 `zh`/`en`/`ja` 中英日三语（零二元语言分支，守决定 67 ⑤ 模型工具说明固定单语）；走查发现的问题与调优在本批同一 PR 内直接修清
- **粒度**（用户 2026-11-25 拍板）：**全批一个 PR 一次性闭环**——隔离 Clean v1 环境跨周全链路实测、走查抓出的跨模块修复、附带独立 `validation` 验证集零倒退账本证据的提示词／阈值调优，以及最终验收与对账报告全部放在本批同一个 PR 内合入（合入前照跑受影响包构建、Chromium + macOS WebKit 双核验证与 `pnpm boundary:check`／`pnpm health:check`）。

**两步走跨周期观察机制（不卡阶段 4 进度）：**

1. **第一步（本批 PR 当场完成的隔离跨周实测）**：在隔离 Clean v1 Home 中从 `64` 的正式助理入口复用[共用周报样本](../../../proactive-assistant/spec.md#recall-workflow)，构造确定性的两周期时间线（第 1 周：起草投资人版 → 人工纠正偏好范围 → 触发一次 `63A` Dreaming 整理 → 撤回现金流来源＋彻底遗忘一条记录 → 重启宿主；第 2 周：换入新一周收支与项目进展数据，依次验证投资人版、内部版、独立项目 B、无 Goals 项目后台任务与 `"personal"` 个人空间简报／建议），用真实模型跑通并记录范围、成品数字准确性、返工次数、零误发送、遗忘零复活与整理成本。
2. **第二步（与阶段 4 并行的真人多天日常观察）**：日常使用中的跨周自然复验与主观体验持续记录，不阻塞本批 PR 合入与 `77`～`86` 开发，在 [`83`](83.md) 相关创作效果验收与 [`90`](90.md) 最终交付对账前汇总签认；未满自然观察期的条目如实注明「隔离跨周演练已过、待真人周期签认」。
