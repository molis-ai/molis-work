# D0244：整理只消费当前可用且仍获授权的索引来源

状态：已实现（2026-11-08 合入 main，[#1974](https://github.com/molis-ai/molis-work/pull/1974)，合入提交 `837a9bd1bf`）；2026-11-13 归档。

## 方案与开工前检查

报告建议对知识目录、模型整理过滤不可用来源并清索引；归位采纳：Knowledge 拥有目录、卡片和整理，Search 拥有来源发现、授权过滤及索引维护，Host 注入两者的公开服务。只清缓存不能处理模型等待中的撤权，故补原来源世代与同步提交检查。原实现的 D0244-01 已实测两个失败：撤权后迟到草稿和模型错误都改写卡片。

本项为小修／横向服务安全边界。SearchService 新增公开 indexedCatalog：按同项目当前 source/reader 权限、可用性与成功索引状态返回可信快照；缺正文 reader 时仅摘要，不交模型整理。消费者保留原授权检查，来源生命周期变化后不得被新的注册复活。Knowledge 仍从注入端口组目录，不 import Search 实现，不读来源业务表。

发模型前复核可信来源，原检查经 writer 的 beforeDispatch 交给同一 hostTextGeneration，覆盖准备后的实际网络派发；返回后重新读可用目录与 revision，再同步核原来源检查后才能写成功或失败。catch-up 失败不继续后台 kick。Search 原有登记变化事件安排已知来源刷新与停用/卸载清理；Home 提供方的项目来源逐个按自身 owner 刷新。不删同步失败前的缓存，但失败缓存不再作为模型材料。

模型仍走原 HostTextGeneration / agent-host；不改提示词、方法、模型选择、预算或调用 schema，不建立第二个推理入口。已发出的请求不回滚；被拒的结果不交付、不写卡片或业务失败账。原本已授权派出的用量不虚构为零。

七项自查：开工前检查过（高项批准范围）；硬约束过（同一 owner/公开端口/单一推理）；系统审查面过（来源、索引、模型到卡片）；调用次数过（每份材料模型前后各取得一次可信目录，每次两轮进程内动作发现与原尾检；增加的检查用于等待竞态，不新增网络往返或轮询，沿原后台节流）；门禁不放宽；代码质量过（复用 Search 既有 source/reader 规则，不复制权限模型）；偏离无，补齐报告没覆盖的等待竞态。没有 UI 或资源变化，不操作真实 Home。

## 验收

1. **D0244-01** 模型等待时原来源撤权，迟到成功或失败都不能改写卡片。
2. **D0244-02** 已有索引的来源停用、不可用或同步失败时不进入整理材料；其他项目不进入目录；仅来源授权而无 reader 时正文为空、降为摘要。
3. **D0244-03** 已捕获的索引目录在提供方登记变化后拒绝，包括 Home 与项目提供方的再次注册；只有新调用取得新授权。
4. **D0244-04** 真实 ActionService、Search、索引与 Knowledge 组合下，来源重新登记也不允许旧整理写入失败账。
5. **D0244-05** 真实 Host、Runtime 来源和 SDK 的模型 HTTP 等待中停止后重新启用 Home 来源，旧结果仍拒绝且不写成功或失败；新显式整理可恢复。

6. **D0244-06** 模型准备期间来源撤回，实际派发检查拒绝，发送次数为零，卡片不改写。

01/06 在 tests/knowledge-cards.test.ts，02/03 在 tests/system-search.test.ts，04 在 tests/security-invariants-knowledge.test.ts，05 在 tests/security-invariants-knowledge-lifecycle.test.ts。现有真实 Host/SDK 的取消、排除和删除测试也必须回归；它证明运行链，不宣称商业模型理解质量或用户验收。动作和 contracts/SDK schema 不变；Search 内部公开服务新增端口，对 Host 同片接入，无旧路径兜底。
