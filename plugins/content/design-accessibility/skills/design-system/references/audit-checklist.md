# 设计系统检查清单

逐类检查。「搜什么」给的是起点，命中后都要人工确认：变量文件本身、第三方代码、测试夹具里的值不算偏离。

## 写死的值

| 查什么 | 搜什么 | 应该用 |
| --- | --- | --- |
| 颜色 | `#` 加 3、4、6、8 位十六进制；`rgb(`、`rgba(`、`hsl(`；颜色关键字如 `white`、`black`、`red` | 语义颜色变量 |
| 透明度叠色 | `opacity` 用在文字上来做「浅一点的字」 | 次要文字、弱文字的变量（叠透明度常常对比度不够） |
| 间距 | `margin`、`padding`、`gap` 里不在刻度上的像素值（如 13px、7px） | 间距变量 |
| 圆角 | `border-radius` 的像素值 | 圆角变量 |
| 字号、字重、行高 | `font-size`、`font-weight`、`line-height` 的数值 | 字体层级 |
| 阴影 | `box-shadow` 的完整写法 | 阴影或层级变量 |
| 时长与缓动 | `transition`、`animation` 里的毫秒数、`cubic-bezier(` | 动效变量 |
| 层叠顺序 | 很大的 `z-index`（如 9999） | 项目的层级刻度 |

## 重复造的组件

- 名字相近的组件：`Button`、`Btn`、`ActionButton`、`PrimaryButton` 同时存在；
- 自己画的按钮、输入框、标签页、开关、提示、弹层，而组件库里已有；
- 复制了组件代码再改几行；
- 在业务样式里改组件的内部类名。

## 系统默认控件当产品界面

- 可见的原生 `<select>` 下拉列表；
- `<input type="color">`、`type="date"`、`type="time"` 的系统弹窗；
- `window.alert`、`window.confirm`、`window.prompt`；
- 没有换肤的 `type="range"`、勾选框、单选框。

原生元素藏在组件后面保留表单值和键盘行为可以，看得见的部分要是组件库的。

## 缺状态

- 只有默认样式，没有悬停、按下、聚焦、禁用；
- 列表没有空、加载、读取失败的样子；
- 出错时清空了用户的输入；
- 不可用的功能被藏起来，或放了一个点了没反应的按钮。

## 无障碍缺口

- `outline: none` 且没有替代的焦点样式；
- 点击事件挂在 `div`、`span` 上，没有键盘支持和角色；
- 图标按钮没有名称；
- 表单字段没有关联的标签；
- 只用颜色区分状态；
- 自定义控件缺键盘操作或状态播报。

完整检查用 accessibility-review。

## 主题缺口

- 只在浅色下定义的颜色，深色下没有值或沿用浅色值；
- 图片、图标在深色背景上看不见；
- 用了原始色阶而不是语义变量，导致换主题时不跟着变。

## 一致性

- 同一个动作在不同地方叫法不同、图标不同；
- 同一种信息（日期、数字、状态）格式不同；
- 同类页面的标题区、操作位置、返回方式不同。
