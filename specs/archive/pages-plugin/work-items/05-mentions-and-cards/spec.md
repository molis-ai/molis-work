# WI5：Pages 提及与卡

depends_on：01、03。完成等级：**3 功能可用**。

## 背景目标

文中能 `@` 本库文档，能插入文档引用卡、任务卡、月历、日程卡。任务卡不派角色。月历/日程先读本篇事件。

## 当前行为与问题证据

slash 只有文字块。没有提及、没有卡。

## 范围

1. `@`：行内输入 `@` 弹出当前项目文档列表，选中插入 `page_mention`（标题可点开该篇）。
2. 文档引用卡 `page_ref`：块级，显示标题，点开该篇。slash 可插入。
3. 任务卡 `task_card`：标题 / 描述 / 状态（todo/doing/done） / 截止日期；不派角色。
4. 日程卡 `event_card`：标题 + 时间。
5. 月历 `calendar`：只读本篇 `event_card` 排进当月格子；无事件也显示空月历。
6. 不要 `@` 空间/角色、三种引用形态、嵌 Goal/Form/Dataset/PPT。

## 非目标

接 Schedule 模块、循环日程、提醒、多人分配。

## 使用场景

周报里 `@` 会议纪要；插一张任务卡「周五交稿」；插日程卡和月历，月历上能看见那天。

## 方案与关键决策

- 提及/卡都是 schema 节点，进 `body_json`。
- `@` 菜单由内核渲染，文档列表经 `mount({ pages })` 从库客户端注入，内核不自己打 HTTP。
- 点提及/引用卡：`onOpenPage(id)` 由客户端 `fillEditor`。
- 月历不存用户格子，渲染时扫文档。

## 输入输出与依赖

允许：本 spec；pages schema / editor / styles / en / client（注入 pages 列表）/ 测试。

## 验收标准

1. `@` 能插入提及；引用卡/任务卡/日程卡/月历能经 slash 插入；刷新 JSON 仍在。
2. 任务卡改状态或日期会保存。
3. 本篇有日程卡时月历标出对应日。
4. 点提及或引用卡打开该文档（同库）。
5. `save()` 仍不重挂内核。
