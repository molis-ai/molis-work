## 使用入口

当前预览：http://127.0.0.1:4201/projects/project-426bc31e-53ad-49e2-9199-93342f3e64b9 。进入左侧「实验」，打开「CGS 材料支持度 · 三组首轮 · Agent 初标」。宿主是 **Molis Work 示例项目**，不是正式项目绑定；实验内容来自有出处的真实研究摘录。

1. 在「参试模型」中保存模型配置。Jev 与 Functions 共用宿主 TypeSafe 凭据；请在密码输入框填写并保存，不要在聊天或实验材料中填写密钥。界面只报告是否配置，不回显密钥。
2. 「新建实验」可以独立编写问题与选项，也可以引用现有 Choice 函数；引用时由服务器读取当前函数定义并冻结版本、模型和配置哈希。
3. 添加材料，或导入 `首轮材料-agent初标.json`。出处、参考答案、标注身份与依据保留在实验里，但不传给参试模型。
4. 选择一至三组模型，先保存，再点运行。每场最多二十条材料，每组每条一次；宿主不自动重试。可取消当前及剩余执行。
5. 查看逐条答案、失败原因、耗时、token 与费用口径。人工复核单独追加，不改写运行前快照；导出 JSON 包含全部结果与复核记录。重新运行需复制成新实验。

补齐 Jev 凭据后，可复制现有实验并保留三组再跑一次；旧实验中明确记录的未配置失败不会被覆盖。若只验证 Jev 连通性，可以复制后只选 Jev，但不能称其为新的三组同时对照。

## 实现与范围

新增独立原生包 `plugins/native/experiments`，由现有宿主构建期装配，沿用 UI contribution、个人导航、控制令牌和 PluginPrivateStorage。它不是运行时隔离安装的第三方 App 插件。任务定义不依赖 Functions；仅可选引用其快照，Jev 执行复用现有 TypeSafe 适配器。对 Functions 的改动限于保留提供方返回的可选 token usage。

当前必须保留的是实验快照、逐条执行状态、独立模型输入、人工复核和可重开的证据。宿主提供执行端口；插件保存个人数据到当前 home 的 `plugins/experiments/private.sqlite`。没有新增独立密钥库、云评测服务或跨仓库流程。

首版每场串行执行、一条一次、最多三组，仅支持 Choice。模型配置可以增加同类型的命名配置，既有实验保持冻结值。新 runtime、生成任务评估、在线 A/B、自动路由、自动调参、大规模统计、共享金标库均延后；只有出现具体需求再评估。没有接入 CGS、Arena 或 jev-workbench 的运行流程。

Grok 使用临时工作目录和临时 GROK_HOME，沿用原生登录引用；不复制密钥，不修改原有 CLI 配置。提交材料前检查扩展/技能/MCP/项目指令，完成后核对实际会话工具、记忆与模型强度；若检查失败，输出不计有效。临时目录用完清理。Laya 强制离线加载指定目录，超限明确失败，绝不静默截断。
