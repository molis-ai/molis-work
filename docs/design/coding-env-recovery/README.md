## 推荐走一遍

1. 环境 A：全部就绪 → 依赖装不上（点放行下载）→ 端口被占 → 缺配置（点选密钥）→ 临时副本启动失败（点修复）→ 清理；再切 B、C。
2. 预算与重试 A：第 1 次 → 第 2 次 → 模型服务出错 → 最后一次 → 用完了（点「再给 3 次」）→ 你要求重做；切 B、C。
3. 重启后接着做 A：命令在跑时重启（点「先核对」）→ 两步之间 → 临时副本 → 推送 → 模型出错；切 B、C。
4. 本轮结果 A：做完了（点「接受」）→ 部分完成 → 卡住 → 绿灯是改之前的（点重新跑）→ 写了但没法启动看；切 B、C。
5. 每块切一次 EN 和「深」，把窗口拉到 1024 和 390 宽看一次；勾「标出组件板新增」看新做的部件。
