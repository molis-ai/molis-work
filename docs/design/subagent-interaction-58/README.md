| 方案 | 阅读与切换 | 取舍 |
| --- | --- | --- |
| A 同面板标签（推荐） | 子任务加入助理面板现有标签栏；「助理」保留，点它回主对话 | 已打开的子任务方便来回切换；任务多时标签可横向滚动，窄屏固定主助理入口 |
