## 给人讲清楚

整条非服务端本机路线的最后一步「毕业总查账」：逐本原需求、逐条待办（Backlog）、逐个插件与纯平台入口清点家底——每一项的代码实现、自动化验证、隔离环境实操，以及需要你本人签字的体验结论（含 `57`、`76`、`83`、`85` 与阶段 4 并行累计的真人日常使用观察）全部核对落账。

严守**「小账顺手清、真缺口绝不糊弄」**：已完成规格书按规矩归档、待办销账、文字与索引小修在本批单 PR 内一次清净；如果查出任何真实功能未打通或交互硬伤，必须先拆出专项修复 PR 合入（或由你本人明确拍板改标「延后」），严禁为了表格全绿凑数签结；条件触发项、服务端批（`SRV-1～8`）和发行批（`REL-1～5`）各自如实保留原状态。同时把本批作为 **M1 首发前的 Clean v1 干净基线总核点**——确认全仓所有数据库拍平为干净的 `version: 1`、评测后台五大基线齐全、全部自动化红线门禁零违规，平顺交接给 `REL-4`／`REL-5`。需要你做的：审阅最终对账总表并签字收口。
