## 5. 做法

**问题的实质。** 这些假服务是测试里起的 HTTP 服务，收到模型请求后读请求体、`JSON.parse` 再决定怎么答。`raw += chunk` 把每个 `Buffer` 块各自转成字符串；一个汉字或 emoji 的字节被网络切在两个块之间时，两半各自解码成 U+FFFD，JSON 里的内容就变了。改法是先把所有块收成字节，最后解码一次。

**形状 A（一行，第 4 节标 A 的文件）：**

```ts
// 改前
let raw = ""; for await (const chunk of req) raw += chunk;
// 改后（变量名 raw/body、请求对象 req/request、引号随文件，原样保留）
const chunks: Buffer[] = []; for await (const chunk of req) chunks.push(Buffer.from(chunk));
const raw = Buffer.concat(chunks).toString("utf8");
```

**形状 B（两行，第 4 节标 B 的文件）：** 删掉单独的 `let raw = "";` 那一行，把下一行 `for await … raw += chunk;`（或 `raw += chunk.toString()`、`raw += String(chunk)`）按上面“改后”两行替换。

改的时候逐个核：
1. 后面有没有给这个变量重新赋值（有就用 `let`，没有用 `const`）；
2. 作用域里有没有已经叫 `chunks` 的变量（有就把新数组改叫 `parts`）；
3. 只改读请求体这一处，周围的注释、别的代码一行不动。

改完用这条命令确认第 4 节列的文件里没有剩下按块拼字符串的：`git grep -nE "(raw|body) \+= (chunk|part|String\(chunk\))" -- <第 4 节的文件>`，应当没有输出。
