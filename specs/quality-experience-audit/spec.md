## 第五批：搜索请求取消贯通与恢复

属于原 QF-08 / BL-search-query-abort，负责人 Codex。深入核对发现旧 BL 的“逐次搜索来源”口径不完整：当前 query 使用由 Search owner 持有的共享索引更新（`catchUp → sync → indexer`），不是每次请求各自查询外部来源。取消只终止本次请求、其私有对象读取及后续反馈，不能取消另一请求仍需要的索引任务。HTTP 的 Home/项目四路由复用现有 `responseAbortSignal`，经 `bindLocalWebActions(..., {signal})` 把控制交给现有 Kernel。对象读取失败后的查存在兜底不应吞掉取消；跨到个人空间打开对象时也保留原调用的取消。

事实/规则仍归 Search 与各插件；Host 只绑定传输生命期，不改身份和权限。不开新队列、不增加信号平台抽象、不改变公开动作或持久结构；搜索本包仍只依赖 contracts。原权限等待后复核保留。正常 UI/Agent/MCP 共用 Search 行为；本批无页面资源和文案变化。允许修改 Host 搜索路由与调用方、Search 实现/说明、对应测试、原 BL 和本任务文档。先复现 HTTP 中止、取消被兜底吞没和个人空间信号丢失，再修复；共享索引继续完成需单独断言。

- **QEA-11** Home 和项目 HTTP 搜索入口断开后，已进入的对象读取看到取消、请求不再执行存在性兜底读取；下一次同操作正常成功且每次对象读取仅一次。个人空间跨项目打开也保持取消。
- **QEA-12** 取消查询不披露迟到结果、不触发后续请求私有读取；共享索引工作仍正常完成并实际写入可重用索引，下一查询成功且不重复索引。验证正常完成后信号不误取消、动作信号不遗留 abort 监听；HTTP 响应监听沿用共享 helper，其 close/finish 清理由代码核对，不冒称该动态断言覆盖它。
- **QEA-13** Search 公共引用读取的真实调用在取消时拒绝，普通对象不可用仍给既有不可用结果；不以空候选掩盖取消。沿原 authority、索引同步、引用及 HTTP 消费回归证明不削弱授权或失败恢复。

验证：完整构建后通过机器槽 `--jobs 1` 跑新增取消回归、`system-search`、`system-search-host`、`system-search-authority`、`system-search-refresh-budget`、`search-references`、`security-invariants-object-references`、Host README 必跑及实际路由消费者；最终 head 的 CI Full 仍由主会话执行。完成本批只更新对应验收，不宣布整项任务完成。

## 第六批：Home 后台任务的完整性与恢复

属于原 QF-04，负责人 Codex。目标是让用户分得清“没有后台任务”和“当前有一部分读不到”，在原任务列表内重试恢复，无额外确认、诊断弹窗或第二套轮询。当前 `collectHomeAggregate` 已保留来源/项目级 issues，`homeBackgroundTasks` 丢弃它们，`attention` 客户端将剩余空数组当成没有任务。沿聚合、HTTP、实际渲染三个入口实施，不能仅把错误记日志。

合同先行：`contracts/services/mainline` 增加 Home 的任务行/完整性结果类型，`homeBackgroundTasks` 与 `/api/attention.background_tasks` 改为同一个 `{tasks, issues}` 结果，仍由 `null` 表示整部分读取失败或此页不适用。来源错误只传项目、动作引用和错误码，不传原文或内容；UI 用所属语言键说明部分读取失败，保留成功来源并提供一次重试。只有完整成功且 tasks 为空才能画“没有后台任务”。既有缺失/关闭项目及插件暴露判断保持，已安装但被策略拒绝与未安装要区分（`home-aggregate.test` RAC-2437）；不删权限检查。复用 Mainline 的 `backgroundTaskRows`，不保留 Home 的重复逐行装配。所有 HTTP、浏览器与测试消费者同片迁移，不兼容旧数组。

正常 Home 入口补查：chooser 的 chosenRoute 会把 attention 转到选中项目，旧项目响应没有 Home 后台任务。Home 客户端在既有同一 attention 请求及变更流上显式带 `view=home`；Host 保留选中项目助理上下文，同时提供已有 Home 聚合并订阅跨项目变更。插件页面不因该参数获得 Home 聚合（沿 pluginPageRequest 的可信边界），项目普通页面仍不取跨项目列表。不新增轮询或另读同一份任务。

事实仍归各插件；跨项目范围/保持已打开项目归 Host，行语义与投影合同归 Mainline，界面仅消费完整性与返回行。不增加缓存、库结构、状态声明、插件专路或平台包。受影响：contracts、local-host、workbench 及真实消费者测试/说明/API 快照。页面沿现有 side-tasks 与 mw-alert/mw-btn 样式，文字归 workbench；不改共享样式。新增词包地址和首屏实际增量完成测量后按已有授权核对，超出批准范围才请求新决定。

- **QEA-14** Home 聚合全失败、部分失败、超时及读取无效回答时保留结构化 issues；正常任务仍按原 owner/项目展示，错误原文不出 HTTP；恢复后 issues 清空，不保留伪失败。不改变外部取消、关闭项目或未安装来源行为。
