# Coding 输入区收成一块

## 背景

Coding 会话底部现在是几层分开的控件：输入框自己一道边，任务方式和模型选择在框外各是一颗按钮，发送再单独一颗；标题栏右上还有「会话设置」「结果与审查」和运行中的「停止」。材料、角色、方法、MCP 又占输入框上方一行。看起来像表单，不像在写下一句。

## 当前行为

- 标题栏右侧：`data-coding-context-toggle`、`data-coding-results-open`、`data-coding-stop`。
- 输入框上方：标签「任务或补充要求」和材料 / 角色 / 方法 / MCP。
- 输入框下方：`data-coding-intent`、`data-coding-model`、`data-coding-send`，再加一行草稿说明。
- 这些控件的点击、草稿、发送、停止、结果栏开关都由现有客户端处理，不改请求。

## 范围

把上述控件收进同一个输入面。会话上下文（工作区、目标、工作树、重命名）仍由「会话设置」展开，贴在输入面上方。

不改任务方式、模型、材料、发送、停止、结果栏的行为与文案。不改目录列。

## 方案

输入面只有一条边界。正文无边框。底栏左侧是任务方式、模型、材料四项、会话设置、结果与审查、停止；右侧是发送。草稿说明和快捷键留在面的下面，与对话同宽（最多 76ch）。

## 验收

1. 打开一条 Coding 会话，任务方式、模型、会话设置、结果与审查、发送都在输入面内部；发送在右侧。
2. 标题栏不再放这些按钮。点「会话设置」仍展开工作区 / 目标 / 工作树。
3. 点「结果与审查」仍打开结果区；有运行时「停止」仍可点。
4. 发送、方式、模型的禁用和文案与改前一致。窄容器里控件仍可点到，不把页面撑出横向滚动。

## 验证

改 `plugins/native/coding` 后构建该包，刷新 `4173` 上的 Coding 会话，看桌面和约 760px 宽的输入区。
