# 外部会话来源差异与接入边界：可点的定样（路线书第 34 批）

状态：用户已定（2026-11-15）——四处均选推荐方案 **A**，已写入 [Sessions 重做 §8](../../../specs/sessions-rebuild/spec.md#8-决策记录)，进入工作台界面片（S-5）实施。

这是参考原型，不是产品界面。第 22 批已定下外部会话的四个大流程（发现会话 **B** 按时间排加来源条、归属建议 **B** 待归类集中处理、查看历史 **A** 原文对话、项目 AI 读取 **A** Sheet 分两页；见 [sessions-sources](../sessions-sources/README.md)），本批直接复用，不再重问。本原型只针对 [第 34 批](../../../specs/post-anticorruption-roadmap/reference/batches/34.md) 要求「先定样」的四处差异与第 22 批转交项出样：

1. **具体来源差异**：不同外部工具回到原工具的方式、工具自带搜索（Droid `sessions.tool.search`）、以及 50 个登记条目里「已自动接通 / 仅支持手动导出 / 工具未开放 vs 待接通」的区分展示；
2. **云端来源连接与账号变化**（[合同设计 §12](../../../specs/sessions-rebuild/contract-design.md#12-和现状对不上的地方) 第 28、29 行）：读取范围里云端来源没有可选连接时去连接设置的入口、多账号连接切换、`gh` 缺 `repo` 权限时的非静默提示，以及 `account_changed`（本机 `gh` 换了登录账号）的两条出路；
3. **项目设置区分工具带进来的目录**（合同 §12 第 24 行，原 R5）：项目设置「输入与输出」里，外部工具经 MCP `context_bind` 带进来的目录与本人连的目录怎样区分、说清后果，并给「确认连入」入口；
4. **助理引用外部会话与选区边界**（合同 §12 第 44 行）：外部会话页面的选区与当前会话默认不自动带入，怎样用最少打扰让用户看懂「点 `+` 才进本轮」「仅本轮有效」「`@` 只含标题和目录、不含对话正文」「本轮还在运行时不能补充外部会话内容」。

另把合同 §12 第 14 行的三处已定文案（读取范围 Sheet 写明含子目录与互指核实的 git worktree、待归类写明发给配置模型的内容且与项目 AI 许可无关、改归属 Dialog 写明「它连着的工具调用仍落在旧项目」）一并放入块 1 供对照。

直接用浏览器打开本目录的 `index.html`（`file://`）。若走本机端口，因为引用了 `../sessions-sources/mw.css` 与 `mw-icons.js`，请在 `docs/design` 目录起静态服务后访问 `/sessions-34/index.html`：

```sh
python3 -m http.server 4472 --bind 127.0.0.1 --directory docs/design
```

## 四处要定的

| 块 | 候选方案 | 取舍 |
| --- | --- | --- |
| **1 · 具体来源差异** | **A 顶栏按工具给恢复或链接 + 筛到工具时露工具搜索 + 读取范围三类区分（推荐）**：CLI 有恢复命令时顶栏给「复制恢复命令」（并在只读行下安静列出命令文本），`mcode` 无单会话恢复参数时安静标明「仅目录内交互恢复」，云端带 PR 时给「在 GitHub 打开 Pull Request」；跨会话默认搜标题／目录／工具名，筛选到带自带搜索的 Droid 时露出「在 Droid 里搜」并注明跳过范围外条数；读取范围 Sheet 分「已接通（10）」「仅手动导出（Grok Build / Amp）」「暂不支持（标清『工具未开放』与『待接通』）」 | 不多占正文高度，不为不支持恢复或工具搜索的来源画常灰按钮，用户也一眼分清「工具本身没给接口」还是「Molis Work 还没接」 |
| | **B 正文上方常驻命令行条 + 独立工具内搜索弹窗**：每个会话打开后在正文上方常驻一整条带底色的命令框；工具栏常驻「工具内搜索」按钮与独立面板（没选 Droid 时置灰） | 命令最醒目；但每次读原文多占一行，且 10 个工具里 9 个没有工具内搜索，按钮平时常灰 |
| | **C 收进「在原工具继续 ▾」菜单 + 搜索框自动混跑工具搜索**：恢复命令收进下拉菜单；顶部搜索框敲字时自动对支持的工具跑子进程搜索并混排结果 | 顶栏最省；但每次输入都起子进程、快慢不一，且很难解释为什么只有 Droid 命中了对话正文 |
| **2 · 云端连接与账号变化** | **A Sheet 行内选连接／去设置 + `account_changed` 双出口恢复卡（推荐）**：读取范围 Sheet 里云端来源行下直接给连接下拉（无连接时禁用勾选并给「去连接设置接入 GitHub CLI」按钮）；`gh` 缺 `repo` 权限时说明不静默扩权并给 `gh auth refresh -h github.com -s repo` 一键复制与重试；`account_changed` 时卡片并列给两条出路：①「我已在终端切回原账号，重新核对」，②「去读取范围改用新账号的连接」 | 少一层弹窗；碰到账号切换或权限不足时，不用先猜去哪修，两条路都在眼前 |
| | **B 勾选时弹窗选连接 + `account_changed` 统一跳回读取范围**：Sheet 行保持单行，勾选时弹二级框选连接；`account_changed` 只给「打开读取范围」一个按钮 | Sheet 行更短；但多一层模态框，且只切回终端账号的人也要先进一次 Sheet |
| **3 · 项目设置区分工具带入目录** | **A 同一张「读取的文件夹」列表内标「工具带入 · 待确认」与后果，行尾给「确认连入」（推荐）**：保持现有单列表不拆节；本人连的目录零变化；工具经 MCP 带入的目录标 attention 状态词与一行后果说明（不进外部会话项目目录范围、不自动归入会话），行尾一键「确认连入」（调 `add_input` 升为本人目录）；输出目录未确认时联动下方「读取仓库说明文件」开关 | 全部目录都是本人加的时候和现在一模一样；有工具带入目录时原地就能看清并一键确认，同一目录兼作输入输出时也不会两处找 |
| | **B 拆成「你添加的文件夹」与「工具带入、待你确认」两节**：把工具带入的目录单独放进第二张卡片，确认后移入上卡 | 分界最硬；但平时目录很少时多一张卡片标题，兼作输出的目录要在两张卡之间对照 |
| **4 · 助理引用外部会话与选区边界** | **A 复用输入框上方上下文条虚线候选签（`+` 加入）+ `仅本轮` 尾注与运行中就地提示（推荐）**：不新造浮动按钮；选中原文与当前外部会话在上下文条显示为虚线候选签（`未加入 [+]`），不点 `+` 绝不自动发送；加入后签内标 `不可信材料 · 仅本轮`；`@` 引用外部会话时标 `仅标题与目录 · 仅本轮` 并附一行安静提示引导用选区 `+` 带原文；本轮运行中置灰 `+` 并一行说明为何不能中途补充 | 与工作台助理现有的上下文条完全同构（`.assistant-strip-chip.is-optional`），不多造浮层，也不常驻大块横幅 |
| | **B 原文选区浮动按钮 + 输入框上方常驻 `info`/`warning` 说明条**：靠左侧选区旁浮出的按钮加入本轮，输入框上方用横幅卡片解释「仅本轮」「`@` 不含正文」「运行中不可补充」 | 选完文字手边就有按钮；但多一套选区浮层定位逻辑，且横幅占掉助理对话高度 |
