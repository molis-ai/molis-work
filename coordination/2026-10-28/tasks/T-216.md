## 1. 背景

- **错在哪**：`for await (const chunk of request)` 里的 `chunk` 是 `Buffer`（请求流没有设过编码）。`raw += chunk` 先对 `chunk` 调 `toString()`，也就是只用这一块自己的字节解 UTF-8。UTF-8 的一个字最多 4 字节，数据块的分界不管字的边界：分界落进一个字里，前一块以半个字结尾（读成 1 个 `�`），后一块以续字节开头（每个续字节读成 1 个 `�`）。`Buffer.concat(chunks).toString("utf8")` 是等所有字节到齐再解一次，不会出这个错。`recording-text-model.ts`、`assistant-text-model.ts`、`model-stand-in.ts`、`images-runtime.ts` 是 `+= chunk`，`plugin-model-runtime.ts` 是 `+= String(chunk)`，`String(Buffer)` 同样是 `toString()`，一样的错。
- **什么时候会撞上**：只有请求体被分成多个数据块，且分界落在一个多字节字中间。发送方一次写完的小请求体通常是一个块，所以现有用例没有红过；提示词、材料长、又含汉字或表情时，请求体有几十 KB，就会分块。起草时没有量过分块大小，只量过「分两次写就是两个块」（独立脚本，见开头）。出错后果：`JSON.parse` 不报错（`�` 在 JSON 字符串里合法），读到的内容悄悄变了，用例的断言红得莫名其妙，或者（`assistant-text-model.ts`）一个本该被认作复盘请求的请求被当成普通请求。
- **五个夹具各自是什么**（谁用它，起草时 `git grep` 了仓库里所有地方，含 `docs/`、`specs/`、`scripts/`、`tooling/`、`.github/`）：
  - `images-runtime.ts`：`imageRuntimeFixture`（`:16`）起一个真的 Home 监督器和一个本机图片厂商 HTTP（`:32-36`），动作经真的动作服务；`f.calls` 是厂商收到的每个请求的 JSON，`f.input.base_url` 是 `http://127.0.0.1:<端口>/v1`。直接用它的是 `tests/images-service.test.ts`、`tests/plugin-image-generation.test.ts`；`tests/images-plugin.test.ts` 只拿 `IMAGE_PNG`、`imageReply`；
  - `model-stand-in.ts`：`startModelStandIn(acceptedKey, reply)`（`:18`）起一个只收一把钥匙的 OpenAI 聊天格式假服务，露着 `baseUrl`、`origin`、`requests`、`close()`；11 个测试文件用（其中 4 个浏览器用例）；
  - `recording-text-model.ts`：`recordingTextModel(t, home, answer)`（`:17`）把假服务配成这个 Home 的文字模型，记下每个请求（`requests`，不含复盘与知识卡片的旁路请求），用 `answer(request)` 回答；`tests/context-onboarding.test.ts`、`tests/security-invariants-injection.test.ts` 用，后者用 `wireText` 对请求里的文字做断言；
  - `assistant-text-model.ts`：`assistantTextModel(t, home, text, pace?)`（`:14`）同样配成 Home 的文字模型，第一次回答会等 `finish()`，认出复盘请求就直接回复盘的答案（`:21` 的 `asideReply`）；6 个浏览器用例用；
  - `plugin-model-runtime.ts`：`modelRuntimeFixture(t, format)`（`:21`）起一个真的 Home Runtime 和可控的 HTTP 厂商，请求记在 `requests`；只有 `tests/security-invariants-plugin-model-materials.test.ts` 用。

// The loopback providers in tests/fixtures read a request body as bytes and decode it once. A body that arrives in two chunks, with
// a character cut between them, must reach the fixture whole: decoding each chunk alone turns the cut character into U+FFFD.

// Long enough for the server to read the first chunk before the second one is sent. Too short a pause could let a broken fixture read both
// chunks at once and pass; it can never make a sound fixture fail.
const PAUSE_MS = 50;

/**
 * POST `body` as UTF-8 in two writes, PAUSE_MS apart. The first write ends one byte into `mark`, so the server reads the character
 * `mark` starts with cut between two chunks. `mark` has to start with a character of two or more bytes.
 */
function postCut(url: string, body: string, mark: string, headers: Record<string, string> = {}): Promise<{ status: number; text: string }> {
  const bytes = Buffer.from(body, "utf8"), start = bytes.indexOf(Buffer.from(mark, "utf8"));
  assert.ok(start >= 0, "the body holds the mark");
  assert.equal(bytes[start]! & 0xc0, 0xc0, "the mark starts with the first byte of a multi-byte character");
  const target = new URL(url);
  return new Promise((resolve, reject) => {
    const request = httpRequest({ hostname: target.hostname, port: target.port, path: target.pathname, method: "POST", agent: false,
      headers: { "content-type": "application/json", ...headers } }, response => {
      const parts: Buffer[] = [];
      response.on("data", (part: Buffer) => { parts.push(part); });
      response.on("end", () => resolve({ status: response.statusCode ?? 0, text: Buffer.concat(parts).toString("utf8") }));
      response.on("error", reject);
    });
    request.on("error", reject);
    request.write(bytes.subarray(0, start + 1));
    setTimeout(() => request.end(bytes.subarray(start + 1)), PAUSE_MS);
  });
}

/** The text a streamed Anthropic-style reply carries: its `content_block_delta` pieces, joined. */
function said(stream: string): string {
  return stream.split("\n").filter(line => line.startsWith("data: "))
    .map(line => JSON.parse(line.slice("data: ".length)) as { type?: string; delta?: { text?: string } })
    .filter(event => event.type === "content_block_delta").map(event => event.delta?.text ?? "").join("");
}
