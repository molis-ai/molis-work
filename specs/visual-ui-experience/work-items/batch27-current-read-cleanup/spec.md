## 范围与做法

旧插件曾允许 2026-09-23 的 HTML 与新脚本一起运行（`3241c870f`）。现在，Host 的项目设置用 [Characters 渲染器](../../../../apps/workbench/src/characters/ui.ts)一次画出五个动作控件，再从同一构建加载[浏览器入口](../../../../apps/workbench/src/browser/characters/entry.ts)。只有 `CharactersPage` 创建动作视图，设置缓存重开会移动同一节点。当前仅有旧的测试夹具会完全省略这些控件。

在 [动作客户端](../../../../apps/workbench/src/browser/characters/action-client.ts) 初始化时用既有的缺件错误取得必需控件，移除空视图。残缺节点在请求目录前即报告具体缺件。正常页面仍读取 `GET /actions`，保持 `null` 继承、`[]` 禁用及动作 ID、版本、提供方组成的精确引用。目录撤回时保留已选引用并标成不可用，刷新失败时保留现有选择和重试入口。沿用原 [测试文件](../../../../tests/characters-action-client.test.ts) 和其产品子集入口，在完整控件夹具上验证这些语义。

另单独提交机械注释清理。调用日志按现行字段拒绝不成形的记录，保留最近 1000 条已执行命令及独立的短诊断尾部。Agent 定义设置按插件聚合同一编辑键，优先启用的安装，执行按调用安装解析。Dataset、Pages、PPT、Form 和判断规则的建库说明以当前基线为准，SQLite 检查的列序与 SQL 字节照旧。Coding 的开发分支迁移注释已过时，Manifest 声明以现行值为准。

本片边界止于以上实现和说明。模型供应商默认与修复、Review 文档终态恢复、接入状态的 OAuth 期限与清理、助理工作视图的字段投影、规划请求剥离服务端字段的两条路径各自维持现有行为。保留 Demo 项目标识和生命周期、色板令牌、Feed 无障碍钩子、Shell 工厂名和现有测试夹具名称。生成插件的三处读取由第 46 批接续。

## 验收标准

1. **BCRC-01** 当前角色页面缺少动作继承控件或列表时，动作视图初始化报告具体缺件，目录请求数为零。
2. **BCRC-02** 完整控件上的继承、显式禁用、精确选择、失效引用和目录刷新失败符合原行为。缺件与正常行为由同一份定向用例覆盖。
3. **BCRC-03** [人工] 机械注释只说明现行实现，去注释后的程序与基点一致，五处 DDL 字面量逐字节一致。
