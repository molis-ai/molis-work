## 验收与验证

- 同一 Home 重开 Store 仍可重试，其他 Home 的运行尝试不受影响。
- 历史关键读取的真实异常令门禁失败；已有合理业务不可用结果有明确依据。
- CLI 退出码为 0 但结果无效/不可读取时，Shelf Promise 拒绝且宿主不收到未捕获异常。
- 等模型、等嵌套动作期间撤权/取消/换注册后，预览、判断和工作流记录不再由旧调用写入；正常调用和恢复保留。
- 同 Home 的其他读写不被判断模型等待串行阻塞。
- 创作台实际加载 AI 章节，幂等示例表达同一意图重试，不使用变化的时间键。
- 按修改范围运行类型/边界、定向回归；源码与 Skill 固定后整体构建，再执行必要跨模块回归，避免安装指纹在测试期间变化。

不改变持久化 schema；现有请求、记录及历史读取保留。新增执行检查可能把过去错误成功的过期调用改为拒绝，这是目标行为。回退可直接恢复代码，不需数据降级。
