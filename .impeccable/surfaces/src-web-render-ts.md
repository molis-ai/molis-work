Current workbench direction (2026-09-12): see `.impeccable/surfaces/immersive-workbench.md` and `specs/immersive-workbench-implementation/spec.md`. The older shell/Goal layout below is historical; retained feature ownership remains applicable.

Scope and mode: Molis Work local Web and macOS desktop workbench, Operate mode. The Desktop core shell remains Level 3; the Feed ownership slice reaches Level 4 for internal use: the single directory, project-scoped Goal tabs, Goal Detail, Feed Item workbench, source manager, scoped Settings, and Runtime behavior use real application state. Sessions and 工作目录 have reached Level 3: both management surfaces only exist inside a selected project as siblings of Goals, their global compatibility routes return to the project index, and their list, detail, confirmation, capability-degradation, and responsive paths use the real Catalog, Session Registry, and API rather than page-local demo records. Browser Web and the narrow Companion reuse the same adaptive DOM.

Audience and job: developers and product leads use Molis Work either as a full desktop workstation or as a narrow companion beside Codex, Claude Code, or another Harness. They must locate the active Goal, understand its next action, and keep a Goal-bound Runtime visible without relearning the layout at each width.

Chosen direction: retain the Single-directory Project-Tab Workbench shell; the Goal surface is the user-confirmed Goal canvas workspace (`seed=user-goal-canvas-workspace-2026-09-12`). The project/list directory stays on the left. The main dependency canvas opens one fixed Goal workspace with full-height Runtime beside Goal info and an inline timeline. This code-led evolution supersedes older Goal comps without changing Feed, Settings, native chrome, or the Calm Desktop palette.

Memorable moment: see the provider → consumer dependencies, click a Goal node to work inside it, then 收起 to return to the same camera and compact-node positions. Expanded Goals cannot move; only compact nodes can be dragged.

Visual system: one 286-334px graphite directory beside a flexible light workbench. Restrained cobalt marks focus and available intent; semantic color is only for real state. Native system typography, Lucide icons, softly rounded 6-14px surfaces, related tonal fills, and local low diffuse shadows define both Light and Dark Calm Desktop. In Light, compact current-location states never use paper plus exterior shadow: directory selection uses a flat tint and tab-like navigation uses a two-pixel cobalt marker. The directory/work-surface boundary is tonal only—no full-height border or standing shadow—and structural lines are intentionally rare. In macOS Overlay mode, a fixed 48px native-chrome band protects the traffic lights and creates one consistent top rhythm across the Goal workspace and scoped Settings.
