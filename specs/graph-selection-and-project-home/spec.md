# Graph 选择与有温度的项目首页

状态：2026-09-12 已完成。完成等级 3（功能可用）；原生 Agent 仅保留输入草稿，不实现推理或消息发送。

## 目标与当前证据
用户要求：Graph 单击仅选中看血缘，按钮/双击打开；默认定位下一个可开始 Goal、100% 缩放；目录恢复文字状态标签；首页加入日期、鼓舞工作的名言轮播、真实最近活动和未来原生 Agent 输入框。当前单击直接 selectGoal，首载 fit 全图，目录 CSS 隐藏状态文本，首页仅四个插件入口。

## 方案、场景与边界
- 保留当前灰白工作台、插件导航、业务接口、工作框、目录尺寸和终端。Graph 浏览选择独立于已打开文档/终端，单击不加载文档或切换 Session；右上角打开按钮、双击及键盘 Enter 打开，Space 选择。拖动不误触打开。
- 首次 Graph 使用现有 display_status=continue 的非复合 Goal，按既有优先级降序、创建时间升序取首个；无可开始目标时取进行中、当前目标、首个作为浏览位置。以 100% 居中。已有手动视角、打开/收起和刷新继续保留；适应全图仍为显式操作。
- Goal 目录恢复原状态图标+文字标签，保留 32px 行高和标题省略。
- 首页继承现有视觉系统，日期与问候组成开头，项目名是上下文；名言是主要阅读段落，来源可查，12 秒切换，支持暂停/上一句/下一句，悬停/焦点/隐藏与减少动态效果时停播。真实 Goal 最近足迹用时间与动作叙述，最多三条，可打开对应 Goal；没有活动时明确留白。插件保留为底部轻入口。
- 输入框位于下方，用户可书写、按项目保存在当前浏览器会话；发送禁用并标“Agent 即将接入”，不伪造响应、不执行 Runtime。

## 模块与依赖
Goals momentum renderer/client/viewport 负责图节点交互与 camera；Workbench 首页 renderer 读取真实 Goals/events，输出有限的 home_activity 摘要；client/styles 消费摘要并跟随刷新更新，不传原始事件负载。目录 scoped styles 恢复标签。语言沿用当前 locale；名言来自公开经典并提供原文出处。无数据库迁移或新增服务。

4. 首页日期正确、轮播可控、草稿恢复与项目隔离、真实活动可导航并在刷新后更新；空态、深色、手机可用。
