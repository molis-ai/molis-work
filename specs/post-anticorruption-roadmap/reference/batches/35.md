## 给人讲清楚

你在别的 AI 工具里已经有的会话，引导时可以直接接进来接着做。Coding 这边补一批基本功：自动写项目说明文件、常用命令模板、能看图片、更懂代码（跳转定义、报错提示）、自动准备需要的工具、审查前自动整理格式。两件事各做各的，不互相等。做完 Coding 用起来更像一个熟练的开发助手。需要你做的：看命令、图片、工具准备和报错诊断这几处的样子并定下。

**Coding A 期各项的做法：**

- **A2 命令模板**：做法同已定方案 A。几条规则：
  - 「这个项目的」由 Host 读项目某个已关联工作目录下的 `.molis/commands`、`.claude/commands`（`commands.project.list@1`），「我的」读本人家目录的同名两处（`commands.personal.list@1`）。两者同一份遍历，Coding 一次菜单加载两个请求（[S-prompt-commands](../../../../docs/system/security-invariants/S-prompt-commands.md)）。

  - 命令只是一段提示文字，不带权限；`$ARGUMENTS` 由 Molis 原样替换，不走 SDK 的 JSON 字面量。
  - 命令签用组件板的命令签标本。
- **A1 `/init`**：做成内置的提示文字命令。读仓库后起草 AGENTS.md，经审查卡批了才写进仓库；这一轮没有能写的意图时不可选。规则菜单就是「这一轮读到的说明」的入口，不另开。

- **A4-2 写后检查与格式化**：方案 A（审查卡检查行）。内置 TypeScript／Python／Rust／Go 四种语言服务器，只用本机已有的。
- **A4 代码理解（CLS-01～03 里本批的部分）**：方案 A。
  - 一轮开始时，按目录顶层与常见源码目录里的文件和标志文件（`tsconfig.json`、`pyproject.toml`、`Cargo.toml`、`go.mod` 等）找出用到的语言，查每种语言的程序在不在本机或 Molis 工具目录。结果记进 `frozen.code_intelligence`，不起进程、不下载。

  - 没有读取各程序的版本号：读版本要执行这些程序，本批不做。
  - 下载、联网限制、「只为这次放行」都随决定 51 移到第 65 批之后。
