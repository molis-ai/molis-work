# Molis Work 0.3.0

状态：发布候选，基于远端 main `aadce77ac5d35ca08c27624a4e38aaeb4244cde7`；本地工程验证与最终 DMG 的隔离安装启动检查已通过；仅准备 GitHub 草稿，尚未公开发布。

本版将 v0.2.0 之后的 Molis Work 插件工作台、助理、Issue、Coding、Pages 与统一动作服务汇成一个桌面版本。发布升版只统一产品和内置插件编号，不修改数据库结构或动作版本。逐项变化见 [CHANGELOG](CHANGELOG.md)。

## 发布范围与验收

- REL-01：产品根包、Tauri、Rust 桌面包、宿主版本均为 0.3.0；`verify-release-versions` 核对。
- REL-02：从明确的 main 基线构建 macOS Apple Silicon App、DMG、App ZIP 与 SHA256，核对内嵌 Runtime 版本、签名完整性和归档校验和。
- REL-03：现行目录内的内置插件 Manifest 均为 0.3.0；源文件门禁和构建后的实际目录均核对。官方集成、示例与第三方插件保留自己的版本。
- REL-04：发布前记录工程检查、安装包启动实操及未验证项；没有公证的包不作为正式公开发行包。

工作顺序：版本与说明 → 构建及回归 → 安装包校验和隔离启动 → 上传 GitHub 发布草稿。复用现有构建、安装和内置插件更新机制。真实 Home 维护、Runtime 接入配置、外部用户兼容机制与 Intel 实机验证不由这次升版自动包含。

## 主要变化

- 统一工作台承载插件内容，助理和 Coding 可接收上下文、补充输入并呈现当前回合的后续操作。
- Issue 提供个人问题记录与重新整理；Pages 增加评论线程与材料写入落点；Form 接入 Plugin Runtime。
- 动作目录统一页面、工作流、Agent 与 MCP 的能力发现和授权。错误与调用记录以诊断编号关联，撤权、取消和停用后的写入按同一边界拒绝。
- 内置插件随当前宿主构建更新；插件方法、按需发现工具与 Coding 等待外部条件的执行路径继续完善。
- 产品从 GoalBoard 改名为 Molis Work；旧根 SDK、Casebook 接口和实验插件已经移除。

这些是合入代码的范围，不能据此推定所有模型场景、连接器或主观体验已经验收。

## 兼容与升级

0.3.0 不是 v0.2.0 Home 的直接无损自动升级。产品已删除旧迁移链；现行数据库版本必须与 [检查清单](CHECKLIST.md#3-各库版本表) 一致，否则拒绝打开。旧 Home 需要先离线完整备份、在副本演练一次性维护，并取得维护授权。不能仅修改版本标记，也不能以空数据替代旧数据。
