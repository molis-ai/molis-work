# D0038 工作台会话认证

状态：执行中（2026-11-08）。用户已选择 D 方案；负责人 Codex。属于既有每日质量修复的底层与架构项，不改变插件业务、动作授权或界面产品流程。

## 决定与范围

用户批准浏览器使用可独立撤销的 HttpOnly 会话，桌面凭据保留在 Rust 原生侧，仅提供受限账号/会话引导。目标是宿主控制凭据不进入页面；同源恶意脚本仍可能借当前会话请求获准操作，不承诺 E 方案的独立敏感操作确认。

认证事实归 `apps/local-host`；页面消费归 `packages/ui-host` 与 `apps/workbench`；桌面接入归 `apps/desktop`。既有账号会话仍独占账号身份，新传输会话只拥有本次浏览器接入及 CSRF 证明，不复制身份或插件授权。MCP 仍要求自己的独立客户端凭据，原生身份仍要求 owner-only 原生凭据。

HTTP 页面只携带随机 CSRF 证明与非授权的空间修订标识；HttpOnly 随机会话 ID 保留在 cookie 中。会话绑定精确回环 origin、宿主实例与当前空间凭据修订，有界有效期；刷新、过期、撤销、重启与账号切换不能恢复旧会话。一次性操作键与 Host/Origin 检查保留。cookie 不作为跨端口隔离，服务端仍核对精确 origin。

桌面沿用限定路径、方法和参数的原生账号桥和一次性 WebView 附着票据，引导同样的浏览器传输会话；不另写任意 HTTP 代理，不把宿主、原生或 MCP 密钥交给 JS。业务 HTTP 和 socket 共用同一会话权限，避免两套业务路由和授权。

## 验收标准

- **WAS-01** 真实宿主渲染的登录前、工作台、设置、项目及插件宿主 HTML 与页面可读账号响应均不包含根 Home 或个人 Home 的控制令牌、原生凭据、MCP 客户端凭据；只移动 meta 不算完成。
- **WAS-02** HTTP 变更须同时持有有效会话 cookie、对应页面 CSRF 证明、精确同源 Origin 与未使用的一次性操作键；缺失、错误、重复、其他会话/端口/空间、过期均拒绝且零业务写。CLI/MCP 的私有控制认证保持独立，不由页面会话冒充。
- **WAS-03** 会话创建仅来自允许的本机页面请求；不接受外站/不透明插件 frame 取得可用认证、地址或请求体指定身份。重复 cookie、跨站及跨端口复用拒绝。
- **WAS-04** `/pty`、`/browser`、`/computer` 同时验证会话与 CSRF 首消息；撤销、过期、空间切换后断开旧连接，后继消息不能产生副作用，异步绑定后再检查原权限。
- **WAS-05** 浏览器会话可单独结束；另一浏览器会话保持有效。退出、账号 A→B→A 与服务重启后旧页面/连接不恢复；正常刷新与重连可恢复新的有效会话。
- **WAS-06** 桌面原生桥不返回宿主凭据，不接受任意目标、方法、头或正文；一次性附着票据的有效期、单次消费及账号租约检查保留。`desktop=1` 与页面可写字段不赋予原生身份。
- **WAS-07** 正常浏览器页面读写、插件桥、终端与侧栏通道继续工作；拒绝测试断言具体未执行事实。安全表、合同记录、公开快照与调用方同步，不保留旧页面令牌认证兼容路径。
- **WAS-08** [人工] 真实 Tauri WebView 下核查 cookie、原生 IPC 与插件隔离；Chrome 或模拟 IPC 不代替真机证据。

## 防腐与验证

复用当前 Host HTTP 与 socket 入口、原生有限账号桥和插件页面授权，不新增插件私路、动作名单、业务副本、第二宿主或模型入口。无持久库结构变化，无读取兼容或数据迁移。旧页面需刷新，旧服务会话在重启后失效。
