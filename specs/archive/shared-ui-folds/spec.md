## 验证记录

Node 24.15.0、pnpm 11.9.0，测试经公共执行槽在隔离 Home 和专用浏览器中运行。工作区构建、依赖边界、API 快照复核、页面资源、首屏及插件样式预算通过。定向回归与两个共享包的必跑清单合计 75 个测试文件。组件板测试修正同页锚点的等待条件后单独重跑通过。

| 验收 | 实测入口与结果 |
| --- | --- |
| SCF-01 | `sdk-ui-markup` 直接核对两出口的函数相同、标题和属性转义、正文保留 HTML。组件板点击折叠标题，Images 服务对话框可手动展开/收起，选择自定义服务仍自动展开。Goals 新建表单可展开至最后的优先级字段并保留草稿。现行文件侧栏的阅读、固定快照和选区引用由 `side-materials-reader.e2e` 验证。[Files 退役记录](../../../docs/releases/CHANGELOG.md) |
| SCF-02 | `visual-mechanisms.e2e` 测短正文、展开后增长、反向收起、隐藏子项的焦点与减少动态效果。`connections-page.e2e` 逐帧比较连接行高度与箭头。组件板测两种内容的实际高度，减少动态效果时同步收至零，焦点返回行按钮。完成连接后，卡片进入 inert，焦点落到已连接结果行。 |
| SCF-03 | `schedule-task-grants-area.e2e` 在实际日程详情让首次清单读取与平台授权区域返回 503。鼠标点击共享警告里的重试按钮，清单请求从一次增加到两次，警告隐藏，任务恢复“读项目文件”的标记。`schedule-plugin` 验证中英文失败提示。 |
