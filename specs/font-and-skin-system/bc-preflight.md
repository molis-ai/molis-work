## 子分支与授权边界

用户已批准 `database.assistant_store_baseline` 从 1 升到 2，在现有 baseline 内增加同步 `from: 1` 升级段，事务内转换上述 JSON，保留所有 ID、去重键、状态、时间与任务身份。能从旧记录的明确结构恢复的系统模板转键；不能可靠恢复的历史原文保留在新格式中明确的原文分支，不猜测翻译。用户明确接受部分历史中文原文因此仍显示中文。任意错误原文可能超过 `TextRef.literal` 的 2000 字上限，不用截断或包装为不合法的 `literal` 解决。用户角色正文、历史对话不在这项转换范围。

读取仍只认新格式；打开旧库继续拒绝，由已有维护升级入口执行连续升级，不读时转换。仅在隔离 Home 验证，不触碰真实 Home。必要文件：助理合同、store/followups/notices 与实际通知生产者、`assistant-text-html.ts` 及其客户端消费者、唯一版本表、库登记和 schema 快照。现有 v1 金样的跟进表为空，补非空升级场景，验证迁移后显示、重启与去重，不能用空金样代替 FSS-38 的原文保留证据。

### 日期时区合同

日期 `TextArg`、`TextArgValue` 增加可选 `time_zone`；SDK 的日期参数构造工具及 `format.date` 接受只含该项的选项。统一校验与格式化，非法时区不静默回退。固定时区提醒保存时间点和原来的时区；普通无指定时区的展示保持原行为，纯日期不变日，relative 仍按时间点差计算。此项补齐 FSS-39，不改 `next_at`、`due_at`、每日/每周与夏令时调度规则。

合同代码限 `packages/contracts/src/platform/ui-text.ts`、SDK 的 `text-ref.ts`、`message-format.ts`、`text.ts` 与必要调用方，更新公开 API 快照。验证同一时间点在宿主和浏览器不同时区下的指定时区显示、夏令时边界、无效时区拒绝以及普通日期行为。
