## 给人讲清楚

在进入全路线最终总对账（第 `90` 批）前，把**三条完全独立、互不等待的主线收尾活儿**拆成 **3 个独立并行 PR（`89-A` ∥ `89-B` ∥ `89-C`）**干净清零：

1. **`89-A` · 情境浮条与右栏 `W7` 总纲收口（独立并行 PR 1）**：补齐任意输入框润色翻译、自动识别选中链接／路径／日期／邮箱给出快捷操作、带出处复制引用、一句话「记住」（直通平台记忆）、选内容跑工作流、轻量划线批注，以及各插件自己的对象快捷动作（彻底清零老代码里写死点名 `Goal` 的残留，剔除早已退役的 `Files`／`Text stats` 插件，复用 `84-A` 已交的 Coding 分叉／旁问，选中日期建日程直接调 `112-2` 瘦身后 `Jelly` 日历或 `Schedule`）。
2. **`89-B` · 输入回执阶段 6 各剩余场景收口（独立并行 PR 2）**：把「发补充不丢进行中的活儿、清楚看到用上了还是没用上及理由、长作业可看真进度与中断续做」补齐到插件创作台、`Schedule` 对话任务、灵光（`Spark`）、`82-A` 新版 `Alchemist`、纯平台 `system.shelf`、开项目引导和 `Images`／`Pages`／`Inbox`（**剔除已在 `112-2` 彻底砍掉的 `Jelly 计划拆解` 私有 AI**）。
3. **`89-C` · 全目录技能包（Skill）三段式效果比武进「`设置 › 评测`」（独立并行 PR 3，前置就绪即可先行）**：同一件工作分别对比「开启 vs 停用某项技能」的真实成品，加全目录正／负向触发准确率与工具模拟回放，结果统一落入 **`63-2` 图形化「`设置 › 评测`」后台**与 SIM 账本。发现没帮助甚至帮倒忙的技能时**内外有别**：系统内置弱效技能附验证集零倒退证据修准触发边界或改为默认关闭自动启用；**用户自建／导入的技能绝不自动删除或暗中停用**，只在评测／技能页温和提示建议改为手动点名或精简说明。需要你做的：在 `89-A`／`89-B` 看每个新增入口或动作的定样并确认。

- **阶段／类型**：4；产品线（情境交互、输入回执、技能包评测）；横向能力收口

- **UI 要求**：`89-A`／`89-B` 每个新增入口／动作先定样，已确认部分直接复用；`89-C` 复用 `63-2`「`设置 › 评测`」管理后台与技能设置页温和提示徽标
