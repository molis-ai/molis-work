已定的不再问：

- 自己写的技能放在「我的技能」里，和从本机导入的同样对待（这台电脑的发布身份，只在这台电脑）。
- 随系统自带的、装来的技能不能直接改；「改一份我的」从它起一个你自己的技能，原来那个不受影响。
- 每次保存是一个新版本；新建的技能保存后是关着的，提示里可以一步设成自动。

- 保存失败时写的内容留在原处，说明「什么都没丢，目录没变」，可重试。
- 这一版只写正文，不带附带文件；要带文件的技能仍从本机导入。

## 三个方案

差别只在**新建一个技能怎样开始**；修改已有的、改一份，三个方案都是右边同一张表单。

| 方案 | 新建怎样开始 | 取舍 |
| --- | --- | --- |
| A 就地写 | 点「新建技能」，右边直接是空表单：名称、什么时候用它、给谁用、放在哪、怎么做 | 最直接，会写的人一步到位；不会写「什么时候用」和做法的人面对空表单容易卡住 |
| B 先说一句，助理起草 | 先用一句话说想让它做什么，助理起草全部字段，再在同一张表单里改；也可以点「我自己写」直接进表单 | 不用从空白开始，起草的使用条件通常比人随手写的更利于 AI 选对；多一步、要等几秒、要花一次模型调用 |
| C 分三步 | 它是什么 → 什么时候用 → 怎么做，一步一屏 | 每屏只想一件事；改起来来回翻页，熟手嫌慢，只有三四个字段不太值得分步 |

主会话推荐 **B**（保留「我自己写」直达表单）：技能好不好用主要看「什么时候用它」写得准不准，这正是多数人写不好的一栏。

## 状态

| 状态 | 看什么 |
| --- | --- |
| 正常 | 新建、填写时的字数行、缺项和重名的就地提示（保存时焦点落到第一处）、保存后回到详情并提示设成自动、修改保存为下一版、改一份、删除与撤销、离开前的未保存提示 |
| 保存失败 | 表单顶上就地报错，内容不丢，重试 |
| 还没有自己的技能 | 右边的空状态，从新建或「改一份我的」开始 |

## 组件板新增

- `au-count`：正文下面一行，左边写法说明、右边行数与字数，超限变色。
- `au-leave`：离开前的未保存提示条（保存再走／放弃改动／接着写）。
- `au-steps`：分步头（只有方案 C 用）。

定下方案后，用到的补成组件板标本并交 D 轨合审。
