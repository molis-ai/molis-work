# Molis Work 字体、皮肤与语言系统

状态：需求已统一整理，尚未实现（2026-10-12）。本书是三套系统及其消费方的统一需求来源。目标为**内部完整**：工作台、现存插件、Plugin Builder、个人助理 Skill 与开发手册共同成立，包含文件加载、真实校验、无重启切换、持久化与恢复。

配套技术文档：[实现方案](implementation-plan.md)。技术落点与切换安排在该文件说明，需求与验收仍以本书为准。

## 1. 目标与现状

用户能独立选择字体、皮肤和界面语言，也能与个人助理描述想要的风格，制作、预览、调整、应用和撤销自己的外观。外观与语言通过文件表达，系统加载后供全部入口使用；日常切换无需修改源码、重新构建、重启或刷新整页，正在进行的工作保留。

保留现有控件语义、工作台位置与导航、业务布局合同、权限和内容归属。可定制的视觉与界面文字由文件定义；控件交互和业务行为继续由实际组件与插件承担。

## 2. 范围、独立选择与统一使用

### 2.1 覆盖对象

| 对象 | 必须具备的能力 |
| --- | --- |
| 工作台与 macOS App | 外壳、底栏、侧栏、设置、到达页面、菜单、浮层、提示、错误和恢复页正确使用字体、皮肤与语言 |
| 标准规格板 | 从共同规格及所选文件展示真实组件、变体、状态与组合，支持三套系统及明暗/密度的相关组合 |
| 现存插件 | 项目/个人插件、岛、设置、侧栏、主区与嵌入全部正确消费，不丢业务状态或执行身份 |
| 外部插件 | 只经公开 contracts 与 SDK 使用三套系统，不依赖私有设计包或宿主源码 |
| Plugin Builder | 候选板、设计/体验/代码/界面/复查上下文、试用、安装与已安装生成插件使用同一份规格、文件和校验规则 |
| 个人助理与内置 Skill | 根据用户描述制作与修订外观文件，执行真实校验、预览、应用和撤销；已有选项的确定切换可直接执行 |
| 开发手册与作者资料 | 人、编码 Agent、Builder 和外部作者能按同一份新规范使用三套系统，资料在实际运行与发行物中可用 |

覆盖以真实插件目录和入口为准，包含已安装的生成插件，不能以少数样板或“部分支持”代替现存入口完成。界面语言包含动作目录标题、说明、授权说明、结构化运行状态与无障碍名称。

### 2.2 选择与作用域

| 维度 | 默认行为与作用域 |
| --- | --- |
| 皮肤与字体方案库 | 当前 Home 管理，内置与自定义使用相同定义格式；当前组合在 Home 保存，浏览器与 App 读取同一选择 |
| 字体策略 | 默认跟随皮肤推荐；用户明确选择后锁定该方案，换皮肤保留它；“同时使用推荐字体”可明确改变策略，等宽方案可单独选择 |
| 界面语言 | 独立于字体与皮肤，默认保留浏览器或 App 入口作用域；同一入口的窗口/页面/嵌入跟随，其他入口按各自偏好呈现 |
| 语言匹配 | 支持明确选择或跟随系统；明确选择优先，未设置时匹配受支持的系统/浏览器语言，无匹配时使用明确默认语言 |
| 明暗、密度与动效 | 明暗支持浅/深/跟随系统；设备侧密度、减少动态效果和终端明暗独立保留，不混入皮肤身份 |

换肤不换语言，换语言不覆盖皮肤或明确选定的字体，只按文字覆盖需要使用后备。用户界面显示具体方案、实际加载状态与后备情况，不要求用户理解内部标识。

设置提供字体、皮肤、语言、明暗/密度、我的方案和预览，支持复制内置版、命名、编辑、另存、导入、导出和移除自定义方案。内置原版不可覆盖，在用或被方案引用的资源不能直接删除。没有模型时已有方案、手动编辑和确定操作仍可使用。

### 2.3 范围边界与待明确项

范围为现有浏览器与 macOS 产品。首批皮肤为 Soft Workbench 与 Folio；字体包含系统无衬线、Folio 圆润、独立阅读与等宽选择；语言完整覆盖中文与英文，并允许通过语言包扩展。额外首批语种尚未指定，扩展能力不等于某个未验证语种已完成。

Home 级字体/皮肤选择、入口侧语言偏好，以及首期不提供项目/插件专用皮肤，是本书的默认范围。首期不增加皮肤市场、云端同步、任意 DOM/CSS/JS 注入，也不通过外观或语言切换改变业务布局、私有内容格式、成果版本、CLI/MCP 协议取值或执行权限。

## 3. 文件定义、加载与恢复

### 3.1 可读写文件与唯一来源

| 文件/资源 | 必须表达的内容 |
| --- | --- |
| 共同外观规格文件 | 语义角色、可定制项、组件变体/状态、默认值、支持的外观配方及组合；标准板与 Builder 使用同一份 |
| 皮肤文件 | 名称、身份、格式与定义版本、浅深色、配色/平面/边界/圆角/阴影、组件规则、字体及素材引用；一套皮肤由一个入口文件完整描述 |
| 字体方案文件 | 各文字角色的字族/字重/字号/行高/字距、语言覆盖、后备、等宽方案和实际资源引用 |
| 语言包文件 | 语言/地区、版本、文案主人、稳定键、译文及参数、必要语言规则和书写方向；共有文案有唯一主人 |
| 字体与受支持素材 | 实际字体数据或明确可用的系统字体、受支持素材、来源、实际可用性及引用关系 |

内置与自定义定义均为可编辑、可校验的数据。用户或助理制作皮肤时主要修改该皮肤入口文件，需要时修改字体方案；无需另写标准板或 Builder 板，也无需修改共同规格才能创建皮肤。新增外观或受支持语言不改业务源码、不重新构建产品。

源文件是定义的事实来源，解析与合并缓存只是投影。Home 管理外观库、草稿、选择和应用/撤销结果；平台与各插件拥有各自文案。语言偏好归对应入口，内容仍归原插件，AI 运行历史沿用既有记录。不同消费者不得持有第二份正式选择或词典事实，配置默认不进入成果库。

文件有准确身份、版本、来源、依赖、默认规则和错误位置；外观选择引用准确版本，编辑产生新版本，未明确应用前保留原有效选择。外部编辑的文件通过导入或明确重新加载进入同一流程，未知或未支持结构不能静默忽略。字体/语言后备是当前资源解析规则，不增加旧协议读取兼容层。

### 3.2 启动加载与运行中切换

系统启动、新窗口、新页面和嵌入打开时，加载共同规格、所选皮肤、字体方案与语言文件，恢复相应作用域的上次有效选择。首次呈现使用正确外观与语言，字体加载中采用声明后备并可观察实际状态。

运行中切换已有选项、导入新文件，或编辑后保存并选择加载，都在当前会话完成。有效定义应用后，相关工作台、已打开插件、规格板、Builder 和嵌入同步更新，无需重启宿主/App、刷新整页、重新安装或生成插件。异步反馈的界面状态与后续提示采用当前语言，结果正文保留其原始内容与本轮语言要求。

更新作为完整有效版本生效，不出现新配色与旧配方混用、旧语言文案长期残留或延迟加载把选择改回默认值。保留输入、草稿、选区、滚动、展开、Runtime 身份、终端进程和执行状态；普通切换不调用模型，不在每个插件重复读完整库、主题或语言全集。

保存成功与视图更新成功分别可核对；某个视图未更新时明确报告并恢复展示，不重复提交选择。无效文件、加载失败或资源未准备好不能替换当前可用组合。启动无法恢复时使用最后有效组合，无可用组合时使用内置基线/默认语言，并说明原因，不静默改写用户选择。

### 3.3 文件移植与独立恢复

导出包含完整定义和明确依赖，说明字体方案、字体/素材、语言资源哪些随文件携带、哪些保留引用，不依赖原机用户名、绝对路径或缓存。导入另一 Home 后核对依赖并实际预览；缺资源或系统字体不可用时提供缺口与后备，不把部分恢复报告为完整恢复。

资源保留来源及已知使用/分发许可信息；随产品或方案分发有相应依据，仅限本地或许可未明确的资源不默认打包。助理不能凭空宣称已取得许可，用户可保留引用或选择可用替代。

提供用户明确触发的恢复入口，即使自定义外观显示异常、设置无法正常操作或模型不可用也能恢复。恢复内置外观采用基线与可用字体并保留语言；语言故障可独立恢复有效语言。恢复不删除自定义文件、工作内容或插件数据。库、选择和资源在重启、备份、升级及普通卸载中保留，保存和选择提交各自完整、可恢复。

## 4. 字体系统

至少提供界面正文、控件、条目标题、页面标题、长文阅读、说明文字及代码/终端角色，每个角色明确字族、真实字重、字号、行高、字距、语言覆盖与后备；数值显示适合对齐。

圆润方案须有中文和英文实际可用策略，不能只依赖某台 Mac 恰好存在的字体。代码、终端、Diff、ID 和按字符对齐的内容保持等宽；界面更换比例字体不破坏它们。支持内置离线资源、已知可用系统字体和用户主动导入，首期覆盖 WOFF2、TTF、OTF，格式支持情况清楚可见。

导入校验实际格式、内容、可读取性、字重与语言覆盖，使用受保护文件引用；不默认扫描/上传字体目录，不接收模型自称获得权限的任意路径。缺字、字重不足或加载失败使用明确后备，不出现空白、不合成未支持粗体，也不以名称存在替代实际加载。

样张包含中英文、数字、标点、长标题、小字号、粗细与等宽文字，说明实际字体与后备。换字体校验基线、控件高度、行尾状态、数字对齐、截断、菜单尺寸与窄屏换行，不能取消触控、焦点与错误说明要求。

界面字体与内容格式分开。无显式格式的阅读可使用阅读角色；用户指定的文档字体、代码语义、PPT 模板、导入文件、图片和固定成果保持原格式，不因切换而改写或重新导出。

## 5. 皮肤系统与标准规格板

保留 Soft Workbench 现有视觉基线，增加 Folio。Folio 参考 Molis Club 的 [产品页面](https://molis-folio-team-preview.guodawang33.chatgpt.site/demos/brand/folio/work/)并以用户修正为准：丰富协调的色彩、圆润字体、活泼感，运用于真实控件、分组、选择与提示，保持信息密度。原型中的蓝、薄荷、珊瑚、淡紫、奶黄只是候选，衬线杂志排版不属于本次方向。

正式皮肤包含可读的浅深色、推荐字体和组件规则。可定制语义配色、平面/边界、选择/强调、圆角/抬升、受支持装饰与动效节奏。主次操作、选择、焦点、链接、状态、内容类型和装饰有清楚角色；状态不只靠颜色，危险操作不能被装饰色伪装。密度与减少动态效果组合均成立。

同一组件只使用语义角色、变体和规则，不为每种皮肤复制 HTML、业务逻辑或客户端脚本。规格板读取共同文件与所选字体、皮肤、语言，真实展示默认、悬停、按下、焦点、选择、禁用、加载、错误、空态、菜单与浮层展开。

真实组合包含目录/详情、工具栏/筛选、表单、嵌套滚动、底栏、助理操作卡与生成插件页面。新增组件在共同目录登记，标准板及 Builder 同步可用，不维护另一套风格或文案清单。规格板自己的展示布局不得改变插件布局。

## 6. 语言系统

中文、英文为完整覆盖基线，其他正式提供语种须有明确清单和实际验证。语言数量由可用语言包决定，不写死在控件或业务逻辑中；支持跟随系统、明确选择、入口侧持久化及无重启/无整页刷新切换。

采用按文案主人区分的稳定翻译键，修改中文措辞不改身份，不同场景可有不同键和译法。共有词有唯一主人，插件声明自己的语言文件，经共同合同发现和读取，不在宿主手写另一份插件词典名单。内置与受支持导入语言包格式相同，新增/更新译文无需重构业务代码。

覆盖菜单、按钮、提示、空态、错误、帮助、无障碍名称、动作目录标题/说明/授权说明、结构化运行步骤和状态，以及生成插件、嵌入、恢复页。加载后显示实际版本、范围、覆盖与后备；缺词采用可读后备，不能出现裸键、空白或伪装完整。必要文案未覆盖的方案不能作为完整正式语言发布。

日期、时间、数字、计数/复数按语言和既有地区设置展示，文案以完整语义及参数表达，不依中文词序拼句。语言变化不改变实际时间、时区、金额、单位或原始数值。字体按所需字形采用后备，校验长度、换行、数字、标点、缺字、窄屏及语言声明的书写方向；未提供语种不宣称已适配。

界面语言不自动翻译项目名、用户正文、资料、成果、终端输出、已有对话或模型原始回传。个人助理的对话与生成内容尊重本轮语言要求，切换界面不授权改写历史。协议标识、稳定键、动作参数和业务取值不翻译；界面状态的本地化不改写原始执行事实与回执。

## 7. 现存插件、外部作者与 Plugin Builder

### 7.1 现存插件与嵌入

所有现存插件入口正确消费字体、皮肤和语言文件。共同角色覆盖真实界面用途，插件专属内容使用语义角色；图表、文档正文等保持必要内容规则，不能用全局样式强行重画或误判合法内容格式。

同页、侧栏、嵌入及隔离页面均得到当前有效定义与更新，来源、窗口、安装、作用域和版本可核对，保留 Origin 等既有校验。不能假定字体、变量或翻译器会自动穿过 iframe，插件只读取展示投影，不保存另一份当前选择。

外部作者仅依赖 contracts 与 Plugin SDK 获取公开视觉角色、语言合同、读取/订阅和使用示例，不安装或转出私有 Design System，不导入另一个插件或宿主实现。

### 7.2 Plugin Builder

候选板、各生成与复查阶段、创作预览、浏览器验证、安装后渲染消费同一共同规格、字体、皮肤及语言定义。设计 Agent 能知道当前视觉语言、可用字体、组件/状态、界面语言和限制，并据此选择层次与组合。

生成结果保留组件、语义角色、变体、布局意图及语言定义，不烘焙某次预览的颜色、字体或单一语言。宿主共有控件使用平台译文，插件专属界面文案归自己的语言文件；Agent 不凭中文按钮名推断操作，也不翻译业务字段值。内容模板需要固定格式时明确属于内容合同。

预览记录当次文件版本，已安装的新旧生成插件使用当前选择；无需重生成即可跟随。验证包含 Soft Workbench、Folio、当前外观及相关字体/语言/明暗/密度，实际操作与布局问题进入原有反馈和修订流程，不另建第二套 Builder 质量流程。

### 7.3 自动检查与介入

现存与新增界面的检查能识别写死字体/颜色、错误角色、默认样式覆盖、未更新嵌入、缺字、对比不足、溢出、不可见焦点，以及未登记/未加载的语言、缺失或冲突键、参数不一致。确定的适配形成可审阅差异，依赖业务意图的问题说明原因。

日常切换只加载并应用有效定义，不运行编码 Agent 修改安装包。作者与生成 Agent 读取当前规范，新增组件/插件从同一检查发现遗漏；用户正文、内容格式和合法素材不被误判为界面违规。

## 8. 个人助理与内置制作 Skill

### 8.1 使用场景

1. 用户说“给我做一套圆润一点、蓝绿为主、活泼但能专心工作的皮肤”，可选择参考图或现有方案。
2. 个人助理发现并读取内置制作 Skill，结合共同规格、当前文件、可用字体、界面语言和用户约束，生成命名草稿与字体建议，并调用共同校验。
3. 在当前工作台展示真实组件、字体样张和插件/Builder 组合，标明预览及校验结果。用户说“绿色柔和一点，正文别变小”时，只修订相关内容并保留其他约束。
4. 用户说“这个就用上”后，应用同一已校验版本，保存选择并加载，各相关入口跟随；反馈给出具体组合、实际生效状态和撤销入口。
5. 用户可继续调整、另存、改名、换回原版，或说“撤销刚才的换肤”，在设置里找到同一方案与版本。

“先看看”只生成和预览；“直接换成”已经授权该效果，校验通过后不重复确认。选已有字体/皮肤/语言直接调用确定操作，不必调用模型。默认在当前设置/预览区域；明确选择当前工作台预览时只临时影响当前窗口，关闭/取消恢复，不提前修改 Home 或其他入口。

### 8.2 Skill 与模型职责

Skill 随 Molis Work 内置，个人助理可发现、按需读取和自然语言触发，无需用户记名称或在外部 Runtime 安装，不依赖 Builder 是否启用。各正式语言的制作/修订请求均能使用，不以中文口令为前提，Skill 的展示名称、说明与操作反馈按界面语言呈现。覆盖内置皮肤制作规范、自定义创建/局部修订和字体搭配，引用当前语言规则；名称、范围、版本及实际读取可查询，正文与必要参考真正进入执行上下文。

Skill 指导助理读取规格/文件、保留约束、选择真实字体、输出结构化皮肤/字体文件、调用校验、展示预览、按授权应用与撤销。Soft Workbench/Folio 风格参考与共同合同分开，规则只有一份；用户修改内置版产生自己的方案，正式内置发布仍受既有授权约束。

输入为本轮描述/约束、用户授权的参考、准确起点版本、可用资源、共同文件规格与组件状态。默认用示例内容预览，不自动将私人工作正文或字体目录发给模型；材料里的指令不授予执行权。输出为结构化草稿、差异、可用字体及后备、真实校验与预览引用，不能生成可执行 HTML/CSS/JS 或假称资源、校验、应用已成功。

生成与修订沿用唯一 Prologue Runtime、登记指令、预算及取消机制，指令可查看/调整，等待模型不阻塞其他独立工作。Skill 只是做法，不授予路径、写入或发布权限；用户修改 Skill/提示词也不能取消平台校验。缺 Skill、动作、授权、模型或合适版本时说明具体缺口，保留当前外观和草稿。

## 10. 共同校验、授权与失败恢复

### 10.1 校验与应用条件

手动设置/编辑、导入、个人助理 Skill、Builder 和正式应用使用同一校验能力。模型自述、文件可解析、词典有键或截图已生成不能单独证明可用。

| 校验范围 | 必须验证的行为 |
| --- | --- |
| 文件与引用 | 当前格式/定义版本、字段、支持项、依赖、作用域和资源；未知结构、无效配方、越界引用与可执行内容明确拒绝 |
| 字体 | 实际加载、各正式语言的字形/数字/标点/字重、后备、等宽对齐、离线与加载失败 |
| 皮肤与组件 | 浅深色及必要状态、颜色语义、对比、非颜色提示、焦点、触控与减少动态效果 |
| 语言 | 登记及实际加载、缺失/重复键、主人冲突、参数/语言规则、覆盖与后备、结构化状态和错误的展示 |
| 真实页面 | 规格板、现存插件、Builder 与嵌入的交互、长文本、缺字、遮挡/截断/溢出、窄屏、书写方向及相关组合 |
| 更新结果 | 准确文件/资源版本、实际入口使用的选择、状态保留、作用域隔离与可撤销结果 |

结果区分通过、未通过和未验证，关联真实版本与范围，指出文件字段、组件/状态或页面、问题、阻断条件和修正方式。必要检查未完成或阻断问题未解决时不能正式应用；可保留草稿与可呈现预览继续修订。文件、字体、语言或共同规格改变后旧结果不能为新版本背书，直接应用也无法绕过校验。

可读性与交互底线不能因换肤/语言而取消，美感和个人偏好由真实预览及用户判断。无效语言包不能覆盖有效语言，必要文案未覆盖不能标为完整发布；合法用户内容不进入界面翻译检查。现有资源体积、公开合同、包边界和安全要求继续有效，本书不放宽门禁。

### 10.2 共同操作与恢复结果

设置、助理、Builder 与获授权入口从共同动作目录完成读取/选择、文件导入/导出、资源导入、草稿生成/修订、保存/管理、校验/预览、应用/撤销和独立恢复，使用同一实现、数据和权限。身份、Home、项目和安装从可信上下文获得，不由输入自称；外部入口不默认获得个人配置写权限。

请求携带准确定义/起点及预期版本，重复请求不重复创建或应用，重启可查询、继续或放弃原任务；未知结果先核对原请求，不换键重发。保存与应用/撤销核对当前版本，旧草稿不覆盖其他入口的新选择，撤销不覆盖后续修改。

取消、撤权、停用期间返回的模型结果不再写记录；异步结果提交前复查原授权、取消与版本。无模型、超时、无效/低质量输出或验证失败保留要求与有效草稿，说明阶段与原因，原外观与工作继续可用。

可确定的问题由共同校验处理，模型修订受原授权和明确预算限制，无界重试或静默放宽规则不可用。自动重试展示投影不重复业务提交；配置保存、资源加载、预览和各入口更新分别如实反馈，未知或部分成功不报告为全部生效。

## 11. 验收标准

以下验证属于未来实现，当前均**未运行**。自动化测试名或注释应引用对应编号；视觉判断单独记录，不能用结构检查代替。

1. **FSS-01** 同一皮肤能使用不同字体，同一字体能用于不同皮肤；明暗与密度独立。明确选择的字体不会被换皮肤覆盖，“跟随推荐”能够解析到正确版本。
2. **FSS-02** Soft Workbench 保留基线；Folio 在真实工作台、控件与插件组合上呈现丰富协调配色、圆润字体和活泼感，浅深色均可读。[人工] 最终视觉由一骏判断。
3. **FSS-03** 中文、英文、数字、标点、真实字重和长标题正确呈现；缺字/字体失败时后备可观察，离线可用。界面圆润方案不破坏代码和终端等宽对齐。
4. **FSS-04** 导入有效字体后可选择、预览和重新启动使用；格式损坏、未授权路径或无有效字体内容被拒绝，既有外观不受影响。
5. **FSS-05** 标准规格板与 Builder 候选板来自同一规格文件、组件目录和真实渲染；新增组件不用维护第二份风格或文案清单，完整状态随字体、皮肤和语言更新。
6. **FSS-06** 真实目录中的每个现存插件入口正确消费字体、皮肤与语言，包含岛、设置、侧栏、菜单、浮层和嵌入；自动检查能识别刻意写死的界面字体、颜色或未接入语言文件的文案，合法内容格式不被误判。
7. **FSS-07** 切换后已打开与新打开的页面、嵌入和 macOS 入口使用正确外观版本；无需重载或重生成插件，草稿、选区、滚动、展开与 Runtime 身份保留。
8. **FSS-08** 未经来源/窗口/安装校验的嵌入外观更新被拒绝；一个预览的临时外观不能污染别的预览或 Home 的正式选择。
9. **FSS-09** 外部插件仅装 contracts 与 SDK 即可消费字体、皮肤和语言的公开能力；样例在切换三项选择与明暗后成立，SDK 没有私有依赖或转出。
10. **FSS-10** Builder 新生成及已安装的生成插件自动跟随字体、皮肤与语言；生成结果使用语义角色和语言定义，不烘焙当次外观或单一语言。验证发现布局、缺字或文案问题后进入原有修订流程。
11. **FSS-11** 真实个人助理和模型能从自然语言或受支持的参考材料创建草稿、展示真实组件预览、接受局部修订、保存并应用；未发生的加载、验证或应用不能被报告为成功。
12. **FSS-12** “先看看”不改变正式选择；“直接换成”可在原授权范围内完成，无重复确认。生成后的明确应用与手动设置调用同一 owner，反馈含实际结果和可用撤销入口。

14. **FSS-14** 重复请求及重启恢复不会重复生成方案或应用；旧结果与并发设置修改发生冲突时被保留为草稿，撤销不能覆盖后来的选择。
15. **FSS-15** 自定义库、准确版本、选择及导入资产在重启后恢复，备份与升级保留。对内置版的覆盖或在用资源的直接删除被拒绝，资源问题有可操作恢复。
16. **FSS-16** 无效配方、任意脚本/选择器/外部样式地址和越界资产引用被拒绝；校验失败不放宽焦点、状态、触控与可读性要求。

22. **FSS-22** 同一 Skill 能指导内置规范下的制作及用户自定义创建/局部修订，保留用户约束，输出共同格式的外观文件；用户修改内置方案不会覆盖原版，Skill 不增加权限。
23. **FSS-23** 共同校验覆盖文件/引用、真实字体、皮肤语义、语言键与参数，以及组件/插件/Builder 的实际呈现；结果区分通过、未通过、未验证，能定位问题、阻断条件与对应版本。

35. **FSS-35** 启动恢复语言偏好，运行中无需重启或刷新整页即可切换，同一入口已打开的宿主、插件、规格板、Builder 与嵌入同步更新；草稿、选择、滚动、展开、会话和异步反馈正确保留。

37. **FSS-37** 缺失/重复键、owner 冲突、参数不一致及无效语言文件可被检查发现，失败不覆盖有效选择；实际检查译文长度、字体、换行与相应书写方向，不能放宽可读性要求。
38. **FSS-38** 语言切换不改项目名、用户正文、资料、成果、历史对话、终端输出或协议取值；个人助理对话与生成内容遵守本轮明确语言要求，原始事实与回执保留。
39. **FSS-39** 日期、时间、数字和计数/复数在各正式语言下正确展示，参数替换无遗漏且不按中文词序拼接；原始时间、时区、金额、单位和数值不因语言改变。

### 11.1 验收证据与未定范围
