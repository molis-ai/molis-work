### 1.2 市场按钮现在长什么样

`renderPickerExtend`（`:226-242`）用设计系统的 `renderButton` 画两颗按钮：市场在前，创作台在后。外面包一层：

```
<div class="plugin-picker-extend" data-global-menu role="group" aria-label="添加与创作插件">…</div>
```

市场按钮的 HTML 按源码推出来是这样（`packages/plugin-sdk/src/ui/button.ts:25-47`、`ui/html.ts:16-22`）：

```
<button type="button" class="mw-btn mw-btn--secondary mw-btn--sm plugin-picker-extend-btn" data-slot="button" data-plugin-id="market" data-work-surface-open="market" title="插件市场">
  <svg …></svg><span data-slot="button-label">插件市场</span><b class="plugin-rail-update-count" data-market-update-count hidden aria-live="polite"></b>
</button>
```

（实际是一行，这里为了看清分了行。）要点：

- **没有 `aria-label`。** 不是只显示图标的按钮，`renderButton` 不写 `aria-label`（`button.ts:45`）。名字在 `title` 和 `<span data-slot="button-label">` 里。
  - 客户端拿到更新数后才用 `paintUpdateCount` 补上 `aria-label`（`apps/workbench/src/scripts/client/plugin-workbench.ts:34-43`）。
- **没有 `data-directory-open`。** `"market"` 在 `DIRECT_WORK_SURFACE_IDS` 里（`apps/workbench/src/plugin-catalog.ts:99-103`）。
- **属性顺序固定。** `attrs` 按写入顺序输出，`title` 是最后一个，后面紧跟 `>`。
- **标记在按钮里面、`</button>` 前面。** 靠 `:236` 的 `html.replace(/<\/button>$/, …)`。
- **客户端怎么找它：** `[data-global-menu] [data-plugin-id="market"]`，再在里面找 `[data-market-update-count]`（`plugin-workbench.ts:22-23`）。

### 1.3 为什么旧断言不能照搬

旧断言（`tests/plugin-market-catalog.test.ts:49`）：

```
/data-plugin-id="market"[^>]*aria-label="插件市场"[^>]*>[\s\S]*data-market-update-count hidden/
```

它要求市场那个标签上有 `aria-label="插件市场"`，而 `renderPickerExtend` 的市场按钮在服务端渲染时没有 `aria-label`（1.2）。所以新用例改为断言三样：
- 按钮的名字：`title` 加按钮文字；
- 外层带 `data-global-menu`（客户端靠它找）；
- 标记的完整写法，以及它在按钮里的位置。
