状态：2026-11-16，Codex（本机）58 主会话；按一骏指定的「右侧浮窗里切换，不在主窗」完成第三版样稿，等待实物确认。未写产品代码，未做产品或本人验收。本批原需求唯一入口为 [subagent-interaction §11](../../../specs/subagent-interaction/spec.md#11-第-58-批开工与定样2026-11-16)。

沿第 32 批已选的 E 整体版：主助理对话保留在中间，右上角展开已有任务浮窗。点任务卡里的步骤，**只把右侧浮窗内容切成子任务对话**；左上角返回任务卡，嵌套子任务返回上级。主助理的内容、滚动位置和标签都不变，背后文档不换页。第三版只落实这条用户指定动线，不再提供主窗切换的 A/B 选项。

底部仍是一个统一输入框，「发给」跟随明确选择；关闭浮窗或点主助理标签后恢复主助理接收者。已发出的请求锁定原目标，迟到回执不改变当前阅读对象。打开子任务不启动执行。窄屏时同一个浮窗覆盖在主窗上方，返回仍在浮窗内，不把主对话替换成子任务内容。

node docs/design/subagent-interaction-58/export.mjs
python3 -m http.server 4458 --bind 127.0.0.1 --directory docs/design
