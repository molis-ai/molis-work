## 三个方案只差在「从草稿到采用」

用户选了 B。下表留着三行，说明为什么不是另外两个。

| 方案 | 怎样看草稿、怎样采用 | 取舍 | 注意力与认知负荷 |
| --- | --- | --- | --- |
| A 首页里直接是草稿（没选） | 草稿做好后，首页底下一行写「第 3 版草稿好了」，点「看草稿」，首页换成草稿。顶上钉一条草稿条：草稿标记、真实／示例内容、检查摘要、「看现在的」「放弃」「采用… ↵」。「采用…」弹出一个对话框，列出会改什么，再采用；采用后可以撤销 | 草稿和用起来时一样大，能真的点、真的筛，看得最准。所有决定都在一条上。代价是看草稿时看不到现在的页面，要点「看现在的」切过去 | 一屏一个焦点。草稿条一直在顶上，不会忘了自己在看草稿。决定集中在一处，要记的东西最少 |
| **B 现在和草稿并排（用户已选）** | 首页分成左右两栏：左边是在用的第 2 版，右边是第 3 版草稿（带改了什么、检查和问题）。底下钉一条：检查摘要、「放弃草稿」「采用… ↵」。窗口窄于 1180 时变成「现在／草稿」切换。采用同样走对话框 | 一眼对比新旧，看得出差在哪 | 两个焦点，表格页挤在半宽里，信息密度高，负荷最大。窄屏退化成切换，等于 A 少了草稿条 |
| C 引导框架里做完再回来（没选） | 「改这个页面」打开 04 的引导框架，盖在首页上：① 说想要的 → ② 看草稿 → ③ 核对（检查与会改什么）→ ④ 采用，底栏写「几/4」和 ↵。中途「回首页」，草稿留着，首页标签上有个点 | 和第一次生成首页同一套框架，最可预期；核对单独占一步，不会漏看 | 一次只做一件事，分块最清楚。代价是步数多，在第 3 步想改草稿要退回第 2 步；做草稿时离开了首页 |

三个方案共用的规则（随 B 一起定，不变）：

- **草稿不替换在用的页面。** 采用之前，在用的页面不变，别的窗口也不变；助理在做草稿时，页面照常能用。
- **每份草稿都要过检查才能采用。** 检查四项：只用公开的操作；在隔离里运行，不碰密钥、别的数据和本机文件；只用本项目的内容；打开速度、中英文和窄屏都排得下。没过的说清是哪一块、为什么，给「交给助理改」或「去掉这一块再采用」，其余部分不受影响。
- **预览默认用真实内容，示例内容另外标明。** 草稿是试用：会改数据的命令按钮（如「标完成」）旁标「预览中不执行」，点了不写任何地方，就地说明「采用以后才能真的执行」（照第 20 批合同 §6.5、安全不变量 S-home-page-authority（待第 37 批真实接入后登记），试用主体调命令动作被拒）；只有读和筛选在草稿里照常。
- **采用前列出会改什么。** 每项写明范围（这个项目）；新的许可单独一行，可以不勾，不勾就先采用其余部分；已经给过的许可写「沿用」，不再问；最后一句写不会做的事（不改待办和 PR、不用到别的项目）。缺依赖时说明哪一块先空着，依赖回来后它自己出现，不用再采用一次。
- **采用分步说进度。** 每一步标「已生效／正在做／还没做／没成」。有一步没成，首页不换，给「只重试这一步」「先采用其余部分」「退回已做的」；重试不重复已做的步骤。采用完给「撤销」。
- **你改过的地方照旧。** 新版本和你的手动修改冲突时，用 19 的对照：你改的和新版本各一张小卡，选「保留我的／用新的／合并后再改」，选好才能采用。
- **在用时出问题，就地说、就地修。**
  - 页面里的操作没成：留在那一行，写原因，给「刷新这一行」。
  - 许可被收回：那几个按钮变灰，并写明什么时候、在哪里收回的，给「看这个页面的许可」；看和筛选照常。
  - 某个插件停用：只有它那一栏空着，给「启用」。
  - 新版本打不开：先回到上一可用版本，写明原因，给「再试一次」「交给助理看看」。所有生成页面都打不开时，回到基础首页。草稿、你的修改和打开的标签都不丢。
- **版本与恢复在一个列表里。** 标题旁的版本按钮弹出列表：草稿、在用、上一可用、你改过几处、没打开的，最后是「基础首页」。换回只换页面，不会重做或撤回已经做过的事，列表底下写明这一点；换回之后可以撤销。更多菜单里也有「回到基础首页」，回去后首页上留一行「已保存，随时换回」。
- **页面只属于它的项目。** 切到另一个项目，用那个项目自己的首页；草稿和页面留在原项目，回去还在。
- **重启后接着用。** 没采用的草稿还在，首页底下一行说「上次没采用的第 3 版草稿还在」，给「看草稿」「放弃」。
- **换页面时整页淡入**，直接用 14 定的「换外观的淡入」，不另做；减少动态效果时直接换。

## 状态（原型条「状态」）

| 状态 | 看什么 |
| --- | --- |
| 正常 | 改这个页面 → 助理在做 → 看草稿 → 采用 → 已换成第 3 版，可撤销 |
| 草稿没通过检查 | 「PR 状态」一栏想直接读 Coding 的数据，已在隔离里拦下；采用按钮不可点并说原因；「交给助理改」后检查都过，或「去掉这一栏再采用」 |
| Coding 已停用 | 草稿和在用的页面里，只有「PR 状态」一栏空着并给「启用 Coding」；采用时不要这个许可，写明 Coding 启用后这一栏自己出现 |
| 和你改过的地方冲突 | 第 3 版把「谁在做」叫回「负责人」：两张小卡对照，三个选择，选好才能采用 |
| 采用时一步没成 | 「记下读 PR 的许可」没成：首页不换，第 3 版已存好；三个出路 |
| 页面里的操作没成 | 在用时点「标完成」：那一行下面说小林刚改过、给「刷新这一行」；刷新后再点就成了，并可撤销 |
| 页面的许可被收回 | 「标完成」全部变灰并说明；看和筛选照常 |
| 新版本打不开 | 已换成第 3 版时：首页回到第 2 版，提示第 3 版在隔离里出错停下 |
| 生成的页面都打不开 | 回到基础首页，提示第 3、2 版都没打开，页面与修改都在 |
| 重启后草稿还在 | 在用第 2 版时，首页底下一行说草稿还在 |
| 切到另一个项目 | 首页换成「官网改版」自己的基础首页，什么都不带过去；切回来草稿还在 |
