## 1. 背景

`tests/assistant-dock-ime.e2e.test.ts` 的四个 `Input.dispatchKeyEvent`（输入法自己的回车 `:43-44`，229；组合结束后的普通回车 `:59-60`，13）同时给了 `windowsVirtualKeyCode` 和 `nativeVirtualKeyCode`。BL-393（`specs/BACKLOG.md:104`）的说法：229 是 Windows 的 VK_PROCESSKEY，作为原生键码发给 macOS 的 Chrome 会让页面变成隐藏（`document.hidden` 为真），之后要页面可见才发生的事就不发生；13 在 macOS 上也不是回车的键码；Linux 上不会红。证据如下，其中前两条是已经修过的同类，第三条说明这个文件本身没量过：

- #859（`ded8ea771`，Coding 问卷卡）：提交说明写明原生 229 在 macOS 的 Chrome 上变成一个让页面隐藏的键，去掉后两例过。现状 `tests/coding-question-card.e2e.test.ts:353-356`（注释加两行事件，只带 `windowsVirtualKeyCode: 229`）。
- #461（`bb2bb07ca`，Issue 输入法用例）：根因记在 `specs/repository-anti-corruption/spec.md:2406`：原生 229 在 macOS 上引出大量 `Unidentified` 键盘事件，连空白 iframe 的求值都卡住；只去掉这一个字段，原六条测试 6/6 过。现状 `tests/issue-capture-page.e2e.test.ts:165-167`。
- 这个文件没在 macOS 上跑过：BL-393 写的时候本机浏览器用例暂停，所以「隐藏页面、求值卡住」在这里是推断，不是量到的。Linux 上是绿的：main 夜间 run `40596890927` 产品子集 1/2（job `122514957315`）有 `[1/216] pass  tests/assistant-dock-ime.e2e.test.ts  23.6s`。它在产品子集里是浏览器冒烟之一（`tests/ci-product-subset.txt:19`）。
- 13 那两个事件去掉原生码不会改输入框收到的回车：同一个输入框的回车，`tests/assistant-*.e2e.test.ts` 有 11 个文件只带 `windowsVirtualKeyCode: 13`（例：`tests/assistant-handback.e2e.test.ts:62-63`、`tests/assistant-follow-live.e2e.test.ts:58-59`）。

这个用例现在证明三件事，改完一件不能少：① 组合中输入法的回车送到输入框、不发送（`:46`、`:48`）；② 另起一次组合选候选，候选进输入框、不发送、不开工作面板（`:55-57`）；③ 组合结束后的回车发送一次（`:61-62`）。它守的产品代码是 `apps/workbench/src/scripts/client/assistant-island.ts:1926` 的 `event.isComposing || event.keyCode === 229`。

## 2. 目标

1. 该文件里没有 `nativeVirtualKeyCode`；四个事件的其余字段、两个测试的全部断言、等待和超时不变；整个文件在 Chrome 上绿（`RAC-1459`）。
2. 去掉产品里的组合判断，改后的用例仍红，并且红在 `:46`「nothing was sent while composing」；还原后绿（`RAC-1460`）。
3. `specs/BACKLOG.md` 里 BL-393 一行已删。

## 3. 不做

- 不放宽、不删、不改任何断言、超时、等待，不改 `type`、`key`、`code`、`windowsVirtualKeyCode` 的值。只删 `nativeVirtualKeyCode` 字段。`:48` 的 `(code === 229 || composing)` 是二选一，不收紧（见第 7 节变异 B）。
- 不改另外五个还带 `nativeVirtualKeyCode` 的测试（`home-side-surfaces`、`keyboard-groups`、`overlay-placement`、`todo-batch-menu`、`truncation-tip`）：BL-393 没点它们，发的是别的键。不开 BL 行。
- 不改产品代码和 `tests/fixtures/goal-browser.ts`；第 7 节的变异只在本地改一次产品文件，还原，不提交。
- 不改 `specs/post-anticorruption-roadmap/spec.md:181`（那一行提到 BL-393，#1324 在改这份文件）：列进【交接】，统筹处理。
