## 1. 背景

本机 MCP 是人选一个本地程序，由宿主用固定的程序、参数、目录和几个环境变量名把它拉起来。环境变量的名字由人在设置页填，值走受保护表单。程序启动时会从自己那一族环境变量里读选项、模块路径和启动代码，所以这些名字不许填。

现在的拒绝在一处：`apps/local-host/src/connector-local-mcp.ts:28` 的 `reservedEnvironment`：

`/^(?:PATH|HOME|SHELL|ENV|BASH_ENV|CLASSPATH|_JAVA_OPTIONS|JAVA_.*|JDK_.*|PYTHON.*|PERL.*|RUBY.*|NODE_.*|LD_.*|DYLD_.*)$/u`

它上面的注释（`:26-27`）写明做法：按族的前缀拒绝，不逐个名字列，因为运行时下个版本会新增同族名字。

这条规则在三个入口生效，都经 `validateLocalMcpLaunch`（`:31`，名字检查在 `:33`）：

- 准备：`apps/local-host/src/connector-local-mcp-plan.ts:23`（动作 `connectors.local.prepare`）。
- 接入：`apps/local-host/src/connector-local-mcp-setup.ts:19`。
- 每次拉起已存的连接：`connector-local-mcp.ts:51`（`useLocalMcpClient`）。

名字先要过形状检查 `^[A-Z_][A-Z0-9_]{0,99}$`（`connector-local-mcp.ts:33`，动作入参的 schema 同一个写法在 `connector-local-actions.ts:27`），所以小写的 `npm_config_*` 根本进不来，只需要处理大写形式。

BL-181（`specs/BACKLOG.md:210`）说名单还漏了：`ZDOTDIR`、`GCONV_PATH`、`DOTNET_STARTUP_HOOKS`、`PHPRC`、`LUA_INIT`、`NPM_CONFIG_*`。我在 main 上核过：这六个现在都不被拒；仓库里除 BL-181 那一行外，没有任何代码、测试、文档把这些名字当环境变量名用（`git grep` 过）。可执行文件由准备方选，真正的闸门是人的批准，所以这是纵深防御，优先级低，但切得小、行为明确。

现有测试：`tests/security-invariants-local-mcp.test.ts`

- `:82-86` 的 `LOADER_FAMILIES` 是一张「族 → 名字」表。
- `:91-99` 对每一族各开一个用例：用这些名字接入，断言以 `connector.mcp.configuration` 拒绝、没有写 `child-pid`（子进程没起）。
- `:101-106` 对表里全部名字走准备动作，断言同一个错误码。

所以往表里加行，两处断言自动覆盖，不用再写新循环。夹具程序（`:12-22`）只要 `SERVICE_KEY` 对、没有继承 `ASC_PARENT_PRIVATE`，就会起来并写 `child-pid`，额外的环境变量它不管；一个没被拒的名字会让「应当拒绝」的断言变红。

S-36 那一行（`docs/system/SECURITY-INVARIANTS.md:50`）把拒绝的名字逐族写出来，要和代码同步。

测试通过包名 `@molis-ai/molis-work-app-local-host` 取 `connectLocalMcp`，加载的是构建产物 `dist`，`scripts/run-tests.mjs` 不会替你构建。

## 2. 目标

1. 下列名字在三个入口都被拒（错误码不变，仍是 `connector.mcp.configuration`）：
   - 逐个名字：`ZDOTDIR`、`GCONV_PATH`。
   - 前缀成族：`DOTNET_*`、`PHP*`、`LUA_*`、`NPM_CONFIG_*`。
2. 名字相近、不属于这些族的凭据名仍然能用：`NPM_TOKEN`、`PHOTO_API_KEY`。
3. S-36 那一行把新增的名字和族写进去，和代码一致。
4. BL-181 那一行删掉。

## 5. 做法

**已定（main 上核过）**

- 逐个名字放进现有的名字交替里（和 `BASH_ENV`、`CLASSPATH` 并列）：`ZDOTDIR`、`GCONV_PATH`。族用前缀，写法同 `PYTHON.*`、`NODE_.*`：`DOTNET_.*`、`PHP.*`、`LUA_.*`、`NPM_CONFIG_.*`。
- `PHP.*` 不带下划线，是为了一并拒 `PHPRC` 和 `PHP_INI_SCAN_DIR`，写法和 `PERL.*`、`RUBY.*` 一致。`PHOTO_API_KEY` 不以 `PHP` 开头，不受影响。
- `LUA_.*` 覆盖 `LUA_INIT`、`LUA_INIT_5_4`、`LUA_PATH`、`LUA_CPATH`。
- 测试表加的行（名字都要是形状检查放得进来的大写）：
  - Zsh：`ZDOTDIR`
  - glibc：`GCONV_PATH`
  - .NET：`DOTNET_STARTUP_HOOKS`、`DOTNET_ADDITIONAL_DEPS`
  - PHP：`PHPRC`、`PHP_INI_SCAN_DIR`
  - Lua：`LUA_INIT`、`LUA_INIT_5_4`、`LUA_PATH`
  - npm：`NPM_CONFIG_SCRIPT_SHELL`、`NPM_CONFIG_PREFIX`
  
  每族里有一个不在 BL-181 那一行上的名字，用来证明是前缀在起作用，不是靠逐个名字。
- `NPM_CONFIG_.*` 保留整族（统筹 10-28 定）：npm 的认证配置名也以 `NPM_CONFIG_` 开头，会一并被拒，这是有意的取舍，PR 说明里写明，不写成「只拦 loader」。要给 npm 令牌的，用不在族里的名字（例如 `NPM_TOKEN`，由程序自己的 `.npmrc` 引用）。【方案】问题 1 里不用再为这一族给去留判断，只写依据。
- 新行上面加一行英文注释，写 `RAC-1350` 和 BL-181。
- 接受用例：`SERVICE_KEY` 之外再带 `NPM_TOKEN`、`PHOTO_API_KEY`，用现有的 `withLoader` 模式或类似写法接入，断言 `status === "connected"`、`child-pid` 存在、工具里有 `record`。测试名以 `RAC-1351` 开头，用现有的 `input(home.home)`、`openTestHome`，不新增 import。
- 第三个入口（`RAC-1352`，统筹 10-28 按二线预审加）：三个入口共用 `validateLocalMcpLaunch`，前两个是准备（`connector-local-mcp-plan.ts:23`）和接入（`connector-local-mcp-setup.ts:19`），第三个是已存连接每次拉起（`connector-local-mcp.ts:51`，`useLocalMcpClient`）。写法：先用 `SERVICE_KEY` 正常接入，记下 `child-pid` 后删掉这个文件；再经各自 owner 的公开写法把这条已存连接改成带一个新名字（例如 `NPM_CONFIG_PREFIX`），模拟改规则之前存下的连接：协议配置里的 `launch.environment_names` 经 `withConnectorProtocols` 改；这个名字的值经 `connectorProtocolSecrets` 写进已存的凭据（否则 `localMcpEnvironment` 因为名字和值对不上，同样报 `connector.mcp.configuration`，用例会为错的理由变绿）；`withConnectorConnections` 只管连接记录，改不了 `launch` 和凭据。这两个导出从包根 `@molis-ai/molis-work-app-local-host` 取（`apps/local-host/src/index.ts:137`），加进第 7 行已有的那条 import，统筹 10-28 准许（回 #1332 6471116993）；不从 `../apps/local-host/dist/…` 或 `src` 取；然后调一次它的工具（照 ASC-15 那例的 `reference(...)` 调法）。断言：以 `connector.mcp.configuration` 拒绝；没有重新写出 `child-pid`；拒绝前后三样各比一次 `deepEqual`（照 ASC-15）：协议配置（`withConnectorProtocols` 读）、凭据（`connectorProtocolSecrets` 读这条连接用到的那几个名字）、连接记录（`withConnectorConnections` 的 `store.require(...)`）。报错文字两条路一样，所以能区分的只有先红：改正则之前这一例必须红在子进程起来了。除上面两个包根导出之外还要新增 import，或 `ConnectorProtocolStore` 没有公开方法能改 `launch`（只能写 SQL、走内部路径或加新的生产接口），先停下，在【方案】里说，不自己开路。
- 改完 `connector-local-mcp.ts` 后，跑测试前先 `pnpm --filter @molis-ai/molis-work-app-local-host run build`（`--filter` 在 `run` 前），否则测试读的是旧的 `dist`。
- S-36 那一行：族清单（现在是「Node `NODE_*`、Python `PYTHON*`、Java `JAVA_*` 与 `JDK_*`、Perl `PERL*`、Ruby `RUBY*`」）后面补「.NET `DOTNET_*`、PHP `PHP*`、Lua `LUA_*`、npm `NPM_CONFIG_*`」，「另拒」那一串里补 `ZDOTDIR`、`GCONV_PATH`。行的其余部分不动。

**【方案】里要回答的问题**（先在本机把用例写出来、跑一遍，把结果写进去，再等批）
