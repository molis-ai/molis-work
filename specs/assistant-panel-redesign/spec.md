# 助理面板与底栏：标签页、左右分栏、四块左栏

状态：进行中。用户 2026-09-30 确认方向（“方向对”），并补充要求把面板的动线、信息陈列、布局、按钮交互、动效与微交互都优化到位；细节取舍按推荐（用户授权），记入 `specs/system-assistant/implementation.md` 2.1。第一期（面板，含第 3.5 节交互、第 3.6 节视觉）、第二期（底栏）、第 3.7 节对话里的呈现（用户同日追加的要求）已实现并在浏览器验证。第三期（步骤清单）面板一侧已实现：合同有 `AssistantRound.steps`，路径里画成打勾清单；Host 把 Prologue 的 `update-todo` 放进工作视图，要等系统级助理会话补上 `AgentRunView.todo` 后接一行映射。

## 1. 为什么改

用户反馈底栏和助理面板“内容太多太杂，没有体系”。实测（测试 Home，2026-09-29）：

- 底栏静止 15 个控件；输入框一段 6 个，最多 11 个；另有 10 种弹层。导航（插件选择）、通知、搜索、对话挤在输入框里。
- 铃铛“需要你看看”里 33 条，几乎全是“做完了”，失去信号。
- 发送前要面对四个互相牵制的选择：由谁来做、角色、方式、放在哪里。
- 面板对话上方最多 3 个容器、9 种信息（对象、可撤销的修改、记忆建议、后台任务、停止时仍在执行、定时、受托于、分工、用量），按数据类型堆，压住对话。
- 同一件事多个叫法（分工 / 子任务；对象 / 材料 / 引用 / 正在看），状态词 20 多个。
- 模型记下的步骤清单（`update-todo`）从未显示，只有“更新工作步骤”一行。

## 2. 一条规则

**一项工作 = 一段对话 = 一个标签。** 要你动手的事只有一个出口。面板左栏讲这项工作的来龙去脉，右栏只放对话。

## 3. 面板

### 3.1 标签页

- 面板顶部一排标签，一个标签是一项工作（session）。当前标签就是下一次发送的去向，所以面板打开时输入框前不再显示“继续：某工作”芯片。
- 标签记号：等你（确认、回答、需要核对）琥珀点；进行中转圈；做完但还没看蓝点；没完成红色三角；其余无记号。
- “＋”开新标签（新工作）；发出第一句后，新标签变成这项工作的标签。
- 关掉标签不删工作，工作仍在“全部工作”里；最多开 6 个，再开时关掉最久没看的那个（当前标签除外）。
- 开着哪些标签只记在本人浏览器（localStorage），换设备为空。
- 标签条右端：全部工作（列表，含搜索前的全部）、收起/展开左栏、最小化。

### 3.2 左栏：概况、路径、材料、成果

| 块 | 回答 | 内容（吸收了原来的） |
| --- | --- | --- |
| 概况 | 现在怎样 | 状态与当前一步；属于哪里；谁来做（助理 / 角色 / Coding 与方式，可改）；交给 Coding / 回到助理；暂停、继续、停止 |
| 路径 | 怎么走到这里 | 受托于（上一级工作与验收）；起点；专业会话（在 Coding 打开）；步骤清单（第三期）；子任务（打开、停止、收回）；之后（定时，取消） |
| 材料 | 用了什么 | 下次发送带上（可去掉、可加入本轮、另一项工作也在用它时可切过去）；用过的（对象的版本变化；每轮带上的文件、图片、方法、能力） |
| 成果 | 做出了什么 | 产出与改过的内容（打开）；可撤销的改动（撤销）；后台任务；停止时仍在执行；建议记住（记住 / 不用） |
| 用量 | 花了多少 | 放在左栏底部，折叠；到上限时自动展开 |

- 没有内容的块不显示。有东西要你处理的块（对象被改、可撤销、建议记住、子任务等你）在块头标出。
- 新工作标签的左栏：谁来做（助理 / 本项目发布的角色 / Coding Agent 与第一轮方式）、放在（本项目 / 个人）、下次发送带上。原来输入框“+”里的这些选择在面板打开时都在这里。

### 3.3 右栏：只有对话

消息、过程 · N 步、助理回复、等你的卡片（确认、提问、操作卡）、出错时的一行说明与下一步。每轮带上的材料显示为你消息下的一行小字。运行时自己停下的一轮，写它给的原因；人手动停的仍写“已停止”。

### 3.4 宽度

- 宽屏（≥ 1240px）：左栏 272px，右栏对齐在底栏输入框正上方，左栏向左展开。
- 中等（601–1239px）：左栏默认收起，标签条上的“详情”按钮把它作为抽屉盖在对话上。
- 手机（≤ 600px）：面板占满宽度，“详情”盖住整个面板主体。
- 任意宽度都可手动收起或展开，记在本人浏览器。

### 3.5 动线、按钮与动效

**动线：先看到“该做什么”，一下就到。**
- 概况顶部是状态小胶囊（等你为琥珀点、进行中为呼吸的绿点、完成、没完成为红点），暂停、继续、停止在同一行右侧。
- 有要你动手的事时，概况里出现唯一的主按钮：去确认 / 去回答 / 去处理 / 去核对 / 看等你的子任务。点了把对话滚到那张卡并短暂描边，焦点落在卡上的第一个按钮；窄屏的抽屉先让开。
- 要你动手的卡在视野下方时，对话底部出现“↓ 等你确认”胶囊；你往上翻看时来了新内容，出现“↓ 新消息”。
- 新工作标签的对话区给起点：从这一页开始（页面的起步建议）、继续最近的工作（带标签记号）、@ 与 / 与拖入文件的提示。

**信息陈列：块可以折叠，块头说重点。**
- 路径、材料、成果三块的块头可点，折叠状态记在本人浏览器。块头右侧写数量或需要注意的事：“1 个在等你”“1 项有变化”“1 条建议等你认可”“2 项可撤销”，需要注意的用琥珀色和圆点。
- 行的名字就是打开它的按钮，整行都是点击区；不再每行一个“打开”。停止、收回、取消这类次要操作平时不显示，指针或键盘到这一行时出现，触屏上常显。
- 对话里第二轮起，每轮开头有一条带时间的分隔线；助理的回答下有“复制”（悬停出现，复制后显示“已复制”）。

**按钮与反馈。**
- 面板里所有按钮按下时轻微回弹（与底栏同一个 130ms 弹簧）；异步操作进行中显示忙碌，出错用提示条说明，按钮恢复。
- 标签：中键关闭；左右方向键切换；Delete 关闭当前焦点标签。Esc 一层一层退：全部工作列表 → 抽屉 → 面板。
- 轮询重绘不再挪动已经在位的节点，所以正在输入的回答、用键盘停在“允许执行”上的焦点，都不会每几秒丢一次（原来就有的问题，这次一起修了）。

**动效（都遵守“减少动态效果”，自动化下静止）。**
- 只用设计刻度里的时长（130 / 250 / 420 / 640ms）和两条曲线，不动画布局属性，只有加载指示会循环（`tests/soft-workbench-refinement.test.ts` 把关）。
- 切换标签：新工作的对话和左栏轻微上浮淡入（250ms）；抽屉从左边滑入；全部工作列表从按钮处长出；新消息和新卡片上浮出现；进行中的记号是转圈（与其他加载指示同一个）；“等你 N”数字增加时弹一下；起步按钮依次出现。
- 折叠不动画高度：收起立刻收起，展开时这一块的行上浮出现一次。“去确认”的描边 640ms 后消失。
- 起始透明度不为 0：即使动画被暂停（页面在后台），内容也看得见。

### 3.6 左栏的视觉：用形状引导，而不是文字罗列

用户看了第一版左栏后指出“更像文字陈列，没有视觉和布局的优化，不能引导用户使用”。这一节是对这条反馈的回应：
- **概况是一张卡**，底色随状态变：等你是淡琥珀，进行中是淡绿，没完成是淡红。卡里只有一个整宽的主按钮（去确认 / 去回答……），下面是“属于、谁来做、方式”。
- **还等你处理**：概况下面单列一组行动卡，放除了对话里的卡之外所有等你的事，例如等你回答的子任务、用过之后被改过或已不存在的内容、建议记住的事。每张卡有类型图标，写清是什么和为什么，按钮直接在卡上。这一组不能折叠，块头是琥珀色铃铛加数量。
- **路径是一条竖线时间线**：受托于、起点、专业会话用旗子或代码图标作节点；子任务节点写“1/2”，带进度条，每个子任务前是状态图标（完成打勾、等你琥珀、进行中转圈、失败红色），等你的那一行整行淡琥珀；“之后”是虚线节点加时钟卡片。
- **材料**：“下次发送带上”是一块虚线投放区，文件可以直接拖进去，里面每样东西是带图标的小块，可以去掉；用过的材料两个一行，排成带图标的格子，被改过的用琥珀边。
- **成果**：产出的东西是卡片（类型图标、来源插件，点开）；改动是卡片，撤销是带图标的按钮，已撤销的划掉变灰；后台任务带转圈。
- 类型图标来自共享图标集（文档、待办、图片、代码、方法、子任务、提醒……），按对象种类和打开位置选。颜色只表达状态：琥珀等你，绿色完成，铜色建议，红色没完成。

### 3.7 对话里的呈现：读得懂、点得到、知道下一步

用户追加的要求：对话里的交互卡片、信息呈现、Markdown 和常见文件格式，都要好用易用、对人有引导，可以参考 Coding App。做法：

**回答按 Markdown 读，但只生成文字节点，不插 HTML。**
- 支持标题、粗体、斜体、删除线、行内代码、链接（只认 http、https、mailto，新窗口打开）、引用、分隔线、嵌套列表、任务清单（打勾的变灰）、表格（按分隔行对齐，太宽时在自己的框里横向滚动）。
- 回答里用「」写到的名字，如果正好是这项工作用到或做出的对象，就变成可以点开的小块，带类型图标。回答直接指向那样东西。

**代码块沿用 Coding App 的着色。**
- 着色器取 Coding 插件公开导出的 `codeLanguage`、`codeTokens`，带源码进面板脚本，不引用它的实现文件。颜色用它已经加载的 `.tok-*` 样式。
- 块头写语言、行数和“复制”；超过 18 行先折叠，“展开全部 N 行”。没写语言时按内容猜 JSON、命令、Diff。

**每轮带上的东西是小块，不是一行字。**
- 文件按扩展名给图标：图片、表格、文本、代码、PDF 等其他文件。方法和能力用闪电，选中的文字用文本图标。
- 是对象的（引用的文档、待办）点了在原处打开。

**过程每一步都有图标。**
- 查找、读取、修改、运行命令、提问、分出子任务、记忆等各一个图标；正在做的一步转圈，失败的一步红色。
- 左栏已经画出步骤清单时，对话里不再写“更新工作步骤”。
- 回答下可以展开“用到 N 条记忆 · 因为篇幅没带上 M 条”，逐条写范围（个人 / 本项目）和内容（记忆会话提供的数据）。

**卡片是同一种外形：一行类型、标题、内容、按钮、一句说明后果。**
- 等你回答：选项是整行按钮（字长时竖排），可以自己写回答；多题问卷逐题分组。说明写“回答后这一轮会接着做”。
- 执行前需要你确认：右上角写要做的事，如运行命令、修改文件。改动、命令、参数用上面的代码块显示（Diff 着色、可复制），准确参数折叠在最后。说明写“允许只执行这一次；拒绝就不执行，助理会知道你拒绝了”。
- 操作卡：右上角写后果，如只读取、会修改可在原处撤回、会修改不能撤回（红色）。字段可以直接改。按钮就是这张卡要做的事；说明按后果写。执行后写结果，失败的给“再试一次”，过期的给“请助理按最新状态重新准备”。
- 出了问题：同样的外形，红色类型行“出了问题”，加一句发生了什么和唯一的下一步。

**最后一轮下面写“接下来”。** 做完并有产出时，给“打开「…」”（最多两个）；没完成时给“用同样的话再试一次”，把原话放回输入框，不自动发送。

## 4. 通知分三级

| 级别 | 例子 | 出现在 |
| --- | --- | --- |
| 要你动手 | 等你决定、失败、到期提醒 | 输入框前“等你 N”；点开直接处理 |
| 有新结果 | 做完了、插件交回结果、新资料 | 这项工作的标签和“全部工作”里的蓝点，看过即消 |
| 过程信息 | 后台完成、定时跑过、停止后结算 | 这项工作左栏 |

铃铛只在有“要你动手”的事时出现并计数。

## 5. 底栏（第二期，已实现）

- **左边管“去哪里”**：插件切换器从输入框前移到底栏最左，和原来的 Dock 菜单合成一个入口（“全部插件与 Dock”）。
  - 按钮上仍写着你在哪里，分屏时每个窗格一小片。这是用户自己设计的能力，所以保留。
  - 列表里是项目的全部入口，列表底部是 Dock 的设置：插件市场、插件创作工作台、常驻在 Dock。
  - 手机上它只显示一个“全部插件”图标，你在哪里由旁边 Dock 的高亮表示。
- **中间只管“叫助理”**：输入框静止时只有输入、“+”、发送；插件切换器和搜索按钮都不在这里了。
  - 占位文字写“让助理做点什么，或按 ⌘K 搜索”。只在页面有搜索、并且有键盘时才写 ⌘K。
  - 搜索放在切换器列表的第一行（“搜索 ⌘K”），手机上也能用；任何地方按 ⌘K 也能打开。找地方本来就是“去哪里”的一部分。点它时列表不收起，关掉搜索后焦点回到这一行。原来项目菜单里的搜索按钮在底栏里一直是隐藏的，所以不能指望它。
- **“+”只负责添加**：添加文件或图片、引用项目里的内容（插入 @）、用一个能力或方法（插入 /）。输入框里已经写的字，在 / 选完或按 Esc 后会还原。
- **谁来做、放在哪里**：在新工作标签的左栏里选。面板关着时，聚焦空输入框后下拉底部有一行“发给：助理 · 新工作 · 某项目　更改”，点它打开面板并定位到这些选择。
- 右边（Shelf、灵光、项目讨论、项目圆钮）不变；平台侧栏会话接手“项目讨论”时另行约定。

## 6. 步骤清单（第三期）

Host 从 Prologue 会话读出 `update-todo` 的清单放进工作视图；左栏路径显示打勾清单。

- **已实现（面板一侧）：**
  - 合同里有 `AssistantRound.steps`，取最近一轮有清单的那份。
  - 路径的“步骤”节点写“2/4”并带进度条，每一步前是状态图标：打勾、转圈、琥珀、划掉。
  - 正在做的一步如果在等你，整行淡琥珀，写“去确认 / 去回答……”，点它跳到对话里那张卡。
  - 块头的数量改为“步骤 N/M”。
  - 清单只表示 Agent 打算怎么做，不是做过什么的证据。做过什么仍以过程和对象为准。
- **等 Host：** 系统级助理会话在 `AgentRunView` 上补 `todo`（agent-host 读出 `todo-changed`）之后，`assistant-service.ts` 的 `roundView` 加一行映射。动那个文件之前先告诉那个会话。
- **以后再做：** 每张卡记下它属于哪一步，卡片标“步骤 N”。这要 Prologue 在调用上带上步骤 id，现在没有。
- **记忆（记忆会话的合同，本侧只负责显示）：**
  - 工作视图的 `memory_changes` 显示在成果的“记住的事”里，可以撤销（`POST /api/memory/changes/<id>/undo`），也可以“去设置查看”。
  - 撤销后只写“已撤销（已从记忆里删掉）”，不再显示原文。
  - 每轮的 `memories_used` 显示在回答下面（见 3.7）。

## 6.1 与其他工作的约定（2026-09-30）

- **平台侧栏**（把“项目讨论”抽成通用侧栏的会话）：
  - 它不用 `.assistant-*` 类名，也不动底栏中间。
  - 侧栏打开时，由它暴露一个宽度变量，面板据此收进主区宽度。
  - “助理工作的文件”清单留在面板左栏，点开后的预览交给侧栏。
  - **已接（2026-09-30，与侧栏会话定下的接口）：**
    - **预览：** 面板里点对象，发 document 事件 `molis:side-open`。
      - 事件可以取消，detail 是 `{ tab: "files", target, focus: false }`。
      - target 是 `{ subject, title, open }`。侧栏处理了就 `preventDefault()`；没人处理时，照旧在原处打开。
      - 入口有：左栏材料、成果、还等你处理里的对象；对话里带上的对象小块、「」点名的对象、“接下来 · 打开「…」”。
    - **自带内容预览：** 待发的图片给 data:image/*，带文字的文件给 text/plain。body 有 `data-side-open` 属性（侧栏在）时才可点。
    - **交还浏览器：** 听 `molis:side-browser-control`，按 session 找工作（`work.session_id` 或 Coding 执行者的 `executor.session_id`）。
      - handback：给那项工作发“我把浏览器交还给你了，先重新观察页面再继续”。轮次还在跑时，由 Host 作为 steer 转进去。
      - takeover：只在概况一行写“浏览器在你手上……”。
    - **宽度：** 可用宽度 = 窗口宽 − `--side-panel-width`（`body[data-side-open=true]` 时）。
      - 可用宽度 ≥ 1240 才并排，否则左栏作抽屉。
      - 面板右边缘按 island 的实际位置，收在侧栏左边缘 12px 以内（`--assistant-room`）。
