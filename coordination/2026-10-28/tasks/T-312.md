## 1. 背景

来源：派单线 2026-10-30 的扫描，已对 `origin/main`（`dfe6d0f7ad`）核过。`plugins/native/coding/src/session-window.ts` 约 :34 `task: task.length > 300 ? task.slice(0, 300) + "…" : task`（`task` 是用户自己写的原话 `originalTask(run)`）与约 :104 `if (kept.length > SHOWN_CHARS) kept = kept.slice(0, SHOWN_CHARS)`（`SHOWN_CHARS = 6_000` 在约 :93）。两处都是服务端算好发给页面的（`routes-timeline.ts` 约 :149、:183、:198 调 `codingRunForDisplay`；`codingRunSummary` 经 `summaryCache`），`fingerprint` 按截后的内容算，没有任何后续修补。用户的长任务描述和命令输出是 CJK 加 emoji 的常见场景，截点落在代理对中间时页面显示“�”，还会进轮摘要缓存。仓库里这个内联写法已在 `apps/local-host/src/browser/browser-host.ts` 约 :768、`contextual-request.ts` 约 :31 用着；同包没有现成的。

## 2. 目标

先在 #1332 贴简短【方案】（乙档：写两处改前改后各一行、用例输入与期望）。
1. `:34` 改为 ``task.slice(0, 300).replace(/[\uD800-\uDBFF]$/u, "") + "…"``。
2. `:104` 改为 `kept = kept.slice(0, SHOWN_CHARS).replace(/[\uD800-\uDBFF]$/u, "")`（后面“kept 长度与原输出相等才沿用原对象”的判断不受影响，少一个单元仍然不等）。
3. 在 `tests/coding-long-session.test.ts` 末尾加 RAC-2430（该文件有 `run(index, over)` 夹具，`over.task` 可设用户话）：`codingRunSummary(run(1, { task: "x".repeat(299) + "🙂尾" })).task` 应等于 `"x".repeat(299) + "…"`；`codingRunForDisplay(run(1))` 在第一条 activity 的 `output` 换成 `"y".repeat(5999) + "🙂z"` 后 `output` 应为 5999 个 y；判断用 `LONE_HALF` 正则（照 `tests/contextual-draft.test.ts` 约 :67）。先对旧代码证明会红（旧代码第一条以 299 个 x 加落单的 `\ud83d` 再接“…”，第二条以 `\ud83d` 结尾）。
