## 子分支与授权边界

首屏检查先在一个子分支完成，合回 `batch/16`，不开独立 PR。Folio 设计在独立设计子分支出可点实物；只写定样材料，不写未确认的产品视觉。B 的合同设计、服务与消费者随后按依赖串行接力；B 验收后才开 C 的文字/样式切换窗口。子分支途中只编译与运行本次新写的用例，全批写完再统一同步 main、构建、定向与浏览器验证；Full 交最终头的 CI。

当前首屏子分支允许修改报告器、首屏测量/比较代码、第一屏清单、现有页面资源许可解析、CI 的该项调用和直接相关测试/手册；不改变产品响应、增加产品资源、放宽既有数字、改版本、读取真实 Home 或调用真实模型。共享的进程、基线检出、许可与统计能力先复用；需要抽取时保留一份实现。

B/C 的翻译门禁适配、内容与存储版本、历史记录转换、字体/语言资源新增尚未包含在上述门禁授权内。准备具体变更与实测后再集中请用户决定，不把“全批开发授权”当成这些红线已批准。

## 首屏检查验收

以下编号属于本批工程前置，不替代原需求的 FSS 验收。测试名或注释标明编号。

- **FSS-BG-01**：同一测量器、固定项目种子、等长隔离 Home 测四个主要页面的中英文首次/再次响应；示例页只报告；对照基点与候选，实际条件响应计字节。相同提交重复测量稳定；增长和未获许可的新路径会拒绝。
- **FSS-BG-02**：现有 `assets` 门禁仍有效；同份许可可带 `pages`，至少有一类有效预算；已采用许可不可重用/修改，新增资源或单行增长超过 10,000 B 仍需用户批准。许可不允许未知字段、负数或用宽松值绕过。
- **FSS-BG-03**：Host 启动失败、信号退出、中途失联，页面/登记资源非成功响应，或采样不完整均非零退出，不输出可当成成功的完整报告；正常、失败、取消都清理本次进程与临时 Home，不停其他服务。
- **FSS-BG-04**：浏览器防漏报告对比实际请求与清单，列未登记路径及有副作用而不纳入硬门禁的请求。每批本机经 machine-slot/test-kit 的独立浏览器执行；不加夜间作业，不把报告遗漏变成未授权的新硬门禁。
- **FSS-BG-05**：CI 使用候选测量器对实际 merge-base 与候选比较，失败挡合并；基点不带新脚本也可测，不依赖候选自身的数值作起点；原资产检查继续运行。两树各读自己的首屏清单；仅首次基点没有清单时，候选清单显式标为新增的补充请求不强加到基点。该声明只补足首次清单缺席的差异信息，不覆盖 HTML 直接或递归发现结果，也不授权忽略任何本树应成功的请求；修改前已有的动态请求仍须进入基点集合，不能因候选删除或替换而漏测。候选新增路径必须成功，并独立核对用户批准，即使页面总量下降也不豁免。基点有自己的清单后不再使用首次声明。单 PR 首次引入的验证与用户决定可追溯。

按 `node scripts/machine-slot.mjs run browser --label "16 first-screen tests" -- node scripts/run-tests.mjs --jobs 1 <本次新写用例>` 验证刚写的行为；交回前健康门禁经 build 槽运行。完整受影响用例、页面资源、包必跑和浏览器矩阵留到本批最终统一验证。测试文件名随实现确定，不能以仅 JSON 可解析或固定条目数证明上述行为。
