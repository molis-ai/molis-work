三份待办分别记录了英文组件板被撑宽、引导提示重复实现、首显列表仍用手写阶梯延迟。从最新 `origin/main` 的独立工作树接手。已查认领板 #1743、开放 PR 和三份 BL。#2258 的共享样式改动已合入，11 月 23 日同步至 `8192cc7b10` 后再验证。本任务在 `craft-finish-pages.ts` 只改首显阶段的阶梯延迟。

组件板按 DESIGN.md 窄屏规则，让超宽的行与长文案在自己的容器内换行，表格与宽画幅标本在自身容器内滚动。主线复现 390px 下组件板滚动区从 366px 被撑到 561px。逐节量测后把表格只给读屏器的列名定位到表格滚动区，限制助理参数组宽度，允许资料恢复长按钮换行。Compose 的筛选菜单打开时复用组件板已有的定位菜单，Interaction 沿用当前主线的窄屏布局并纳入整板回归。

范围限工作台、设计系统的相关样式与标本、回归和文档。引导保留现有流程和提示文案。公共接口、样式令牌取值和预算沿用现状。

1. 事实主人沿用现有归属。三项只呈现已有内容和状态。
2. 插件同等待遇。工作台与组件板沿用公开的 SDK 原语。插件装配不涉及。
3. 能力注册不涉及。产品没有新增动作、调用者身份或等待外部服务的路径。
4. 合同不涉及。SDK 出口、动作、Manifest 和 DOM 事件均沿用原约定。
5. 包边界。组件与样式留在设计系统，工作台经既有浏览器组件束接入引导提示。
6. 表与存储不涉及。持久化读写沿用原入口与数据结构。
7. 兼容与迁移不涉及。这里的迁移只替换提示组件。
8. 安全边界不涉及。提示样式和换行与授权判断独立。
9. 调用次数沿用现状。布局和延迟由 CSS 控制，引导组件复用已经加载的资源。
10. 升级与数据不涉及。记录、引用和设置格式保持原样。
11. 成果与过程项不涉及。本片只调整控件呈现。
12. 页面、外壳与文字。使用已有组件、翻译和语义变量，验中英文与浅深色，按页检查资源体积。
13. 错误不涉及。原提示内容和条件继续使用已有错误与状态。
14. 冲突面已对照 #1743 与在途 PR。共同编辑区是 spec 索引和待办销号表，共用样式由 D 轨处理。
15. 全局复用。插件、工作台与助理采用同一设计系统。后续同类页面可沿用提示与动效规范。运行时动作与资料授权继续走各自已有入口。

## 验收标准

1. **DTC-01** 390px 英文组件板页面无横向滚动，compose、interaction、assistant、data-table 的内容可见或在自己的容器内可滚。打开 Compose 筛选时菜单在视口内，表格能独立滚到末列。保留原三宽度回归。运行 `node scripts/run-tests.mjs tests/board-overflow.e2e.test.ts --jobs 1`。
2. **DTC-02** 引导普通提示和警告提示使用 `renderNote`，图标与正文可见、长文字可换行、警告用共享警告样式。运行 `tests/onboarding-journey.e2e.test.ts` 和 `tests/context-onboarding-sessions.e2e.test.ts`，在同一 Sessions 授权引导场景做改前改后截图。
3. **DTC-03** 每组首显最多四项按 60ms 依次出现，减少动态效果时无延迟。用组件板与助理空态核对浏览器计算样式，运行 `pnpm visual:compare` 检查共享样式的影响。

验收后删除三份 BL 并登记 `docs/backlog-removed.md`。推送及开 PR 依仓库授权规则。
