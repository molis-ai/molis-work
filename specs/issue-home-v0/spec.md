# Issue：个人 Home 问题记录

状态：V0 本地实现快照，最终全量按用户要求中止；完整回归、真实模型与用户体验待验收（2026-10-10）。本地分支 `codex/issue-home-v0`，基于 `origin/main` 的 `c9aafc08e4d02c405cec2476e025278a1111e9eb`；本轮按用户新指示先保存本地提交，不推送、不合并，未操作日常 Home。

## 目标与依据

人在 Work 页面、Work 助理或外部 MCP 中录入、查看、编辑、删除自己的问题；换项目仍然看见同一份记录，没有项目也能使用，重启后保留。V0 面向个人，不承担团队工单、项目流程或 Casebook 分析。

用户在 2026-10-10 明确要求「直接根据他现在已有的规划，自行推进，按照我们自己的节奏」。据此，原先等待平台负责人对齐的前置暂停条件取消；平台能力仍归平台层，Issue 不自建第二套运行时。已接受的设计来源是 Casebook 仓库的 `docs/Issue-Home-Runtime最小设计-2026-10-10.md` 与本地 `Casebook-3-V0实现方案.md`；本文记录当前执行与证据。

开工核对：远端主线已经更新；现行 Runtime 仍按项目装配，没有 Home 插件 Runtime 或插件自有 SQLite 服务。公开在途 PR 为 #180、#178、#156，未发现覆盖这些能力的实现。#178 涉及插件目录，修改该处仅追加本次声明，后续集成再核对。独立工作树避开其他会话的已有修改。

## 顺序与责任

1. 平台：复用 Runtime、Supervisor、Action Registry 和本机唯一执行进程，增加一次 Home 装配。安装身份、授予、启停、路由、数据库连接归 Host。
2. 平台：提供受当前安装与权限约束的 SQLite 服务；插件声明当前基线并拥有业务 SQL。数据库路径由可信 Host 决定，升级不自动迁移旧库。
3. Issue：在 `plugins/native/issues` 实现 schema、查询、原子增改删、动作、页面与方法说明。标识 `io.molis.work.issues`，业务数据 `{home}/issues/issues.db`。
4. 接通页面、Work 助理与 MCP 对同一 Home 动作的发现、授权与调用；用隔离 Home 验证真实链路，再交用户试用。

平台补丁和插件补丁保持可独立审阅的文件边界；不等待 Form、Todo 完整迁移，不改变它们的现有实现。

## 复杂度与范围

当前必须：Home 安装记录与生命周期、统一 provider 定位、SQLite 当前基线、授权和取消检查、条件写入版本、三入口接线及失败反馈。缺少它们会导致无项目不可用、项目切换分裂数据、旧实例继续写入或并发覆盖。

复用：已有 Runtime、Supervisor、权限检查、动作与路由适配、UI 壳及本机单进程转发。项目插件继续按安装 ID 定位；Home 内置插件以稳定插件 ID 发现，同时保留 install_id 和 installation_generation 约束执行。

延后：Form/Todo 迁移、完整统一注册表、完整方法系统、模型服务抽象、团队同步、截图/环境采集、历史迁移与分析。只有出现真实消费者需求或另获授权才重新评估。

不采用：假项目、业务 JSON KV、Issue 专用 Host HTTP 分发器、冻结的构建期动作清单、异步回调内持有 SQLite 事务、未知提交后的自动重放。

## 数据与调用约束

- 记录标题、类型（bug / experience / feature）、原始描述、上下文与来源。类型不替用户默认；保留描述空白与换行。
- Host 绑定当前 Home 所有人与入口身份，输入不接受 actor、install、provider、创建时间等可信元数据。页面上下文区分 Host 可验证值、调用方陈述与用户修改；MCP 没有 Work 页面时允许为空。
- 列表有界分页、排序稳定；修改与删除要求 expected_version，在数据库中条件写入，冲突不覆盖。
- 所有写入在事务前执行 beforeEffect，并复查当前安装授权；同步事务内不等待。停用、撤权、取消后拒绝写入，错误不得伪装成成功。
- UI 出错保留草稿和当前选择，删除先确认。助理缺标题或类型时询问，最多约两轮，不编造上下文。

## 验收标准

- **ISSUE-01** 无项目时可启动 Home 插件；项目切换复用同一实例和数据，两个隔离 Home 不串数据，重启后保留。
- **ISSUE-02** 页面、助理和 MCP 发现同一 Home provider；权限绑定安装，停用/撤权/旧实例调用明确拒绝，不重新启用。
- **ISSUE-03** 五个 CRUD 动作通过同一业务实现，验证类型、标题、描述、分页与来源；调用方无法覆盖可信身份与时间。
- **ISSUE-04** 并发更新/删除检测 expected_version；取消或撤权在提交前生效，事务失败回滚，未知结果不自动重放。
- **ISSUE-05** 使用真实 SQLite 和当前 schema 基线；不匹配拒绝打开，不改写旧库；关闭过程撤销服务后释放连接。
- **ISSUE-06** 页面可完成录入、列表、详情、编辑和删除，失败保留输入；切换项目、无项目与刷新后可继续使用。
- **ISSUE-07** 助理与外部 MCP 经公开发现/调用路径完成 CRUD，返回结果与页面及持久化一致；明确记录模拟与真实模型的证据边界。
- **ISSUE-08** [人工] 用户检查中文输入、视觉与连续使用体验，明确确认是否达到 V0 试用预期。
