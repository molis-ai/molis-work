## 验收与复验

- **BQN-01**：组件板 212／188、254／230 与 300／276px 标本的短标题单行，长中英文能多行完整阅读。用元素边界和正文行量标题、状态签、收起与表单，所有可见字段、操作仍在卡内，日期值完整可读。状态签位于标题块下方，收起可 Tab 到达且触控时至少 44×44px。
- **BQN-02**：宽问卷保持状态签在标题旁，操作卡原排版不变。界面与真实入口看 1440／1024／390 × 中英文 × 明暗；补 348 与 436 的边界，检查减动效。全板 VUX-39 原断言照跑。
- **BQN-03**：隔离 Host 的四处现有问卷用真实输入、提交和恢复路径，核对长标题、待答和等待、字段错误及保留值、键盘焦点和一次续跑。组件板模拟不计入生产实操。
- **BQN-04**：冻结锁离线安装、`pnpm build`、`node scripts/run-tests.mjs --jobs 1 tests/board-overflow.e2e.test.ts`、`node scripts/check-health-gates.mjs --base origin/main` 和 diff 检查。对照同源码基点的真实 Host 页面资源；路径不增，单资源增量不超过 10 KB。

**工程与板上实物。** BQN-01／02 新回归与原 VUX-39 都通过。隔离板的短标题在三档窄卡均单行，标题主列宽为 140／182／228px；300px 卡的长英文由 13 行降到 5 行，收起中心可命中，卡与表单的横向滚宽为零。30 个标本涵盖深浅色、长中英文、原短标题与三档窄卡、两档桌面，使用减少动态效果。同宽英文对照固定原标本容器宽，以免英文板的其他样本改变它。日期文本在窄桌面测字宽、手机布局目视，均完整；宽卡日期轨与旧排法测量相同。BQN-04 的页面资源对照 52 条路径、无新增及漏测；工作台与入口页 CSS 各增加 890 字节，整批按基点净值评审。

**生产入口隔离实操。** BQN-03 的助理底栏、助理主区、项目选择页和 Coding 四处，各走 1440／1024／390／348、中英文与深浅色的真实问卷。卡和表单不溢出，只有提示签时标题块仍占整行。390px 下用真实浏览器按键填答；助理与 Coding 各一次数字越界返回 400、保留字段并聚焦错误，修正返回 200，同一轮只续跑一次。等待时原按钮禁用并显示 spinner 或文字。Coding 成功后回到输入框；助理仍在收卡后回到页面。最终只改日期字段的几何；生产探针用文本与数字字段，日期改动另在板上验证。

最终头由统筹统一做 [Design System](../../../../packages/design-system/README.md#开发要求) 必跑项、受影响回归、共享视觉对照和整批资源核算。本人实物验收仍待；真实账号、触屏实机、原生壳和读屏实听未验证。
