## 给人讲清楚

第 44 批（含 `#2258` 独立复核清扫）清掉了 Goals 的大部分私路，但系统里还留着一批「名义上是插件、实际上被平台开后门」的遗留：Shelf 挂着插件壳却独占常开与双实例、Alchemist 仍是构建期手写装配和全仓唯一的 `better-sqlite3` 例外、官方集成绕过统一运行时并把 20 个 CLI 与各厂商分支写死在宿主里、Characters 与 Assistant 漏出保留 id 安全缺口、`#2231` 的同步目录借用 Inbox 一拔就崩。这一批把必须跨全局打底的能力（Shelf、成果库、Characters、创作台、`planning-methods` 系统技能）彻底收归纯平台，删掉旧 Alchemist，把其余插件特例全部收敛成公开声明并上线 **G1「平台不点名插件」门禁**。做完后全仓 `always_on = 0`、构建期例外 `= 0`、`better-sqlite3 = 0`、第三方插件拿得到和内置完全一样的公开声明能力。

需要你做的：如提前切出 `44B-0` 安全小 PR，确认合并；本批其余按已拍板的[决定 66](../decisions.md#decision-66)直接实施，不动真实 `~/.molis-work`。
