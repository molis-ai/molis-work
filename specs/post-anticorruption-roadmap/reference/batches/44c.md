## 给人讲清楚

第 44B 批（#2262、#2279、#2294、#2308）已经把置物架 Shelf 收成了纯平台部件、删掉了旧 Alchemist、把官方连接器改成了声明式驱动；随后第 106 批（#2316～#2323）把统一工作分区的 Home 单张安装表与分区底座架好了，全站中/英/日三语（#2307）也已落地。但把平台里剩下的特例彻底收干净还差最后一截：

- **身份和登记还没完全归拢**：查一个插件动作是谁提供的，代码里还有几套算法，甚至有两处旧代码给沙箱插件拼错了名字（导致目录设置和场景采用对不上安装号）；成果库、角色（Characters）、外部会话（Sessions）三个平台自带页面还没进统一的平台页面登记表，资源路径还挂在旧插件目录下；几处合同和桌面壳里还把平台部件 Shelf 当成名叫 `"shelf"` 的插件调，主线接收站里还写死了英文 `"Shelf"`。
- **连接器宿主还没彻底脱钩**：连接器的内存注册表还没并进第 106 批的 Home 统一安装表，宿主仍有 11 个文件直接引用连接器包，宿主和工作台里还留着几家外部服务的专门分支；首页判断和规则路由里还写死了 `feed`、`inbox` 的权限名。
- **收尾验证与门禁校准还没封口**：随包发布插件的放行校验只在安装预览做了一层、启动复核没绑包摘要；用同一个第三方签名样例插件把所有公开声明走通一遍的端到端验证还没补；组件样板间里还拿真实内置插件名当例子；「平台不点名插件」（G1）门禁把网页通用“表单（form）”英文词误判成了问卷插件。

用户 2026-11-24 / 11-25 定：**一次做完、一个 PR**；平台部件统一用 `system.shelf` 身份且标题走三语词表；随包放行在预览与启动两处收紧绑定包摘要/签名；G1 在本批把真正的插件包引用与 `io.molis.work.<id>` 压至绝对 0、组件样板间例子换虚构样例名、修掉通用表单词误报，排在第 109 批搬家的 Git 代码按原计划留 109 清零。

### 44C-1 统一提供方身份与平台登记

- **提供方身份一处算**：`resolveActionProviderId` 只留在 `@molis-ai/molis-work-plugin-runtime` 一份（宿主构建的插件是插件编号，签名沙箱包是 `plugin:<插件编号>`，其余是安装编号），六处三种算法收成一处；签名沙箱包经 Runtime 注册的动作，提供方原来随宿主各处传的回调、缺省是安装编号，现在一律 `plugin:<插件编号>`（跨版本、项目与两半稳定）；插件启动时由 Runtime 给 `PluginStartContext.provider_id`，插件不再自拼 `plugin:<编号>`。
- **平台登记**：`apps/workbench/src/platform-settings-registry.ts`（平台设置一张表）、`runtime-plugin-directory.ts`（运行时插件目录）、`platform-surfaces.ts` 与 `packages/ui-host/src/platform-surfaces.ts`（成果库、Characters、Sessions 一张 `PLATFORM_SURFACES` 登记），宿主路由从 `platform-surface-routes.ts` 读同一份登记。**偏离 M15**：M15 写的是扩进 #2239 的 `HostSurfaceRegistration`；这三页没有 Manifest、不经插件装配，套进按插件登记的 `HOST_SURFACE_REGISTRATIONS`（`apps/local-host/src/host-surface-list.ts`）要给它们造假 Manifest，所以另立一张平台页面登记，两张并存。宿主与外壳各自只从一张取，没有逐个写的平台页面路由了。
- **`"shelf"` 专名**：定成平台部件身份，合同里的接收站写 `PLATFORM_RECEIVE_STATION`（`system.shelf`）；呈现槽、DOM 事件的 `owner: "shelf"`（`packages/contracts/src/platform/dom-events.ts` 四条）与桌面壳的 `molisWorkOpenPlugin("shelf")`（`apps/desktop/src/shell.ts`）按 `docs/system/GLOSSARY.md`「平台部件名」留作平台部件名，不改字面（44B 允许的做法；桌面壳中途改过又改回，免得动 Rust 侧与已存的桌面状态），呈现槽只补了注释；`CODING_QUESTION_TYPES` 收掉，问题卡按声明。`tooling/versions.json` 的 `sync.collection.platform.attention` 排回字母序。
