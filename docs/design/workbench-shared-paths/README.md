## 怎么打开

在仓库根目录运行（原型要用上一级的 `../kit/`，所以从 `docs/design` 起服务），然后打开 <http://127.0.0.1:4410/workbench-shared-paths/>：

```sh
python3 -m http.server 4410 --bind 127.0.0.1 --directory docs/design
```

也可以直接用浏览器打开本目录的 `index.html`。顶上带斜纹边的一条是**原型控制**，不是产品的一部分：切方案、场景、状态、中英文和浅深色；「重置」清掉本页记住的状态。

## 已定（2026-11-03）

用户选了 **A 按来源分组，最上面加一节「最近用过」**（最多 5 份，跨来源，每行写出处）。B、C 留在原型里作对照，不再实施。决定记在[目录与资料整合方案 §8](../../../specs/product-flow-governance/workspace-and-materials-design.md#8-决策记录)。

## 三个方案只差在「项目资料」怎么组织

三个方案共用同一套外壳和同一份「输入与输出」管理，只换资料本身的排法：

| 方案 | 排法 | 好处 | 代价 |
| --- | --- | --- | --- |
| A 按来源分组（已定，加「最近用过」） | 本机文件夹（每个一棵树，标「参考／输出」）→ 导入的文件 → 项目里的内容（Pages、Shelf、成果） | 每份东西从哪来一眼看清；代码树保持是树；三类项目都一样 | 来源多时要往下翻；常用的几份要每次去找 |
| B 先看最近 | 默认是跨来源的「最近用过」列表，每行写出处；「按来源」是第二个页签，进去就是 A | 反复用同几份资料时最快 | 第一次进来看不出项目有哪些文件夹；结构藏了一层 |
| C 工作目录为主 | 输出文件夹（工作目录）在最上面展开，其余放进「参考资料」 | 做代码时最像编辑器的文件栏 | 只有写作资料的项目，最上面是一个空的输出位置，参考资料反而靠后 |

## 推荐走一遍

1. 右侧「项目资料」里点 `brand-assets › 品牌指南 2026.pdf`：看到出处（来自哪个文件夹、当前文件还是固定版本、读到第几页），点「加入任务」，底栏输入框出现带出处的小卡，可以撤销。
2. 同一份预览里点「在 Coding 里看」：左边 Coding 的文件栏换到 `brand-assets`，顶上写「正在看 brand-assets（只读参考），Coding 仍在工作目录里做」，点「回到工作目录」回来。项目输出和本轮位置始终写在 Coding 顶上。
3. 点「输入与输出」：参考文件夹可以加多个、移除、「设为输出」；输出只有一个，所有任务和插件共用；同一个文件夹既是参考也是输出时会说明「可以直接改这里的原文件」。右下角项目圆钮打开的「项目设置」里是同一块。
4. 「在主区打开」把一份资料作为标签开到主区；标题栏的「＋」在原地出列表菜单；右侧是和主区同一套的窗格，有自己的标签，底栏右边的按钮收起和打开它。
5. 用顶上的「状态」切：大文件夹还在读（先读到的可以先用、可以停）、参考文件夹不见了（之前引用的还能看，给「重新找到位置」）、停止了一个文件夹的读取（新的读取被拒，旧引用留出处）、运行中改了输出位置（本轮仍在原位置，下一轮起用新位置）、本轮在临时副本里做（完成后经审查交回）。
6. 「场景」切到「只有研究和写作资料」和「第一次进入」：没有本机文件夹的项目也有默认输出位置，随时能改；空项目给出「添加文件夹」「导入文件」两条路。

预览里另有几种读不通的情况：`.key` 读不了正文（原件还在）、表格解析失败（保留原件，可重试）、长 PDF 只读了前 20 页（可以读全部）、`node_modules` 等默认不读的说明。

## 组件板实件

页面的零件来自组件板（共用的 `docs/design/kit/`：`kit.css` 与 `kit.js` 的 `window.mwKit`）。`kit-bridge.js` 给第 03 批的六份原型共用：`kitRing(状态)` 画组件板的状态环；分段按钮随 `aria-pressed` 加上组件板的 `mw-toggle`、`is-current`；页面画好后启动组件板自己的客户端脚本（按下手感、分段滑块、状态环动效）。地址加 `?lang=en&theme=dark` 可以直接打开某种语言和外观（评审截图用），值会写进本页记住的状态。`styles.css` 只管版面，开头把原型原来的几个变量名接到组件板的令牌上。

## 宽度、键盘与外观

- 1440、1024 宽度下主区和右侧并排；760 以下只显示一个窗格，标题栏用「主区／右侧」切换，底栏变两行，点按目标 44px。
- 菜单与面板：Esc 关闭并把焦点还给打开它的按钮，↑↓ 在菜单里移动，点外面关闭；靠边时自动挪位置。
- 浅色、深色都可切；系统设了减少动态效果时去掉所有动效。

## 模拟边界

所有文件夹、文件、对话和 Coding 的进展都是示例数据（`data.js`），没有读任何真实文件夹、没有调用模型，也没有连真实 Home。按钮的结果（加文件夹、改输出、重新找到位置、恢复读取）只改本页的状态，存在浏览器的 `localStorage`（`molis-proto.workbench-shared-paths.v1`），不代表产品的持久化、权限或恢复已经做好。标签组、拖动排列、分屏调宽沿用产品现有行为，这里没有重画；Shelf、讨论两个页签只占位置。
