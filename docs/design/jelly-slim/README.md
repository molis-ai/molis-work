# Jelly 瘦身定样（第 112-2 批，可点）

状态：**已定方案 B**（2026-11-26 出样，用户选「日历旁放当天」），实现随第 112-2 批同一个 PR；落地核对完后按决定 60 移入归档。瘦身后的 Jelly 只留日历日程（月 / 周 / 列表、单次与每周重复、分类）和纯文本 / Markdown 随手记。不是产品代码；选定后在 `plugins/native/jelly/` 里实现，逐屏对照这里的状态。

## 怎么看

```bash
python3 -m http.server 4461 --bind 127.0.0.1 --directory docs/design
```

打开 `http://127.0.0.1:4461/jelly-slim/`。顶上切方案（A / B）、状态、宽度（1440、1024、390）、深浅色、中 / 英 / 日。窗口里的日程、分类、页签、随手记都能点。

地址参数：`?plan=a|b`、`&do=<状态>`、`&w=1024`、`&theme=dark`、`&lang=en|ja`；`&bare` 只留窗口、`&still` 关动效（截图用）。

| `do=` | 画的是什么 |
| --- | --- |
| `month`（默认）、`week`、`list` | 月 / 周 / 列表 |
| `new` | 新建日程（右侧面板；窄屏从底部升起） |
| `repeat` | 改一次重复日程，保存时选范围 |
| `undo` | 删除后工作台提示条撤销 |
| `conflict` | 这一条在别处改过（行级版本冲突，只影响这一条） |
| `notes`、`read` | 随手记：写 Markdown / 看排版 |
| `notes-empty`、`empty`、`fail` | 随手记空、日历空、没打开 |

## 两个方案

- **A · 两个页签**：日历和随手记各占一个页签，各自专心。最接近现在的 Jelly，学习成本最低。
- **B · 日历旁放「当天」**：日历右边固定一栏，显示选中那天的安排和那天的随手记，像日程本；随手记页签仍在，放没挂日期的和旧的。

## 两个方案都一样的取舍

- 去掉：AI 拆解按钮、模型设置、进展页、块编辑器与格式工具栏、整库导入导出、优先级、置顶、完成说明、日程与笔记的关联、Jelly 自己的撤销 / 重做按钮。
- 撤销：删除不先弹确认，直接删，由工作台底部提示条（宿主 `host.showToast`）给「撤销」。
- 冲突：日程和随手记各按自己的行版本保存，别处改了只提示这一条，不锁整个日历。
- AI 排期交给助理调用日历的公开动作；空状态里提一句。
