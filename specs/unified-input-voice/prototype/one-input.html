一个输入框（定样稿）

工作台只留底栏一个输入框。它跟着眼前的页面：看着 Coding 会话时，它就是这个会话的输入框，任务方式和模型都在它的脚条里；换到助理或别的工作只要点一下「发给」。它的左右边缘和页面的对话栏对齐，「发给」收进框里，不再悬在框外。

1 · 在 Coding 会话里，没在写

Coding 页面里不再有自己的输入框，对话一直排到底栏上方。底栏的输入框静止时只有一行：＋、发给谁、提示语、任务方式、模型、发送。

要你拍板的一件事：「共用助理会话」指哪一种

  • 甲 · 共用一个输入框（这版画的）Coding 会话还是 Coding 的会话（任务记录、审查、任务图都在 Coding），只是没有自己的输入框，用底栏这一个；收件人跟着页面，也能一键换成助理。改动集中在工作台外壳和输入组件，事实的主人不变。
  • 乙 · 会话也合成一个Coding 会话就是助理的一个会话：在助理里也能看到、接着说，助理按需调用 Coding 去读写代码。体验更统一，但要改「每项事实一个主人」的分工（Coding 的会话记录归谁），是产品语义的变化，工作量也大得多。
