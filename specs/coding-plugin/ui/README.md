# Coding App 设计稿

2026-09-19 定稿的四张主屏，1440×900，直接用浏览器打开即可。
全部用 Molis Work 现行 token 画（`packages/design-system/src/palette.ts`），没有自造颜色和控件尺寸。

| 文件 | 画的是什么 |
| --- | --- |
| [`01-session.html`](01-session.html) | 会话：左栏导航（会话面）、中部对话、右栏结果页（变更集 + 行级意见 + 动作） |
| [`02-taskboard.html`](02-taskboard.html) | TaskBoard：左栏任务树带子代理、中部报告正文、右栏 Canvas（执行画出来的图） |
| [`03-files.html`](03-files.html) | 文件：左栏工作区目录、中部对话、右栏上下分屏（浏览器 + 只读终端） |
| [`04-new-session.html`](04-new-session.html) | 开一条会话：关联 Goal、带 Shelf 材料、选角色与运行时，右半是端口接线 |

三段式的分工写在 [`../design.md`](../design.md) §4：**左边找东西，中间谈，右边看结果并对结果动手**。

这些是**设计稿，不是实现**。它们是静态 HTML，没有交互、没有真数据；
实现以 [`../spec.md`](../spec.md) 的验收条件为准，不以这几张图的像素为准。

稿子里几处是**故意画成不可用**的，不要当成没做完：

- `build · 未接审批`：审批桥还没挂到 Runtime 上，可写档位就是真不可用。
- `应用` 按钮置灰：只读档下变更集不落盘。
- 终端页标着「不能在这里输入」：它是 Sessions 的命令回执只读投影，不是 PTY。

原始画布（可编辑、带批注）在 Artifact 里，链接见 `../spec.md` 的「设计稿」一节。
仓库里这份是定稿快照，改动以仓库为准。
