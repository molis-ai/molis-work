# 引导里连接文字模型

状态：待验收（2026-10-25）。

## 背景

引导里「连接文字模型」原来离开这一页，打开设置里的模型页。要配的是这次整理用的文字模型，人还留在引导里。选文件和连接模型是前后两个步骤，各占一整屏。

## 行为

- 点「连接文字模型」或「更换」不离开引导，也不打开设置页。地址仍是这次引导。标题栏的「设置」仍去设置。
- 选文件是一步：左边是说明，右边是已选文件。选完文件，主按钮进入的下一步就是连接文字模型：左边是这一步的说明，右边只放这一步的内容（常用供应商、要补的密钥和模型名）。右边不再出现文件，也不出现设置页的标题、侧栏和供应商详情。
- 这一步可以不填密钥，直接先带入资料或开始整理。返回回到文件清单，可以逐项取消；文件清单的主按钮再回到模型这一步。
- 文件清单里每一组可以收起和展开。时间范围和「刷新预览」不在勾选标签里面，点了会按那个范围重新列出文件。点一行的名字、大小或「未读取」都会勾上或取消。清点到的项如果没进名单，这一页仍显示那个数量，不写成 0。从模型这一步返回后，这个数还在。没有列出文件的一组，勾选表示这个文件夹还在这次里面，点一下可以拿掉，再点可以加回。每一组的标题跟着内容排，不盖住上面的文件。
- 供应商名单、未保存的表单和保存后的连接检查，走设置里模型设置已经在用的同一套读取和保存。密钥只在保存时送出，页面不把密钥画回去。
- 动效是规格板上的引导步骤：离开的一步向后淡出 130ms，进来的一步按方向滑入 420ms，`--ease-quint`，只动 transform 和 opacity。从选文件到连接模型，新的一步从右边进入；返回从左边进入。焦点落到新一步的标题。减弱动效或自动化时直接是终态。外框不动。

## 验收

- ONB-MODEL-01：选完文件进入下一步，仍停在这次引导。左边是「连接文字模型」，右边是供应商选择，不是已选文件，也不是设置页。点一个供应商后，右边出现密钥。点「返回」回到文件清单，文件还在；再点「下一步」回到模型这一步，右边仍没有文件。
