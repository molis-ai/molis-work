# WCAG 2.1 A 级与 AA 级成功准则清单

WCAG 2.1 的 A 级 30 条、AA 级 20 条，共 50 条。每条一句话说要求，一句话说怎么查；准确措辞以 W3C 发布的 WCAG 2.1 原文为准，这里只是审查时用的提要。「2.1 新增」指 2.0 没有、2.1 才加的准则。

阈值速查：

| 项 | 数值 |
| --- | --- |
| 正文对比度（1.4.3） | 至少 4.5:1 |
| 大字对比度（1.4.3） | 至少 3:1；大字指 18pt（约 24 CSS px）以上，或 14pt（约 18.7 CSS px）以上的粗体 |
| 非文字对比度（1.4.11） | 控件边界、焦点框、图标、图表里要看懂的部分，对相邻颜色至少 3:1 |
| 文字放大（1.4.4） | 放到 200% 不丢内容和功能 |
| 重排（1.4.10） | 宽 320 CSS px（竖向滚动的内容）或高 256 CSS px（横向滚动的内容）时不需要两个方向滚动 |
| 文字间距（1.4.12） | 行高 1.5 倍字号、段距 2 倍字号、字距 0.12 倍、词距 0.16 倍时不丢内容 |
| 闪烁（2.3.1） | 任意 1 秒内不超过 3 次闪烁，或低于一般闪烁与红色闪烁的阈值 |
| 自动内容（2.2.2） | 自动开始、与其他内容并列且持续超过 5 秒的移动、闪动或滚动，能暂停、停止或隐藏；自动开始且与其他内容并列的自动更新，无五秒豁免，能暂停、停止、隐藏或控制更新频率；两者仅在活动本身必需时例外 |
| 自动声音（1.4.2） | 自动播放超过 3 秒的声音要能暂停、停止或单独调音量 |
| 时间限制（2.2.1） | 能关掉、调整到至少 10 倍，或到期前至少给 20 秒、用一个简单操作就能延长 |

## 1 可感知

| 准则 | 级别 | 要求 | 怎么查 |
| --- | --- | --- | --- |
| 1.1.1 非文字内容 | A | 图片、图标、图表等有等价的文字替代；纯装饰的让辅助技术忽略 | 看 `alt`、图标按钮的名称；装饰图 `alt=""` 或 `aria-hidden`；验证码说明用途并给另一种方式 |
| 1.2.1 仅音频和仅视频（预录） | A | 预录的纯音频给文字稿；纯视频给文字稿或音轨描述 | 找到每个媒体，确认旁边有替代 |
| 1.2.2 字幕（预录） | A | 预录视频里的语音和重要声音有同步字幕 | 打开字幕看是否完整、同步 |
| 1.2.3 音频描述或媒体替代（预录） | A | 预录视频里只靠画面传达的信息，有音频描述或完整文字替代 | 关掉画面只听，看是否漏信息 |
| 1.2.4 字幕（直播） | AA | 直播的音频有实时字幕 | 有直播功能时确认字幕来源 |
| 1.2.5 音频描述（预录） | AA | 预录视频有音频描述 | 同 1.2.3，但这里必须是音频描述 |
| 1.3.1 信息和关系 | A | 视觉上表达的结构（标题、列表、表格、分组、标签与字段的对应）在代码里也表达出来 | 看语义元素、表头、`label` 关联、`fieldset`；关掉样式看结构是否还在 |
| 1.3.2 有意义的顺序 | A | 读取顺序和含义一致 | 按 DOM 顺序读一遍；看 CSS 有没有把顺序打乱 |
| 1.3.3 感官特征 | A | 说明不只靠形状、颜色、大小、位置、方向或声音 | 找「点右边的」「绿色的那个」这类说法 |
| 1.3.4 方向（2.1 新增） | AA | 不锁定横屏或竖屏，除非这个方向是必需的 | 旋转设备，看内容是否跟着转、能用 |
| 1.3.5 标明输入用途（2.1 新增） | AA | 收集用户本人信息的字段标明用途，便于自动填写 | 看姓名、邮箱、电话、地址等字段的 `autocomplete` 值 |
| 1.4.1 颜色的使用 | A | 颜色不是传达信息、提示操作或区分元素的唯一方式 | 转成灰度看：错误、必填、选中、链接是否还看得出 |
| 1.4.2 音频控制 | A | 自动播放超过 3 秒的声音能暂停、停止或单独调音量 | 打开页面听有没有自动声音 |
| 1.4.3 对比度（最低） | AA | 文字和文字图片的对比度达到阈值（见上表） | 用取色量前景与背景；浅色、深色主题分开量；悬停、禁用以外的状态都量 |
| 1.4.4 调整文字大小 | AA | 不用辅助技术就能把文字放到 200%，内容和功能不丢 | 浏览器放大 200%，看有无截断、重叠、按钮跑出视口 |
| 1.4.5 文字图片 | AA | 能用文字表达的不用文字图片（标志等除外） | 找画在图片里的标题、按钮字 |
| 1.4.10 重排（2.1 新增） | AA | 窄到 320 CSS px 时内容不用横向滚动就能读、能用；数据表、地图、图表、代码等二维内容除外 | 窗口 1280 宽放大到 400%，或直接设成 320 宽 |
| 1.4.11 非文字对比度（2.1 新增） | AA | 控件的可辨认部分、状态、焦点框，以及理解图形必需的部分，对相邻颜色至少 3:1 | 量输入框边框、开关、勾选框、焦点框、图标、图表线条 |
| 1.4.12 文字间距（2.1 新增） | AA | 用户把间距调到阈值（见上表）时内容和功能不丢 | 注入间距样式，看是否截断、重叠 |
| 1.4.13 悬停或聚焦时出现的内容（2.1 新增） | AA | 提示、浮层这类内容：不移动指针和焦点就能关掉，指针能移上去，不自己消失 | 悬停出提示后按 Esc；把指针移到提示上；等一会儿看是否消失 |

## 2 可操作

| 准则 | 级别 | 要求 | 怎么查 |
| --- | --- | --- | --- |
| 2.1.1 键盘 | A | 所有功能都能只用键盘完成，不要求按键时机 | 不碰鼠标走完主要任务；自定义控件、拖拽、悬停菜单都要有键盘路径 |
| 2.1.2 没有键盘陷阱 | A | 焦点能进入某处，也能只用键盘离开；要用特殊按键时有说明 | Tab 进入编辑器、弹层、嵌入框，再试着出来 |
| 2.1.4 字符键快捷键（2.1 新增） | A | 只用字母、数字、标点的单键快捷键能关掉、能改，或只在相关控件有焦点时生效 | 在页面上直接按字母，看是否触发功能 |
| 2.2.1 时间可调 | A | 有时间限制的，能关、能调或能延长（见上表） | 找会话超时、倒计时、自动跳转 |
| 2.2.2 暂停、停止、隐藏 | A | 自动的移动、闪动、滚动或更新能暂停、停止或隐藏 | 找轮播、跑马灯、自动刷新的列表 |
| 2.3.1 三次闪烁或低于阈值 | A | 没有 1 秒内超过 3 次的闪烁 | 看动画、视频、加载效果 |
| 2.4.1 跳过区块 | A | 有办法跳过多个页面重复的区块 | 第一个 Tab 是否是「跳到正文」；或用地标与标题 |
| 2.4.2 页面标题 | A | 页面有说明主题或用途的标题 | 看 `title`；单页应用切换视图时标题也要变 |
| 2.4.3 焦点顺序 | A | 焦点顺序保持含义和可操作性 | 按 Tab 看顺序是否跟着阅读与操作顺序；弹层打开时焦点进弹层 |
| 2.4.4 链接目的（上下文中） | A | 链接文字本身或连同上下文能看出去哪里 | 找「点这里」「更多」；读屏的链接列表能否看懂 |
| 2.4.5 多种方式 | AA | 一组页面里找到某页的方式不止一种（流程中的步骤除外） | 是否同时有导航、搜索、目录等 |
| 2.4.6 标题和标签 | AA | 标题和标签说清主题或用途 | 只读标题和标签，能否知道每块是什么 |
| 2.4.7 焦点可见 | AA | 键盘焦点看得见 | Tab 一遍，每一步都能看到焦点在哪；检查有没有 `outline: none` 不给替代 |
| 2.5.1 指针手势（2.1 新增） | A | 多点或按路径的手势，有单点不按路径的替代 | 双指缩放、滑动操作是否有按钮可替代 |
| 2.5.2 指针取消（2.1 新增） | A | 单指操作不在按下时完成；或能在松开前移开取消、能撤销 | 按住按钮移开再松手，看是否仍触发 |
| 2.5.3 标签包含在名称中（2.1 新增） | A | 控件读出来的名称包含看得到的文字 | 比较可见文字与无障碍名称，`aria-label` 不能换一套说法 |
| 2.5.4 动作触发（2.1 新增） | A | 摇晃、倾斜等动作触发的功能有界面替代，并能关掉动作触发 | 找「摇一摇」类功能 |

## 3 可理解

| 准则 | 级别 | 要求 | 怎么查 |
| --- | --- | --- | --- |
| 3.1.1 页面的语言 | A | 页面的默认语言能被程序识别 | 看 `<html lang>`，界面切语言时是否跟着变 |
| 3.1.2 部分内容的语言 | AA | 和页面语言不同的段落或短语标出语言 | 中文页面里的英文段落、引文 |
| 3.2.1 获得焦点时 | A | 控件获得焦点不会自动改变上下文 | Tab 到每个控件，看是否跳页、提交、弹窗 |
| 3.2.2 输入时 | A | 改变设置不会自动改变上下文，除非事先说明 | 选下拉项、勾选框，看是否直接跳走或提交 |
| 3.2.3 一致的导航 | AA | 多个页面重复的导航顺序一致 | 对比几页的导航 |
| 3.2.4 一致的标识 | AA | 功能相同的组件标识一致 | 同一个动作在不同处是否同名、同图标 |
| 3.3.1 错误标识 | A | 自动检测出的输入错误，指出哪一项并用文字说明 | 故意填错提交；读屏能否听到错误、知道是哪个字段 |
| 3.3.2 标签或说明 | A | 需要用户输入时给标签或说明 | 每个字段有可见标签；格式要求事先写出 |
| 3.3.3 错误建议 | AA | 知道怎么改时给出修改建议（安全或用途不允许的除外） | 看错误文字是否说怎么改 |
| 3.3.4 错误预防（法律、财务、数据） | AA | 涉及法律承诺、付款、修改或删除用户数据的提交：可撤销，或提交前检查并能改，或要确认 | 找付款、删除、提交申请类操作 |

## 4 健壮

| 准则 | 级别 | 要求 | 怎么查 |
| --- | --- | --- | --- |
| 4.1.1 解析 | A | 标记完整、不重复 id、嵌套正确 | 2.1 里仍列为 A 级；W3C 后来说明这条对 HTML 与 XML 视为总是满足，WCAG 2.2 删掉了它。重复 id、错误嵌套造成的问题按它引起的 1.3.1 或 4.1.2 记 |
| 4.1.2 名称、角色、值 | A | 每个界面组件的名称、角色、状态和值能被程序读出，变化时会通知 | 用读屏或无障碍树看自定义控件：开关是否读出开/关，展开是否读出已展开 |
| 4.1.3 状态消息（2.1 新增） | AA | 不移动焦点就出现的状态消息能被辅助技术读出 | 保存成功、加载中、搜索结果数、错误汇总：看是否放在 `role="status"`、`alert` 或 `aria-live` 区域 |

## 不在 2.1 AA 里、常被问到的

这些可以写成「建议」，不能写成不合格：

- 2.5.5 目标尺寸（44×44 CSS px）在 2.1 里是 AAA。WCAG 2.2 新增的 2.5.8 目标尺寸（最小值）要求 24×24，是 AA。
- WCAG 2.2 新增的准则：AA 级的 2.4.11 焦点不被遮挡（最低）、2.5.7 拖动动作、2.5.8 目标尺寸（最小值）、3.3.8 无障碍认证（最低）；A 级的 3.2.6 一致的帮助、3.3.7 冗余输入。
- 2.3.3 交互触发的动画（尊重「减少动态效果」）是 AAA。
