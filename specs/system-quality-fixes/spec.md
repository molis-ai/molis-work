## 验收标准

| 编号 | 场景与验收 |
| --- | --- |
| QRF-01 | 同一请求的一条无关写入成功不能抵消目标 Todo 写入失败；要求证据时无法核对的主人版本只能记未知。回放只消费自己的观察记录，空回放即使前一轮留下 501 条也不得通过，并发轮次不能互借。 |
| QRF-02 | 样本执行中申请的保留与样本版本有明确关联。正常删除释放所属保留，清理后旧证据不可读，同时保住其他样本仍需要的数据。单轮超过 500 条、或两轮各 260 条，均须保留全部不同记录且逐轮生成独立评测。后续留存或评测落库失败、取消时，恢复先前完整留存；既有授权被撤导致撤销也被拒时，恢复授权后删除可释放该真实版本的留存，即使尚无评测和回执，或首次登记从未写出样本行。按指定版本和按所有版本都能清除该样本的孤立留存，空 Home 删除不存在的样本不建库。删除一个版本可一次释放其全部记录，保住其他版本和主人的留存。同一毫秒删除再按原文重建同版，在途旧回放也不得写入新样本。 |
| QRF-03 | 100 项等待后另有一项需决定时，SQLite、文档 SDK、分区与公开状态按当前可见范围完整计数，工作台能找到并处置该项。保留读权限、操作时的版本和核权。 |
| QRF-04 | 同一项主人工作被评两次，保留两次尝试和一件完成成果。第 37 批首页与第 61 批工作卡的实际呈现、明确采用与撤回按主人回执、对象版本和工作关联核算，重复请求不产生第二次采用，沉默不计选择。 |
| QRF-05 | 已知发生时间的晚到事实按实际顺序判读；不确定的次序与覆盖记未知。今天暂停不改变不相交的封闭历史窗口。动态查询曾保留的记录不能证明后来没有其他匹配记录被清理。仅当本轮核全冻结的记录编号且全部仍受该样本留存保护，才忽略项目级过期或清除缺口。 |
| QRF-06 | 搜索被关闭后迟到的打开结果不抢导航或焦点；只读搜索失败保留原词与重试入口；成果的各个引用来源均成功且无引用时才能画空态，单源失败保留成功来源并可重试。成果详情分别读取关系账本、当前项目中本人可读的插件引用动作和助理工作。缺席或无权的来源不影响空态；一个可读来源失败时保留其他来源的打开入口，该来源的重试重新核权，只更新仍在查看的版本，并保住当前语言与键盘焦点。以真实 Pages 文档、成果账本读取故障及助理工作并存验证故障和恢复。 |
| QRF-07 | 首次纯空白建项目进入项目首页；保留正式摘要与材料采用后的打开路径。等待期间不重复提交，服务端幂等仍有效。 |
| QRF-08 | 新脚手架的成果类型由插件 ID 派生，保存、预览与清单一致；已有插件的身份不改。安装版作者可循随包说明跑通公开命令、打包和验签，随包文档链接可达。在安装版 Web 登录且个人项目可见后，从安装根运行手册的 plugin install 命令可先预览，再明确确认并在同一项目读回插件版本与发布者。手册区分现行第三方和内置接线，统一命令、所有权及已过期说明。 |
| QRF-09 | 发行冒烟用真实归档和隔离的受控登录验已登录工具发现，同时保留登出拒绝；同一安装未登录时拒绝插件安装，错误项目及单纯预览均不能固定发布者或安装包。A 切到 B 后旧安装调用须拒绝，B 无权确认 A 的项目，切回 A 仍须重新附着。MCP 校验器对匹配请求的协议错误及时结束。续验 SBOM、卸载预览和确认。 |
| QRF-10 | 无变更的文档同步五轮不重写相同字节，实际修改仍使用条件写入；工作记录在批量阈值不把同步落盘放在业务返回路径，保留有界队列及关闭排空。Goals 丢回执后真正重建协调器再重试；修订本地与 Full 执行说明。 |

涉及评测、工作记录、首页／助理、同步适配器与工作台、作者工具、发行烟测及各主人的现有测试。沿用公开合同、已有身份、请求 ID、版本与事务，不由 UI 重算权限。不涉及发布或推送、生产密钥、真实用户 Home、后续批次未实现的第三方驱动或用户长期采纳指标。

## 主干集成

复查基线为 3b00662be6，集成在含三语治理的 487a0890e0 上。QRF-06 的引用状态随三语词包交付。QRF-08 保留脚手架的三语权限理由，日语开发预览须能读出日文标题、保存数与来源。新项目的成果按作者 ID 区分，仓库样例已发布的 `com.example.note` 继续可读。QRF-04 沿用 v1 运行、原始结局计数及逐条预期指针。汇总按本轮确曾引用的记录编号，经工作记录的评测用途重新读取主人、工作、对象版本与回执；同一事实跨次去重。每个互动阶段单列无法还原身份的原计数，执行及完成只计主人有据的工作，并单列证据不足的运行。回放以自己的记录编号为准；动态样本、部分消失的记录、同号样本删除重建均不能借用后来的记录。首页与工作卡的漏斗预期可直接使用现成 funnel_stage_separation 保存这项预期的完整证据。历史结论、人审与其他预期的证据内容原样保留。
