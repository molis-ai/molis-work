## 打开

```bash
python3 -m http.server 4410 --bind 127.0.0.1 --directory docs/design
```

再打开 `http://localhost:4410/intelligent-surfaces-forms/`。顶部带斜纹边的一条是原型控制：方案、位置、异常、中英文、深浅、重置。

## 三个方案

四种形态在三个方案里都有，同一份声明（标题、状态、摘要、时间、谁做的、操作）画出来；三个方案只差**用什么领头**：

| 方案 | 名字片 | 行 | 卡片 | 速览 |
| --- | --- | --- | --- | --- |
| A 状态领头 | 状态环加名字，带边框 | 状态环、标题、「插件 · 时间 · 谁」、状态标签、主操作 | 状态环加标题、状态标签在右；下面插件与时间、摘要、进度、操作 | 锚定的浮层 |
| B 主人领头 | 插件色块加名字，需要你时带色点 | 插件色块（大）、标题、「时间 · 谁」 | 顶上一条插件色带（插件名、时间、状态标签），下面标题和正文 | 锚定的浮层，头部用插件色块 |
| C 内容领头 | 像正文里的链接，下划线加色点 | 标题后面直接跟摘要，操作悬停才出 | 截图在最上，标题大字，状态、插件、时间收进底部一行 | 右侧滑出的窄栏（手机上是底部弹层） |

取舍：

- A 一眼看出哪件要你管；插件身份弱，几个插件的东西混在一起时要读小字。
- B 一眼看出东西来自哪个插件，适合对话、讨论里几个插件混排；颜色多，状态只剩右边一个标签，和插件色容易互相抢。
- C 最像在读内容，适合 Feed、文稿这类内容多的对象；状态和后果藏在底部，扫一列「哪件要我管」最慢，行的操作不悬停看不见。

三个方案共用的部分（不在比较之列，也请一起看）：

- 状态：进行中、要你决定、要你验收、失败、部分完成、过期、无权查看、已删除，加没有声明的兜底（只显示图标、名字、所属插件和打开，IUI-02）。状态环是简化画法，产品里用状态环体系的 12 段细环。
- 读不到时（IUI-10）：过期显示最后读到的值与时间并给「再读一次」；无权查看只写「没有权限查看」和它属于哪个插件，不露标题；已删除只留名字（划掉），不留可点的操作。
- 操作（IUI-07、IUI-08）：主操作一个，次操作一两个，其余收进「更多」（打开到准确位置、速览、复制引用、放进、交给、挂到 Goal、提醒我）；外发和停止这类有后果的，后果写在按钮旁；点了按钮变成「正在做…」，再点不重复执行；做完收成一行回执，能撤销的带撤销。
- 速览：名字片悬停或键盘聚焦出，点标题也出；顶上是「在哪」（例如 Goals › 发布 v2 › 完成要求），底下「打开到准确位置」「放进」「交给」。
- 「放在这里：…」一句理由（§3 第 7 条），在对话和讨论的卡片底部。
- 等你不放卡片，按梯度降为行（IUI-03）。
- Inbox 详情只在两个挂载位接受别人的东西（IUI-13）：「对上哪条要求」放 Goals 的名字片；交给 Coding 以后，「交给了谁」出现 Coding 接的那一轮。
- 同一件东西在各处是同一份事实：在 Inbox 里交给 Coding，对话、讨论、等你里那张卡都收成回执（IUI-03）。

## 建议走一遍

1. 位置「标本」：从上往下看九种状态，三个方案来回切。把鼠标停在名字片上看速览，点「更多」。
2. 位置「插件内：Inbox」：点「交给 Coding」两次（第二次不重复执行），看下方「交给了谁」出现新的一轮；再撤销。
3. 位置「对话」「项目讨论」：看名字片、卡片和理由；在讨论里勾「以成员小周的身份看」，客户反馈那张卡变成「没有权限查看」。
4. 异常切成「Goals 读不到」「Inbox 撤权」「Coding 一轮被删」，各处跟着变。
5. 位置「等你」：卡片降成行。
6. 换 EN、深色，窗口缩到 1024 和手机宽度。

## 模拟的部分

- 对象、状态、操作结果都是 `data.js` 里的示例；「执行」只等 0.65 秒再写回执，没有动作网关。
- 进行中的卡片不会实时更新（活卡在第二片）。
- 按钮、标签、分段、状态记号、状态环、进度条和提示条用的是组件板实件（共用的 `docs/design/kit/`）；名字片、行、卡片、速览这四种形态本身还是原型的写法，做产品时按 IUI-21 在组件板加「呈现形态」一节。
- 状态存在浏览器 localStorage（键 `molis-proto.intelligent-surfaces-forms.v1`），「重置」清掉。
