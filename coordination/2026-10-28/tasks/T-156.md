## 2. 目标

1. 三处都不留下半个字，不超过上限的原样保留：
   - 选中内容的正文：按字截到 200000 个字；
   - 读到的文字：按字截到 198000 个字；标题按字截到 200 个字；「超了没有」也按字数判断；
   - 对话里每条灵光：超过 12000 个单元才截，取开头 12000 个单元，截点落在字中间就退到这个字之前；截了才写「（以下省略）」。
2. 不含两单元字的文字与现在完全一样。
3. 截完的长度不超过下游的上限：
   - 正文和读到的文字不超过按字数的上限，`lingguang.create` 的 schema 与库照样收下；
   - 对话里每条灵光仍不超过 12000 个单元，整场 180000 个单元的预算不变。
4. 用例钉住上面几条：
   - `:81`、`:153-156` 改回按单元截，或改成按单元、不切开字（T-153 的写法），都有一句断言红；
   - `:162` 改回直接按单元截（留下半个字），或改成按字数，都有一句断言红。

   ```ts
   /** A spark's opening part for the conversation, said so when the rest is left out: up to SPARK_IN_PROMPT UTF-16 units, as the whole prompt is counted, and never half a character. */
   function sparkOpening(body: string): string {
     if (body.length <= SPARK_IN_PROMPT) return body;
     let end = 0;
     for (const character of body) {
       if (end + character.length > SPARK_IN_PROMPT) break;
   ```

   ```ts
       if (count === limit) break;
       end += character.length;
       count += 1;
     }
     return value.slice(0, end);
   }
   ```

   - 没超过时 `end` 就是 `value.length`，`slice` 回整串。

M8 的写法：

```ts
function firstCharacters(value: string, limit: number): string {
  let end = 0;
  for (const character of value) {
    if (end + character.length > limit) break;
    end += character.length;
  }
  return value.slice(0, end);
}
```

M9 的写法（就是起草线第一版、统筹改成按单元之前的写法）：

```ts
function sparkOpening(body: string): string {
  const kept = firstCharacters(body, SPARK_IN_PROMPT);
  return kept.length < body.length ? kept + "\n（以下省略）" : body;
}
```
