## 打开

从工作树根启动：

```sh
python3 -m http.server 4439 --bind 127.0.0.1 --directory docs/design
```

访问 `/authorization-review/?scheme=B&surface=manage`。`scheme=A|B`，`surface=choose|manage|review`，`lang=zh|en`，`theme=light|dark`，`scene=normal|restored|expired|revoked|unknown|error|empty|loading`。顶部控件可切换，不属于产品界面。

按钮只改变当前页内存：授权后转管理；收窄保留原范围外的拒绝；撤销显示影响并确认；第一次模拟保存失败保留选择，重试可以成功；重启后原等待已取消、已到期的请求都没有决定按钮；仍 pending 但授权撤销时仅可关闭；结果未知只核对、不重放。刷新后重置演示数据。恢复状态在合同评审核查真适配器后修正，不再把「重启后记录」一概画成可拒绝的 pending。
