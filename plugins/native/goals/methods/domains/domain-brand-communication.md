# 品牌与传播

## 规划路径

1. 明确目标受众、使用时刻和希望建立的核心认知
2. 提炼现有替代方案的不足、独特机制、结果和 Why us
3. 建立信息层级、事实证据、语气和视觉原则
4. 按渠道与场景制作可复用的表达资产
5. 用理解、记忆、主动转述和行为反馈校验认知

## 必须覆盖

| area | label | question |
| --- | --- | --- |
| brand_audience | 目标受众 | 希望改变谁的哪一种认知或选择？ |
| positioning | 定位 | 我们替代什么，独特机制和结果是什么，为什么由我们实现？ |
| message_hierarchy | 信息层级 | 一句话、三点展开和完整叙事分别传达什么？ |
| proof_assets | 可信证据 | 哪些产品事实、案例或演示支撑主张？ |
| expression_system | 表达系统 | 语气、视觉和渠道适配怎样保持同一核心认知？ |
| perception_feedback | 认知反馈 | 如何知道用户真正理解、记住并愿意转述？ |

## 依赖规则

| rule_id | statement | direction_hint |
| --- | --- | --- |
| expression-after-positioning | 文案、视觉和渠道资产消费已经确认的受众、定位与证据。 | expression system depends_on positioning and proof |
| launch-after-assets | 大规模发布消费已经验证的核心信息和可复用表达资产。 | launch depends_on validated message assets |

## 完成证据

- 可追溯到产品事实的主张清单
- 关键受众对核心信息的理解或转述反馈
- 跨主要渠道的一致表达样例

## 收口检查

- 受众、时刻、独特机制和结果都能用一句人话说明
- 传播主张没有超出可验证证据
- 渠道差异没有改变品牌的核心认知

## 常见误拆

- 先做 Logo 和口号再补定位
- 用行业套话代替独特机制
- 把曝光量当成理解和信任
