## 1. 背景

### 1.1 现在有三条路能起本机终端进程

| 路 | 谁用 | 谁选程序、谁选目录 | 授权 |

| ① 工作台 control token 通道 | 工作终端（`[data-tui-pane]`，`apps/workbench/src/terminal/`） | `POST /api/goals/:id/panels` 收请求体的 `command`（自定义终端）与 `cwd`（`apps/local-host/src/web-panel-routes.ts:104-118`），写进项目目录库的面板表，再由页面经 `/pty` 发 `{ type: "spawn", command, args, cwd, env }`（`apps/workbench/src/terminal/panel-spawn.ts:21-40`）；`apps/local-host/src/pty-socket.ts:150-152` 对 control token 连接只查「有面板号、不是只附着就要有命令」 | 只有 control token；没有安装、没有 grant |

### 1.2 现有服务 `pluginTerminalFor`（`apps/local-host/src/plugin-terminal-service.ts`）

原样（`:20-42`）：

```ts
export function pluginTerminalFor(home: string, manifest: PluginManifest, context: PluginStartContext,
  files: PluginOwnerFilesClient | undefined, assertActive: () => void) {
  if (!files || !manifest.permissions.some(item => item.permission === permission)) return undefined;
  const panels = new Map<string, MolisWorkPtyHost>();
  const client = Object.freeze<PluginTerminalClient>({ async open(input) {
    const scope = currentPluginInvocation();
    if (!scope || !inPluginInstance(scope, context) || !("definition" in scope) || scope.definition.operation !== "command"
      || pluginInvocationReadOnly(scope) || scope.caller.audience !== "user" || !scope.definition.action.permissions.includes(permission))
      throw new ActionError("actions.forbidden", "交互终端只能由当前页面的授权动作启动");
    if (!/^[a-z][a-z0-9-]{0,63}$/u.test(input.key) || !isAbsolute(input.command) || input.command.includes("\0")
      || !input.title.trim() || input.title.length > 120) throw new ActionError("actions.input_invalid", "终端启动参数无效");
    const check = () => { assertActive(); context.requireGrant(permission); assertCapturedPluginActionCurrent(scope, context); };
    check(); await scope.caller.beforeEffect(); check();
    const host = hosts.get(resolve(home));
    if (!host) throw new ActionError("actions.unavailable", "终端宿主尚未连接");
    const identity = [context.install_id, scope.caller.project_id, scope.caller.actor_id, input.key];
    const panelId = "plugin-" + createHash("sha256").update(JSON.stringify(identity)).digest("hex").slice(0, 32);
    const cwd = files.rootPath(); check();
    host.spawn({ panelId, command: input.command, args: [], cwd });
    panels.set(panelId, host);
    return { panelId };
  } });
  return { client, dispose() { for (const [id, host] of panels) host.kill(id); panels.clear(); } };
}
```

## 2. 目标

1. **一项服务，两种实例。** 宿主运行的插件（不论官方、内置、个人；Home 实例与项目实例）只要 Manifest 声明 `terminal:run`，就得到 `services.terminal`；没声明就没有这项服务。沙箱包声明了（必需，或人批准的可选），在启动时以 `sandbox.service_not_given` 拒，代码一行不跑。
2. **只认可信上下文与授权。** `open` 只在本安装（同一半、同一世代）当次的、受众为 `user`、command、非只读、自己声明了 `terminal:run` 的动作里有效；每次都核安装在跑、持有 `terminal:run` 授权、原调用没取消没撤权，`beforeEffect` 前后、每次异步 I/O 之后各核一次。安装、项目、人只从调用上下文取，输入里出现就整个拒。
3. **工作目录只在允许的根里。** 根只有两种：本次调用所在项目已关联的工作目录（按 `workspace_id` 选，另要 `workspace:read` 授权），或本插件 Manifest 声明的主人文件目录。相对路径按段检查，解析真实路径后仍须在根里、是目录。别的一律拒，不起进程。

全部拒绝都有用例（第 6 节 RAC-2550～2559），S-103 行逐分句点名用例。

## 5. 做法

### 已定的决定（起草线定，统筹审稿时可改；改了写进【统筹答】）

1. **服务形状：只做 Runtime SDK 服务 `services.terminal`，不登记成动作。** 启动本机进程不是目录里的能力：不给 Agent、工作流、MCP、别的插件调。能被目录看见、被授权的是插件**自己的**那个动作（例如 `shelf.terminal.open@1`，`tooling/gates/actions/actions.tsv:547`），它声明 `terminal:run`、受众只有 `user`；服务只是这个动作的效果端口。这符合 `specs/action-architecture/spec.md` §3「注册一次」：能力只在动作目录登记一次（插件的动作），平台不另开第二个入口、不写宿主分支、不列插件名。
2. **权限名不变：`terminal:run`。** Shelf 的 Manifest（`plugins/native/shelf/src/manifest.ts:37`）已经这么写；`HOST_SERVICE_PERMISSIONS` 加一项 `terminal: [TERMINAL_RUN_PERMISSION]`，常量 `TERMINAL_RUN_PERMISSION = "terminal:run"` 放在 `plugin-service-permissions.ts`，`plugin-terminal-service.ts:9` 改用它。
3. **新输入形状**（合同 `PluginTerminalClient.open`，输出不变 `{ panelId }`）：

   ```ts
   export type PluginTerminalDirectory =
     | { readonly root: "workspace"; readonly workspace_id: string; readonly path?: string }
     | { readonly root: "owner_files"; readonly path?: string };

   export interface PluginTerminalClient {
     /**
      * Starts (or reattaches to) the plugin's interactive terminal for this key. The Host takes the installation, the project and the person
   ```
