## 做了什么

灵光的记录、材料读取和对话迁到项目 Plugin Runtime，经共同动作、模型、材料和数据库端口执行。删除宿主专属动作/HTTP 适配、插件旧路由和私有读流器。每个项目一个实例，仍用原 Home 灵光库及基线 1；ID、项目分区、幂等、移动/复制、版本冲突、对话快照与项目删除保持。对应防腐唯一 spec 的 RAC-31–36。

页面转到 `/api/plugins/io.molis.work.lingguang/sparks…`，共同 `molisWorkRequest.stream` 读取 NDJSON。文字先预览；模型成功且原材料、调用与安装授权仍有效，才成对保存消息。取消、断连、停用、两种撤权及重启拒绝迟到预览和写入，恢复后可继续。工作流内容处理器保留原调用的权限与限定名单，不能借插件自身授权扩权。

## 公开合同与 API 影响

`contracts/platform/ui` 增加 `UiRequestCall.stream` 与 `UiStreamRequestInit`；自行实现请求客户端的调用方需提供这个新方法，普通请求调用方式保持。灵光工厂、数据库声明与端口取代删除的内部 Host 接口；仓库调用方和手册同片更新。材料读取动作补必要的材料权限，业务动作 id/version/schema 与 MCP 名称不变；工作流和绑定仍指向同一业务动作。API 与动作快照已更新。

## 只许减少的数字与基本合同

相对材料候选，巨大单元、浏览器原始 fetch、插件专属宿主文件及宿主外点名数量下降，其他受控数字不增长。能力仍由插件统一声明；身份来自调用上下文，密钥只给引用；模型/外部等待经并发动作，提交前复查原权限；插件不引用其他插件实现，模型执行仍经 Host 的 Prologue。
