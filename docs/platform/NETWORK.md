# Molis Work 会联网去哪里

[English](NETWORK.en.md)

Molis Work 是本地优先的工作台：你的目标、笔记和文件放在你自己的电脑上。这一页写清楚的是它**自己**向外发起的网络请求：哪些功能会联网、去哪个网站、发出去什么、有什么限制。共 16 类编号（第 0 类是模型，第 1–16 类不是模型调用；原来的第 6 类 Casebook 参考客户端已随 Casebook 删除、第 7 类已随旧炼金术士删除，其余编号保留不复用）。

你在终端面板里运行的命令、你批准后由宿主运行的命令（如 `git push`）、你自己启动的外部 Agent，以及你点击的外部链接，都是你的操作，不在本页范围内。

> 给维护者：新增任何向外的请求（`fetch`、`https.request`、子进程里的联网命令），要先在本页加一类或补进已有的类，写明主机、触发、发出去什么和限制。最初对照 2026-10-09 的 `main`；第 0 类于 2026-10-10 对着 `06a64c98c` 核对；第 14–16 类（账号头像、中央账号 V2 Auth 服务、个人云同步 Cloudflare Worker/R2）于 2026-11-26 对照 `2ca43ef58f` 补齐。

只有第 9 类和第 10 类会把一个**名字**（包名、网站名）发给与你的功能无关的第三方；它们发出去的不含你的内容。下面单独写了这三种情况。

## 会把名字告诉第三方的三种情况

1. **插件创作台的构建检查（第 9 类）**：生成的插件如果声明了运行时依赖，构建检查的「打包」一步会把依赖的**包名和版本**发给 npm 官方仓库（`registry.npmjs.org`）下载。没有声明依赖就不联网。创作台界面里写了这一句。
2. **代理的假地址环境（第 10 类，10a）**：你的电脑开了代理软件，并且查任何网址都先得到一个占位用的假地址（`198.18.0.0` 到 `198.19.255.255`）时，Molis Work 会把要连的**网站名**发给 Google（`dns.google`）和阿里云（`dns.alidns.com`）的公共域名查询服务，问真实地址。受影响的网站名是：你配置的模型、图片和判断服务，以及 AnySearch（`api.anysearch.com`，Feed 的网页搜索）。只有设置了代理环境变量（`https_proxy`、`HTTPS_PROXY`、`all_proxy`、`ALL_PROXY` 之一）并且系统返回了假地址才会这样；普通网络不会。
3. **Jelly 导入网页时的假地址环境（第 10 类，10b）**：系统给出的地址全是假地址时（不看代理变量），Jelly 读网页会把**那张网页的网站名**发给 Google 的公共域名查询服务。它比上一种更接近「你读了哪些站点」，所以单独写出来。

这三种都是为了在特殊环境里仍能工作，发出去的只有名字，没有凭据和内容；代理软件本来就能看到这些名字。

## 逐类说明

### 0. 模型、图片、判断服务

- **什么时候**：你用助理、插件里的 AI 功能、图片生成、Functions 等；另外，你在「设置 › 模型设置」保存供应商时，如果这次保存改变了 Molis Work 到达该供应商的方式（新的密钥或连接、地址、API 格式、思考与缓存设置，或新增、重新启用了一个模型），会先向这个供应商的地址发**一次连通性检查**：一个很短的测试请求，带你输入的密钥或你选的那条连接里的密钥。只改名字、关掉一个模型这类没有改变到达方式的保存不发检查。每个模型旁的「测试这个模型」按钮发的是同一种测试请求。
- **去哪里**：你自己在「设置 › 模型设置」或「服务连接」里配置的服务地址。Molis Work 不替你选模型厂商，没有哪个厂商的地址是默认联网的；代码里带着厂商地址的有三处，前两处在你保存之前都不会联系任何地方：（1）「设置 › 模型设置」的一键模板（代码里叫 `MODEL_PROVIDER_TEMPLATES`）：选一个模板只是把地址、API 格式和长期不变的模型名预填进表单，不带密钥，共 8 家的官方地址：`api.anthropic.com`、`api.openai.com/v1`、`api.deepseek.com`、`api.minimax.cn/anthropic`、`dashscope.aliyuncs.com/compatible-mode/v1`、`api.moonshot.cn/v1`、`open.bigmodel.cn/api/paas/v4`、`openrouter.ai/api/v1`；（2）图片连接的表单里点选 OpenAI 或 Gemini 预设时预填它们的接口基址（你保存之后才会用）；（3）一条只给开发用的环境变量路径，不经过保存：只有开发者设置了 `MINIMAX_API_KEY`、又没有配置任何模型供应商时，才把 `https://api.minimax.cn/anthropic` 当作文本模型地址，文本模型请求直接发往那里；普通使用不会碰到。判断服务（Functions）使用 `api.typesafe.ai`。
- **限制**：所有模型请求都经同一个 Home 的 Prologue 推理端口。这个端口默认拒绝一切出站，Molis Work 只放行三条：模型、外部 MCP 服务（助理和 Coding 调用你连接的 MCP 服务）、本机回环地址。派出前会复查授权和配置，被取消或撤权的调用不再发出。保存时的连通性检查和「测试这个模型」按钮都不走这个常驻端口：它们用同一套 Prologue 代码、同样只放行这三条，由一个用完即丢的临时实例发出，没有逐次的授权复查。连通性检查只发往你填写的那个地址；没通过就什么都不保存，提示里不含密钥。

### 1. 服务连接

- **什么时候**：你在「设置 › 服务连接」连接第三方账号时；之后连接器同步、读文档，或助理、Feed、成果库用到这个连接时。开新项目时如果你在项目上手里选了 Gmail 来源，Molis Work 会用这条连接直接读你最近的邮件作为上手材料（只读近 7 天或 30 天、排除垃圾邮件和已删除、至多 20 封、不读附件）。
- **去哪里**：各服务自己的主机（目录里有数十个）。可选的 OAuth 经纪服务（`auth.molis.ai`，一个 Cloudflare Worker，只有配置了才用，不在你的电脑上运行）。
- **限制**：访问令牌由连接提供，不从插件输入里读；不跟随跳转；单次请求有时限。
- **本机命令行与 MCP 子进程**：有的连接用你本机的命令行（`gh`、`hf`、`sentry`、`lark-cli` 等）登录，联网的是那条命令。飞书和 Lark 的 MCP 连接器会在你的电脑上启动一个子进程：运行的是随 Molis Work 一起安装、版本固定的 `@larksuiteoapi/lark-mcp`（不再用 `npx` 临时下载），这个子进程只拿到 App ID、App Secret、令牌、你已经设置的代理与证书变量，以及系统的 `HOME`、`PATH` 这类基本变量，拿不到你的模型密钥或其他环境变量。每次启动它的工作目录都是一个新建的空目录（只有你的账号能写），用完即删：这个包会读工作目录里的 `.env` 文件，里面写一个代理变量就能改变带着 App Secret 的请求发往哪里，所以不在 `/tmp` 这类共用目录里运行。

- **准备安装。** 准备原生客户端或 PowerShell 的方案时，Molis Work 会查询官方发布信息与校验值。原生客户端来自 GitHub、`gitlab.com` 或 `acli.atlassian.com`。GitHub 的发布与元数据也可能经 `api.github.com`、`raw.githubusercontent.com`、`release-assets.githubusercontent.com` 和 `objects.githubusercontent.com` 提供。
- **执行安装。** 缺少合适的运行时时，Node.js 从 `nodejs.org` 下载，uv 和 PowerShell 从 GitHub 下载。uv 补装所选 Python 时使用 GitHub 上的 Python Standalone Builds。Molis Work 自行下载的发布文件逐跳核对地址，原生客户端的归档按方案核对 SHA-256。[uv 的 Python 下载来源](https://docs.astral.sh/uv/reference/settings/#python-install-mirror)
- **包源收到的信息。** npm 和 Python 工具默认使用 `registry.npmjs.org` 或 `pypi.org` 的索引及其返回的分发地址，方案也可指定无凭据的 HTTPS 包源或本机包源。Microsoft Graph 的身份验证模块从 PowerShell Gallery（PSGallery）获取，Microsoft 列出的包分发域名有 `cdn.oneget.org` 和 `cdn.powershellgallery.com`。包管理器查询包名、版本和依赖，下载所选版本及适合本机系统与架构的文件。安装使用独立工具目录和环境，下载时项目内容、模型密钥和服务令牌留在本机。[PowerShell Gallery 的联网说明](https://learn.microsoft.com/en-us/powershell/gallery/getting-started#network-access-to-the-powershell-gallery)

### 2. 订阅源（RSS、YouTube）

- **什么时候**：Feed 手动或定时拉取来源。
- **去哪里**：目录里的现成 RSS/Atom 源、你填的公开 RSS 地址、YouTube 公共频道订阅（`www.youtube.com`）。
- **限制**：白名单传输；你填的公开地址会先解析并拒绝本机和内网地址；使用条件请求（etag、last-modified）。

### 3. 网页搜索（AnySearch）

- **什么时候**：Feed 的网页搜索来源手动或定时拉取。
- **去哪里**：只有 `api.anysearch.com:443/mcp`，匿名，不带凭据。
- **限制**：到 AnySearch 的出站**只有一条实现**（`apps/local-host/src/anysearch-transport.ts`）：固定主机；解析出的地址必须是公网地址并钉住，校验证书并核对连上的对端地址；不跟随跳转；请求 64 KiB、响应 1 MiB 的上限。代理的假地址环境下的处理见上面第 10 类，Feed 的网页搜索在这种环境里可用。
- **发出去的**：搜索词和要提取的网页地址。

### 4. 你点名的网页和链接

- **什么时候**：材料导入读网页；Jelly 读你给的来源。
- **去哪里**：你给的 http(s) 地址。Jelly 的哔哩哔哩适配器还会去固定的 `api.bilibili.com`，并下载接口返回的字幕地址；小红书适配器下载笔记里给出的图片地址（必须是公开的 https）。音频和视频不下载、不转写。
- **限制**：材料导入读网页是你明确的抓取，请求不带凭据，12 秒、4 MiB、最多 5 次跳转，**不拦本机和内网地址**（包括本地页面）。Jelly 只收公网地址、逐跳复验、解析后钉住地址、只带公开页头、不带 Cookie；网页和接口 400 万字节，图片每张至多 25 MiB。

### 5. 插件创作台生成的插件

- **什么时候**：你试用或安装了创作台做出来的插件，它运行时联网。
- **去哪里**：该插件声明、你批准过的主机。
- **限制**：只许 https、默认端口、地址里没有凭据；连接实际用的每个地址都要是公网地址（代理的假地址段按正常环境放行，这是开发机的既定做法）；不跟随跳转；15 秒、响应 1 MiB、请求 256 KiB。检查与验收阶段不联网，人手试用时只读（GET、HEAD）。

### 7. （已不再有）

原来的第 7 类是炼金术士的市场脉搏，随旧炼金术士在第 44B 批删除；编号保留，不给别的类用。

### 8. 本机内部

Molis Work 的组件之间用回环地址（`127.0.0.1`）联系：动作网关、安装器对本机服务的健康检查、对侧栏浏览器和创作台预览浏览器的调试端口。不出你的电脑。

### 9. 创作台的构建检查

- **什么时候**：插件创作台的构建检查在「打包」一步，**只在生成项目声明了运行时依赖时**联网。
- **去哪里**：`https://registry.npmjs.org`，包的元数据和压缩包（压缩包地址必须同源）。
- **发出去的**：只有包名和版本（请求路径）。
- **限制**：只收精确版本或 `^x.y.z`、`~x.y.z`；20 秒；不跟随跳转；元数据和压缩包各至多 8 MiB；至多 64 个包、深度 12；SHA-512 完整性必须对得上；不执行任何包脚本，解包在禁网的沙箱里。

### 10. 主机名的公共 DNS 回退

见上面「会把名字告诉第三方的三种情况」的第 2、3 种。

- **10a（模型、图片、判断服务和 AnySearch）**：只在设置了代理变量且系统解析返回假地址时，向 `https://dns.google/resolve` 和 `https://dns.alidns.com/resolve` 查 A 和 AAAA 记录，先试上次通的那一家，传输失败才换另一家。发出去的只有网站名和记录类型；8 秒；不缓存答案；返回的每个地址仍要通过公网地址检查。
- **10b（Jelly 读网页）**：系统解析全是假地址时，向 `https://dns.google/resolve` 查 A 记录（只有 Google 一家）。发出去的只有被读网页的网站名；6 秒；答案必须是完全公开的 IPv4；缓存 60 秒；返回后仍要通过公网地址检查。

### 11. （已不再有）

原来的第 11 类是本机语音转写组件下载约 626 MB 的模型；第 112 批删除了本机语音转写，音视频只保存原件。编号保留，不给别的类用。

### 12. 侧栏浏览器

你在侧栏浏览器里输入网址，或助理在同一页上操作时，Molis Work 启动的 Chrome 系浏览器（无头、独立的用户数据目录）访问任意 http(s) 网站；输入的不是网址时会落到 `https://www.bing.com/search`。本服务自己的回环地址禁止加载；助理的每次查看和动作由 Prologue 判断，站点按你允许或屏蔽的决定执行。

### 13. Feed 的研究库来源

Feed 的「研究库」来源同步时，Molis Work 起一个 `git` 子进程，向 `https://github.com/<owner>/<repo>.git` 的 `main` 分支浅拉取（`git fetch --depth=1`）到 Molis Work 自己的缓存目录，不碰你的检出；不弹出终端提问；120 秒、输出 16 MiB；只读 `sources.json`、`catalog.json` 和每个包下的 `manifest.json`、`research.json`、`report.md`。

### 14. 账号头像

- **什么时候**：你在已登录状态下查看包含绑定第三方账号头像的界面（例如顶栏账号菜单或账号设置页）时，由浏览器加载头像图片。
- **去哪里**：Google 与 GitHub 的头像图片域名（`*.googleusercontent.com`、`avatars.githubusercontent.com`）。
- **发出去的与限制**：仅普通图片请求，不发送中央 Auth 令牌或 Molis Work 凭据，且使用 `no-referrer` 策略；未登录或未绑定对应头像时不发起请求。

### 15. 中央账号登录与会话管理（Auth V2）

- **什么时候**：你在 Molis Work 中点击登录（密码、邮箱/手机验证码、Google/GitHub 授权）、恢复或刷新账号会话、查看或修改个人资料与登录方式、查看租户/订阅/权益，或退出登录撤销会话时。
- **去哪里**：宿主环境配置中固定的中央认证服务地址（`horizontal/account`；测试环境如 `https://auth.test.molis.ai`，生产环境为经平台核准的 HTTPS Auth 域名，本机开发为配置的数字回环地址如 `http://127.0.0.1:8787`）。前端、插件与业务输入不能指定或篡改上游 Auth 地址。
- **发出去的与限制**：仅按冻结的 Auth OpenAPI 合同发送认证事务、会话刷新/撤销及资料/权益请求；不遵循 HTTP 重定向、拒绝超大或结构异常响应、不对带副作用的写请求自动重试；中央访问令牌与刷新令牌只在 Host 密钥库与内存会话管理器内使用，绝不暴露给浏览器、插件或模型。未配置中央 Auth 或未登录时，不发起请求，本地空间完全离线可用。

### 16. 个人云同步（Cloudflare Worker / R2）

- **什么时候**：仅当你已登录个人账号、主动进入个人空间、且在本台设备上明确选择开启自动同步或手动点击「立即同步」／查看云端保留历史与回收站时（默认关闭；新设备首次进入个人空间会先询问，未同意不启动后台传输）。
- **去哪里**：可信宿主环境显式配置的规范 HTTPS 同步服务地址（`modules/sync-replication` 与 `apps/sync-worker` 经 `MOLIS_WORK_SYNC_ORIGIN` 等配置，测试环境如 `https://work.test.molis.ai`，或开发显式开启的本机 `http://127.0.0.1:8788`）。同步服务运行在 Cloudflare Workers + D1 + 私有 R2 上；浏览器、插件与登录页参数不能选择或覆盖同步目标。
- **发出去的与限制**：仅上传你在「设置 › 同步」里明确勾选的集合的增量变更记录，以及由各内容主人显式声明的受保护私有附件分块（固定 4 MiB 分块、逐块与整体 SHA-256 校验，结构化记录与附件共享 100 MB 账号配额；不扫描本地任意目录，不上传本地空间数据、模型密钥、第三方服务连接凭据或外部 AI 工具会话原文）。请求仅携带当前账号的 Auth Bearer 令牌（或短时签名读取证明），不跟随重定向；退出登录、切号或切回本地空间时立即中止在途同步。未配置 `syncOrigin` 或未开启设备同步时，零网络请求。

## 想少联网

- 不连接服务、不添加订阅源、不用网页搜索，对应的类就不会发生。
- 保持使用本地空间且不登录中央账号，第 14、15、16 类均不会发生；即使登录账号，默认不开启本设备云同步就不会触发第 16 类。
- 模型请求只发给你配置的那个服务，不会发给其他厂商。
- 第 10 类只在代理的假地址环境下发生；不设置代理环境变量就不会触发 10a。
