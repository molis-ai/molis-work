# Issue V0 本地试用说明

状态：本地试用入口和操作说明；工程、实际操作、用户验收的最新结论以 [V0 规格与验收记录](spec.md) 为准。未推送、未合并或安装到日常 Work。

## 从这里开始

打开 [Issue 本地预览](http://127.0.0.1:63950/plugins/issues)。此预览使用独立 Home，原有记录及 DEMO 01—07 已保留。它复用已获准的模型配置，修改这里的问题或配置不会修改日常 Work Home。

1. 点「记录问题」，只填写问题描述，按需拖入、粘贴或选择截图。文字区随内容伸缩，图片接在文字后。用户自行截图，Issue 不申请屏幕共享。
2. 点「交给助理整理」。描述是标题和类型的依据，截图辅助理解。生成后核对或修改标题、类型，点「确认并保存」才写入问题库。
3. 打开问题默认只读。点「编辑」后可修改，直接「保存修改」或「取消编辑」；也可主动让助理重新整理，确认后更新同一条问题。
4. 点图片查看大图，可切换原始尺寸。点图片外空白、页面遮罩、关闭按钮或按 Escape 退出；整理中及待确认时也可以查看图片。
5. 删除需要再次确认，弹窗会显示问题标题。取消或点遮罩不会删除。确认后的删除无法从 Issue 恢复。

## 模型与失败恢复

- 在录入或编辑中点「模型设置」，使用 Work 原有的供应商和模型设置。进入账号连接后可以返回模型设置，关闭浮层后继续原问题草稿。未保存的模型设置输入在往返时保留；保存配置仍需点设置页自己的保存按钮。
- 没有模型、连接失败或没有生成确认卡时，原文和图片保持。按提示重试、修改描述，或者明确选择「手动填写标题和类型」。助理的普通回复不会被当成已保存。
- 修改描述不自动请求模型；助理整理中的描述与图片受保护，需要先点「停止整理」或「修改描述」再改。
- 服务重启或录入草稿过期后，重新交给助理整理。已保存的问题保留。看到“未能确认提交结果”时，先刷新列表核对，避免重复录入。
- 同一问题在另一个入口被修改时，会展示最新内容与当前草稿。明确选择保留自己的修改或采用最新内容；核对本身不会保存，也不会静默覆盖。

## 三种入口与数据

页面、Work 助理、外部 MCP 共用个人 Home 的同一份问题库；切换项目仍是这些记录，没有项目也可使用。

Work 助理可按问题描述提出 Issue 动作建议，写入仍通过确认。外部客户端按 Work 的 [MCP 接入说明](../../docs/mcp.md) 接入同一 Home，在「能力 → 对外接入」逐客户端授予需要的 Issue 动作，再从客户端发现实际工具名称。公开 CRUD 为 `issues.list`、`issues.read`、`issues.create`、`issues.update`、`issues.delete`；编辑和删除先读取当前版本，不猜版本号。客户端未授权、插件已停用或权限撤销时拒绝调用。此说明不会自动配置或授权日常 Claude Code / Codex。

普通对话入口可以从 [Work 首页](http://127.0.0.1:63950/) 底部的「发给助理」进入。例如：“帮我记录一个问题：打开详情再返回时，筛选条件丢失。请整理标题和类型，确认后保存。”后续让它查看、修改或删除时，明确是哪一条问题；查看可以直接返回结果，写入先核对操作卡再确认。这里与 Issue 页面使用同一预览 Home。

2026-10-11 已用该普通助理入口的真实 MiniMax，以及真实 Codex CLI MCP 客户端，交叉完成创建、读取、修改和删除，并核对取消、版本冲突与撤权。测试客户端的五项授权已全部撤销，永久客户端配置未改，原有 9 条记录保留。日常安装版还未装入 Issue，因此这份实操证据属于当前分支的完整 Work 预览；日后集成安装时，仍需让客户端指向对应 Home，再按实际需要授权。其他外部客户端版本不由 Codex 的实测结果代替。

每条问题最多 6 张 PNG/JPEG/WebP，保存后单张不超过 2 MiB、合计不超过 8 MiB；大图会先压缩。一次录入一条问题，可含多图；不自动按截图拆分成多条问题。V0 不含团队共享、分派、处理状态、分析或旧 Casebook 导入。

## 建议用户验收的路径

| 场景 | 要观察的结果 |
| --- | --- |
| 纯文字、图文、只有截图，各录入一条 | 标题与类型符合本次问题，确认前不出现新记录，保存后原文原图一致 |
| 打开、编辑后取消、修改后保存 | 查看态不能误改；取消恢复；保存后回到查看态 |
| 长描述、多图、窄窗口 | 保存入口可找到，图片可查看及退出，没有文字区固定空白 |
| 模型设置与账号连接往返 | 每次点击有反馈，回到 Issue 后文字和图片仍在 |
| 助理整理失败或取消 | 草稿保留，能继续修改、重试或手动录入 |
| 中文输入法、从其他应用拖图和粘贴、连续使用 | 候选输入正常、操作顺手、反馈清楚 |

真实模型的生成质量、中文 IME、跨应用输入手感及主观视觉仍需用户确认。自动化回归中的模型替身用于检查数据流、权限和写入边界，不代表这些用户验收已通过。
