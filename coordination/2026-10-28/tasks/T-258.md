## 1. 背景

来源：MISC「T-112 二审 建议（6511950830）」。`docs/releases/CHANGELOG.md` 的 `## [Unreleased]` → `### 升级须知（需要动手）` 一节里，T-112（#1527）写了一条（“平台合同删去 Goals 的三个子路径”，可作写法范本）。但同一类改动的两个先行 PR 没有写：

- T-110 `9170e7eb50`（#1440）：Feed 的合同搬进 Feed（`plugins/native/feed/src/contract/`），平台合同只留拉取与适配器的形状。`packages/contracts/package.json` 删了 16 行 `exports`，`tooling/gates/api/contracts/` 的几份快照变了。
- T-111 `b8be29f283`（#1468）：判断规则编辑器的 `Behavior` 改叫 `Option`，Agent 的 `Method` 合同名改叫 `Skill`（W5-14 R-A5/R-A6），也是合同导出的改名。

另一件：插件包自己的 `./contract` 子路径（例如 `@molis-ai/molis-work-plugin-goals/contract`、Feed 的 contract）没有 API 快照——`tooling/gates/api/` 只管 `packages/contracts` 与 plugin SDK。T-110、T-111、T-112 都把公开合同搬进了这类子路径，之后它们的改动没有快照盯着。这要进 `specs/BACKLOG.md` 一行。

## 2. 目标

1. `docs/releases/CHANGELOG.md` 的升级须知里补两条（写法照 T-112 那一条：日期、任务号、PR 链接、切片或 spec 路径、旧路径/旧名 → 新路径/新名、旧写法会得到什么错、调用方要怎么改）：一条给 T-110（Feed 合同搬家），一条给 T-111（两个改名）。事实全部从两个 PR 的 diff 里读（`git show 9170e7eb50 -- packages/contracts/package.json` 看删了哪些出口；`git show b8be29f283` 看改了哪些名），不凭记忆写。
2. `specs/BACKLOG.md` 加一行：插件包 `./contract` 子路径没有公开 API 快照（门禁 `tooling/gates/api/` 只覆盖 contracts 与 SDK）；写明现在有哪些插件有这样的子路径（`git grep -n '"./contract"' -- 'plugins/native/*/package.json'` 列出），建议的做法一句话（把这些子路径纳入同一套 `pnpm api:update` 快照，或者约定它们不是公开 API，二选一，由统筹定——这一行是待办，不替统筹选）。
