## 怎么打开

先按[组件板实件](../component-board/README.md#生成)生成 `component-board/dist/`，再在仓库根目录运行，然后打开 <http://127.0.0.1:4422/risk-plugin/>：

```sh
python3 -m http.server 4422 --bind 127.0.0.1 --directory docs/design
```

顶上一条斜纹是**原型控制**，不是产品的一部分：切区域（总览、风险记录、复查）、记录怎么打开（B 整页两栏／C 侧栏打开）、状态、中英文和浅深色；「重置」清掉本页记住的选择（`localStorage` 键 `molis-proto.risk-plugin.v2`）。宽度 1440、1024、375 都能看。

## 选定的样子

### 风险记录（总览、Goal、会话、简报打开的都是这一条）

- **B 两栏整页**：左边说明、处置、进展；右边要点卡片：状态（菜单改）、影响 × 可能性小格、负责人，下面关联与复查。和 03 定的「主人领头」一致。
- **C 侧栏打开**：从 Goal 的顾虑（引用这条风险）等处点开时，在右侧打开，原页面留在左边；可展开成整页（B）。

状态：正常；没关联 Goal（风险可以单独存在）；记一条新风险；关联对象已删除或无权查看；保存时别人刚改过（两边对照，不覆盖）；已关闭（只读，可重新打开，不再复查）；只能查看（没有修改授权）；读不到这条风险。

### 项目风险总览：A 按状态分组

一行筛选（未关闭／全部／已关闭、影响、负责人、关联 Goal），下面按 打开／缓解中／已接受 分组，已关闭的折叠在最后。

状态：正常；只看没关联 Goal 的；含已关闭；筛选没有结果；部分关联读不到（只标那一项，风险照常显示）；还没有风险；读取失败（写明「不代表没有风险」，不显示成 0 条）。

### 复查：A 详情里的复查段

风险详情里单独一段：下次时间、要看什么、改期／暂停／取消，下面是历次结果（助理带来的结果用组件板的 `mw-brought`）。右边是 Work Brief 的风险段（简报归 Work Brief，这里只画风险这一段）：已登记风险可打开同一条详情和项目总览；从别处看出的「潜在 · 未登记」风险单独标出，只给「登记为风险」按钮，不自动登记。

状态：已安排、上次无事；没安排复查（不强制每条都排）；到期有变化要你定（给建议，你采纳才改处置；按通知设置只提醒一次）；到期没有变化（安静，只留一行）；复查没完成（写明读不到什么，不当成「没有变化」）；已暂停；风险已关闭、复查停止；简报是旧版本（标出当时与现在的状态，给「刷新简报」）；简报读不到风险来源（只这一段标缺口，其他段照常）。

## 用到的组件板实件

按钮、徽标、状态标（`renderStatusMark`，状态环取 `status-ring-system`）、提示、空状态、卡片、Frame、菜单、弹出层、切换组、输入框、下拉框、条目行（`mw-items`）、折叠段、人像与负责人（`mw-who`、`mw-owner`）、来源列表（`mw-sources`）、助理带来的结果（`mw-brought`）、提示条（Toast）。状态对应：打开 → 要处理、缓解中 → 进行中、已接受 → 搁置、已关闭 → 完成；影响与可能性用徽标（高 danger、中 warning、低 neutral）。

## 组件板新增（交 D 轨补标本）

| 部件 | 原型里的写法 | 为什么要 |
| --- | --- | --- |
| 影响 × 可能性小格 | `.rk-mm`、`.rk-mm--big`（3 × 3，亮的一格按严重程度取 `--tone-blocked`／`--tone-attention`／`--tone-quiet`） | 风险的严重程度一眼看位置，总览行里用小号、详情要点里用大号；组件板没有矩阵类标记 |
| 提示里的按钮 | `.rk-alert-actions`（`mw-alert` 正文下一排 `mw-btn`） | 读取失败、保存冲突、关联读不到都要在提示里直接给「重试」「去设置里看授权」；组件板的 Alert 标本没有操作区 |

另外：作为链接用的风险标题（`mw-btn--link`）在简报里会很长，原型里让它折行（`.rk-line > .mw-btn--link`）；组件板的链接按钮不折行，请 D 轨定是不是给链接按钮一个可折行的写法。窄屏下 `mw-items` 撑出容器的缺陷见[组件板实件](../component-board/README.md#已知的组件板缺陷)。

## 模拟边界

- 数据是编的（`data.js`），不读任何 Home；人名、项目、Goal 都是示例。
- 改状态、改处置、安排／改期／暂停／取消复查、记新风险只改本页内存里的数据，刷新或「重置」就回到初始；不经真实动作，也没有授权检查。
- 关联对象名片、「展开成整页」「关联 Goal」「去设置里看授权」「重试」只弹一句提示，不真的打开。
- 复查结果、简报文字是写死的样例，不调模型；日程是「经日程」的文字，不真的排程。
- 控件已是组件板实件；进产品时同一批 `mw-*` 由插件 SDK 的 `render*` 画出，原型的版式 css 换成插件自己的样式。
