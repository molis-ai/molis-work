# 项目自动化建议

项目到达、助理和插件创作台打开同一份建议。Host 读取 Projects 当前授权的目录，并把原目录里可用的技能、服务和角色交给建议服务。扫描路径、大小和次数有固定上限，报告只显示相对路径、识别出的信号与能力来源。

建议下方的按钮打开原设置。技能的开关、连接认证和角色配置继续由各自 owner 处理。没有可用来源的类别会说明缺口。用户明确保存时，Host 向项目里的 Pages 创建文稿；同一报告的重复保存复用原请求。忽略、已有和不再提示由建议服务按用户与项目保存，使用当前 revision。

助理也会主动说：项目页打开后看一次，有以前没说过的技能或连接，就在这个项目留给建议的那项工作里放一张勾选卡（最多三样、连接最多一样），并在 Dock 亮一次。卡以本人身份运行 `automation.adoption.adopt@1`：技能按选的方式开，连接只准备、在卡里接着登录或贴密钥，「以后别再提」写进偏好；工作里可以撤销这次开的技能。连接候选来自服务声明的 `project_hints`，不写名单。设置 › 助理里可以关掉主动建议。

验收与当前覆盖见 [项目自动化建议](../../specs/automation-recommender/spec.md)。开发和验证入口见 [包 README](../../horizontal/automation-recommender/README.md)。
