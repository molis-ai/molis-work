# 项目删除、待办和生图一致性修复

状态：独立分支已实现并通过定向验证，待集成。基线为 651432a3ba，验证使用独立工作树、临时 Home 和本地模拟厂商。

目标是让入口回执、持久事实及后续操作一致。各业务主人继续负责自己的写入。按合同变更政策第 3 节在现行动作版本更新输入输出，旧的无观察值确认明确拒绝。项目删除复用已有清理步骤。Images 跨库操作若要在崩溃后也阻止错误账户派发，需要持久化待完成操作；1 → 2 新建空表的方案已在合同变更文档列出，用户已确认，仅在隔离库验证。

| 验收 | 用户路径与约束 |
| --- | --- |
| ARF-1 | 项目删除先持久化目录清理步骤和可信暂存位置，再移动目录。任一步中断后重启均可按同一回执重试。已存在的暂存回执仅清理其暂存处，用户重试历史上移走但没有回执的项目时，只接管没有历史删除、唯一且项目库身份吻合的暂存目录，歧义时保留原件。保留输出选择与项目隔离。 |
| ARF-2 | Todo 页面传出所确认的提醒时间。改期后拒绝旧确认，同一次重复确认幂等。到期列表与助理窗口共用资格判断，继续使用各自的时间窗与范围。 |
| ARF-3 | 生图后台执行结束后停止占用并发名额，页面、单条读取、后台任务与同键重放反映中断。撤权或停用的旧调用不能再写结果，新授权恢复可清理遗留状态。 |
| ARF-4 | 生图配置和凭据各归原主人。配置未提交时不改变绑定，跨库部分完成要能辨认并从同一服务重试；删除失败时能区分解绑和删除。 |
| ARF-5 | 批量待办回执保留各项结果，给出实际变更数，全未更改时不提供撤销；过期观察不能绕过整批事务。 |
| ARF-6 | Todo 列表按可信范围取行；对象读取保留存储错误；超过单次上限的草稿都能清理。复用生图同步字段定义，删除纯转发、无读者返回值和新建行的冗余写入。 |

验证：pnpm build，更新动作快照，以 machine-slot 运行 todo-actions、images-service、project-settings-deletion、输入框草稿及相关真实入口测试。库列删除、未来表重建迁移、真实 Home 维护和厂商计费均不在此次变更范围。

## 已验证的用户路径

- ARF-1 使用真实子进程分别在改名前后退出；重新打开 Catalog 后同一回执能继续。对历史暂存目录还验证了其他项目的数据库不会被接管。
- ARF-2、ARF-5 通过动作测试复现跨入口改期、同次重复确认、不同日期混合批次及整批回滚。隔离浏览器同时验证个人空间内的原地移动没有撤销，真实改变归属时出现撤销。
- ARF-3 通过隔离 Host、受控 HTTP 厂商和项目 A/B 验证执行中两项会挡住第三项，执行失效后第三项能开始，同键重放不会重新发单。撤权后界面投影为中断，原执行者未写业务行。后台任务表在结束展示期内保留该任务，助理能按执行器实际结束时间报告一次；新授权恢复后沿用同一时间。
- ARF-4 用实际连接器和 Images 私库在操作前、绑定后和解绑后注入事务失败，重启再读、生成被拒、原 ID 重试和另一侧事实均有断言。v1 金样通过 Host 使用的同步库声明升级，再次执行为无操作。仅验证隔离库。
- ARF-6 通过工作台输入框的构建产物验证 500 条有效草稿后面的一条失效草稿能被清理；待办用一个项目内的损坏行验证其他项目列表可读、越界读取拒绝、本项目读取报告解码错误。同步与项目删除用例核对导入、导出及留存数据。

39 个定向回归文件与 68 个合同测试文件通过。构建和包边界检查通过。对照同一基线的两份测试类型检查，现有诊断从 4221 条降至 4220 条，本分支没有新增。未运行 CI Full，未连接真实 Home 或真实厂商。
