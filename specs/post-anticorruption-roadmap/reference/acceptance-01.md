# 第 01 批 · 一骏的试用单

依据：[主线快照 cbd019de6](https://github.com/molis-ai/molis-work/tree/cbd019de68878c71615630a7b32f22aa83fe5311)，文档入口已跟进 [a4aec9352](https://github.com/molis-ai/molis-work/commit/a4aec93525c27ffcabf0701602488d1dd1c5a699)、[逐项核账](batches/01.md#baseline-01)、[统一待办 §1](../../BACKLOG.md)。本页是操作单，不是验收结果。没有勾选的行均未由本轮代签。历史上已明确接受或委托的项目单列；有前置的行可以跳过。

**先准备。** 用这一版已经安装依赖、构建好的仓库，在终端从仓库根运行下面两行。使用一个新临时 Home、临时密钥及空闲的独立端口；只打开终端打印的地址，不用日常桌面应用、4207/4208 或真实 Home。需要重启验证时，保留同一终端里的临时目录、密钥和同一端口。以下启动步骤供试用人操作。如果 4199 已被占用，另选空闲端口，不停用已有服务。原生专属项须另有明确指向隔离 Home 的桌面产物；只有网页时跳过那些行。

```sh
trial_home=$(mktemp -d) && trial_key=$(openssl rand -hex 32)
MOLIS_WORK_HOME="$trial_home" MOLIS_WORK_ENCRYPTION_KEY="$trial_key" pnpm web --home "$trial_home" --port 4199
```

用独立浏览器资料打开该地址。建一个空测试项目，命名「周五交付」。准备两段不含敏感信息、允许用来试的材料，给一段取唯一名字「周五校样」，另一段故意不取标题。只选试用目录。需要模型、订阅内容或账号的步骤等具备条件再试；模型连接和真实外部登录各自在隔离环境里进行。

**怎么记：** 每行单独记「通过／失败／跳过（缺什么）」，加上所用版本、Web 或桌面、出错的那一步和看到的文字；涉及生成/写入的，刷新后找到同一个对象再记通过。截图不带密钥、登录页内容或私人材料。完成示例：`BL-947｜Web，版本 ____｜失败｜回到首页时日期条闪了一次`。自己的观察可直接写在本页副本；确认后再更新对应原需求或待办。同一行的各子项可以分别留空。
