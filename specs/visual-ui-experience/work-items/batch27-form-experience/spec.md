# 第 27 批 · Form 导出、必填与控件名称

状态：实现和隔离 Home 实操验证通过，待第 27 批整体验证及一骏本人验收（2026-11-09）。

depends_on：基点 `4547c26b5` 的现行工作台槽、Form 和共用披露控件。本片在独立工作树修改以下三个文件，与其他片无共享写入；整批由统筹合回。

本片承接[第 27 批](../../../post-anticorruption-roadmap/reference/batches/27.md) 27-1、27-3。[原 QA #784](https://github.com/molis-ai/molis-work/pull/784) 的 QA-031：导出菜单可由键盘操作，但显示超出工具栏的裁切边界；QA-032：浅色下已勾的必填框与底色同白。无障碍清点的 [F-17](../../copy-help-inventory.md#54-第二轮新增的跨页面问题) 只核 Form 一处（[BL-1038](../../../backlog/BL-1038.md)、[VUX-52／58](../../spec.md)）。

基点 `4547c26b5` 实测：1024px 中文明暗菜单的左侧落在工作区外，两项的左侧均不能命中，键盘仍可下载；其余十个组合的同一已发布问卷未复现。十二个组合的勾号与底色对比为 1.01～1.02:1，未选中边界可见。编辑标题与图标按钮在十二个组合均有正确的浏览器无障碍名称，键盘操作通过；这部分只核回。

现有导出按钮、填写页文件和答卷 CSV 全部保留。下拉面板用 Form 工具栏作为可用范围，沿用原披露控件和共用 Escape／外点关闭逻辑。在支持 CSS 锚点的引擎中，同一个面板随工具栏换行后的按钮展开；基础布局把它放在工具栏下方，供较早的桌面 WebKit 使用。选中的必填框沿用组件板的选中底色和勾号；局部样式只限定未勾选时的底色。保留字段值、试填、收集、校验和文件格式，不新增交互，不动其他插件、组件板、宿主或共享文案清单。

输入是已保存的问卷与答卷，以及工作台现有语言、主题和窗宽。输出是可操作的菜单、可辨的必填状态和同一份问卷 owner 产出的文件与答卷。预计只改 `plugins/native/form/src/styles.ts`，测试为 `tests/form-experience.e2e.test.ts`，不需要真实 Home、模型或外网。若需要改控件名称，先确认真实 AX 的缺口，再在 Form 私有页面使用现有翻译键。

## 验证记录

- **B27-FORM-01：通过。** 在同一份长标题、可滚动的已发布问卷上，Chrome for Testing 157 的十二个组合都能完整看到两项操作，左右两端及中点均命中；指针和键盘各实下载 HTML、CSV，读取实际保存的文件核对内容。Escape 收起并恢复按钮焦点，外点也能关闭。同一浏览器只禁用实际下发样式中的锚点增强规则后，十二个组合的基础布局和两项下载也通过。
- **B27-FORM-02：通过。** 组合内同时看到勾选和未勾选，勾号与底色、未选边界与底色均达到 3:1。Space 切换的真、假值从 Form owner 读回；键盘空答报缺题且不新增答卷，填写文字和选择后只新增一份，本机填写来源及答案从结果和 owner 读回。
- **B27-FORM-03：基点与候选均通过。** 同一矩阵的浏览器无障碍树名称、Tab 到达和键盘移动题目保持焦点均核回，未改名称来源。
- 候选整体构建通过；标准 Chrome 与关闭增强规则的临时验证各通过全部 36 个子项，无跳过。旧 WKWebView 实机、读屏实听及整批页面资源比对尚未做。
