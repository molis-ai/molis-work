# 插件标签组

状态：执行中（2026-10-18）。

本文件取代 [plugin-default-no-tab](../archive/plugin-default-no-tab/spec.md) 里「插件默认页不占标签」的合同，和 `DESIGN.md`「Where am I」里的位置芯片、「Plugins carry no identity colour」在标签条上的部分。分栏几何、条目标签、首页标签、历史仍按原文。

## 问题

插件首页不是标签，只在标签条最前面显示一个位置芯片；插件页里点开的记录又是原地打开的。所以从 A 切到 B 以后，A 在标签条上什么都没留下，想回 A 只能回左下角的插件入口。用户（2026-10-18）要的是 Chrome 那样的标签组：打开过的插件留在标签条上、可以点；同一个插件的内容排在一个有颜色的组里；组头这张标签就是插件首页。

## 用户决定（2026-10-18）

| # | 问题 | 决定 |
| --- | --- | --- |
| 1 | 插件页里点开的记录怎么开 | 原地打开，插件标签记住它；⌘/Ctrl 点击或中键点击才在组里多开一张标签。从首页、搜索、助理、链接打开的仍开组内标签。 |
| 2 | 手动分组 | 保留。默认按插件自动分组，手动组优先：放进手动组的标签离开插件组。 |
| 3 | 关插件标签（组头） | 关掉整组，可以撤销。 |
| 4 | 样式 | 结构参考 Chrome 标签组，视觉按本项目的审美做，不照抄 Chrome；颜色要丰富，整体要好看。 |

## 规则

- **插件标签。** 打开一个插件（Dock、切换器、深链、「+」菜单）就开出它的插件标签（`kind: "plugin"`），每栏每个插件只有一张；已经开着的只激活它。插件标签显示插件图标和插件名，就是插件首页。插件标签不会在一栏里出现两张：按住 Alt 把它拖到已有这个插件标签的栏（包括本栏），只是在那里显示这个插件；把整组拖进已有这个插件组的栏，组并进那里的组头，同一条记录不重复。看插件首页时这张标签是当前标签；状态里仍记作 `viewPlugin = 插件`、`activeTabId = null`，所以首页的记录、滚动、历史照旧。
- **自动组。** 没有固定、没有手动组的插件标签和这个插件的条目标签组成一组，插件标签当组头，条目紧跟在后面。打开一个条目时，没有组头就先补一张组头。标签不会散落到别的组中间：规则在每次改动后重新把组收拢。
- **拖动。** 拖组头带着整组走（同栏换位、移到别的栏、拖到边上分栏）。自动组里的条目只能在组内换位：拖到组外，落点预览仍停在组里，松手后它回到组里；要让它离开插件组，就固定它或放进手动组。拖动时落点先占好位：一开始就是标签原来的位置，指针移动后，新的落点按宽度展开、旧的按宽度收起，周围的标签和组的底色跟着滑过去，不跳。整组的占位就是组的宽度和组色。
- **手动组优先。** 放进手动组的标签（条目或插件标签）只属于那个手动组。手动组照旧可以命名、换色、收起、解散。固定的标签不进任何组。
- **组头可以点。** 点组头回插件首页。右键（或 Shift+F10）菜单里可以收起或展开这个组；收起后只剩组头，上面显示组里有几张标签。组里有条目时组头带 `aria-expanded` 和组里的标签数。组头的关闭按钮和菜单写「关闭标签组」。
- **在组里多开（PTG-06）。** 能这样打开的记录行由各插件在自己的目录条目上声明（`recordRow`，没有就用 `searchRow`），宿主不点名插件；记录属于列出它的插件：外层的 `data-work-surface`、目录栏的 `data-plugin-section`，或插件在自己的容器上写的 `data-record-owner`（Goals 的列表画布就是这样）。分栏时每栏是 iframe，这次打开经 `workbench-pane-open`（带 `background: true`）交给外层，在那一栏的组里开。列表本身能多选的（插件页里、记录行外面有一个 `aria-multiselectable="true"` 的容器，如 Pages、灵光的列表），⌘/Ctrl 点击归列表自己去多选，中键照旧在组里开；宿主只认这个标准属性，不点名插件（2026-10-19，D24、QA-024：#765 合入后 Pages、灵光的 ⌘ 多选被吞。这和更早的 W2-18-PAGES-SOURCES-01「Ctrl 点击多选」冲突，统筹按体验裁定：多选列表照 macOS 列表与 WAI-ARIA listbox 的约定，⌘/Ctrl 归选择）。纯键盘多选（方向键移焦点、Space 切换、Tab 只进出一次）是 QA-024 的第二片，另做。
- **关组可以撤销。** 关组头会关掉这个自动组里的全部标签；如果正在看这个插件，就回到这一栏的上一处，没有上一处就回首页。标签条末尾出现「撤销关闭 <插件>」，6 秒后消失（手机宽度下只留插件色的撤销图标，文字作为它的读屏名）；⌘⇧T（其他平台 Ctrl+Shift+T）也能恢复最近关掉的那一组；这个组合键在桌面壳里可用，普通浏览器标签页里多半被浏览器留作「重新打开关闭的标签页」，页面收不到，那里靠撤销芯片。读屏会听到「已关闭某插件标签组」和恢复的办法。单张条目标签照常单独关。
- **位置芯片取消。** 插件标签就是位置。覆盖层芯片（插件市场、设置、项目设置）不变。
- **项目首页**仍是第一张标签，不分组。
- **持久化。** 插件标签和别的标签一样按项目存在本机。恢复时，看着某个插件页却没有它的插件标签、或条目没有组头的，按上面的规则补上；这是现行形状的不变量，不是兼容旧数据。

## 视觉

- 标签条放在桌面（`--desk`）上。普通标签透明，悬停 `--nav-hover`；当前标签是纸面（`--paper`）加 `--lift-1`，与 `DESIGN.md` 的当前标签一致。
- 每个组铺一层组色淡底（组色 `--hue-<色>` 按 10% 与透明混合，所在组为当前时 15%），圆角 `--r-row`，把组头和组内标签包成一体。组头文字是组色按 72% 与 `--ink` 混合、500 字重，带插件图标；组内标签的文字是组色按 35% 与 `--ink` 混合，图标取组色。当前标签在组里仍是纸面加 `--lift-1`，下沿有一条 2px 的组色短线（`--hue-<色>-fill`）。
- 自动组的颜色取插件在 Manifest 视图里声明的 `hue`（设计系统的色名；PG-075 起设计系统不再保留插件名单），没声明的按插件 id 在备用色里挑一个，不用人选。手动组的组头是一枚实心组色小签，写组名（没起名就只有色点），和插件组头区分开。
- 收起的组只剩组头，后面跟一枚组色计数。
- 深浅两套主题都从 `MW_HUES` 的 text 色（`--hue-<色>`）和 fill 色（`--hue-<色>-fill`）用 `color-mix` 算出；标签文字对淡底的对比度不低于 4.5:1。
- 这条只在标签条上给插件颜色。Dock、切换器、目录里的插件仍按 `DESIGN.md` 不带身份色。
- 选中、悬停、组的出现和收起走现有动效时长；减少动效时去掉动画。

## 验收标准

1. **PTG-01** 从 Dock 打开 Goals 再打开 Feed，标签条上同时有 Goals 和 Feed 两张插件标签，Feed 是当前标签；点 Goals 标签回到 Goals 首页。
2. **PTG-02** 同一栏里重复打开同一个插件，只激活已有的插件标签，不重复开。
3. **PTG-03** 打开某插件的条目时，条目标签排进这个插件的组，紧跟组头和组里已有的条目；还没有组头时先补上组头。
4. **PTG-04** 放进手动组的标签离开插件组；手动组可以照旧命名、换色、收起；固定的标签不进组。
5. **PTG-05** 关组头关掉整组；正在看这个插件时回到上一处或首页；「撤销关闭」和 ⌘⇧T / Ctrl+Shift+T 都能原样恢复这一组，包括组内顺序和当前标签。
6. **PTG-06** 插件页里普通点击记录仍是原地打开；⌘/Ctrl 点击或中键点击在这个插件的组里多开一张条目标签，当前位置不变。能多选的列表里，⌘/Ctrl 点击是多选，不开标签，选中的几项能接着执行（Pages 双来源准备、灵光批量丢弃），打开的那一篇和正文不变；中键照旧开（D24、QA-024）。
7. **PTG-07** 插件首页不再显示位置芯片；覆盖层芯片照旧。
8. **PTG-08** 刷新以后插件标签、组和当前标签都还在；看着插件页却没有插件标签的状态会补上插件标签。
9. **PTG-09** 自动组的颜色取插件色，深浅主题下组色淡底、组头文字、当前标签的组色短线都正确；标签文字的对比度不低于 4.5:1。
10. **PTG-10** [人工] 用户看过实物，认为标签条好看、颜色丰富、合本项目的审美。
