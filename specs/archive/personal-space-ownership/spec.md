# 个人版：空间归属

状态：本机空间归属切片已实现，2026-09-30 自动回归通过。云同步、团队空间写入、跨空间迁移不在本期。

## 已确认的模型

- 资产归属由 `spaceId` 表示；空间类型 local/personal/team，不用 -1/0 猜测。
- 本地空间保留原 Home 与数据库位置。个人空间按 Auth issuer/application/user 稳定派生 ID，使用独立 Home。
- 项目目录、托管项目库及 Home SQLite 适配打开的 Store 保存唯一 `molis_storage_space` 元数据；其他文件/私有 Store 通过 Home 继承。记录、版本和文件引用继承归属，不给所有业务表重复增加可任意修改的字段。对外交换使用 `SpaceAssetRef.spaceId`。
- 不复制插件数据库，不绕过 owner 操作业务表；项目和个人插件在同一个空间运行上下文中装配。
- 登录不迁移本地数据；选择个人空间后创建的数据才属于本人。团队空间拒绝创建/写入。
- 账号更换/退出使旧业务请求与长连接失效；旧数据保留，不转交新用户。

## 必须验收

旧本地数据不改内容与关系；A/B 账号与本地空间互相隔离；同账号重新登录空间 ID 稳定；伪造空间/用户 ID、旧页面控制令牌不能跨空间写入；插件库、项目、附件和搜索均按 Home 隔离；不产生云上传。
