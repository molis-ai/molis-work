# 可视化实验工作台

状态：本地网页主流程已检查，尚未完成用户验收。仅支持离线 Choice 对照；每场最多 20 条材料、3 组模型，每条执行一次。

## 用户操作

1. 从个人导航打开“实验”，新建并选择证据判断、内容筛选、自定义任务或已有 Function。
2. 粘贴正文，或用独占一行的 `---` 分隔批量材料；检查整理结果。名称自动生成，出处缺失会明确记录，参考答案可留空。JSON 导入追加材料，保留已有内容；参考选项不匹配时拒绝导入。
3. 选择参试模型，保存快照，再点击运行。首次默认勾选已配置的内置模型，同一页面内沿用上次保存的选择。未配置模型有明确提示。
4. 查看答案分布和耗时；点击分布区段筛选材料。逐条矩阵支持全部、分歧、未复核和调用失败筛选。
5. 点选材料，在旁边查看原文、参考答案和模型概率。人工复核单独追加；支持保存并看下一条。切换材料或筛选时，当前页面内的复核草稿保留；刷新不保留未保存草稿。
6. 导出完整结果，或复制成新实验重新运行。原快照和已完成结果不覆盖。

## 表达边界

- 没有人工参考答案时不评定正确率；Agent 初标一致程度不是准确率。分歧统计仅覆盖至少有两份有效答案的材料。
- 无有效答案与答案类别分开显示。调用失败不包装成模型的拒绝答案。
- 概率只画模型实际返回的字段；缺失则明示，不补造统一置信值。
- 总耗时包含执行准备；加载和推理明细按运行器提供的信息显示。未知费用不记作零；Grok runtime 报告费用不是订阅实际扣款。
- 模型一致的材料也需要抽查，不能只复核分歧后外推整体质量。
- 创建和运行仍分开；未新增自动联网取文、AI 自动出金标、自动调参或大规模评测服务。

## 设计来源

- [TypeSafe Typewriter](https://x.com/stevekrouse/status/2100287368221659289)：材料与多项概率同时展示。原帖视频已查看，公开体验站预算耗尽，未作为本次模型实测。
- [DiffJury](https://github.com/raihankhan-rk/diffjury)：低成本入口、材料与判断并排；公开 PR 示例实际跑通。
- [Magic Compose](https://github.com/SawyerHood/sawyer-plugins/tree/main/plugins/magic-compose)：默认配置减少填写；此处只采用模板及默认选择，未新增自动模型路由。
- [1kpapers](https://www.1kpapers.com/)：从整体分布深入具体材料；不据站点外观推断 Jev 分类质量。

视觉沿用宿主的字体、色彩变量、按钮、目录与详情布局。新增的分布条、矩阵、概率条均由现有实验记录渲染。
