统计 Git 跟踪的 `apps/local-host/src/` 内各级目录的 TypeScript 与 JavaScript 源码。扩展名覆盖边界检查认作宿主源码的 `.ts`、`.tsx`、`.js`、`.jsx`、`.mjs`、`.cjs`，以及 health 使用的 `.mts` 和同族的 `.cts`。当前树全为 `.ts`。生成源码、夹具、声明与测试源码都按扩展名计，其他扩展名与未跟踪文件排除。空行、注释和没有结束换行的末行计入，LF 与 CRLF 都只换一次行，文件末尾的换行不增加一行，空文件为零。

常规 health 显示总量，有实际 merge-base 时同时显示基点和净增减。带 `--report` 的文本输出列文件计数，有基点时只列变化；`--top` 可收窄明细。JSON 的 `hostLines` 提供两份逐文件计数、总量和变更，不受 `--top` 截断。复用现有 Git 改名识别，在统计范围内的改名带原路径，同一内容搬动的净变化为零。未识别的改名按删旧加新显示，跨统计范围移动按移入或移出显示。没有实际基点时只展示工作树数量，不从本地快查推断差值。

实现边界是 `scripts/check-health-gates.mjs` 的接线和 `scripts/gates/host-lines.mjs` 的测量与展示，另有定向测试、门禁手册和本 spec。共用现有工作树和 merge-base 快照，测量阶段同一份宿主工作树文本只从文件系统读取一次。行数报告与判定、阈值、快查数据和 CI 配置隔离。
