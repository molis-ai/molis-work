# 69 · 第三批插件功能

[执行目录](../../spec.md#execution-batches) · 阶段 3：持续工作与创作 · [上一批 68](68.md) · [下一批 70](70.md) · [执行规则](../execution-rules.md)

## 给人讲清楚

又一批插件功能，各做各的：本机按规则脱敏；Gmail 读取完整正文和附件；YouTube 取字幕；PPT 能放图片和图表；Pages 支持个人模板；比较两个固定版本逐段的变化；生成的内容放进 PPT、待办等地方时保留出处，AI 写的部分有标记、可以改；材料变了先列出要重看的结论；导出 Word 和指定版本；规划方法补上更多行业。需要你做的：看新增的内容操作、比较和导出的样子并定下。

## 交付与前置

- **阶段／类型**：3；体验与效果；横向能力
- **需求来源**：[产品建议 H9／11／16～20、D2～4／D6][P]、[Backlog][BL]、[智能呈现各插件清单][IUI]
- **前置／待决**：新增对象与动作都补智能呈现声明。43 只挡 Dataset 消费，60／61 只挡对应服务，68 只挡跨表面／材料篮接入；本机插件逻辑不等无关子项。
- **可并行项**：71 的场景组装设计准备
- **UI 要求**：先定样：新增内容操作、比较与导出

| 交付项 | 做什么、产出什么 | 该项前置 |
| --- | --- | --- |
| <a id="batch-69-item-1"></a>本机规则脱敏 | 本机规则版脱敏（H9），供实际内容处理路径使用。 | 已有内容处理合同；无服务接入前置 |
| <a id="batch-69-item-2"></a>Gmail 全文与附件 | 读取完整邮件正文与实际附件（H11、H19）。 | 60／61 中 Gmail 的连接、授权与恢复；不等其他服务 |
| <a id="batch-69-item-3"></a>YouTube 字幕 | 取得可用于后续处理的字幕（H20）。 | 60／61 中相关服务能力；仅用现有能力可独立完成的部分先做 |
| <a id="batch-69-item-4"></a>PPT 图片与图表 | PPT 生成／编辑支持图片与图表（H16）。 | 既有 PPT 公开能力；图表使用 Dataset 时才等 43 |
| <a id="batch-69-item-5"></a>Pages 个人模板 | 个人模板可用于实际文稿（H17）。 | 既有 Pages 能力；本机模板不等服务全覆盖 |
| <a id="batch-69-item-6"></a>固定版逐段差异 | 比较两个固定版本的逐段变化（D6），复用 Diff／SDK 的公共比较能力。 | 既有固定版本与比较合同；跨表面接入时才消费 68 |
| <a id="batch-69-item-7"></a>出处追溯 | 生成内容到 PPT／待办等落点保留可追溯出处，AI 写入标记可编辑（D3）。 | 各原主人公开来源与版本合同；跨表面材料篮接入等 68 |

| <a id="batch-69-item-10"></a>规划方法扩行业 | 补 BL-056 的行业覆盖并验证对应规划路径。 | 既有规划插件；按实际方法所需输入接入 |
