/** The notification service takes a title of at most 200 UTF-16 units; a longer one is cut at a whole character and ends with 「…」. */
function notificationTitle(title: string): string {
  if (title.length <= 200) return title;
  let cut = "";
  for (const character of title) {
    if (cut.length + character.length > 199) break;
    cut += character;
  }
  return cut + "…";
}

5. 几处为什么这样写，别改：
   - **截到 199 再加「…」。** 「…」是 U+2026，占一个单元，加起来不超过 200，与通知服务的上限一致。
   - **`for … of` 按码点走。** `character.length` 是 1 或 2；代理对整个算一个，所以不会劈开。
   - **不超过 200 的原样返回。** 195 个「提」的标题正好 200，不截、不加「…」。`RAC-1670` 的「a 200-unit title is not cut」守的就是这一点。

   - **一次性闹钟停在 `ok`。** 成功时闹钟一侧 `status` 默认 `"ok"`（第 1 节）；`enabled` 为 `false` 是一次性闹钟响过（`index.ts:436`），不是失败。
