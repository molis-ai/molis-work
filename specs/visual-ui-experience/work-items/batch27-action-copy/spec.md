## 目标与现状

BL-1039 和 BL-1040（[F-18、F-19 清点](../../copy-help-inventory.md#54-第二轮新增的跨页面问题)）承接 [VUX-52、VUX-54、VUX-58](../../spec.md#全产品文案与按需帮助2026-11-02待实现)。基点 `7182c1b0e` 在隔离 Host 和 Chrome 实测，导入本地 Markdown 后，Host 保留一份正文引用并报告缺模型。重试仍写「已连接，继续整理」和「Connected — continue」。Git 无远端、无暂存时展示三个像按钮的状态，仍能打开 PR 表单，发一次检查请求。实际输入提交说明后点击按暂存内容生成，空草稿覆盖了已输入文字。

资料就绪但缺模型时，重试改名「连好后继续整理 / Continue after connecting」。保留连接入口与原重试，仍按当下配置反馈。模型已连接后，重试仍叫「继续整理」，由用户决定何时开始。两条保存路径沿用同一个旅程。

Git 用现有分支状态区显示「没有远端」或「没有远端跟踪分支」，每条只出现一处。无暂存且无法完成合并时，在提交说明下显示普通文字「没有已暂存的文件」。只有存在暂存内容时才提供按暂存内容生成，避免空草稿覆盖输入。有暂存或合并可提交时保留原操作。有远端时显示符合既有条件的推送和 PR。跟踪分支存在且可拉取时显示拉取，也保留对同一仓库本地跟踪分支的拉取。没有这些操作时收起整组。配置远端后，首次推送仍可建立跟踪分支。英文名称「Push and track this branch…」在窄目录里完整呈现。无远端时收起已开的 PR 表单，保留字段，远端恢复后沿用既有检查和拒绝反馈。

方案沿用现有 `mw-btn`、Git 提示位置和视觉令牌。首次使用的状态由 Host 的旅程和模型配置给出。Git 按当前工作区的 summary 渲染，原审查、权限和 Git 执行链负责最终判断。本片范围是工作台的首次使用脚本和英文词典、Git 的页面、客户端呈现、词表，以及对应的定向浏览器用例。

## 验收

- **ACTCOPY-01** 未连接时，中英文按钮说清继续的前提，视觉文字与读屏名称一致。键盘重试一次，反馈并回到原旅程，材料引用与已输入项目名保留。
- **ACTCOPY-02** 从既有入口实际配置模型，回到原旅程并显示已连接和「继续整理」。确认后复用原材料生成摘要，保存的项目和材料可由 owner 读回。固定的本地模型答复只替代外部推理。
- **ACTCOPY-03** Git 无远端、无暂存时，各状态在相应区域为普通文字，PR、拉取、推送、提交及空草稿入口在键盘和读屏中不可达。Git 页不发 PR 支持或写请求，输入的提交说明保留。
- **ACTCOPY-04** 使用本地 bare 仓库观察加、移除、恢复远端及跟踪分支。无跟踪分支有真实首次推送入口，有跟踪分支有真实拉取入口。暂存后可键盘提交并进入原审查，拒绝后 Git 与说明保持。远端恢复后 PR 检查按需发出，本地远端仍得到原不支持反馈，表单草稿可接着编辑。
- **ACTCOPY-05** [人工] 看 1440、1024、390 下中英文、浅深色的缺项状态，以及关键恢复状态。状态不借用按钮外观，可用按钮清楚，焦点和可见布局随实物验证。界面以用户本人验收为准。
