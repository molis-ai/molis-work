## 1. 背景

C（#1327）的 FI-6 删掉了宿主的 `apps/local-host/src/feed-history-release.ts`；Runtime 里的 Feed 改经 Home 的引用账释放正文（`tests/feed-runtime-plugin.test.ts` 的 RAC-518）。那个文件原来调的两个函数从此没有生产调用方：`listFeedMaterialContentRefs`（`plugins/native/feed/src/store/items/index.ts:19`）、`listListenerRunReceipts`（`plugins/native/feed/src/store/listener.ts:155`）。只剩 `tests/owner-readers.test.ts` 的第二个用例测它们，`plugins/native/feed/README.md:101,105` 和 `docs/system/HOME-DATA.md:187` 还把它们写成别的包该用的读法。

## 2. 目标

1. 两个函数删掉，代码里没有任何地方再引用它们。
2. 现行文档不再把它们写成现在的做法。
3. `tests/owner-readers.test.ts` 只留第一个用例，文件头注释写明现状。

## 3. 不做

- `listener.ts` 里的其他函数（`saveListenerRun`、`deleteListenerSourceState` 等）：不做。
- `specs/repository-anti-corruption/slices/` 下的设计稿和切片记录：是历史，不改；第 715 行的跟进项由统筹在协同账里关。
- Feed 的其他导出：不做。

## 5. 做法

1. 先证明没有调用方再删。这条命令应该只给出两处定义和 `tests/owner-readers.test.ts`，它在改动前的输出贴进 PR 正文「做了什么」：
   ```bash
   git grep -n "listFeedMaterialContentRefs\|listListenerRunReceipts" -- ':!*.md'
   ```
2. `tests/owner-readers.test.ts` 文件头注释，从 "the Host's Feed caller" 起的半句改成：这两个读取函数随这个调用方没了用处，已删；Runtime Feed 经 Home 的引用账释放正文，见 `tests/feed-runtime-plugin.test.ts` 的 RAC-518。用英文，和文件其余注释一致。
3. `plugins/native/feed/README.md`：
   - 第 101 行「别的包要读 `feed_materials` 里的正文引用，调导出的 `listFeedMaterialContentRefs`，不写 SQL（`scripts/gates/table-owners.mjs`）」改成「别的包不读写 `feed_materials`（`scripts/gates/table-owners.mjs`）」；
   - 第 105 行删「扫回执里的正文引用用 `listListenerRunReceipts`，读不出的回执抛错、不当作没有引用（否则会误删仍被引用的正文）」这一句，前后句照留。
4. `docs/system/HOME-DATA.md:187` 照第 185 行 Coding 那一条的写法，原话不删，句末补：「2026-10-28（T-001）再改：宿主这个文件随 FI-6 删了，`listFeedMaterialContentRefs` 和 `listListenerRunReceipts` 没有了调用方，也删了。」
