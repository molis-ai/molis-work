# 第 27 批项目列表的个人内容搜索

状态：用户于 2026-11-10 选定 A，待实现与本人验收。负责：第 27 批 Codex 统筹，D／工作台搜索。[BL-041](../../../backlog/BL-041.md) · [搜索原合同](../../../archive/system-search/spec.md#5-合同) · [设计认领](https://github.com/molis-ai/molis-work/issues/1743#issuecomment-6766272137)

## 定样与行为

项目列表已有搜索项目和预览，但没有搜索个人内容的入口。预览项目会修改页面显示的项目 ID，这个 ID 只用于预览。无项目的 Home 入口已能查询和核对个人结果，可信作用域由宿主固定。

用户看可点对照后选择 **A**。在项目筛选下方放同一规格的带字按钮「搜索个人内容」，手机保留文字和 44px 触控高度，有项目和空 Home 都可用。接受目录多占一行的取舍。B 将按钮放标题栏，手机折成放大镜；用户选择 A 作为实现。共用工作台搜索对话框与现有令牌，默认与唯一范围都是个人内容。结果、空态、等待和失败采用同一现行状态控件。

打开时聚焦搜索框。普通关闭或 Esc 回到按钮，保留原筛词和预览。⌘K／Ctrl+K 继续聚焦项目筛选，即使搜索对话框刚关闭也由项目筛选持有焦点。用键盘或鼠标打开结果时经原 `/api/search/open` 核对，然后按原 owner 入口打开个人空间的对应记录。仅搜索和切换预览都不打开或激活普通项目。主动打开个人记录会进入 Personal 容器，返回走现有项目列表导航的重载行为。

隔离原型已用真实 Home 的 Cognia 记录和两个项目的同名 Pages 核对。两案均可搜、可开个人记录，Home 请求其他项目范围被拒，真实项目 hit ID 也无法从 Home 打开。候选含 1440／1024／390、中英文、明暗、空／有项目、等待、命中、无结果、错误和归焦。可点对照的请求使用明确标示的离线样本，真实权限与打开由另外的 Host 验证。现行对话框有两处与新入口接线有关的缺口。查询失败时仍显示无结果，异步关闭会抢回已去往项目筛选的焦点。采用原型已验证的归焦保护，失败与空结果分别用原状态控件显示。

| 2. 插件同等待遇 | 走现有搜索来源声明与 owner 打开路径，入口按 Home 权限工作。 |
| 3. 能力注册 | 复用现有查询、打开、控制令牌和动作绑定。可信上下文取自 Home 入口，项目预览值只用来呈现。 |

| 5. 包与分层 | 入口、对话框与焦点在 Workbench 的既有 chooser 和搜索实现。宿主仍只装配并绑定权威调用者。 |
| 6. 表与存储 | 走既有索引、个人记录与导航服务，查询与预览沿原读路径。 |

| 9. 调用次数 | 空查询、关闭与切项目预览保持原请求预算。每次实际搜索按原防抖查询，打开时对同一结果核对一次。 |

## 验收

- **BCS-01** A 位于筛选项目下方。1440／1024／390 的中英文、明暗及有／无项目入口可见，手机保留文字及 44px 按钮。项目列表可正常筛选、预览、滚动及进入。对话框用原控件，既有项目内搜索的视图与范围照常。
- **BCS-02** 真实个人记录命中后可由 Enter 或鼠标打开同一记录。两个项目的同名内容在各自项目里确实可搜；从 Home 查询看不到，从 Home 提交真实 hit ID 打不开。项目预览不改变可信范围。显式打开个人结果沿原 owner 的打开位置，覆盖进入 Personal 容器的记录，普通项目保持未打开。已失效结果沿现有提示处理。
- **BCS-03** 初始、等待、无结果、连接失败和重试按真实响应呈现。Esc／关闭回入口，⌘K／Ctrl+K 交回筛选输入，迟来的关闭和响应不抢焦点、不显示另一轮结果。保留筛词、预览与输入所处状态，直到现有跨页面导航。
- **BCS-04** 隔离 Host 实际计数、浏览器定向回归、健康检查和真实下发资源对照通过。工程、隔离实操、本人验收分别记录；共享视觉与整批回归在最终头。
