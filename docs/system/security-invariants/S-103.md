### D0256：目录失败的同型投影

终端 open、list、close 及其工作目录读取通过同一错误投影：失败时先重查当前调用权限，保留已有 ActionError；未知驱动失败只写不含正文的诊断，对调用方返回「项目目录暂时读不到」。TERM-CATALOG-01～03 除 list/UI 外，新增真实列损坏的 open/close 故障注入，断言拒绝发生在终端记录和进程效果之前，恢复后仍可读原记录。测试文件和CI归属沿本行登记。
