# 引导里同时选多个文件夹位置

状态：待验收（2026-10-25）。

## 背景

桌面引导展开「文件夹资料」后，下载、文稿、桌面、其他文件夹排成两列，而且一次只能点亮一个。后面的时间范围和授权都跟着这一个走。

## 行为

- 这四项改成一列。每一项可以单独选上，互不影响。
- 点一项还没授权的位置，打开系统目录选择器；允许之后，这一项计入本次。再点已经选上的一项，把它从本次拿下，已经拿到的授权还留着。已授权的可以更换目录，或取消连接。
- 改时间范围时，所有已经选上的位置一起改。
- 展开后不再显示「每一项单独授权…」和「先列出文件名和大小…」这两句说明。
- 不在页面右侧嵌入 Finder。系统不允许把 Finder 放进别的窗口；目录授权仍用系统选择器。

## 验收

- ONB-FOLDER-01：桌面里这四项是一列；下载和文稿可以同时处于选中；关掉下载时文稿仍选着。
