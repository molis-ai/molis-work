# 本机个人版试用工具

状态：仅供明确授权的本机模拟用户试用。产品账号实现保持使用原有 PKCE 登录链路。这里的替身不是真实账号或云服务，不可部署或用于保护真实身份。

`mock-auth.mjs` 只监听调用方创建的回环服务，接受约定试用 client、确切回调地址与单次 PKCE 证明。稳定模拟用户显示“个人试用用户（本机模拟）”；试用令牌仅落在独立 Home、权限为 0600 的状态文件。

`run.mjs --home <独立试用Home>` 要求安装标记及内容摘要吻合，启动回环账号替身（43218）和已安装 Web（43217），删除继承的同步端点设置，不连接真实云端。停止时只关闭自己启动的子进程。内容和附件走产品现有 owner、SQLite 与文件落盘路径。

普通浏览器重启服务后需重新点击登录，并选择个人空间；这会打开原模拟用户的同一空间。客户端保留的本机身份可离线重新选择个人空间。暂不包含已有本地项目整批复制、真实云端与双实体设备验收、永久清理。

验证：`tests/personal-trial.test.ts` 覆盖真实 HTTP 的登录→新建项目→完整正文/二进制附件→重启→离线继续；`tests/security-invariants-personal-trial.test.ts` 覆盖拒绝永久删除原件。
