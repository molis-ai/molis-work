# 首页：日期栏 + 当天事件 + 适时详情

状态：高保真切片。完成等级 **2**。不改生产 `renderProjectHome`。Impeccable 方向轮次作废，不绑器物隐喻。

## 背景目标

坐下先选一天，再读这一天接到的事。点开一件才腾出第三栏看正文和动作。首页是工作台三栏，不是任务纸，也不是滚轮刻度。

## 当前行为与问题

上一版把今天做成凹槽轨 + 滚轮 + 右侧任务纸。结构不是日期 → 当天 → 这件事，第三栏常驻，Hero 被挤在事件轨上面当一张纸。

## 范围与非目标

范围：`.impeccable/review/flow-home/index.html` 可点切片。工作台 chrome（32px 顶栏、48px 三卡竖岛）与 `mw-*` 不变。

非目标：不改生产。不做真实日历同步 / 真实事件库。不做器物、刻度滚轮、常驻任务纸。

## 使用场景

- 打开首页：两栏。左是纵向日期卡片，今天默认选中。中栏稍宽：最上 Hero（日期大字 + 当天总结），下面是当天事件列表。
- 事件按当天时间排序；每条标「个人」或「组织」，不拆成两叠。
- 点一条事件：第三栏出现。内容卡正上方是一行同宽的动作（接着做 / 做完了 / 说一句，失败件是重新授权）；正文在卡里。
- 换一天：第三栏收起，中栏换成那一天的 Hero 和列表。空的一天 Hero 说清楚没事。
- 390：日期卡横着排；点事件后详情盖住中栏。

## 方案与关键决策（v6）

**三栏，第三栏适时出现。** 默认只有日期栏和当天栏。点事件才插入详情栏。关详情（× / Esc / 换日期）回到两栏。

**第一栏是日期卡片，不是月历。** 纵向一叠日卡：数字、星期，下面一行点阵表示那天接到什么——一个事件一个点，个人是灰点，组织是蓝点，超过四个收成一道短横，空的一天只有一道横线。今天在星期后带一个蓝点。选中抬起成纸。不是格子月历，也不是左侧插件轨。

**第二栏是一张纸，不是两张卡。** 上半是 Hero：眉标（今天用太阳，别的日子用日历）+ 大日期 + 一句总结 + 一段说明 + 一行统计（几件 / 个人几 / 组织几，点色与日卡一致）。一条 hairline 之下是当天事件。内容宽度封到 880px，宽屏不把一行字拉散。

**事件列表是时间轴。** 左边时间右对齐（等宽数字），中间一条竖线串起节点，右边标题 + 一行「个人/组织 · 一句话」，最右是来源 chip（插件图标 + 名字，底色取该插件色 10%）。今天会在当前时间处插一条「此刻 13:20」的线，节点做缓慢呼吸。

**个人 / 组织靠节点形状 + 图标说话。** 个人是实心点，组织是空心环，颜色都取来源插件色；副标题前再带一个单人 / 多人图标。不拆成两叠，不给整行上色。选中行只铺一层 11% 主色。

**第三栏是这件事。** 内容卡正上方一行同宽动作：主按钮、次按钮、说一句。卡里头是来源 chip + 时间 + 收起，正文下面接一张「来自 / 状态 / 挂在」的小表。内容可划词。卡底没有动作栏。说一句仍对着这件事弹出，弹层与卡片同宽、从动作条落下，不另开一列聊天。

**动效只做三件事。** 第三栏靠列宽从 0 撑开；换一天时 Hero 上浮、事件按 34ms 逐条跟进；详情换事件时从右滑入。进场用 class 触发过渡而不是 `animation ... both`，后台标签里也能停在终态。`data-skip=1` 与 `prefers-reduced-motion` 全部关掉。

## 输入输出与依赖

输入：切片示例日期与事件（2026-09-15 到 2026-09-21）。
输出：单文件 HTML，`html[data-theme|data-frame|data-event|data-ai|data-skip]`。
依赖：design-system 字体与 `mw-*`。

## 验收标准

1. 默认两栏：日期卡 + 当天 Hero/列表。没有第三栏，没有滚轮刻度，没有任务纸。
2. 点日期，中栏换成该日总结和按时间排序的事件；个人/组织在节点形状与副标题图标上都能分辨。
3. 点事件出现第三栏：内容卡正上方一行同宽动作（含说一句），卡内含来源、正文和事实表，卡底没有按钮；关详情（× / Esc / 换一天）后第三栏消失。
4. 今天有「此刻」线，别的日子没有；空的一天 Hero 与列表都说清楚没事。
5. 写进今天之后，事件进列表、Hero 统计和日卡点阵一起更新；重置回到初始数据（事件数、文案、授权状态都复原）。
6. 浅色 / 深色、桌面 / 390 成立。390 日期卡横向、隐藏来源 chip，详情盖住中栏。
7. 控件是 `mw-*`。没有 2px 插件色条。
