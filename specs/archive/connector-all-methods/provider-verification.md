# 官方方式与实网验收

核对日期：2026-09-26。当前 45 个目录项，39 个 API OAuth 适配、20 个官方 CLI 适配、38 个 MCP 入口、44 个 Key / Token 入口。通用远程 MCP 在 Coding 中配置 URL 并选择 Bearer 连接；其余官方 MCP 使用专门的协议适配。

实现了配置、授权、连接级验证、读取或显式工具调用及断开路径。这里的“未实网验收”表示尚未拿到本任务可用于逐服务验收的测试账号、Client ID/Secret、租户或产品资格；不表示官方接口不存在，也不能把协议fixture通过当作实网成功。

OAuth 需在服务商登记应用和回调，应用审核、scope、租户管理员许可及付费资格仍由服务商决定。部分官方 MCP 为预览或需要准入，限制保留在设置页。CLI 需安装官方程序并先完成其应用配置；实际登录在本机终端会话执行。Supabase CLI 需≥2.118.0；Sentry CLI 此入口固定官方云 sentry.io；Stripe CLI 使用默认测试环境。

MCP 协议没有统一稳定账号 ID，因此新授权创建新连接，不覆盖已被其他功能选择的旧连接。原连接的 OAuth 刷新仍自动完成。CLI 凭据由官方 CLI 管理，本机 CLI 切换账号后，旧连接拒绝读取。API OAuth 与 Key 用于现有 Feed / 文档导入；CLI / MCP 使用各自原生能力，不把工具列表伪造成 Feed。
