# 应用图标换成炭黑 M

完成等级：3（功能可用）。不改菜单栏图标，不随系统深浅色切换。

## 背景与目标

程序坞、访达和启动台里的 Molis Work 图标现在是紫色章鱼。换成设计稿 `molis-work-app-icon-charcoal`：1024 画布、透明外缘、`#222326` 圆角方标、`#F7F8F8` 的连续笔画 M。

## 范围

做：替换 `apps/desktop/src-tauri/icons/icon.png` 与 `icon.icns`。源 SVG 放在同目录，方便以后再导出。

不做：不改菜单栏模板图标。不做浅色另一版。不重装已经装好的 App。

## 验收

1. `icon.png` 为 1024×1024，四角透明，方标色约为 `#222326`。
2. `icon.icns` 含 16 到 1024 的标准尺寸，由这张图缩小得到。
3. `tauri.conf.json` 仍指向这两个文件。
