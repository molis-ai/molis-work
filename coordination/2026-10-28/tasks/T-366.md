## 4. 先红实验：用实际响应制造交错

复用 `alchemist-client-boundaries.e2e.test.ts:31-47` 已有模式：生产导出的 ALCHEMIST_CLIENT_FACTORY_SCRIPT、UI生命周期、真实Kernel/Studio HTTP/SQLite、测试Chrome和Node HTTP服务器。`alchemistFixture`暴露的ai是显式外部模型fixture；把listModels配置为空，走真实缺模型失败，不伪造bootstrap/jobs的业务字段。

测试运行时不调用 runtime.start，让worker只在明确的 `runtime.runPending()` 时执行（`studio/server/bootstrap/studio-lifecycle.ts:10-25`已有这个控制口）。用命名的 entered/release Promise闸门，不用sleep猜交错、不修改生产worker。

实验步骤：

1. 从真实UI提交“新建方向，保存并炼化”；在explorations POST后记录本轮真实directionId/runId/jobId。先确认持久化探索queued且该job被接受。
2. 让当前轮bootstrap先真实读出queued/running，保存该Response副本/实际JSON；只有读完成后才放worker执行到缺模型failed。等待runPending真正结束，并用独立后台GET证明同一run的status=failed、errorCode=alchemist.runtime_not_configured、cards=[]，再真实读取runs确认同一job accepted=false。
3. 把这两份确实来自不同时间的真实响应交给未改的客户端，记录在子执行上下文的提示次数、progress个数、当前方向id/标题、该轮两份响应对应的run/job身份。旧代码应稳定复现后端终态已到、旧progress留下且读不再推进。不能只观察宿主wrapper的innerText。
4. 重新炼化同方向重复这个交错，明确新runId不同于上轮。不能让前一轮的终态或旧DOM替本轮通过。

**闸门不能把修复写死成同样的请求并发顺序**：旧实现中在bootstrap已经发起时，测试可让runs的实际读取等旧bootstrap快照完成后再drain worker；若修复采用runs先读、再读bootstrap的因果顺序，则runs先到时直接drain并读取，后续bootstrap自然取得新终态，不能反过来等待一个尚未允许发出的bootstrap造成测试死锁。可在测试装载生产脚本之前局部观察window.fetch的真实调用顺序/Response，沿用现有测试里的fetch装饰模式；只控制请求何时进入真实 API 及真实响应何时交付，不重写业务 JSON。runs 必须在 worker drain 完成之后才进入真实 API 做读取；不能在已经真实读取出 accepted=true 后仅扣住其 Response，并把这误当成较新的 accepted=false。判定分支看浏览器实际 fetch 发起轨迹，不依赖 Node HTTP 请求的到达顺序。两种路径都以真实后端与最终DOM为oracle。

若用例只在增加长延时后偶尔红，不算确定性交错；若旧版本不红，先补齐事件轨迹并更新根因假设，不更改期望来制造假红。

## 5. 实证后最小完整修复方向

确认该因果后，优先只调整load的读取因果：**先拿到本轮worker接受状态，再读取需要绘制的bootstrap业务状态**；不让较晚的“worker已停”与较早的业务快照共同成为停止刷新的依据。pulse、decisions、runtime仍可在安全的位置并行。loadSeq须等全部本轮读完成后核对，再原子替换客户端data/jobs；生命周期signal和旧load失效规则保留。

这只是依据现有提交顺序的首选方案，作者必须用实验验证它：worker accepted=false是在业务终态提交之后，因此后续bootstrap不应倒退到之前的queued状态；若accepted仍true但随后已结束，允许当前正常轮询获得最终状态。

不默认加“再轮询几次”的计数器、终态保险timer、无界retry、全局刷新框架、revision仓库、额外endpoint或后端合并快照。也不简单把schedule改成“data里有queued就永远轮询”，否则重启后未被接受、等待本人确认继续的任务会永久占用刷新。隐藏停读、卸载取消、当前选择与loadSeq的收敛必须保持。

如果实验表明真正根因另在open/paint或生命周期，先把同一书的根因、路径和方案改准确，由根核必要扩围；不让多个补偿补丁互相掩盖。
