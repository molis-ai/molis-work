# Personal Goal replication

状态：本机实现并验证。Goal 项目一致性集合复用现有个人空间本机增量传输；公网部署和真实 Home 验收仍未完成。

## Scope and design

逐 Goal 独立恢复会暂时拆开关系图、用户决定和约定；原样复制数据库会复制运行状态、凭据及本机游标。本期采用项目内 Goals 事实的一致性聚合：Goals、Governance、Goal 相关 ContextLedger 与它们的 Journal/幂等回执，由各 owner 明确声明可移植字段，Host 只组合公开端口。

项目聚合作为冲突单元，不自动合并两端编辑。变更日志仍增量上传项目聚合，不全量扫描上传整个 Home。单项保留当前 512 KiB 限制，超限报错且保留源数据。运行中的 Session、Agent、Scheduler 不复制、不执行；缺失的跨插件对象保留精确引用，物化仍向真实 owner 查询。

## Acceptance

- GSYNC-01：两份隔离个人 Home 经真实 Host 注册同步，恢复 Goal 本体、目录定位、关系、规则、指导、规划、约定、要求、工作历史、状态、归档/回收站、结构提案及可信决定出处。
- GSYNC-02：序号只在本机有效；传输以稳定事件 ID 表示顺序边界，在目标事务内重建顺序和所有声明过的序号引用。已有无关插件历史不被复制/删除。
- GSYNC-03：Goal 输入/交付物的 ContextLedger 保留精确来源、版本、移除历史；不复制正文、不生成新权限，也不启动任务。
- GSYNC-04：修改/删除/重启/重复回执不丢失；应用内容、依赖、Journal 与同步回执原子提交，远端恢复不产生同步回声。
- GSYNC-05：并发编辑保留双方并显式选择；未知字段、错误项目/空间、跨项目 ID、无效 JSON/关系/决定关联以及撤权都拒绝并回滚。
- GSYNC-06：集合显式勾选，默认不上传；同步关闭、本地空间和停用项目保持原行为。
