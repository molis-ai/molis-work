# 第 37 批独立复核修复
状态：已提交[修复 PR #2298](https://github.com/molis-ai/molis-work/pull/2298)。本人场景生成、整日使用和真实窗口走查沿用[验收记录](../backlog/BL-b37-generated-home-mainline-acceptance.md)。以 #2288 的合入提交 0dc996734a 为问题基线，复用 #2295 中的修复。需求依据为[第 37 批定样和验收](../post-anticorruption-roadmap/reference/batches/37.md)、[生成页公共合同](../scene-and-page-contract/spec.md)、[工作主线](../work-mainline/spec.md)。

- B37R-1 场景首页内容交给声明的首页主人保存可审核的草稿；只有本人可批准。人工冲突的三条选择可完成，差异未知不能覆盖，重试保持原请求，重放取回原回执，独立版本可恢复。
- B37R-2 对照中显示当前首页与草稿，检查失败阻断预览。文件和授权由首页主人和宿主核对，换版、撤下、离开、并发装载均释放原会话。清理重复文件读取和无消费者导出。
- B37R-3 切换事项保留其页签、右栏、草稿和助理归属，迟到打开不会污染当前事项。清除输入范围仅影响一次发送。个人空间、讨论与停靠的事件卡按约定打开和恢复。已打开的卡在主人改名后能刷新呈现。关窗或切回事项，助理和有独立输入框的对象页签均在主人读回草稿后恢复原选区。首次回读或读回缓存中的已有等候项时保持安静，后续真正转为等候时提示一次。
- B37R-4 当前范围决定清单、卡叠与件数。组首次折叠；来源的标题、状态、呈现由主人提供。避免逐事项重复取内容，选择放入对象支持继续查找。
- B37R-5 对照逐项修正收尾、上下游依赖和验收说明，核对资源预算、定向回归和隔离浏览器。真实 Home 与本人一天实操按原验收队列办理。

- B37R-6 SPC-11：一骏确认有限开放。已采用版本可通过 `surfaces.compose@1` 取本项目主人明确向页面开放、且该版本已逐项批准的呈现。页面给出对象引用，组合与基础首页复用主人的字段与形态。概况也须单独批准并显式开放。普通插件、预览和本人专属概况继续受原拒绝约束。

在隔离项目用有／无 Goals 两种夹具复验。定向运行 home-pages、mainline、场景 adoption、工作台和助理用例，构建、合同、资源及 UI 门禁按仓库要求执行。
