## 怎么打开

在仓库根目录运行，然后打开 <http://127.0.0.1:4418>：

```sh
python3 -m http.server 4418 --bind 127.0.0.1 --directory docs/design/work-brief-core
```

也可以直接用浏览器打开本目录的 `index.html`。顶上一条斜纹是**原型控制**，不是产品的一部分：切区域（首页、版本、来源、下一步）、方案（A/B/C）、状态、中英文和浅深色；「重置」清掉本页记住的选择（`localStorage` 键 `molis-proto.work-brief-core.v1`）。四块是拼在同一页上的：选「首页」的方案决定整页版式，另外三块的方案在任何版式里都生效，所以可以把四块的组合一起看。宽度 1440、1024、390 都能看。

## 四块，各三个方案

### 首页

| 方案 | 样子 |
| --- | --- |
| A 一页简报 | 一栏读下来：各来源的红黄绿、现在怎么样、要你处理的、和上次比、下一步 |
| B 状态页 · 分页签 | 概览／要你处理／下一步／和上次比 分页签，没有内容的页签不出；概览里是各来源的状态格（需求 §3.1 的可刷新状态页） |
| C 插件领头的卡片墙 | 上面一段综合说明，下面每个插件一张卡，插件名领头（延续 03 定的「插件领头」） |

状态：正常；没装 Work Brief 时的基础首页（插件自己给的概览与继续入口，不用模型，不生成简报）；新项目还没有内容（与读取失败分开）；一个来源读不到；定时简报没被授权读待办；后台刷新中（不清空画面）；综合首页没打开（退回基础首页，工作不丢）。

### 版本

| 方案 | 样子 |
| --- | --- |
| A 版本条 + 当时／现在 | 标题旁一个版本按钮列出历次版本；看旧版本时切「当时／现在」，变了的句子下面标出现在的样子 |

## 对第 15 批公共呈现的假设

第 15 批的公共呈现（卡片、名片、来源状态的公共组件）还没定样，本原型按下面的假设画，15 批定样后以它为准：

- 对象名片沿用 03「插件领头」：插件色块图标在前，名字在后；点开走统一的打开与定位。
- 来源状态共用一套词：正常／注意／要处理／无数据，以及读不到／未授权／过期／口述；读不到与未授权用虚线，不显示成 0 或「正常」。
- 状态环用简化画法，进产品时换 `status-ring-system` 的状态环。
- 页面上的一句话（撰写块）和引用对象（引用块）分开：句子由助理写，名片的字由事实主人给（设计稿 §5）。

## 模拟边界

- 数据是编的（`data.js`），不读任何 Home；项目、人、数字都是示例。
- 刷新、改版本、处理冲突、执行下一步、勾选并交给助理只改本页内存，刷新页面或「重置」就回到初始；不调模型，也不调真实动作。
- 对象名片、「去勾选授权」「重试」「继续」等只弹一句提示，不真的打开。
- 红黄绿是写死的样例，不是计算出来的；「定时简报」的授权只是文字，不连第 18 批的授权数据。
