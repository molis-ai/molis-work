这些不是不做，是现在没有足够理由排进来；阶段 4 结束时再看一次。原条件触发项 `BL-925`（「第 3 个 `dual_instance` 插件出现时重评 Manifest 分节」）已随 2026-11-22 [决定 66](decisions.md#decision-66) 废除 `dual_instance` 与 Shelf 纯平台化而正式退役删除（记入 [已删除 BL 墓碑](../../../docs/backlog-removed.md)）。

- 插件市场与审核流水线（BL-058、BL-167）、团队/企业托管策略（BL-168）、MCP 服务端作者工具（BL-170）。
- 状态机申报对第三方的强制：插件市场与第三方安装（BL-058、BL-167）开放时，未申报状态机的第三方插件不能上架／安装（用户 2026-11-08 定；[状态与状态机平台能力](../../state-machine-platform/spec.md) §5、§9）。
- 跨项目移动对象（BL-044）、问卷公网链接与 PPT 富排版（BL-045）、真实图像厂商（BL-046）、LLM Wiki 专有格式（BL-057）、浏览器自动捕获等新来源（BL-061）、群聊公网部署（BL-063）。
- 跨平台桌面与不依赖 `sandbox-exec` 的沙箱继任方案（C 端 M3／C-6；保留 S1 在已授权临时环境中的 R1～R6 隔离能力探针及据此选型的决定条件，不自动启动替换）、手机随手收（产品建议 I5）、本地模型模板（I4，按 Prologue 收敛口径暂缓）、用 ChatGPT 账号额度（I7，先要你确认能不能接）、国内写回飞书钉钉 WPS（I3）。

- 记忆与项目资料的向量召回（BL-036、BL-399）：等工具式检索的评测真出现「换个说法就找不到」再开。
- Coding 下一阶段 E 期里的 Vim 与快捷键、状态栏、导入配置及原未排期 ACP 方向。VS Code 扩展、Tab 补全与行内编辑已确定本阶段不做，不列为本期交付。
