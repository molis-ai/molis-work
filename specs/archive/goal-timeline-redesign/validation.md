### 第三版独立复核后的修正

独立审阅发现两项 P1：普通新报告会覆盖仍有效的待决定/受阻/中断/已完成状态；当前说明与交接仍使用旧的重启缺口文案。已在同一批修正中统一当前结果读取：

- 未关联要求的普通报告保留既有状态、下一步、责任和风险；Concern 追加到现有风险，不抹掉已有缺口。
- 报告和配置只重算涉及的结果要求；仍待处理的用户决定、环境条件、Host 连接继续显示。已完成目标的普通补充不改变完成结论；新增未满足要求、反证和未知结论会显示需跟进。
- 目标说明、当前成果、接续摘要与顶部使用同一组当前要求和结果事实，保留“你报告满足 · 未独立核对”等来源限定。历史事件和附件继续保留当时内容。

验证：`node specs/archive/goal-timeline-redesign/check-projection.cjs` 通过。脚本调用实际原型函数，检查普通报告对决定/受阻/中断/完成场景的状态保留，以及支持→反证、未知、新增要求、当前读入口一致性和历史保留。它不验证生产 Runtime 或浏览器布局。

浏览器定向复测：从工程规划打开行为验证，实际填写并上报重启支持结果；顶部、目标说明和接续摘要均更新为来源限定支持与待收尾，未继续要求重做已有重启检查。窄屏重新执行添加字段与可选勾选，无横向溢出；控制台 error 为空。脚本语法检查通过。`git diff --check` 无报错，但该目录仍为 untracked，不能据此宣称这些新增文件已被 Git diff 完整检查。
