## 给人讲清楚

标签页、标签组、分屏、侧栏和底栏现在各有一套切换和恢复的方式，用起来不一致；有的页面还在后台不停地发请求，甚至一直重复发必然失败的请求。这一批把工作台的导航统一成一套，让你装的插件都能出现在同一个地方，同时把多余和必然失败的请求清掉，并把 Feed 的页面数据整理搬回 Feed 插件自己。做完你会感觉切换更顺、不再莫名卡顿。需要你做的：如果出现之前没定过的新导航样子，要你看一眼定下。

- PR 按模板填，「开工前检查」一节贴检查结果和定样决定；推送前先 git fetch origin main 再跑 pnpm secrets:check；合并交统筹，你不合。
