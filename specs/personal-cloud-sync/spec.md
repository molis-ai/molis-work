## 3 技术责任边界

以下是实施设计，不是已经发布的新接口。实现时按 [合同变更流程](../../docs/system/CONTRACT-CHANGES.md) 同步消费者、测试、API 快照与手册，不预埋未兑现的空接口。

| 层 | 负责 | 不负责 |
| --- | --- | --- |
| contracts | 集合、格式版本、附件引用、空间策略与设备配置的静态合同 | IO、业务 SQL、可执行适配实现 |
| plugin-sdk | 作者与平台共用的声明检查、依赖展开、适配辅助 | 依赖私有平台包，或包含各插件业务逻辑 |
| 业务 owner | 可携带字段、稳定对象键、引用、附件声明、语义验证、事务导出和恢复 | 直接调用云端、读写其他 owner 的业务表 |
| storage | 本地连接、事务日志、回执、游标等技术机制 | 判断 Goal 是否完成，或解释问卷与知识库内容 |
| sync-replication 与 Host | 生命周期装配、可信身份、设备选择、共同收发与恢复协调 | 新建另一份逐插件名单，绕过 owner 写业务数据 |
| Rust Worker 与 D1 | 服务端鉴权、账号和空间隔离、远端记录、配额预留与结算、附件索引、删除状态与清理账本 | 为每个插件写专用云端传输分支，信任请求体自报账号 |
| R2 | 受控附件字节存储 | 决定业务引用、身份或回收条件；公开暴露账号附件 |

Auth 与同步服务分别部署。客户端只能连接可信配置注入的正式 HTTPS 服务；不提供任意上传目的地输入，不把用户令牌发送到重定向目标。服务端复核应用与用户并推导空间，每次访问 D1/R2 都经过相同授权边界。更换账号、撤权或退出后拒绝旧请求的迟到提交。

插件数据通过同一扩展合同接入。内置插件沿现有目录提供适配，独立插件沿安装实例的生命周期注册、注销；安装身份、权限和格式必须核对。声明而未兑现的集合显示不可用。数据格式版本与传输协议版本分开，不通过自动换版本扩大同步范围。当前仓库不留读取兼容期的规则不因本规格改变；真实 Home 维护仍需当次批准。

## 5 附件与大对象

附件声明包含稳定引用、所属空间和资产版本、字节大小、内容摘要及媒体类型。对象键由可信服务确定，网络输入不能指定另一账号对象或本机文件路径。插件提供有界、经授权的本机读取入口，平台执行共同传输。

上传过程为容量预留、分块传输、完整性核验、确认提交，再发布完整附件引用；下载校验后以原子方式加入目标资产。重试、断点与中途退出保留可恢复状态；未完成的上传不能冒充可用附件。分块技术和大小在实现切片核定，不把 R2 的某一种具体 API 当作已选定方案。

启用后按空间所选范围同步实际附件，不增加“离线可用”开关。新设备可以先显示结构与下载进度，未就绪的附件明确标记；全部选中内容与文件就绪前不显示全部已同步。本机创建而未上传的唯一原件不作为缓存清理。

超过现有 512 KiB 的结构化内容同样要处理，不能只补图片：由 owner 提供稳定分片和一致提交清单，传输可分批、恢复必须保持领域一致性。附件正文使用 R2；不把整个 SQLite 或不透明数据库备份塞进 R2 作为通用适配。损坏、超限或格式错误的项单独隔离，可定位、可重试，不阻塞该集合其他健康资产。

## 6 容量与删除规则

账号容量按 molis-work 应用内可信账号主体合并计算，不能按设备、项目或插件重复分配。100 MB 的实现单位采用十进制 **100000000 字节**，界面明确标注 MB，不混用 MiB。

用户容量口径为业务记录及保留版本的规范化 UTF-8 字节，加上账号内唯一、已确认附件的实际字节。回收站内容和可恢复的冲突版本仍计入；共同引用的同一账号附件不因引用数重复收费。索引、传输控制日志、墓碑和幂等回执不重复作为业务正文计量。该口径是用户逻辑容量，不等于 D1/R2 的物理账单或 Cloudflare 免费额度。

服务端以事务和幂等回执预留、确认和释放容量；两台设备同时上传也不能穿透账号上限。中断上传的预留与临时对象在核对引用和提交状态后回收。单附件上限可配置，不能超过账号总限额及当时剩余可用额度；实现若需要更小的产品限制，应明确说明后确认。

超限时阻止增加占用的上传，保留原件与待处理项；下载、删除与减少占用的更新仍可进行。不能因为“达到容量”把所有同步请求一起拒绝。

30 天以服务端确认软删除的 UTC 时刻起算，设备时钟不能提前触发清理。期间删除和恢复同步到其他设备；恢复与清理竞争须原子裁决。存在未同步编辑时先保留冲突，不静默覆盖为删除。永久删除是带二次确认的不可逆操作，不能由关闭同步或退出登录触发。

到期清理只处理已无有效业务、回收站及恢复历史引用的对象。共享引用仍存在时，R2 字节继续保存并计量。最小删除标记和防复活信息与业务回收站分开：30 天不意味着删光所有墓碑；长期离线设备必须通过当前头或重新对账辨别已清理资产，不能重新上传旧副本使其复活。历史压缩、清理失败及重试须有账本，不靠一次遍历删除对象。

## 9 验收标准

以下编号是新交付的验收要求，不能用旧阶段测试直接视为完成；S1 首片的局部证据见第 8 节。实现时把编号写进对应测试名或注释，人工证据记录设备、版本、环境和结果。

- **PCSYNC-01** 云端从 Auth 取得应用与用户后派生账号和空间，篡改 body、命名空间、附件键或旧账号令牌均不能跨账号访问；迟到授权和重定向不泄露令牌。
