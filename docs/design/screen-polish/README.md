颜色、阴影、圆角、控件都取自 [`../kit/`](../kit/README.md)，`screens.css` 只管版面。事项线和对话框的结构沿用[第 32 批定样](../work-line-32/README.md)的方案 E。

## 怎么看

从 `docs/design` 起服务：

```bash
python3 -m http.server 4433 --bind 127.0.0.1 --directory docs/design
```

打开 `http://127.0.0.1:4433/screen-polish/`。右上角切浅色和深色。地址后加 `?only=coding`（或 `dialog`、`event`、`start`、`settings-assistant`、`settings-runtimes`、`tabs`、`split`、`b-strip`、`b-switch`、`b-split`、`c-hero`、`c-top`、`c-split`、`c-line`、`c-foot`、`c-open`、`d-hero`、`d-foot`、`d-open`、`home`、`home-brief`）只看一屏，加 `&theme=dark` 直接进深色。
