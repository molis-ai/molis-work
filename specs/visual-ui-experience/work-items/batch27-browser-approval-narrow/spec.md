# 第 27 批窄窗浏览器审批

状态：现有控件的局部方案已在隔离 Host 验证，待实现和整批验收（2026-11-10）。负责：第 27 批 Codex 统筹，A／D 写手实施。[BL-102](../../../backlog/BL-102.md) · [VUX-19／29／30](../../spec.md#4-验收标准) · [认领与原型结果](https://github.com/molis-ai/molis-work/issues/1743#issuecomment-6766272137)

## 现状与方案

基点 `6bb683b352` 的真实工作台在 740、759、760px 同时打开助理和侧栏浏览器时，浏览器审批的拒绝按钮九个采样点全部被浮层遮挡，助理最小化又被标题栏的第二行挡住。实际鼠标点拒绝位置没有审批请求。761px 两处入口可命中，390px 可从原助理入口审批。卡片处理完毕后，原按钮失去焦点，浏览器焦点落到页面。

在 601–760px 且浮层助理与当前侧栏浏览器均可见时，两者在实际标题栏下分用现有空间。浏览器占助理右侧的剩余宽度，助理使用左侧原本空出的部分。浏览器的普通、待审和处理结束三个状态保持同一横向分配。沿现有的主区／右侧切换、独看与显式最小化。待审详情和接手说明使用同一滚读区域，三种决定与网页控制可达，长文可读，继续采用现有控件和语义样式。

审批卡从当前表面移除时，若焦点还在即将移除的卡里，归到该表面的可见入口。侧栏归到浏览器标签，助理归到当前助理输入；焦点已移走时保留人的选择。到达待审、审批失败与同卡重绘时保留可用焦点。决定、站点授权、接手和收据继续走现有入口与 Host 状态。待审 ID 继续由该状态提供。

原型在 740×900、740×620 和 740×560 证明实际允许、记住站点、拒绝、请求失败和重试。601×560 的待审画面从约 1px 增到约 60px，真实接手、滚页、点击与刷新已通过，页面仍被 200px 逻辑视口缩压。范围限于审批可达、焦点与既有网页控制，画面比例与独看在此宽度下的既有缺口分列。原型用隔离 Chrome 和临时布局替换取证，生产实现另验。

## 开工前检查

| 项 | 结论 |
| --- | --- |
| 1. 事实主人 | 审批、站点规则与网页控制仍分别由现行审查和浏览器服务提供。工作台只消费已授权的当前视图与布局状态。 |
| 2. 插件同等待遇 | 只动工作台和共享样式的现有界面，装配与插件权限沿现行规则。 |
| 3. 能力注册 | 现有审批、站点许可、接手请求各走原入口，可信身份由宿主上下文提供。 |
| 4. 合同 | 改动限于 DOM 内部布局、现有卡片滚动和焦点，无公开接口或共享事件变更。 |
| 5. 包与分层 | 浮层、侧栏呈现和回焦各由 Workbench 既有部件处理；共享浮层几何用 Design System 样式。 |
| 6. 表与存储 | 审批和站点选择继续使用现行持久化流程。 |
| 7. 兼容与迁移 | 现有可见状态、待审记录与窗口设置直接使用。 |
| 8. 安全边界 | 真实受保护审批走现有令牌与权限；拒绝和网络失败均验网页效果为零。保持画布视口协议、坐标映射与保护范围。 |
| 9. 调用次数 | 复用当前的布局与渲染更新；同一决定按原路发送，记住站点沿原许可和决定各一次。无新增读取、轮询与宿主发现。 |
| 10. 升级与数据 | 待审 ID、站点偏好与窗口状态按现行合同读写。 |
| 11. 成果与过程项 | 本片仅呈现和交互，无产物声明。 |
| 12. 页面、外壳与文字 | 复用标题栏、浮层、当前浏览器及原审批控件，配色、字号、间距沿语义样式。实测下发资源的增量。 |
| 13. 错误 | 保留原请求助手和可访问的错误反馈。请求失败后仍可核对原卡并显式重试。 |
| 14. 冲突面 | 主线 #2002／#2004／#2006 的助理、浏览器和侧栏修改及第 16 批的文字键随最终集成保留。只碰现有布局、审批卡渲染与收卡的必要位置。 |
| 15. 全局最优 | 共用现有两处入口和决定路径，布局随真实可见性变化，不给待审新增窗格或持久状态。 |

## 验收

- **BBA-01** 窄段 601、740、760px 实际元素命中三种审批、浏览器工具和助理最小化。两种开窗顺序、长中英文、明暗、正常和短高窗口均可操作。待审前后宽度稳定，760／761、600／601 的边界以及 390px 助理原动线保留。
- **BBA-02** 隔离 Host 的鼠标允许、鼠标记住站点、键盘拒绝分别验证同一待审 ID、决定次数与网页实际效果。仅在原卡仍持焦点时归还，网络失败后原卡与焦点可用，显式重试同 ID，拒绝及失败的网页效果为零。
- **BBA-03** 短高时详情和接手说明可由键盘、滚轮读到，页面依然可以真实接手、滚页、点击和刷新。站点权限面板、助理显式最小化和重新打开、侧栏切换均验。画面比例单列实测，不以控件可点击代替画面验收。
- **BBA-04** 先证明生产基线能触发遮挡断言，再在实际构建后通过定向浏览器用例和健康检查。比较同条件真实 Host 下发资源。共享视觉、受影响测试与 Workbench／Design System README 检查在整批最终头验证。按工程、隔离实操和本人验收分别记录。
