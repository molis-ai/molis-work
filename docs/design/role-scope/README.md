## 方案 C：默认跟随，改了才覆盖

项目里的角色默认跟随你的原件，原件出新版本，新任务就用它。在项目里改了「做事方式」或「能用什么」中的一节，那一节就成了本项目自己的，标「本项目改过」，可以恢复跟随；没改的一节照旧跟随。原件也改了覆盖过的那一节时，项目设置里提示一句，可以就地看差异。

- **取值从近到远**：任务里另选 → 本项目 → 你的默认 → 助理自己。选择器里每一项标出它是「项目默认」还是「我的默认」，项目设置里用「来源」一行把这几层排出来。
- **项目默认的角色停用时**，新任务直接由助理自己做，跳过个人默认。项目保留原默认配置，换选或重新启用都在原处。任务内另选仍优先，进行中的任务继续用开始时的版本。此行为于 2026-11-08 确认。
- **任务里换一个只管这一次**；选了别的，下面出现「设为本项目默认」「设为我的默认」，点了才扩大范围。
- **保存并使用**：每次保存都固定成一个版本；进行中的任务继续用它开始时的版本，新任务用新的。抽屉底部一行写清这次保存影响哪些地方。
- **选角色不授权**：「能用什么」只能在任务允许的范围里再收窄。
- **个人工作也能用角色**（今天会被拒），取「你的默认」。

## 不切换页面（用户补充）

角色的每个操作都在开始它的页面上完成，做完回到原处：

| 操作 | 在哪里发生 |
| --- | --- |
| 改一个角色、新建一个角色 | 右侧抽屉盖在当前页上（任务里、项目设置、全局设置都一样）。保存后抽屉里出「已保存」和「撤销」，选择器或列表里随即用上新版本 |
| 在项目里改时改到哪里 | 改动后抽屉底部出现「改到：只本项目／我的原件」，旁边一行写影响：本项目自己的一版，或原件新版本连同跟随它的项目 |
| 别处刚改过 | 抽屉里一条提示，就地看差异，选「在新内容上保留我的改动」或「丢掉我的改动」之后才能保存 |
| 版本与恢复 | 抽屉里的「版本」折叠区，每一版旁边「恢复成这一版」；恢复是存成新的一版，不盖掉之后的修改。框里有没保存的改动时先就地问「恢复成 vN 会丢掉没保存的改动」：「继续改」或「丢掉改动并恢复」 |
| 有没保存的改动时关抽屉 | 按 Esc、点 ×、点「关闭」都不直接关：抽屉底部就地问「有没保存的改动」，「继续改」回到输入框，「丢掉改动」才关；问的时候再按 Esc 等于继续改。不另开对话框 |
| 设本项目默认、我的默认、另选角色继续 | 选择器就地换成「选一个，作为……」的模式，顶上一行说明在选什么，「取消」退回 |
| 加入角色、看原件的差异 | 项目设置里在按钮下面就地展开 |
| 停用一个角色 | 每一行行末都有「调整」和「更多」（组件板 `mw-menu`：复制成新角色、停用…）。选「停用…」后在那一行下面就地展开确认：影响哪些项目默认、进行中几件、以后能不能再启用 |

抽屉、菜单、就地展开都用组件板的动效 token，减少动效时不做位移。

**焦点**（D 轨共审定）：展开停用确认后焦点在确认的标题上；取消回到那一行的「更多」，停用后回到那一行；抽屉关上回到打开它的按钮，新建保存后回到新角色那一行；菜单可用上下键移动、Esc 关上回到「更多」。几个同名按钮的可读名都带上对象（「调整：审稿人」「恢复成 v3」「更多：研究员」），停用确认和就地展开的面板是带名字的组（`role="group"`）。
