# Capabilities

Specify audience, effect and input/output in the shared action directory. UI, workflows, Agent and MCP use one handler. An `agent` action is also available to generated plugins unless irreversible or marked `plugin: false`; irreversible actions are never offered. Validate schemas, use caller/session identity and recheck authority and revision after external waits. Invalid query output fails; invalid output after a committed command requires refresh.

Use the actual capabilities the person approved; inactive dependencies require consent before building. Prefer an enabled equivalent. Writes in trial and acceptance use schema stand-ins and do not touch foreign data. A read stand-in produces one list entry (strings `示例`, minimum number, first enum); examples assert structure or local saved facts. Paid or quota-limited calls require an explicit click, never a load query.

Host verifies the exact installation and grant for each bounded call. Register published operations once from the contract. Cost follows actual dependencies; unknown effects and cycles are not free. Sandbox and public limits differ. Use SDK lifetime and Host guards; do not repeat a paid call with unknown outcome. Declare result summary and pointers without editing business output.
