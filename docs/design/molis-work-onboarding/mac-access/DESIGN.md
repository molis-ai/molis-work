# macOS 工作资料准备 · 可交互切片

模式：Operate。沿用现有灰白纸面、细分隔线、深色主动作和少量靛蓝，保持工作内容先于装饰。范围只在此设计目录，不改变全局视觉系统。

直接打开 `index.html`，或用静态服务器访问。底部「查看演示场景」可独立进入来源清单、资料预览、整理进度、工作摘要；右上角可切换浅深主题。页面顶部持续标明全部为示例，未读取真实资料、调用模型或授予系统权限。

- **清单作为连续工作面。** 四个 macOS 目录独立成行，选择、时间范围、真实准备状态和管理入口保持相邻。其他已有来源在同一清单的次分组中，不掩盖当前不同的接入方式。全选支持半选状态，零选禁用继续。
- **授权逐项处理，不丢失清单。** 统一主动作在清单上方展开当前待授权目录；每次只处理一个，允许跳过。原型按钮明确叫「演示授权」。管理已连接目录明确区分清除 Molis 记录和撤销系统权限。选目录与读取正文保持分离。
- **预览是正文读取之前的决定点。** 来源页签、每目录独立时间范围、文件元数据、文件勾选和整子目录排除组成单一连续清单。显示本轮数量/体积、50 份/6 MB 上限及未列出内容不读取。唯一主动作「开始整理」承担读取和模型处理的边界。
- **进度呈现完成事实。** 文件读取、分批提取、摘要生成分层展示，允许暂停/继续。不可提取文件的例子说明单个失败如何继续。正式实现必须连接真实进度；此处是明确标注的演示计时器。
- **结果首先是一份可读文档。** 工作主题、正文要点、待确认事项和来源阅读构成主要内容。编辑切换为原位编辑，保存后可采用；采用一个项目，不暗示自动生成多个项目。引用可打开示例原文，重新整理返回范围。

主动作采用底部固定可见的操作条：桌面工作面按视口限制高度、内容在内部滚动，操作条吸附面板底部；窄屏改为页面滚动、动作条吸底。1180×760 时不必滚过所有来源才找得到继续。

桌面采用 244px 说明栏与最多 768px 主工作面；820px 以下说明栏收为顶部，步骤横排；480px 以下目录行操作折到名称下方，预览文件名与元数据保留同一阅读顺序。44px 左右的主要操作、可见焦点、原生 checkbox/select/dialog 和 reduced-motion 保留。

生产接入时保持既有契约：来源未就绪必须显示真实原因；目录路径为授权返回的实际范围；预览、读取、取消连接与采用各自使用现有 owner。当前原型不具备这些真实能力，也不作为其验收证据。

## 生产实现 · 2026-09-26

以下记录当前应用实现，与上方 `index.html` 模拟切片分开。视觉继续沿用 [Operate](../../../../DESIGN.md) 的中性纸面、细边界和黑白主动作。实现依据为 [页面入口](../../../../apps/workbench/src/context-onboarding-renderer.ts)、[交互](../../../../apps/workbench/src/scripts/context-onboarding.ts)和[样式](../../../../apps/workbench/src/styles/context-onboarding.ts)。

- **清单与真实授权。** 有原生 bridge 时，下载、文稿、桌面、其他文件夹各自选择、授权和显示实际路径；全选支持半选，零选禁用继续。统一继续动作逐项打开系统目录选择器，正常取消后可处理后续来源。浏览器提供选文件夹的替代入口，不显示伪造的 macOS 授权状态。取消连接只清除 Molis 的访问记录。
- **先预览，再读正文。** 授权后显示文件名、大小、修改日期；原生目录可分别选择最近 7／30／90 天或全部时间，排除文件或整个子目录。只读取预览中选中的范围，显示 50 份／6 MB 上限；未就绪来源可重试或本次跳过。单文件提取失败保留原因，其余内容继续。
- **可用的无模型路径。** 未连接文字模型时，预览主动作是「先带入资料」；读取后呈现「资料已经准备好」，以「保存资料，开始工作」为主动作。用户可命名项目并进入工作，也可连接模型后继续整理。此状态不伪装成摘要生成成功。
- **摘要与采用。** 已配置模型通过既有 Prologue 接口分批整理，显示来源读取与整理进度。摘要为可编辑文档，引用可打开暂存原文。采用后保存原始文件快照、资料正文与工作摘要，并打开项目 Pages；本次导入不自动持续同步。生产进度来自服务状态，上方原型的暂停计时演示不代表已实现暂停处理。

桌面保持 244px 说明栏、52px 栏间距和连续主面板；面板高度受视口约束，标题与底部操作条吸附，长清单在内部滚动。820px 以下改为单列页面滚动、步骤横排，480px 以下文件元数据折到文件名下方。沿用 Inter／Noto Sans SC、浅深主题与 reduced-motion；既有 Inter 检测提示本轮接受，未更换字体。
