## 成熟度标签

对外引用本目录材料时，只使用以下成熟度标签，不得把规划或分支能力写成今天可下载：

| 细标签 | 含义 | 官网简标签 |
| --- | --- | --- |
| **已发布** | 在公开 Release 里可取到。目前唯一的历史公开正式版是 `v0.2.0`（2026-09-11，当时名 GoalBoard，仅源码、MIT 许可；现行 `0.1.0` 复位后的主线尚未公开发布） | 已发布 · v0.2.0（源码，当时名 GoalBoard） |
| **main 可用** | 已合入 main，主路径能走通，尚未公开发布安装包 | 开发中 |
| **main 部分** | 已合入 main，仅覆盖部分路径、缺关键环节或未完成真实账号/真机验收 | 开发中 |
| **分支** | 在独立分支或开放 PR 上实现，尚未合入 main | 开发中 |
| **规划** | 有 spec 或路线书批次，尚未实现 | 规划中（演示须标「示意」） |
| **撤回** | 曾经规划或实现，已下线或删除 | 不对外 |

补充口径：

- **需模型**：仅因首次使用需配置模型的能力不降级，标注「需模型」；直接决定流程走向的推荐/判断类模型输出若未做命中率评估，标 `main 部分`。
- **建议（未立项，不对外）**：仅存在于[产品优化建议](产品优化建议.md)且未立项的条目，不标「规划」，不进官网。
- **路线书排期**：规划项的先后顺序与交付状态以[路线书执行目录](../../specs/post-anticorruption-roadmap/spec.md#execution-batches)与[暂缓项](../../specs/post-anticorruption-roadmap/reference/deferred.md#section-8)为准；路线书无日历，对外不承诺上线日期。
- **团队协作例外**：多人实时团队协作与团队记忆内部标**规划**（服务端批 `SRV-N`），按负责人 2026-10-18 决定官网对外可标「开发中」（须注明按项目共享、尚未验收）。
- **示意 / 内部**：场景故事均为构造的「示意」，非客户实绩，无实测不写省时比例；内部 `Issue` 插件不出现在任何对外材料中。

## 维护与更新规则

自 2026-11-26 起**废除每日 09:00 人工日更机制**（原[日更规范](archive/2026-11-04-日更规范.md)已归档）。本目录改为**按产品里程碑按需同步**：

- **触发条件**：仅在发生以下变化时更新对应活跃文档——公开 Release 发版、主推场景或定位调整、重要产品决策改变对外承诺（如决定 66/68）、或关键大能力合入导致主推场景瓶颈跨级。
- **单源原则**：不在此复写全量包列表、动作计数或数据库版本表；涉及内置插件目录、包成熟度、联网披露与安全不变量，直接链接 [PRODUCT.md](../../PRODUCT.md)、[SSOT-MATRIX.md](../SSOT-MATRIX.md) 与 [NETWORK.md](../platform/NETWORK.md)。
- **禁止越权操作**：文档维护不改产品源码、真实 Home（`~/.molis-work`）、官网仓库或供应商账号；招募访谈、发帖、录屏发布或修改官网文案均须先获用户明确授权。

### 公开摘要与私有采集

本仓库为公开仓库，本目录内任何文字均会对外可见（2026-10-18 `#719` 确立，门禁见 [仓库卫生](../system/REPOSITORY-HYGIENE.md)）：

- **私有采集留在仓库之外**：完整 API 响应、机器快照、本地工作树与未提交列表、文件哈希与非公开研究原文一律放在仓库外本地私有目录，受 `.gitignore` 与 `scripts/gates/doc-raw-data.mjs` 守卫。
- **公开摘要仅写可公开事实**：日期与基线提交 SHA、公开 PR 与外部一手链接、产品影响、实现状态与验证边界；禁止出现 `/Users/<name>` 或 `/home/<name>` 等本机绝对路径、私有草稿链接（如不可公开访问的个人文档/Artifact URL）、未公开 Release 细节或凭据。
- **合规自检独立于密钥扫描**：`pnpm secrets:check` 通过不代表内容适合公开；涉及第三方或关联项目材料须先确认可公开边界。
