## 1. 背景

来源：MISC「T-400 起草 发现」与「T-400 二审 建议」（6537141182），合成一单；T-400（#1637）已合入。

现状（`origin/main`）：
- `mcp.authority_denied`、`mcp.tool_unknown` 在 `apps/local-host/src/mcp-start-preflight.ts:5` 用 `defineErrorCodes("mcp", { authority_denied: "forbidden", tool_unknown: "not_found", unexpected_field: "invalid" })` 声明；但 `apps/local-host/src/mcp-authority.ts:33、37、46`、`apps/local-host/src/mcp-server.ts:246`、`apps/mcp/src/tool-dispatch.ts:30、71`（`ports.createError(...)`）仍是裸 `new ActionError(code, …)`，抛出处不带 kind——同一个码，一边有 kind 一边没有，靠平台码表兜底。
- 同样裸抛的还有 `mcp.tool_disabled`（`mcp-authority.ts:41`）、`mcp.context_changed`（`mcp-server.ts:46、146、249`、`apps/mcp/src/context-presentation.ts:42`）、`mcp.context_host_missing`（`mcp-server.ts:273`）、`mcp.grant_invalid`、`mcp.grant_scope`（`mcp-action-grants.ts:25、27`）等。

今天没有代码按码读 kind，所以对外状态不变；本单是把“kind 随抛出处走”做齐，防止以后有人按 kind 读时出现同码两种结果（T-400 刚把撤权的几个码做成这样）。

## 2. 目标

先在 #1332 贴【方案】：逐码列出“声明放哪里、抛出处各几处、kind 取什么”。
1. 把上面各码（`git grep -n 'new ActionError("mcp\.' -- apps` 找全）收进**一份** `defineErrorCodes("mcp", …)` 声明（可放 `mcp-action-grants.ts` 旁已有的 `mcpGrantErrors`，或新建同目录一个小文件；`apps/mcp` 包不依赖 `apps/local-host`，它的 `createError` 端口要怎么拿到声明的 kind，在【方案】里写清，不引入反向依赖）。
2. 每个抛出处改用声明；kind 取值与现行平台码表（`ACTION_ERROR_KINDS`）及 `mcp-start-preflight.ts` 已声明的一致，**不改对外 HTTP 状态**（先对每个码列出现行状态，改完逐个核）。
3. RAC-2713：对每个码的抛出处，错误 `kind` 等于声明的 kind（表驱动，先对旧源码证明红）；RAC-2714：`mcp.authority_denied` 与 `mcp.tool_unknown` 从 preflight 与从 authority／dispatch 两条路径抛出，kind 相同。
4. `error-scan` 的数字（裸 `extends Error`、非 `<主人>.<原因>` 码、不以主人名开头的码）只许减少。
