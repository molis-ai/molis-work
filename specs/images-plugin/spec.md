# 图片生成插件

用户在 Molis Work 中选择生图服务，描述图片，明确点击生成，查看进度与失败原因，预览和下载图片；刷新或返回插件后可继续查看记录。本次在独立工作树交付本地实现，不提交、推送、合并或发布。

## 当前必须

- 沿用一等 Native 插件、Workbench 工作面、本机 SQLite 和宿主加密密钥存储；不新增模型平台或调度服务。
- 本机服务配置支持 OpenAI Images 协议、Gemini generateContent 协议，以及同协议的自定义厂商 / 本地 API。模型名、API 基址可编辑；支持的协议不等于任意厂商 API 都兼容。
- 配置为本机共享，任务和图片按宿主当前项目隔离。浏览器或任务记录不回传 API Key；修改端点或协议须重新填 Key，避免旧密钥发送到新地址。
- 单次文生图、异步状态、历史、重新使用提示词、停止本机等待、错误恢复和本地图片预览 / 下载。图片从 Base64 或临时 URL 下载到插件私有目录，限制体积和格式。
- 同一请求 ID 幂等。失败、取消、重启不自动重新请求可能收费的 API；重启将未完成任务标为中断。停止本机等待不承诺厂商停止计费。
- 默认不调用远端生图；首次真实厂商生成由用户提供连接并点击生成。

## 可以延后

图生图、蒙版编辑、多图批处理、厂商异步专有协议、工作流编排、远程 MCP 生图工具、跨插件 Artifact 发布。需要真实场景时再接入，不声明尚未兑现的能力。

## 应当删除的额外复杂度

不新建 Integration poll / Signal 流，不重构既有文字模型设置，不引入 React、第二套插件平台、自动重试或任务队列服务。

## 验证与交付边界

工程验证覆盖协议请求、Base64 / URL 图片保存、错误和凭据隔离、项目隔离、取消 / 重启、幂等和注册接线。浏览器实操覆盖配置、提交、失败恢复、结果和窄屏。受控本地服务的图仅是链路验证，须与真实厂商生图分开报告；图像质量及用户体验由真人验收。
