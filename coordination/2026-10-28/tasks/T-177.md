## 2. 目标

3. 写作助手拿到的整篇文字：不超过 180000 个字时原样；超过时取前 180000 个字。
4. 合成、比较多篇文档的卡片说明：不超过 600 个字时原样；超过时取前 600 个字。
5. 不含两单元字的文字与现在一字不差。
6. 用例钉住上面几条：任何一处改回按单元截，或差一个，都有一句断言红（第 6 节）。

下面源码的行号：`intake-offers.ts`、`store-generations.ts` 是 main 上改之前的；`fragment-offers.ts` 按 T-157 头（T-157 合入后与它相同）。每个文件**从下往上改**，行号就不会错开。

1. **`intake-offers.ts`**：`:12-17` 共六行（一行注释加五行函数）换成下面五行，别的一字不动：

   ```ts
   /** Cut to `max` whole characters (the length Pages checks a title by), the last of them 「…」; an emoji is one character and is never cut in half. */
   const clip = (text: string, max: number) => {
     const characters = [...text];
     return characters.length <= max ? text : characters.slice(0, max - 1).join("") + "…";
   };
   ```

   说明：
   - 文件从 35 行变成 34 行，`:18` 以后的行号各减一（原 `:28` 变成 `:27`，原 `:30` 变成 `:29`），那两行的文字不变；`TITLE_MAX`、`SOURCE_MAX` 还是 80；
   - 写法与 T-157 的 `extract.ts` `clip` 一样：同样的局部量名 `characters`、同样的 `characters.slice(0, max - 1).join("") + "…"`；
