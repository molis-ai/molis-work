提醒规则的两个表单各有自己的失败例外，原名却相同。分别说清「在这些地方」和「暂停期间」，沿用各自的保存请求和选项。能力开关的可访问名称取自同行已经翻译的动作名，原生开关状态表达启用或关闭。记忆设置卡移除会命中助理过程行的类名，回到共用设置区布局。

Jelly 日程没有侧栏预览，结果已带名称和打开位置。没有预览来源时，侧栏用通用的「这项内容」说明，保留结果名称与「在插件中打开」，无需再画空预览框；不猜是权限问题，不把未读内容带入下一次发送。读不到已声明来源时继续由原错误路径解释。

首次使用已有必填和真实提交按钮。390px 深色隔离浏览器实测：点击空值会拒绝并聚焦，底栏副提示隐藏，浏览器的英文气泡难辨认。保留必填阻止提交，在项目名称旁已有的错误位置显示本地化的「请填写项目名称」，聚焦原字段，输入有效文字时撤下这条提示。纯空白继续由 Host 拒绝并在同一位置给出原因，焦点回名称框。实测原来纠正后按回车只产生名称变化事件，上一条错误触发重画，替换了即将提交的表单；名称已在输入时保留，离开字段不再走来源变更与重画。

范围限于工作台的助理设置、侧栏文件、空白命名脚本及对应英文字典，直接浏览器用例、本文和文案清点。空白命名由 [context-onboarding-blank-name.ts](../../../../apps/workbench/src/scripts/context-onboarding-blank-name.ts) 负责，沿现有脚本片段方式装配。片段从引导读取同一份名称草稿、错误和页面状态，画原表单，接收字段和提交事件，更新名称预览、提示与焦点；实际创建仍调用引导原来的采用函数。无独立页面资源。无需修改助理运行时、Jelly、来源合同、授权、开关语义、项目创建流程和其他引导步骤。不改视觉需求主 spec 与共享待办；BL-092 的最终状态由批次会话根据证据关闭。
