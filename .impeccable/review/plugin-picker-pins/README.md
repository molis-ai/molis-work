# 插件切换器：头部两个按钮、一张网格、悬停才出现的两个图标按钮 · 评审截图

对应 `specs/archive/plugin-picker-dock/spec.md`。2026-10-02 在最终构建上取的：一个开发用 Home 里的项目，装了 Pages / 工作流程 / Schedule / Coding 等一批插件，
其余是项目没有的（灰）。悬停与点击用的是真实的鼠标事件；手机那张开了触控模拟（没有悬停，按钮常在）。

| 文件 | 看什么 |
| --- | --- |
| `rest-1440-{light,dark,en}` | 静止：头部是搜索和「插件市场」「插件创作工作台」两个按钮，在「项目首页」之上；一行只有名字和一句说明，没装的整行置灰，常驻的行尾一个小钉子 |
| `hover-installed-1440-{light,dark}`、`hover-1440-en` | 悬停一个装了的：📌 常驻 Dock 与红色垃圾桶淡入，说明让位被挤短 |
| `hover-available-1440-{light,dark}` | 悬停一个没装的：📌 不可用，深色的 ＋ 添加 |
| `kept-at-rest-1440-{light,dark}` | 常驻之后静止的样子：行尾钉子，Dock 里多了一个钉子 |
| `removal-asked-1440-{light,dark,en}` | 移除要点两次：第一次，第二行换成「再点一次移除」，垃圾桶填成实心红 |
| `rest-900-light`、`hover-900-light` | 两列时：头部仍是一行 |
| `phone-390-{light,dark}` | 没有悬停的设备：头部搜索占一行、两个按钮平分下一行（44px）；条目按钮常在；Goals 的垃圾桶不可用 |

动效（截图看不出）：按钮 `opacity` 130ms、从右侧滑入 250ms、第二个晚 32ms；加号与垃圾桶在按钮里互换（缩放加渐变）250ms，图钉立正是 250ms 的弹簧；
没装的条目变色是 250ms 的色调；Dock 里的钉子进出是缩放 + 渐显。全部走设计系统的时长与曲线，只动 `opacity` 和 `transform`，减少动态效果时为 0s。

持续的保证在测试里：`tests/plugin-picker-pins.test.ts`（结构）、`tests/plugin-picker-pins.e2e.test.ts`（悬停出现、钉子、就地添加与移除、确认与垃圾桶配色、舞台页、
Feed 重载、键盘、头部两个按钮的位置、市场，以及浅/深色 × 1440 / 1024 / 768 / 390 的版面审计）。
