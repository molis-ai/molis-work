## 三个方案都一样的（这批新定的做法，跟样一起确认）

1. **改动先是草稿，你采用了才生效。** 不管是你自己改、助理从对话里起草、恢复旧版，还是改一份通用技能，先成为一份草稿；AI 在采用之前用的一直是现在那一版。草稿边写边存，所以第 41 批的「离开前未保存提示条」在技能这里不再需要。第 41 批的「保存＝新版本、马上生效」改成「采用＝新版本」，步数一样（改完点一下）。
2. **从对话生成。** 你在助理里说「存成技能」，助理从刚才真实的过程里提取：固定步骤、可变参数、要问你的地方，起草成一份草稿；对话里只出现一张平台现有的结果回执（一句话加「打开草稿」）。草稿不会自己生效，也不会给 AI 任何新权限。
3. **已知答案回放。** 从对话起草的草稿自带一个「已知答案」：那次你要做的事和你改定的结果。采用前要先回放一次。回放只让模型读做法和材料、写出结果，不调任何工具，所以改不了项目里的东西、也发不出去；回放记录和真实工作分开，不进报告和效果指标。
4. **两边各试一次。** 技能给助理和 Coding 都用的，回放在两边各跑一次（用各自的角色说明）；改已有技能时，现在的版本和草稿并排跑，看谁和你的结果一致。
5. **比较。** 两种：比做法（正文一行一行的改动，用平台现有的对照部件）和比结果（回放出来的和你的结果差在哪）。
6. **采用与退回。** 「采用为第 N 版」才生效，下一次用到时用新版，进行中的那一轮不变；回放和你的结果还有出入时，就地问一次「仍然采用／回去改」，不弹窗。放弃草稿可以撤销。
7. **恢复。** 详情里列出全部版本；「恢复这一版」先开一份草稿对照现在的，采用后存成下一版（不改写历史），提示里可以撤销。
8. **改通用技能。** 随系统自带或装来的技能「改一份我的」：它记得是从哪一版改的；通用写法里的占位符（如 `~~项目管理工具`）列出来让你换成自己用的；采用时可以顺手把原来的改成关。原来的出了新版时，你的版本照旧在用，详情顶上说一声，可以看差在哪、带进草稿或先不管。

## 三个方案：改进的那一圈（改 → 回放 → 比较 → 采用）放在哪

| 方案 | 怎么排 | 取舍 |
| --- | --- | --- |
| A 详情里分页 | 草稿在技能详情那一栏里打开，上面三个页签「修改／试用／比较」，底下钉着采用条；列表一直在左边 | 和第 08、41 批的样子最一致，窄屏不用变；改一句就要切到「试用」看结果，再切回来 |
| B 左边改、右边试 | 打开草稿时列表收起，左边是表单，右边是「试用／比较」；改完就在旁边回放、看差在哪；1100 以下右栏变成页签，同 A | 一屏同时看到做法和结果，来回改最快；打开草稿时看不到别的技能（顶上有「← 技能」） |
| C 在对话里改 | 草稿、回放结果和改动都是对话里的一张卡，在输入框里说「改一下……」，卡上直接回放、采用；设置里只管版本、恢复和改通用技能 | 从对话生成那一条最顺；正文长了在卡里不好改，从设置里开始改的没有对话可依（卡上留了「在设置里改」） |

主会话推荐 **B**：这一批的核心是「改了马上看效果」，B 让做法和回放结果同屏；窄屏自动退成 A，三种宽度都成立。对话里起草仍然只出一张回执（三个方案都一样），不把长正文塞进对话。

## 怎么打开

先按[组件板实件](../component-board/README.md#生成)生成 `component-board/dist/`，再在仓库根目录运行下面的命令，打开 <http://127.0.0.1:4422/skill-improvement/>：

```sh
python3 -m http.server 4422 --bind 127.0.0.1 --directory docs/design
```

顶上一条斜纹是**原型控制**，不是产品的一部分：切方案、看哪一段（从对话生成／试用／比较／采用／恢复／改通用技能）、状态、中英文和浅深色。

## 状态

| 段 | 正常 | 有出入／有新版 | 出错 |
| --- | --- | --- | --- |
| 从对话生成 | 回执 → 草稿（自带已知答案）→ 先回放 → 采用为新技能（先关着，提示里一步设成自动） | 回放有 1 处不同，采用时就地确认 | 对话里没有能重复用的步骤：助理说明为什么，不起草 |
| 试用 | 现在的第 2 版与草稿、助理与 Coding 四格结果 | 草稿还有 1 处不同 | 没有能用的文字模型：就地说明，草稿还在，去设置模型 |
| 比较 | 比做法（第 2 版 → 草稿）、比结果（回放 → 你的结果） | 同上，结果里能看到那一处 | 草稿基于第 2 版，别处已经采用了第 3 版：先对照第 3 版，采用存成第 4 版 |
| 采用 | 采用为第 3 版，下一次用到时生效 | 就地确认「仍然采用／回去改」 | 采用失败：草稿还在，什么都没变，重试 |
| 恢复 | 版本列表 → 恢复第 1 版（先对照）→ 存成第 4 版，可撤销 | — | 恢复失败：草稿还在，重试 |
| 改通用技能 | 改一份「分析与决策」，换占位符，采用时把原来的改成关 | 原来的出了第 2 版：你的照旧在用，可看差别、带进草稿或先不管 | 占位符没换完：标出还剩几处（不挡采用） |

## 组件板新增（定下方案后补标本，交 D 轨合审）

- `im-bar`：草稿的采用条（主按钮、放弃、一句状态；还要回放时主按钮换成「先回放」）。
