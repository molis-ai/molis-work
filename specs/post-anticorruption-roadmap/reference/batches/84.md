## 给人讲清楚

（注：原稿里的「跟进 GitHub 评论、浏览器余项」已在第 [`67`](67.md) 批交付，本批不再重复。）这一批把 Coding 剩下的**会话进阶操作、命令行接入、长期记忆联通和可视化交互计划页**分 **2 个互不阻塞的独立 PR（`84-A` ∥ `84-B`）**补齐，全程以**「少弹窗、少记参数、点一下就成」**的极简体验为准：

1. **`84-A` · 会话进阶四件套、长期记忆与插件命令行接入（独立 PR 1）**：
   - **一键会话分叉（`C1`）**：点「从这里分叉」**零弹窗直接开出新分支会话**（默认不动当前工作区文件，绝不误冲未提交改动；需要连代码一起隔离时，仅在侧旁给一个轻量的「在新工作树打开」可选项），列表清晰展示分叉树关系。
   - **无打扰随口旁问（`C4`）**：主任务正在跑或做到一半时，直接在输入框敲 `/btw` 或点情境条「问一句」，借当前缓存前缀秒回只读解答，**不打断正在跑的任务、不弄脏主对话历史**；觉得答案有用可一键「带入主对话继续改」。
   - **一键脱敏导出（`C2`）与长期记忆联通（`C3`）**：整段会话（含工具调用、审查决定与成果链接）经 `70-1` 本机脱敏一键导出清爽 Markdown／HTML（不传第三方）；Coding 正式接通平台记忆（常驻记忆在开会话时冻在前缀区、每轮动态召回放后面，不打碎缓存）。
   - **免记参数的顺畅命令行（`D1`＋`D7`）**：插件在 Manifest 声明 CLI 子命令（平台通用机制，不给 Coding 开特权），终端敲 `molis-work coding run "任务"` 经本机常驻宿主单进程执行并支持 `--json-schema` 结构化输出；只读与已放行范围内一路跑通零打断，真遇到待批高风险动作时**自动按环境省心处理**——人在终端前可直接按一下键或在已打开的工作台里任一处确认（不用复制粘贴链接），若是管道／脚本非交互环境（非 TTY）自动立即返回清晰结构化待批原因退出，不挂死脚本也不用背额外参数。
2. **`84-B` · Coding 可交互实施计划页（`E7`，独立 PR 2，提前解锁第 `85` 批）**：复杂任务的实施计划直接生成为一张清楚好用的交互页（改动主张、对应代码片段展品与待拍板问题放在一起），你在页上勾一下、批注一句一键送回 Coding 开干。需要你做的：分别看会话极简操作与交互计划页的样子并定下。
