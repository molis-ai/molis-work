# 工作台分组、分屏与 Feed / 全局设置重设计

## 目标与完成等级
完成等级：功能可用，并以真实浏览器验证主要路径。保留真实数据、原有动作、项目设置独立页面；替换标签视觉、平铺分屏结构、Feed 主区目录树、全局设置卡片；忽略旧页布局约束。

## 问题证据
标签宽度 72–208px 随内容变化；分屏只有一维三栏，同插件第二栏是占位文字，边缘 drop 拆的是目标活动标签；Feed directory renderer 返回空字符串，来源任务树在主内容区；全局设置仍用旧 topbar、预览大卡片和默认展开路径。

## 场景与方案
- 顶部取消主题快捷操作，外观设置保留。
- 标签统一宽度，按插件稳定分配颜色，支持拖动排序、跨组移动、Option/Alt 复制、四边拖入分屏，键盘选择和关闭保留。
- 二叉布局树允许横纵嵌套（包括 T 型）；分隔条拖动/键盘调整、双击均分，刷新恢复。独立同源内容窗口复用现有功能客户端，隔离 UI 持久化；首次单窗使用原生内容，分屏后保留已加载窗口以避免丢失草稿。窗口关闭自动合并。窄屏只展示当前窗口，布局保留。
- Feed 左目录每个来源一个任务，含名称状态和数量；选中时右侧列表及标题同步，搜索筛选仍有效。列表提供摘要、来源、时间、阅读状态，详情采用阅读宽度与明确操作层级。来源管理仍可达。
- 全局外观、执行工具、诊断、规划库使用独立设置壳；外观紧凑设置行，Runtime 状态与接入动作优先，路径收进披露，规划浏览/详情/编辑适配。

## 边界、依赖与非目标
工作台客户端/渲染/CSS、Feed UI、设置渲染/CSS、定向测试。不改变领域数据协议；不重写 AI 执行器、不新增浏览器外浮窗。保留前轮未提交修改。独立窗口通过同源消息同步选中窗口，禁止子窗口覆盖父工作区布局。

## 验收
1. 工作台无主题按钮，设置主题仍可切换。
2. 标签等宽、组颜色不同；排序/移动/复制保持正确标签。
3. 横纵嵌套、调整尺寸、关闭合并、刷新恢复；同插件两个窗口内容均可用。
4. Feed 来源目录存在，切换时右侧只显示对应来源，标题同步；详情与原动作可达。
5. 全局设置不嵌旧壳，外观/工具/诊断/规划有适配内容，项目四页无回归。
6. 桌面、窄屏、明暗主题无主体溢出；键盘焦点、减弱动效可用。

## 验证
pnpm build；node --import tsx --test tests/tab-workspace-ops.test.ts 和针对性浏览器/Feed/设置测试；真实预览批量截图检查。最终记录通过/失败/未运行。

## 假设
自由分屏指应用主区域内嵌套编辑组；每个插件稳定颜色，无需新增用户自定义组数据模型。真实内容框架按需加载，比例和标签保存在项目本机状态。
