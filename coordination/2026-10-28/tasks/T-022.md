## 1. 背景

每个 Runtime 显示给人看的名字，合同里有一张表：`RUNTIME_DISPLAY_NAMES`（`packages/contracts/src/platform/installation-detection.ts:7-13`，从 `@molis-ai/molis-work-contracts/platform/app-host` 取）。表头注释写明，这张表就是为了让名字只有一处。

安装器没读这张表，五个名字自己又写了一遍：`apps/local-host/src/installer/runtime-config-adapters.ts` 第 9、27、45、66、87 行的 `displayName: "Codex"`、`"Claude Code"`、`"OpenCode"`、`"Pi Agent"`、`"Grok Build"`。现在两边的值逐字相同，但表里改一个名字，安装器的提示、确认按钮、接入计划还是旧名字（`runtime-integration-planner.ts` 的第 21、72、93、139、189、194、216 行都用 `adapter.displayName`）。

现成的写法：`apps/local-host/src/character-import-discovery.ts:4,13`，从同一个子入口 import 表，再按 id 取 `RUNTIME_DISPLAY_NAMES.codex`、`RUNTIME_DISPLAY_NAMES["claude-code"]`。

## 2. 目标

1. 安装器五个 adapter 的 `displayName` 都从 `RUNTIME_DISPLAY_NAMES` 取，文件里不再有这五个名字的字面量。行为不变：五个值和现在逐字相同。
2. 有一条用例钉住「安装器对外给的显示名就是表里的名字」：以后有人在表里改名、或在安装器里重新写字面量，这条用例就红（`RAC-1240`）。
3. BL-392 那一行改成只剩还没做的两处。

## 3. 不做

- 不改 `apps/workbench/src/terminal/pane.ts:25-29`：它在浏览器包里，改了会动 `/assets/` 的字节，单独做。
- 不改 `modules/shelf/src/runtimes.ts`：它的键是另一套（含不在 `SupportedRuntimeId` 里的 Runtime），而且 Shelf 还在迁移。
- 不改 `RUNTIME_DISPLAY_NAMES` 本身，不改 `SupportedRuntimeId`，不改 contracts 的导出（公开 API 快照不能变）。
- 不改 adapter 的其他字段（重启说明、可执行文件名、配置路径）。

## 5. 做法

**已定（main 上核过）**

- import 写成 `import { RUNTIME_DISPLAY_NAMES } from "@molis-ai/molis-work-contracts/platform/app-host";`。这个文件已经从同一个子入口 import `SupportedRuntimeId` 的类型（`runtime-integration-contract.ts:15-16`），不新增依赖。
- 用例只经公开入口：`tests/runtime-integration.test.ts` 已经从 `@molis-ai/molis-work-app-local-host` 取 `RuntimeIntegrationService`（第 7～13 行），表从 contracts 的子入口取。**不要** import `apps/local-host/dist/installer/...` 或 `src/...`：「测试引用包内部」这个数字按文件只许减少。

**【方案】里要回答的问题**（先在本机写出来跑一遍，结果写进去，再等批）

1. **断言放哪里**。`RuntimeIntegrationService.detect(id)` 返回的结果里有 `display_name` 吗（`runtime-integration-planner.ts:189,216` 一带）？它是在没检测到 Runtime 时也给，还是只在某几种状态下给？据此选：对 `SUPPORTED_RUNTIME_IDS` 的每一个 id 断言 `display_name === RUNTIME_DISPLAY_NAMES[id]`；或者另找一条公开路径，并说明为什么。写出用例的完整代码。
2. **先红**。现在两边的值本来就相同，新断言在 main 上也是绿的。写出你打算怎样让它红一次，证明它真的读到了安装器给的名字。例如临时把一个 adapter 的 `displayName` 改成别的字面量，看哪一条断言红、报什么；然后再改回来。
3. **`full`**。`node scripts/affected-tests.mjs --base origin/main --json` 的 `full` 和原因。预计 `false`：只改 `apps/local-host` 一个包，没有改合同导出。
