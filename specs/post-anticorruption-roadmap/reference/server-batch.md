## 服务端批（SRV）

要服务端（账号、云上存储与转发、部署、运维和费用）的需求独立成这一批，排在 01～89 之后（用户 2026-11-03 定）：个人云同步、团队协作首版、团队记忆和 M2（自动更新、在线备份、可选崩溃上报）。以后再有要服务端的需求，也加进这一批，片号接着往下编。

- **什么时候开工由你定**（[决策记录](decisions.md#section-7)第 24 项）：部署正式服务、开真实账号、承担费用都只能你办。开工前这一批不占轨道写手和机器额度，01～89 不等它；各片的前置写在表里，最早在 M1（56）发出之后。
- **合同在 M1 之后加**：Manifest 里的同步声明、同步与团队的动作和数据合同，都按[合同变更流程](../../../docs/system/CONTRACT-CHANGES.md)的过渡期加、带读取兼容，协议接受上一版客户端；不为赶 M1 提前冻结（用户 2026-11-03 定）。合同照[轨道与冲突规则](tracks.md#section-5)规则 1 排队。
- **批内顺序**：SRV-1 共同设计在前；个人同步 SRV-2 → SRV-5；团队 SRV-3 → SRV-4 → SRV-6 → SRV-7，完整团队产品建在个人同步上（SRV-6 等 SRV-5）；SRV-8 只等 M1、U6 和账号条件，和前七片互不等待。
- **轨道**：服务一侧归 G 轨（[轨道与冲突规则](tracks.md#section-5)）；插件里的同步声明按规则 4 一起落；桌面一侧（更新器、崩溃上报的客户端）在 `apps/desktop/`，由 F 落（规则 7）。
- **原编号**：原 23、48～50、73、78～80、86、87 整行移到这里，59、71、74 只移出同步、团队与 M2 那部分；[执行目录](../spec.md#execution-batches)留着编号写去处。

<a id="srv-1"></a>

## SRV-1 · 共同设计与对账

- **类型**：产品线（同步、团队）；底层与架构
- **具体交付**：**共同设计与对账**（原 23）：拿当时的 main 对一遍 `personal` 分支，列出还成立和要重写的适配；定身份、版本、三档访问、并发、撤权、离线／冲突、项目退出；定同步合同及 Outbox（BL-070），协议接受上一版客户端，明确个人主线随后同步的边界；核团队记忆的来源、用途与访问边界
- **需求来源**：[个人同步][SYNC]、[同步基础][SYNCF]、[团队协作][TEAM]、[团队记忆][TMEM]、[升级持续可用][UPG]、[主线第三片][MLN]、[BL-070][BL]
- **前置／待决**：你定开工；56（M1 已发出）、21 的使用边界；要决策：同步接入方式（[决策记录](decisions.md#section-7) 第 13 项）与协作协议
- **可并行项**：服务与账号条件核查
- **UI 要求**：先定样：同步、共享、冲突与实时协作切片

<a id="srv-2"></a>

## SRV-2 · 个人同步核心

- **类型**：产品线（同步）；底层与架构
- **具体交付**：**个人同步核心**（原 48）：先交独立服务、账号、Worker、Outbox／回执与撤权；再交附件实际字节、大对象分片／一致提交、丢回执和重启续传、冲突版本保留；随后接 Goals／待办／Pages／成果库，落实配额／保留与跨版本接入。附件未就绪不得显示全部已同步，核心成果库验收必须有字节往返
- **需求来源**：[个人同步][SYNC]、[同步基础][SYNCF]、[插件复制][SYNCP]、[升级持续可用][UPG]
- **前置／待决**：SRV-1，接入方式已定；按传输→附件／冲突→owner 接入顺序；部署与账号你办
- **可并行项**：SRV-3 的关键协作切片走查
- **UI 要求**：复用 SRV-1；账号／同步状态差异先定样

<a id="srv-3"></a>

## SRV-3 · 团队关键路径

- **类型**：产品线（团队）；底层与架构
- **具体交付**：**团队关键路径**（原 49、50）：真实成员身份、项目访问拒绝、Pages 并发合并、人与 AI 交错、撤权、断线与持久恢复；再用两个独立身份验证 Pages 同改、AI 修改、广播撤权、断网／重启和最终持久结果，明确对象覆盖缺口
- **需求来源**：[团队协作 §2.5、TCO-11～15][TEAM]
- **前置／待决**：SRV-1、SRV-2；实际身份／客户端条件具备
- **可并行项**：SRV-4 的团队交互设计准备
- **UI 要求**：先定样：共同编辑、权限变化及恢复

<a id="srv-4"></a>

## SRV-4 · 团队剩余交互与团队记忆设计定稿

- **类型**：产品线（团队）；横向能力
- **具体交付**：**团队剩余交互与团队记忆设计定稿**（原 71 的团队部分）：在共同设计与关键验证上收拢团队协作权限／同步／实时编辑的剩余覆盖与交互（共享范围、首版三档、插件／资产扩展及参考 Codex Projects 的首版实时协作已定）；定团队记忆的持续理解、价值筛选、形成／融合、管理与交接使用方案及高保真（PMO 定位、主动协作与质量改善、个人发布确认／不可撤回及管理员管理已定）
- **需求来源**：[团队协作][TEAM]、[团队记忆][TMEM]
- **前置／待决**：SRV-3；要决策：团队剩余协议与记忆策略
- **可并行项**：SRV-5 的同步证据只读盘点
- **UI 要求**：先定样：团队完整路径及团队记忆

<a id="srv-5"></a>

## SRV-5 · 个人同步完整交付

- **类型**：产品线（同步）；底层与架构
- **具体交付**：**个人同步完整交付**（原 59 的同步部分、原 73）：其余插件及个人主线的声明，逐插件列出覆盖与缺口；逐 owner 验完整历史／附件、关联删除与冲突，按原覆盖表接 Work／Coding／Workflows／Schedule 等且接收不执行；用只装公开包的独立插件验证安装、停用、注销和重新发现，不用内置名单冒充扩展能力；全插件自动／手动同步、整项目复制／回收、异常恢复、配额／保留／删除；两台真实 Mac 验跨版本客户端、主线顺序及工作接续，完成正式服务交付；验完整附件与大对象、损坏／丢回执／断点恢复、冲突双方历史及删除回收；正式环境验真实限额与负载、告警、配对数据备份、只读止损和恢复演练，和本机模拟证据分开
- **需求来源**：[个人同步][SYNC]、[插件复制][SYNCP]、[主线第三片][MLN]、[升级持续可用][UPG]
- **前置／待决**：SRV-2；主线数据在 36／37／52 就绪，跨项目视图按 63 覆盖；真实设备／账号条件具备
- **可并行项**：SRV-8 的安装与恢复说明走读
- **UI 要求**：复用 SRV-1、SRV-2；同步异常与项目生命周期差异先定样

<a id="srv-6"></a>

## SRV-6 · 团队完整产品

- **类型**：产品线（团队）；底层与架构
- **具体交付**：**团队完整产品**（原 78～80）：项目共享、成员邀请／退出、查看／编辑／管理三档、统一资源访问、项目讨论，保护未共享信息；把已验证的并发核心接到首版内容清单，成员光标／选区／在线状态、人与 AI 交错修改、任务与结果接续；在途撤权、广播、离线／重连、AI 旧版本保护、跨客户端持久结果；两名真实成员完成真实项目
- **需求来源**：[团队协作 §2～2.5、TCO-01～15][TEAM]、[身份与访问方案][IDENT]
- **前置／待决**：SRV-3、SRV-4、SRV-5；63 的相关共享消费能力
- **可并行项**：SRV-7 的团队记忆样本只读核查
- **UI 要求**：先定样：共享、邀请、权限、讨论和各类内容共同编辑差异；恢复缺口先修再验

<a id="srv-7"></a>

## SRV-7 · 团队记忆

- **类型**：产品线（团队）；横向能力
- **具体交付**：**团队记忆**（原 86、87）：必要合同、获准来源采集、价值筛选、形成／融合、来源及纠正，不复制业务事实或另建个人记忆规则；发布前确认及不可撤回说明、管理员维护、助理消费、三类交接、主动协作与质量改善验证
- **需求来源**：[团队记忆][TMEM]、[观测采集][OCL]、[Memory][MEM]、[主动助理][PAST]
- **前置／待决**：29、63、SRV-4、SRV-6；**所需 Memory 能力已具备且原暂停解除**
- **可并行项**：不依赖记忆的其他片可继续
- **UI 要求**：复用 SRV-4；形成／融合、发布与管理差异先定样

<a id="srv-8"></a>

## SRV-8 · M2

- **类型**：产品线（发布）；底层与架构
- **具体交付**：**M2**（原 74 的 M2 部分）：U6 副本演练／回退接自动更新，留各发布版金样；定时在线备份与恢复，和 72 的整份导出分开验；可选崩溃上报，沿 26／27 确认的 BL-812 本机日志边界外送，联网默认关闭且先预览字段
- **需求来源**：[C 端就绪 M2][CEND]、[升级 U2／U6][UPG]、[BL-115、BL-812][BL]
- **前置／待决**：你定开工；26、56；更新、备份与上报服务的账号条件具备；日志与上报待决已处理
- **可并行项**：与 SRV-1～SRV-7 互不等待
- **UI 要求**：先定样：更新、备份与诊断上报
