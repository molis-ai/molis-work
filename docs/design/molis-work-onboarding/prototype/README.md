# 从已有工作开始 · Molis Work

高保真可交互原型，供评审首次使用与后续项目创建的完整体验。独立于生产应用。

```sh
node docs/design/molis-work-onboarding/prototype/server.mjs
```

打开 http://127.0.0.1:4336/ 。可用 `MOLIS_ONBOARDING_DEMO_PORT` 指定其他端口。字体、Gmail/飞书标识与 Lucide 复用仓库已有资产，需要当前仓库的依赖已安装。

## 体验路径

1. 勾选来源或「全选」。行末箭头展开读取范围；全选保留范围调整。
2. 点「开始整理」。已就绪来源继续读取；Gmail/飞书模拟连接，可体验失败、重试或跳过。
3. 看总结：项目建议由实际选中且读入的演示材料组成。点击数字看原文，可改名、取消采用或先保存整理稿。
4. 建立项目，直接查看摘要、资料与下一步；可以编辑摘要，也可以主动创建目标。
5. 「新建项目」复用资料清单，或只填名称空白创建。空白项目可通过「带入材料」补充到当前项目。

右上角可切换主题或重置演示。浏览器刷新会保留原型进度，包括处理中、整理稿和已创建的演示项目。

## 模拟边界

- 所有文件、网页、邮件、聊天、连接和模型均为本地演示。不会读真实文件、浏览器历史或账号，也不发出授权请求。
- 自动总结采用预设材料与规则，展示产品应有的来源关联、范围过滤和冲突提示；没有接入真实模型。
- 项目只存于当前浏览器的原型 localStorage；不写入 Molis 的项目数据库。资料是一次导入的快照，不持续同步。
- 「文档」展示工作摘要，未实现完整文档编辑器；项目壳用于验证首次内容如何承接到正常工作。
- 原型使用固定的 2026 年 9 月 24 日及 11 份虚构材料。30 天/7 天选择会保留，但当前邮件和聊天样本都处于最近 7 天内，因此不产生数量差异。
