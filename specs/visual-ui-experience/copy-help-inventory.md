## 1. 怎么清点的

- 环境：一次性隔离 Home（`MOLIS_WORK_SECRET_BACKEND=file`，端口 4420），代码为 main `cbd019de6` 的构建，Web 版，中文界面，1440×900；模型只配了 MiniMax-M3。用仓库的测试浏览器逐个入口打开，取每页的标题、按钮、说明文字、输入框和截图。没碰真实 Home。
- 路径：走完首次使用（Welcome → 语言 → 外观 → 带入材料 → 给项目起名）后，在项目「团队例会」里打开项目首页、插件菜单里的全部入口、插件市场、侧栏六个标签、全局设置全部十四节、项目菜单、⌘K 搜索、布局与分屏、个人助理的一轮真实对话；在市场里把未添加的六个插件（Coding、Files、Git、Diff、Inbox、Feed）加进来后再逐个打开。插件创作台另走一次完整的真实创作，断点记在[创作台复现记录](../plugin-builder-upgrade/reproduction-2026-11.md)。
- 每行记录：主要对象与动作、默认说明、帮助入口、下一步、发现的问题、结论。结论用「可用」「待改（附 F 编号）」「未覆盖（附原因）」「不适用」。

- 个人助理、子代理、后台任务、Coding 会话里的操作卡与审批、Schedule 到点运行、炼金术士炼化、AI 生成题目／列／页：都要真模型与真 Agent 运行。本轮没连模型，这些只记到「缺模型时怎么说」为止。
- 通知：隔离 Home 里没有插件产生通知，要等有到点任务或外部来源时再看。
- Feed 订阅、服务连接登录：要联网和第三方账号。
- text-stats：要先有一份固定成果交给它，本轮没走「存为固定版本」后的交接。
- 删除回执与撤销：本轮只走了新建与保存；删除、归档、回收站留给第 40 批接入帮助时一起看。
- 项目设置的项目说明、记忆、项目资料三节和其余插件的设置页：要在页面里逐节点开，本轮没走到。
- 读屏实际朗读：F-17 是按可访问名查出来的，没有用读屏软件实听。
- 插件创作台、Coding 会话、市场里的安装：沿用第一轮的记录（§2.3、§2.4 与[创作台复现记录](../plugin-builder-upgrade/reproduction-2026-11.md)），本轮没有重走。
