# 首页一屏与侧栏间距

状态：已实现，等用户验收（2026-10-01）。分支 `feat/home-one-screen`。样例先在对话里画过，用户只改了一处（去掉随手记）后按它做。

## 背景目标

用户的话：首页内容尽量调整到一屏；「从这里开始」下面三个大按钮改成横向小按钮、排成一行；随手记去掉；侧栏和主区中间的间隔太大，参考 Claude 桌面端那种右侧的完整窗，四周留一点呼吸。

## 做了什么

首页（`apps/workbench/src/project-home.ts`、`scripts/client/project-home.ts`、`styles/project-home.ts`）：

- 随手记整块删掉：标记、读写 localStorage 的脚本、样式、英文词条、craft-finish 里的入场动画。已存在浏览器里的旧笔记不再读取，也不清理（本来就只在本机浏览器）。
- 空的一天：一行引导语 + 一排 32px 小按钮（图标 + 名称；原来每行的那句说明改成悬停提示）。「浏览更多工具」是第四个。其他日子：回到今天排在最前。`data-home-start`、`.home-start-action` 保持不变。
- 节奏收紧：上边距 48→32，标题下 32→20，日期条下 24→16，事件区上边距 32→24；「正在推进」卡片最小高度 296→208，标题 30→24px，插画缩到 78%。日期条每格高度不动（今天的小标签要留位置）。
- 窄页（首页宽 ≤ 1020）：回到手边的内容在日期条下面，各行并排成一行；原来 ≤ 1160 的断点把行间距也撑成 32px，改为只作用于列间距。

侧栏（`apps/workbench/src/side-panel.ts`）：

- 之前：主区与侧栏相隔 22px（主区自己的 14px 右留白 + 侧栏外 8px），侧栏右 8px、顶对齐、底却比主区高 8px，12px 圆角 + 描边。规格 AC01 写的是 8px，实际没做到。
- 现在：侧栏是桌面上的又一张纸——14px 圆角、`--sheet-shadow`、无描边；上下与主区完全对齐；右边留 `--sheet-inset`（14px）；与主区之间正好一条分栏缝（8px，与 `TAB_SASH_GUTTER` 相同）。拖动条在缝中间，只在悬停、聚焦、拖动时露出。
- 助手气泡避让侧栏的量按新的右边距算（`assistant-island.ts` 的 `sideInset()`）。

## 取舍

- 缝取 8px 而不是和外边距一样的 14px：分栏缝在整个应用里已经是 8px，侧栏是同一类东西；外边距沿用桌面一直以来的 14px，左右对称。
- 「一屏」指安静的一天不滚动；有「正在推进」和多条事件时事件列表自己滚。1280×720 的笔记本上，示例项目（一个进行中的 Goal + 两件事）比视口多约 100px。

## 验证

- 预览（干净 Home，空项目与示例项目）：1056×1044 无侧栏、侧栏打开（侧栏左缘 682，主区右缘 674，上下同为 32/968，右缘 1042）；1280×720；390 宽深色。
