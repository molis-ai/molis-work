## 怎么打开

在仓库根目录运行，然后打开 <http://127.0.0.1:4411>：

```sh
python3 -m http.server 4411 --bind 127.0.0.1 --directory docs/design/onboarding-full-journey
```

也可以直接用浏览器打开本目录的 `index.html`。顶上一条斜纹是**原型控制**，不是产品的一部分：切场景、状态、中英文和浅深色；「从头再来」清掉本页记住的进度。

## 框架：和第一次打开软件时一样

整个窗口是一个框架，三部分不动，只换里面的内容：

- **标题栏**：Molis Work 标志和「第一次使用／新建项目／为 Coding 补齐」这类位置说明；语言、外观两步有「切换主题」。
- **一张纸**：开场是左下角的大字「Molis Work」打字出来，上面一行 Amplify Ideas，左上暖光、右下冷光；之后每一步都是 Welcome 的样子——左边一个问题和回答它要的控件，右边是这一步的「景」。只有引导里有这层光。
- **常驻底栏**：左边是出口（首次「稍后再说」，项目里「返回项目」，从 Coding 来时「回到 Coding」）和步骤短线，到过的短线可以点回去改；中间一行状态（这一步在做什么、什么会被改）；右边「上一步」和主按钮，主按钮带 ↵，按回车就走。

右边的「景」随步骤换：

| 步骤 | 左边 | 右边 |
| --- | --- | --- |
| 语言、外观（仅首次） | 两三个选项 | 「你好。」；工作台缩略 |
| 目的 | 一句话的大输入框、例子、从哪里开始 | 正在成形的项目：名字、材料、模型、整理、给谁看、多久一份、谁来做、首页，随回答一格格填上 |
| 材料 | 已选份数、添加位置、读取说明 | 逐项确认：几个位置的树，点文件名看详情 |
| 模型 | 提供方与密钥，或已有的模型 | 材料（或 Coding）→ 模型的一条线，连上才亮；密钥只存钥匙串 |
| 读取与整理 | 两段进度，失败时写原因和处理方式 | 整理结果（每句带出处）；失败或稍后整理时只列已读好的材料，不显示假的摘要 |
| 补几件事 | 已经知道的（带来源、可改）、两三个问题 | 正在成形的项目，回答哪一项，哪一格闪一下 |
| 看方案 | 第一次能做成什么、采用会做哪几项 | 方案：成员、插件和连接、什么时候、首页（占位）、设置存在哪 |
| 采用 | 正在采用／结果，中途关掉会怎样 | 逐项结果 |
| 工作目录、回到 Coding（从页面进入） | 选文件夹、多给的授权 | Coding 页面缩略：缺的两项和你写的那句 |

做完以后才离开这个框架，进入项目（首页是占位）。

## 推荐走一遍

1. **首次使用**（场景默认）：开场按回车或点「开始」→ 语言（「你好。」）→ 外观 → 点一个例子 → 回车 → 材料（展开「下载」，点 Gartner PDF 看「先读前 20 页」）→ 回车 → 连模型（点「检查连接」）→ 回车开始整理 → 补几件事（选「发到团队频道」会多问一句发到哪里）→ 看方案 → 采用 → 进入项目，点「开始」看「做法已配好」和「第一期已写好」的区别。
2. **状态切到「整理失败：超时」**，走到读取与整理：已读好的材料留着，失败原因写清楚。点「缩小范围」回到材料，已替你去掉大 PDF；再继续，只说明去掉了哪份，不重读其余材料，摘要按新范围重出。另外两种失败（密钥被拒、额度或限流）给的处理方式不同。
3. **场景切到「从 Coding 的缺项进入，再回去」**：Coding 页说缺模型和工作目录，输入框里已经写好一句话；点「补齐这两项」，同一个沉浸式框架盖上来；连上模型、从资料里选工作目录并给出新增的授权；最后「回到 Coding」，那句话还在，发送按钮亮了。中途点左下「回到 Coding」也行，进度留着。
4. **场景切到「新建项目」或「给已有项目加一套做法」**：没有开场和语言、外观；出口是「返回项目」。加做法时原有资料、成员和首页都不动，项目里已有同名的「研究员」，要你选沿用还是复制一个。
5. 其余状态：大文件夹还在清点（已清点的先能用，可以停止）、方案缺一个插件（只影响哪一步，看看要什么权限）、采用时一项没成（其余已生效，只重试这一项）、关掉后重新打开（从停下的地方接着走）。

每一步都有「说明」，点开不丢输入，Esc 关闭，焦点回到按钮。

## 宽度、键盘与外观

- 1440、1024 宽度下左问右景并排；760 以下上下叠放，纸里整页滚动；底栏留出口、上一步（只剩箭头）和主按钮，状态行收起；900 以下步骤短线收起。点按目标 44px，390 宽度逐步检查过不横向溢出。1024 宽度英文时底栏状态行会省略，完整文字在提示里。
- 回车走主按钮（在输入框里也行；按钮、复选框、下拉框上回车照常）；开场打字时按任意键或点一下就打完。
- 浅色、深色都能切；系统设了「减少动态效果」时去掉所有动效，开场直接显示全名。

## 占位与模拟边界

- **项目首页是占位**：首页长什么样，要等第 03 批的「智能呈现」定样后补上（原需求 §3.10）。成员的「改」只演示入口，没有展开职责与资料范围的编辑；这一块要接第 03 批的助理路径，同样等它定样后补。
- 所有文件夹、文件、模型、摘要、成员和采用结果都是示例数据（`data.js`），用定时器模拟读取、整理和采用。没有读任何真实文件夹、没有调用模型，也没有连真实 Home。密钥输入框不保存任何内容。进度存在浏览器的 `localStorage`（`molis-proto.onboarding-full-journey.v2`），不代表产品的持久化、授权或恢复已经做好。
- `window.protoJump` 只用于截图时直接跳到某个状态，不是产品接口。
