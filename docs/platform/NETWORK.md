# Molis Work 会联网去哪里

[English](NETWORK.en.md)

Molis Work 是本地优先的工作台：你的目标、笔记和文件放在你自己的电脑上。这一页写清楚的是它**自己**向外发起的网络请求：哪些功能会联网、去哪个网站、发出去什么、有什么限制。分 14 类（第 0 类是模型，后面 13 类不是模型调用）。

你在终端面板里运行的命令、你批准后由宿主运行的命令（如 `git push`）、你自己启动的外部 Agent，以及你点击的外部链接，都是你的操作，不在本页范围内。

> 给维护者：新增任何向外的请求（`fetch`、`https.request`、子进程里的联网命令），要先在本页加一类或补进已有的类，写明主机、触发、发出去什么和限制。对照的是 2026-10-09 的 `main`。

## 一眼看完

| 类 | 功能 | 去哪里 | 发出去的 |
| --- | --- | --- | --- |
| 0 | 模型、图片、判断服务 | 你在「设置 › 模型设置」「服务连接」里配置的服务地址 | 这次要处理的材料和你的密钥（只发给你配置的那个服务） |
| 1 | 服务连接 | 你连接的第三方服务（Gmail、GitHub、Notion、飞书等） | 你的授权，以及读取你选的内容的请求 |
| 2 | 订阅源（RSS、YouTube） | 目录里的订阅源，和你填的公开 RSS 地址 | 普通的读取请求 |
| 3 | 网页搜索（AnySearch） | `api.anysearch.com` | 搜索词和要提取的网页地址 |
| 4 | 你点名的网页和链接 | 你给的网址 | 普通的读取请求，不带你的凭据 |
| 5 | 插件创作台生成的插件 | 该插件声明、你批准过的网站 | 插件自己的请求 |
| 6 | Casebook 参考客户端 | 没有产品功能在用 | — |
| 7 | 炼金术士的市场脉搏 | Toolify、观猹、GitHub | 公开页面和搜索请求；GitHub 带「服务连接」里最早添加、未断开的 GitHub 账号 |
| 8 | 本机内部 | 本机回环地址 | 不出你的电脑 |
| 9 | 创作台的构建检查 | `registry.npmjs.org` | **依赖包名和版本** |
| 10 | 主机名的公共 DNS 回退 | `dns.google`、`dns.alidns.com` | **网站名**（只在代理的假地址环境下） |
| 11 | 本机转写模型下载 | 模型托管站（一般是 Hugging Face） | 模型下载请求（约 626 MB，要你明确允许） |
| 12 | 侧栏浏览器 | 你或助理要打开的网页 | 浏览器的普通访问 |
| 13 | Feed 的研究库来源 | `github.com` | `git fetch` |

只有第 9 类和第 10 类会把一个**名字**（包名、网站名）发给与你的功能无关的第三方；它们发出去的不含你的内容。下面单独写了这三种情况。

## 会把名字告诉第三方的三种情况

1. **插件创作台的构建检查（第 9 类）**：生成的插件如果声明了运行时依赖，构建检查的「打包」一步会把依赖的**包名和版本**发给 npm 官方仓库（`registry.npmjs.org`）下载。没有声明依赖就不联网。创作台界面里写了这一句。
2. **代理的假地址环境（第 10 类，10a）**：你的电脑开了代理软件，并且查任何网址都先得到一个占位用的假地址（`198.18.0.0` 到 `198.19.255.255`）时，Molis Work 会把要连的**网站名**发给 Google（`dns.google`）和阿里云（`dns.alidns.com`）的公共域名查询服务，问真实地址。受影响的网站名是：你配置的模型、图片和判断服务，以及 AnySearch（`api.anysearch.com`，Feed 的网页搜索和炼金术士的研究都在内）。只有设置了代理环境变量（`https_proxy`、`HTTPS_PROXY`、`all_proxy`、`ALL_PROXY` 之一）并且系统返回了假地址才会这样；普通网络不会。
3. **Jelly 导入网页时的假地址环境（第 10 类，10b）**：系统给出的地址全是假地址时（不看代理变量），Jelly 读网页会把**那张网页的网站名**发给 Google 的公共域名查询服务。它比上一种更接近「你读了哪些站点」，所以单独写出来。

这三种都是为了在特殊环境里仍能工作，发出去的只有名字，没有凭据和内容；代理软件本来就能看到这些名字。

## 逐类说明

### 0. 模型、图片、判断服务

- **什么时候**：你用助理、插件里的 AI 功能、图片生成、Functions 等。
- **去哪里**：你自己在「设置 › 模型设置」或「服务连接」里配置的服务地址。Molis Work 不替你选模型厂商，没有哪个厂商的地址是默认联网的；代码里只有两处带着厂商地址：图片连接的表单里点选 OpenAI 或 Gemini 预设时预填它们的接口基址（你保存之后才会用），以及一条只给开发用的环境变量路径（设置了 `MINIMAX_API_KEY`、又没有配置任何模型供应商时，默认把 `https://api.minimaxi.com/anthropic` 当作文本模型地址；普通使用不会碰到）。判断服务（Functions）使用 `api.typesafe.ai`。
- **限制**：所有模型请求都经同一个 Home 的 Prologue 推理端口。这个端口默认拒绝一切出站，Molis Work 只放行三条：模型、外部 MCP 服务（助理和 Coding 调用你连接的 MCP 服务）、本机回环地址。派出前会复查授权和配置，被取消或撤权的调用不再发出。

### 1. 服务连接

- **什么时候**：你在「设置 › 服务连接」连接第三方账号时；之后连接器同步、读文档，或助理、Feed、成果库用到这个连接时。开新项目时如果你在项目上手里选了 Gmail 来源，Molis Work 会用这条连接直接读你最近的邮件作为上手材料（只读近 7 天或 30 天、排除垃圾邮件和已删除、至多 20 封、不读附件）。
- **去哪里**：各服务自己的主机（目录里有数十个）。可选的 OAuth 经纪服务（`auth.molis.ai`，一个 Cloudflare Worker，只有配置了才用，不在你的电脑上运行）。
- **限制**：访问令牌由连接提供，不从插件输入里读；不跟随跳转；单次请求有时限。
- **本机命令行与 MCP 子进程**：有的连接用你本机的命令行（`gh`、`hf`、`sentry`、`lark-cli` 等）登录，联网的是那条命令。飞书和 Lark 的 MCP 连接器会在你的电脑上启动一个子进程：运行的是随 Molis Work 一起安装、版本固定的 `@larksuiteoapi/lark-mcp`（不再用 `npx` 临时下载），这个子进程只拿到 App ID、App Secret、令牌、你已经设置的代理与证书变量，以及系统的 `HOME`、`PATH` 这类基本变量，拿不到你的模型密钥或其他环境变量。

### 2. 订阅源（RSS、YouTube）

- **什么时候**：Feed 手动或定时拉取来源。
- **去哪里**：目录里的现成 RSS/Atom 源、你填的公开 RSS 地址、YouTube 公共频道订阅（`www.youtube.com`）。
- **限制**：白名单传输；你填的公开地址会先解析并拒绝本机和内网地址；使用条件请求（etag、last-modified）。

### 3. 网页搜索（AnySearch）

- **什么时候**：Feed 的网页搜索来源手动或定时拉取；炼金术士的研究阶段搜索。
- **去哪里**：只有 `api.anysearch.com:443/mcp`，匿名，不带凭据。
- **限制**：到 AnySearch 的出站**只有一条实现**（`apps/local-host/src/anysearch-transport.ts`），Feed 和炼金术士共用：固定主机；解析出的地址必须是公网地址并钉住，校验证书并核对连上的对端地址；不跟随跳转；请求 64 KiB、响应 1 MiB 的上限。代理的假地址环境下的处理见上面第 10 类，Feed 的网页搜索现在和炼金术士一样在这种环境里可用。
- **发出去的**：搜索词和要提取的网页地址。

### 4. 你点名的网页和链接

- **什么时候**：材料导入读网页；Jelly 读你给的来源。
- **去哪里**：你给的 http(s) 地址。Jelly 的哔哩哔哩适配器还会去固定的 `api.bilibili.com`，并下载接口返回的字幕和音轨地址；小宇宙和小红书适配器下载页面里给出的音频、视频或图片地址（必须是公开的 https）。
- **限制**：材料导入读网页是你明确的抓取，请求不带凭据，12 秒、4 MiB、最多 5 次跳转，**不拦本机和内网地址**（包括本地页面）。Jelly 只收公网地址、逐跳复验、解析后钉住地址、只带公开页头、不带 Cookie；网页和接口 400 万字节，音视频和图片每个至多 25 MiB。

### 5. 插件创作台生成的插件

- **什么时候**：你试用或安装了创作台做出来的插件，它运行时联网。
- **去哪里**：该插件声明、你批准过的主机。
- **限制**：只许 https、默认端口、地址里没有凭据；连接实际用的每个地址都要是公网地址（代理的假地址段按正常环境放行，这是开发机的既定做法）；不跟随跳转；15 秒、响应 1 MiB、请求 256 KiB。检查与验收阶段不联网，人手试用时只读（GET、HEAD）。

### 6. Casebook 参考客户端

仓库里没有任何产品功能实例化它，只有测试用；它是给外部 Casebook 消费者的参考实现。

### 7. 炼金术士的市场脉搏

- **什么时候**：你在炼金术士里点「采集市场信号」。界面上写明了会联网访问这三个站点。
- **去哪里**：`www.toolify.ai`、`watcha.cn`（观猹）、`api.github.com`。
- **GitHub 的令牌**：用「设置 › 服务连接」里**最早添加、且未断开**的那个 GitHub 账号（令牌或 OAuth 账号；命令行登录没有存储的令牌，不算）的令牌，每次请求时读取，更换或断开立即生效。你有多个 GitHub 账号时，用的永远是最早添加的那个；市场脉搏本身不能单独指定账号；断开最早的那个（它在别处的用途也会随之断开）后，才轮到下一个未断开的。那个账号的令牌读不出来时不会改用别的账号，而是匿名访问；没有可用账号也是匿名访问，限额较低。炼金术士的市场脉搏列表上写着这条规则。不读环境变量。
- **限制**：固定主机名单，每次跳转都复验，12 秒，响应上限约 8 MB，只读公开页面和搜索接口，不发送你的内容。

### 8. 本机内部

Molis Work 的组件之间用回环地址（`127.0.0.1`）联系：动作网关、安装器对本机服务的健康检查、对侧栏浏览器和创作台预览浏览器的调试端口。不出你的电脑。

### 9. 创作台的构建检查

- **什么时候**：插件创作台的构建检查在「打包」一步，**只在生成项目声明了运行时依赖时**联网。
- **去哪里**：`https://registry.npmjs.org`，包的元数据和压缩包（压缩包地址必须同源）。
- **发出去的**：只有包名和版本（请求路径）。
- **限制**：只收精确版本或 `^x.y.z`、`~x.y.z`；20 秒；不跟随跳转；元数据和压缩包各至多 8 MiB；至多 64 个包、深度 12；SHA-512 完整性必须对得上；不执行任何包脚本，解包在禁网的沙箱里。

### 10. 主机名的公共 DNS 回退

见上面「会把名字告诉第三方的三种情况」的第 2、3 种。

- **10a（模型、图片、判断服务和 AnySearch）**：只在设置了代理变量且系统解析返回假地址时，向 `https://dns.google/resolve` 和 `https://dns.alidns.com/resolve` 查 A 和 AAAA 记录，先试上次通的那一家，传输失败才换另一家。发出去的只有网站名和记录类型；8 秒；不缓存答案；返回的每个地址仍要通过公网地址检查。
- **10b（Jelly 读网页）**：系统解析全是假地址时，向 `https://dns.google/resolve` 查 A 记录（只有 Google 一家）。发出去的只有被读网页的网站名；6 秒；答案必须是完全公开的 IPv4；缓存 60 秒；返回后仍要通过公网地址检查。

### 11. 本机转写模型下载

Jelly 导入音频或视频时，如果你明确允许下载，本机的语音转写组件会下载约 626 MB 的模型（仓库标识 `argmaxinc/whisperkit-coreml`，一般来自 Hugging Face）。没有你的允许，这个组件拒绝联网。

### 12. 侧栏浏览器

你在侧栏浏览器里输入网址，或助理在同一页上操作时，Molis Work 启动的 Chrome 系浏览器（无头、独立的用户数据目录）访问任意 http(s) 网站；输入的不是网址时会落到 `https://www.bing.com/search`。本服务自己的回环地址禁止加载；助理的每次查看和动作由 Prologue 判断，站点按你允许或屏蔽的决定执行。

### 13. Feed 的研究库来源

Feed 的「研究库」来源同步时，Molis Work 起一个 `git` 子进程，向 `https://github.com/<owner>/<repo>.git` 的 `main` 分支浅拉取（`git fetch --depth=1`）到 Molis Work 自己的缓存目录，不碰你的检出；不弹出终端提问；120 秒、输出 16 MiB；只读 `sources.json`、`catalog.json` 和每个包下的 `manifest.json`、`research.json`、`report.md`。

## 想少联网

- 不连接服务、不添加订阅源、不用网页搜索和市场脉搏，对应的类就不会发生。
- 模型请求只发给你配置的那个服务，不会发给其他厂商。
- 第 10 类只在代理的假地址环境下发生；不设置代理环境变量就不会触发 10a。
