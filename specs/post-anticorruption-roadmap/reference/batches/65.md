## 给人讲清楚

这一批把写代码（Coding）在**联网查资料、安全跑命令、自动跑检查脚本（Hooks）**上的真沙箱与权限规则彻底立起来，按 **3 个清晰的串行 PR** 稳步交付：

1. **上游 AI 底座窗口 C 双平台操作系统真沙箱与本地出站代理换包（`65-0`）**：先在上游 `molis-prologue` 落地 macOS（`sandbox-exec`）和 Linux（`bwrap`／`seccomp`）真进程沙箱、本地出站域名白名单代理（**按请求域名核验并显式兼容开发机 `198.18.0.0/15` fake-IP 代理环境，同时拦截直接写裸 IP、回环地址与私网重绑定**）以及桌面端 `"hook"` 专用通道与流式输出防卡死背压；经你确认上游提交号后完成换包、全金样与 Rust 检查。
2. **联网搜索开关 + 真沙箱命令接线、长期放行规则与「AI 低风险代批」（`65-1/2`）**：
   - 默认允许模型联网查公开技术资料（直接复用「设置 › 网页搜索」选好的默认服务，支持按项目或仅本次任务一键断网）；
   - 命令真正关进操作系统沙箱运行，已授权开发任务可在沙箱与包源域名白名单内自动下载公开依赖和所需代码分析工具（严禁越出项目目录或触碰系统全局环境与私有凭据）；常用命令经你明确同意可存为长期规则；
   - **AI 低风险自动审批默认关闭（2026-11-25 拍板）**：需你按本次任务或项目主动开启才生效，开启后只代批沙箱内单条无害开发命令，时间线上每一条都明明白白标出「AI 低风险代批（点开看理由、一键切回人工确认）」，绝不冒充你亲自批准；所有新增面板 100% 复用设计系统共用组件，严守 Coding 私有样式零字节增长。
3. **带脚本内容指纹锁的用户 Hooks 与自动化建议收口（`65-3`）**：支持 `.molis/hooks.json`（兼容 Claude Code 格式），首次启用或改动时展示差异给你确认；**同时对 `hooks.json` 和它调用的脚本文件内容做指纹锁定**（就算只改了被引用的 `.sh` 脚本也会立即停跑等你重新确认，且把钩子配置与脚本列入 AI 禁改保护名单），随时可停用、重启自动恢复；顺手收口第 `61` 批留下的 `G-09` 缺口（让自动化建议卡支持推荐项目的 Hooks 与常用检查命令）。

需要你做的：`65-0` 换包前确认一次上游 `main` 提交号；`65-1/2` 与 `65-3` 开工前看一次联网开关、命令规则／AI 代批标记与 Hooks 确认面板的轻量样稿并定下。

**`65-1/2` 与 `65-3` 的命令安全与防注入硬护栏**（[决定 57](../decisions.md#decision-57) ③ + [决定 67](../decisions.md#decision-67) ④ + 2026-11-25 拍板；全部安全拒绝同步登记 `docs/system/SECURITY-INVARIANTS.md` 并附断言拒绝本身的测试）：
