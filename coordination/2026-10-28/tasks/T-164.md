## 2. 目标

1. 上面七处，各自按下游的数法：
   - 标题、题目、问题、选项、文件名：不超过上限的原样保留，超过的取前 N 个字，不留下半个字；
   - 选项说明：取前面能放进 300 个单元的整字；
   - 填写页：回答按字数查，4000 个字以内放行，4001 个字拒。
2. 不含两单元字的文字与现在完全一样。
3. 截完的结果不超过下游的上限，所以下游照样收下：问卷的库、先问的问题的 `questionSetFlaw`、导入的动作 schema。
4. 用例钉住上面几条：任何一处改回按单元，都有一句断言（或一次抛错）红；选项说明改成「按字截到 300」，也红。

     ```ts
     /** At most `units` UTF-16 units of `text`, in whole characters: the question rules count an option's description in units, not characters. */
     function clipUnits(text: string, units: number): string {
       let kept = "", used = 0;
       for (const character of text) {
         if (used + character.length > units) break;
         kept += character;
         used += character.length;
       }
       return kept;
     ```
