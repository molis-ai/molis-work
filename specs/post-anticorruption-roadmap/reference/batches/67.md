## 给人讲清楚

这一批给写代码（Coding）补齐**「看网页与操作桌面验证界面」**和**「紧凑的 Git、PR、提交签名与 CI 检查跟进」**两套外部手眼能力，最后把 8 类真实硬任务录进评测后台做一次完整基线大考，按模块归属拆成 **3 个清晰的有序 PR** 交付：

1. **`git` 插件补齐提交签名、防提权清洗与 PR／CI／部署／评论跟进（`67-1A`）**：
   - 在 `plugins/native/git` 落地提交签名配置（GitHub API 签名或 SSH 签名，审查卡显示签名身份）、紧凑展示关联 PR 状态、当前提交的 CI 检查（新提交绝不沿用旧绿灯）、失败日志重跑与部署结果（复用平台已连 GitHub 账号，不要求另登 `gh`；Coding 可选调用，移除 Git 插件或普通非 Git 文件夹下优雅降级）；
   - **锁死 PR 安全红线（2026-11-25 拍板）**：读取项目配置（`.molis/`、`AGENTS.md`、`.mcp.json`、钩子等）强制只认受信任的 **base 分支**，绝不让外部 PR 分支自带的配置提权；PR 正文、评论与日志一律清洗 HTML 注释、零宽不可见字符与隐藏属性；且**默认只有「你当前连接的本人 GitHub 账号」明确发起的委托，或你在 Molis 界面亲手点击某条评论的「去修复」，才触发本机 Coding 执行**——其他任何人的 PR 评论一律只展示为待读卡片，绝不自动遥控你的电脑改代码或跑命令。
2. **Coding 接通桌面操控与共用右栏浏览器验证界面（`67-1B`）**：解除真实目录 Coding 会话挂接桌面与浏览器的旧限制，共用右侧栏同一个浏览器（共享网站拦截黑名单、你接手与交还、密码框拒截屏保护；助理和 Coding 同时要用时清晰排队提示），让模型改完网页样式能自己打开本地页面点按截屏验收；同步让桌面窗口 OCR 对齐 `112-1` 的中 / 英 / 日（`ja-JP`）识别并用统一的不可信围栏包裹（去掉硬编码中文拼接）。
3. **8 类真实完整任务大考基线录入「设置 › 评测」（`67-2`）**：把 `R12` 八大真实端到端任务（目录选择修复、跨文件改码与测试、长会话纠正与摘要、助理接续 Coding、改 UI 并开浏览器验证、断线重启恢复、跟进 PR 检查与评论、创作台生成并安装持久化插件）注册进第 `63-2` 批的评测服务与「设置 › 评测」实验记忆账本（供第 `86` 批效率实验同条件对比，不再另起孤立脚本）。

需要你做的：开工前看一次紧凑 PR／CI／签名与评论面板、桌面与右栏浏览器排队过程展示的轻量样稿并定下。
