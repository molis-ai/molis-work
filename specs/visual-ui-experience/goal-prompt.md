# Goal Prompt

让 Molis Work 在 `specs/visual-ui-experience/spec.md` 约定的完整范围内，达到“内部完整”的视觉、交互与性能体验：保留现有色彩、工作台结构和业务能力，让文字更耐读、信息更清楚、操作更跟手，长内容和持续使用仍然顺畅。

阅读区舒展，目录和工具区紧凑；明暗字重、换行、图标、控件和边界协调。新回答自然显现且不拖慢输出，拖拽、吸附、分屏、折叠和浮层衔接准确，快速操作、取消与中断后状态仍正确。

个人助理清楚呈现工作环境、上下文、连接、产出、变更和后台任务，兼顾编程与非编程场景。草稿待提交、本次执行与历史引用不混淆，状态、权限和用量真实，重要问题可见，来源和结果可打开。

阅读与输入始终由用户掌控：不抢滚动、焦点或选区，不丢草稿、附件和引用；输入法、建议、发送、停止、重试与恢复可靠。附件部分失败不被隐藏，正文、Markdown、图片、代码和 Diff 保持原始内容与定位准确，复制完整，失败可恢复且不重复副作用。

当前可复现的 UI 性能瓶颈得到解决，首次反馈、实际可操作和完成耗时均有可比较证据；长会话、持续输出、多分屏与反复开关不产生明显卡顿、无谓请求或资源持续累积，新增视觉效果不造成明显退化。

这些结果在浏览器与 macOS 产品、所支持语言、明暗模式、窄分屏、缩放、字体后备、键盘、触控和减少动态效果下成立。真实工作台、现存插件、生成插件与组件板保持一致，开发规范和 Builder 能持续产出同等质量。

完成意味着约定范围有可操作成果、逐项验收与性能前后对照；工程通过、真实场景通过和本人验收分别清楚，任何未完成或未验证部分明确呈现。局部切片、演示效果或静态截图不等于整个目标完成。
