## 选定的样子（四块都是 A）

### 首页：一页简报

一张 Frame 从上读到下：各来源的状态、现在怎么样（助理写的句子）、要你处理的、和上次比、下一步。

状态：正常；没装 Work Brief 时的基础首页（每个插件一张组件板卡片，插件自己给的概览与继续入口，不用模型，不生成简报）；新项目还没有内容（组件板空状态，与读取失败分开）；一个来源读不到；定时简报没被授权读待办；后台刷新中（不清空画面）；综合首页没打开（退回基础首页，工作不丢）。

### 版本：版本条 + 当时／现在

标题旁一个版本按钮，点开是弹出层里的版本列表；看旧版本时，提示里一个切换组切「当时／现在」，变了的句子下面标出现在的样子。

状态：看当前版本；看已分享的旧版本（固定不变，可回当前）；再生成和你的修改冲突（两张预览卡对照，保留我的／用新的／合并后再改，人工修改不被覆盖）；刷新后有变化（只报变化，旧版不动）；旧版本的依据已取不到（保留当时文字，不用现在的内容替代）；第一份，没有历史。

### 来源：句后角标

每句话后面带小编号，点开是弹出层里的预览卡：来自哪个插件的哪一条、截至何时；页尾一条依据说明读了几个、缺什么。各来源的状态用徽标，读不到／未授权／过期用状态标。

状态：正常；来源过期（标出数据时点）；来源读不到（那一句换成缺口说明，其他照常）；没有读取授权（对应第 18 批的按任务授权，给「去勾选授权」）；你口述的数字（标「你口述的，未核对」，不冒充读取）。

### 下一步：选项卡片

每个下一步一张组件板操作卡（`renderInteractionOperation`）：对谁做、为什么、一个真实动作（原插件的）或交给助理，另有「暂不」；下面一个输入框写自己的下一步。

状态：正常；对象已变、选项失效（按新状态重新准备，旧按钮不能点）；交给助理、进行中；部分完成（一项完成、一项失败可重试）；授权已撤回（这一项不能做）；都处理过了（完成的成回执，暂不的可撤回）。

## 组件板新增（交 D 轨补标本）

| 部件 | 原型里的写法 | 为什么要 |
| --- | --- | --- |
| 插件色标 | `[data-hue]` 给 `mw-mark` 与插件名前的图标着 `--hue-*` | 一页里有六个插件的来源，靠颜色分得开；组件板的 `mw-mark` 只有一种颜色 |
| 句后角标 | `.wb-fn`（点开是组件板的 Popover + Preview Card） | 来源方案 A 的核心：句子后面的小编号；组件板没有行内引用标记 |
| 提示里的恢复按钮 | `.wb-alert-actions`（`mw-alert` 正文下一排 `mw-btn`） | 来源读不到、未授权、冲突都要在提示里直接给「重试」「去勾选授权」；组件板的 Alert 标本没有操作区 |

窄屏下 `mw-items` 撑出容器的缺陷见[组件板实件](../component-board/README.md#已知的组件板缺陷)。

## 对第 15 批公共呈现的假设

第 15 批的公共呈现（卡片、名片、来源状态的公共组件）还没定样，本原型按下面的假设画，15 批定样后以它为准：

- 对象名片沿用 03「插件领头」：插件色标图标在前，名字在后；点开走统一的打开与定位。下一步卡片里，插件写在操作卡的「对谁做」一行，不另画色块。
- 待办、Coding、风险、日程的插件颜色是暂定的（从组件板 `--hue-*` 里挑），以第 15 批定的为准。
- 来源状态共用一套词：正常／注意／要处理／无数据，以及读不到／未授权／过期／口述；读不到与未授权用虚线，不显示成 0 或「正常」。
- 状态环已用组件板的状态标（`status-ring-system`）。
- 页面上的一句话（撰写块）和引用对象（引用块）分开：句子由助理写，名片的字由事实主人给（设计稿 §5）。

## 模拟边界

- 数据是编的（`data.js`），不读任何 Home；项目、人、数字都是示例。
- 刷新、改版本、处理冲突、执行下一步、勾选并交给助理只改本页内存，刷新页面或「重置」就回到初始；不调模型，也不调真实动作。
- 对象名片、「去勾选授权」「重试」「继续」等只弹一句提示，不真的打开。
- 红黄绿是写死的样例，不是计算出来的；「定时简报」的授权只是文字，不连第 18 批的授权数据。
