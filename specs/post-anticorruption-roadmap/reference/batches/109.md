这一批完成最后一批插件的统一分区收口并彻底消灭全仓所有「双实例」和「两套平行装配」：① Goals、Coding、Risk、Schedule、Inbox、Feed、Work Brief 等主库插件全部删掉业务表里多余的 `project_id` 列；② Feed 的证据引用账本迁入平台 `horizontal/evidence`、Work Brief 个人简报改读总览索引，全仓再没有任何双实例插件（Shelf 已在 `44B` 收归纯平台），旧 `HomePluginHost` 平行装配代码彻底删除；③ 按 **D6=B** 把宿主里约 1,400 行 `workspace-git*.ts` 连同 `projects.workspace.writers.*` 一起迁进 `plugins/native/git`，Coding 声明 Git 为随启用依赖（V9，可单独移除、先提示，V10），Diff 声明可选依赖，无 Git 时优雅降级，审查种类彻底开放申报；④ 第三方签名沙箱包开放 `databases.partition` 并删掉沙箱 `homeDatabase` 与 `--scope home`。

需要你做的：复核受限 argv-only VCS 执行边界 `S-git-plugin-command-scope` 的拒绝测试，其余按[决定 66](../decisions.md#decision-66)直接实施。
