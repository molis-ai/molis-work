# 已批准视觉迁回正式运行时

2026-09-23，独立设计交接；只读对照三张图片与实现。视觉权威是 `../../ui/design/approved-comp.png`；V3 是已完成的可交互译稿，不能用正式版 `screenshots/desktop.png` 重新定义风格。本文不是工程或真实模型验收。

## 判断与失真原因

批准图是「左侧连续设计对话 + 右侧正在被装配的真实作品」。V3 已保留摄影卡片、双指针、三方案缩略图、底部零件池。正式稿却把它变成「消息记录 + 全展开表单 + 表格」，候选确认后消失，零件池退成页脚文字，功能完成后只留下每段的“已连接”。因此外框比例即便接近，视觉与手感仍明显不同。

现实现 `styles.ts` 中 `--pb-panel:var(--paper,...)` 同时供侧栏、画布、控件使用，批准稿暖灰地面、近白侧栏、纯白画布的层级被宿主变量吞掉；统一 button/input 规则又抹掉了圆形发送键、弱操作、分段切换和零件按钮的差别。`client.ts` 把候选限制在 `phase==='choosing'`，蓝框也没有对齐正在装配的节点；指针目标只有最后一个节点/固定表单，不能说明各自正在做什么。

## 候选与右侧素材卡片

三候选必须是真实内容缩略图：阅读用图文行、整理用表格、灵感用摄影卡片，不再用字段标签矩形代替缩略页面。选中使用 1.5px 蓝线、右上蓝色圆勾，下面只放短名称；说明进入 hover/辅助描述。确认后候选与选中状态保留，成为当前方向与局部换布局的可见入口；切换不能丢失记录和功能绑定。

复刻批准稿的验收场景应使用灵感/素材库；库存场景适合验证通用能力，却不能作为摄影素材库的视觉等价证据。正式插件若为库存，不强行塞摄影封面；但素材类型必须有正式渲染分支，让已有受控字段绑定到封面、标题、摘要、标签、来源/日期与操作，而不是一律渲染 `dl` 字段列表。

素材卡片区直接继承 `material-preview.css`：三列 `1.18fr 1fr 1.04fr`，列隙16px、行隙18px；首张高卡占左列，第二行湖景放中列、右列为虚线添加位。首张封面宽高比约1.49，普通约2，湖景约2.5。卡片7px圆角、`#e9e9ed`细边；标题16px/550、摘要13px、标签10px浅灰、底部来源/日期和更多动作。搜索/分类/排序在同一行；“收集灵感”是标题区主按钮，录入表单由它打开，不能默认在内容顶部摊成数行输入框。

可复用 `../../ui/assets/inspiration-atlas.png` 的生成示例封面及现有裁切；标明示例。摄影需要成为每张真实卡片的一部分，不得将整张批准图当页面背景，也不能给用户实际记录随机匹配风景。新记录没封面时用明确无图卡样式。

## 指针与逐步装配

1. 保留两只具名指针：蓝 UI Agent、绿 功能 Agent；箭头约23×29px，名字色签约11px，下方动作白标签约10px。箭头尖必须定位真实 DOM 的当前目标；滚动、尺寸变化后重算，目标离开视口就隐藏，不能钉在静态百分比位置。
2. UI 角色实际提交合法节点时，让指针先抵达放置区；短虚线占位/目标区域提示后出现节点，再显示蓝色1px选中轮廓及四角小方点。V3 750ms 指针移动、轻微4px入场可作为手感参照，不为动画人为拖慢后端。
3. 功能角色定位真实按钮/搜索等行为目标，只在对应能力校验并接通后变绿。批准图里保存按钮内的绿勾及邻近“保存已接通”就是准确范式；禁止整页每一段永久挂“已连接”。
4. 左栏角色当前动作、画布蓝框、底部所选零件必须指向同一节点/同一修订。当前 demo 固定 tick/定时器只作动画参考，正式版状态必须来源于真实工作流事件，不能重放虚构 Agent 完成过程。
5. 暂停保留画布与当前状态，继续从该处恢复；试用隐藏指针/轮廓/零件池并将事件交给真实插件控件。减少动态效果设置下取消位移动画，但保留步骤与接通状态。

## 本轮必须看见的验收证据

在同一个素材需求、同一视口下比较批准图和正式页面：构建中截图必须同时看见三候选、白画布摄影卡片、两个分工明确的角色、当前蓝框与底部零件池；完成截图展示完整作品，试用截图展示真实内容保存后的结果。另录一段从候选确认到节点装配的短操作过程，验证移动目标、节点出现、接通标记与真实状态一致。

实际点击至少覆盖：候选切换→确认→暂停/继续→选中卡片/换布局→试用新增/搜索/筛选→独立插件打开；选中/编辑不丢焦点或输入。窄屏只显示当前主面板，对话可返回、浮动工具不挡控件、作品内部滚动可用。现有测试通过只能证明对应功能，不能替代上述视觉与过程证据。
