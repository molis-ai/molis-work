# Molis Work · 柔和层次与动态引导高保真原型

目标完成程度：可交互原型。用户要求以当前系统的项目首页和代表性插件重新设计，验证字体、布局、容器、控件、微交互、动效和层次感；Onboarding 复刻其提供的 Orvia Mail 视频的视觉与交互表达。本轮交付独立原型，不替换生产页面。

## 依据、方向与范围

参考：https://www.xiaohongshu.com/explore/6ab91c4c000000000200c061 。已观看语言、外观、云 AI、通知、已读折叠和完成等步骤。特点为横向单窗、左侧问题与选项、右侧动态小型产品预览、底部短线进度与右侧继续按钮，暖冷柔光、石墨选中态、柔软阴影。视频字体名称未获确认；原型使用 macOS 原生系统字体及苹方，Inter 作为跨平台后备，明确标题 600、标签 500、正文 400，不继承生产全局 400 强制规则。

产品事实来自 PRODUCT.md、project-home.ts、Onboarding renderer、Design System README 和现有插件约定。保留项目范围、目标完成要求与事件、信息流原始内容与保存资料。原有 Nordic 原型及其他未提交文件均保留。以用户指定的视频作为视觉方向，不另做随机风格评选。

用户补充的结构约束：保持现有底部统一对话栏和菜单栏，撤销原型自行引入的左侧全局导航。依据 `renderWorkbenchBar`，左侧放菜单及常驻插件，中间为插件切换与统一 Assistant 输入，右侧为对话和项目偏好；插件目录仍属于内容区。Onboarding 外观预览和完成后的首页沿用相同底栏。统一对话提供标注清楚的本地脚本演示、当前页面上下文和跨插件草稿保留，不调用模型。

- 项目首页：日期切换、当前工作、当天事件、可展开的事件详情、快捷入口与本地随手记。
- 目标插件：列表筛选与选中、目标详情、完成要求、进展时间线、记录进展表单与保存反馈。普通记录不自动完成目标。
- 信息流插件：搜索、未读/已保存筛选、文章选择、长文阅读、保存/撤销保存、来源信息和更多菜单。
- Onboarding：语言、外观、项目、Runtime、AI 使用边界、通知、密度、完成。复刻视觉骨架与动态语法，业务文案适配 Molis Work；允许上一步、跳过可选步骤、重新体验，保存选择并进入项目首页。选项即时联动右侧预览。AI、Runtime 连接及通知只作预览，不调用系统权限、不写配置、不发送数据。

## 方案与边界

独立 `docs/design/soft-workbench/`，使用 HTML/CSS/JS 和只读 loopback Node 静态服务；复用现有 Lucide sprite 和本地 Inter 文件，无新增依赖、无远端业务请求。数据为精心编写的示例，页面持续标注设计预览。可编辑内容与偏好只存原型专属 localStorage，具备重置入口；不访问生产 DB。

布局由低对比背景、连续白色内容面、按需浮层构成；阴影仅标识抬升，减少重复外框。Onboarding 按原片使用局部暖冷柔光。按钮按压、导航滑块、详情进出、保存反馈和引导转场遵循统一节奏；减少动态效果偏好关闭非必要位移和循环。

允许新增路径仅为本 spec、原型目录和 `.impeccable/review/soft-workbench/` 验证产物。不改根 DESIGN.md、生产 UI、安装/接入、现有原型或其他任务成果。

## 验收与验证

1. 首页、目标、信息流和完整 Onboarding 均可直接访问并相互导航。
2. 日期/筛选/搜索/选中、菜单键盘关闭、进展保存、文章收藏、本地草稿和刷新恢复走真实原型逻辑。
3. Onboarding 每一步有动态可见预览，上下步保留选择，外观与密度实际影响原型；完成后进入首页；可从导航重新体验。
4. 1440×1000 桌面、用户实际浏览器宽度、390×844 窄屏可读且无横向溢出；关键控件可用键盘操作，有焦点，状态不只依赖颜色。
5. 验证 Node 语法、服务返回、浏览器实际主链路、控制台错误和关键截图。截图与操作覆盖支持原型交付，不代表生产集成、真实 AI 接通或用户审美验收。
6. 首页和插件共享底部菜单及对话栏，无左侧全局导航；底栏不遮挡内容。菜单向上展开，插件切换更新输入上下文，统一草稿在切换和刷新后保留；窄屏入口仍可操作。

命令：`node --check docs/design/soft-workbench/app.js`、`node --check docs/design/soft-workbench/onboarding.js`、`node docs/design/soft-workbench/server.mjs`。验证结论写原型 `verification.md`。

当前假设：复刻的是视频的设计与交互，邮件业务步骤替换为 Molis Work 配置；代表性插件选目标和信息流。用户没有要求发布或生产替换。
