## 怎么打开

在仓库根目录运行，然后打开 <http://127.0.0.1:4417>：

```sh
python3 -m http.server 4417 --bind 127.0.0.1 --directory docs/design/risk-plugin
```

也可以直接用浏览器打开本目录的 `index.html`。顶上一条斜纹是**原型控制**，不是产品的一部分：切区域（风险记录、总览、复查）、方案（A/B/C）、状态、中英文和浅深色；「重置」清掉本页记住的选择（`localStorage` 键 `molis-proto.risk-plugin.v1`）。宽度 1440、1024、390 都能看。

## 三块，各三个方案

### 风险记录（总览、Goal、会话、简报打开的都是这一条）

| 方案 | 样子 |
| --- | --- |
| A 整页文档 | 一栏从上读到下：标题、四格要点（状态、影响、可能性、负责人）、说明、处置、关联、复查、进展，每段一个容器 |
| B 两栏 · 要点在右 | 左边说明、处置、进展；右边要点面板：状态、影响 × 可能性小格、负责人、关联、复查。和 03 定的「主人领头」一致 |
| C 侧栏打开 | 从 Goal 的顾虑（引用这条风险）等处点开时，在右侧打开，原页面留在左边；可展开成整页（A 或 B） |

状态：正常；没关联 Goal（风险可以单独存在）；记一条新风险；关联对象已删除或无权查看；保存时别人刚改过（两边对照，不覆盖）；已关闭（只读，可重新打开，不再复查）；只能查看（没有修改授权）；读不到这条风险。

### 项目风险总览

| 方案 | 样子 |
| --- | --- |
| A 按状态分组 | 一行筛选（未关闭／全部／已关闭、影响、负责人、关联 Goal），下面按 打开／缓解中／已接受 分组 |
| B 影响 × 可能性 + 列表 | 左边 3 × 3 小格看分布，点一格筛出那一格；右边按严重程度排的列表 |
| C 按 Goal 分组 + 右侧详情 | 左边按关联的 Goal 分组，「没关联 Goal」一组放最前；右边直接看选中那条 |

状态：正常；只看没关联 Goal 的；含已关闭；筛选没有结果；部分关联读不到（只标那一项，风险照常显示）；还没有风险；读取失败（写明「不代表没有风险」，不显示成 0 条）。

### 复查（安排、到期结果、并进简报）

| 方案 | 样子 |
| --- | --- |
| A 详情里的复查段 | 风险详情里单独一段：下次时间、要看什么、改期／暂停／取消，下面是历次结果 |
| B 复查进时间线 | 下次复查钉在进展时间线顶上；每次结果是时间线里的一条，和改状态、改处置排在一起 |
| C 总览里的复查清单 | 总览多一个「复查」视图，按 要你看／已安排／最近完成 排；详情只留一行下次时间 |

三个方案右边都是 Work Brief 的风险段（简报归 Work Brief，这里只画风险这一段）：已登记风险用风险名片，可打开同一条详情和项目总览；从别处看出的「潜在 · 未登记」风险单独标出，只给「登记为风险」按钮，不自动登记。

状态：已安排、上次无事；没安排复查（不强制每条都排）；到期有变化要你定（给建议，你采纳才改处置；按通知设置只提醒一次）；到期没有变化（安静，只留一行）；复查没完成（写明读不到什么，不当成「没有变化」）；已暂停；风险已关闭、复查停止；简报是旧版本（标出当时与现在的状态，给「刷新简报」）；简报读不到风险来源（只这一段标缺口，其他段照常）。

## 模拟边界

- 数据是编的（`data.js`），不读任何 Home；人名、项目、Goal 都是示例。
- 改状态、改处置、安排／改期／暂停／取消复查、记新风险只改本页内存里的数据，刷新或「重置」就回到初始；不经真实动作，也没有授权检查。
- 关联对象名片、「展开成整页」「关联 Goal」「去设置里看授权」「重试」只弹一句提示，不真的打开。
- 复查结果、简报文字是写死的样例，不调模型；日程是「经日程」的文字，不真的排程。
- 状态环、按钮、输入框是原型画法，进产品时用 `mw-*` 组件和 `status-ring-system` 的状态环。
