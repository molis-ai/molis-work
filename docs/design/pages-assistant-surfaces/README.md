# Pages 与个人助理：可交互切片

这是参考原型，目标为可交互高保真切片。规范沿用 [DESIGN.md](../../../DESIGN.md)，唯一需求来源是 [统一 spec](../../../specs/pages-assistant-surfaces/spec.md)。生产接线与验收进度见规格第 8 节；本目录仍是独立模拟原型，不会连接真实 Home。

在本工作树根目录运行：

```sh
python3 -m http.server 4349 --bind 127.0.0.1 --directory docs/design/pages-assistant-surfaces
```

然后打开 [本地切片](http://127.0.0.1:4349)。也可直接在浏览器打开本目录的 [index.html](index.html)，无需构建或安装依赖。

## 推荐体验路径

1. 点击正文里「十分钟」的评论标记，在右侧输入问题；点击「@个人助理」，再发送。个人助理约 2.6 秒后在同一条评论里给出预设回复。
2. 回复过程中切到「访谈观察」，再回来；检查回复仍在原线程。普通评论只追加自己的消息，不调用模拟助理。「回复这条」可以回应具体消息。
3. 选中正文任意文字，点击出现的「评论所选内容」；也可用正文上方的「评论」建立全文评论。引用快照保留；任意选区的精确编辑器锚点映射尚未实现，点击此类引用会明确提示。
4. 在右侧「备注」修改示例备注，然后切换文档并返回。草稿与备注保存在独立浏览器 localStorage。
5. 点击底部助理入口，输入一段草稿，再用右上角展开按钮进入主区。切换 Pages 标签、回到助理、收回底部；同一输入与对话实例持续保留。关闭标签不清除历史。
6. 点窗口右上角的切片设置，勾选「下一次评论 AI 回复模拟失败」，从评论召唤助理。原处重试不重复追加用户请求；也可在回复中点停止。刷新时未完成的评论请求标为中断，需明确重试；设置内可重置本切片的示例与草稿。
7. 切换到常驻讨论或 Shelf 后，再切换 Page，常驻内容不被抢走。收起侧栏后切换文档不会自行展开。

## 键盘与外观

- ⌘/Ctrl + J 打开或聚焦助理；⌘/Ctrl + Enter 提交当前输入，中文输入法组合中不提交。
- Escape 关闭切片说明或底部助理浮层；各按钮支持 Tab 与可见焦点。
- 侧栏分隔条支持拖拽，获得焦点后按左右箭头调宽。
- 右上角切换浅深色；760px 以下侧栏变为下方 sheet；遵循减少动态效果设置。

## 模拟边界

两篇正文只读，所有作者、材料和消息为示例。AI 是本地定时器与预设文字，没有调用模型、联网读材料、接入真实项目或修改正文。localStorage 只属于 `molis-review.pages-assistant-surfaces.v1`，不代表生产持久化、安全隔离、幂等或重启恢复已完成。模拟失败仅应用于下一次评论 AI 请求。

此切片没有实现生产全部侧栏工具、多人协作、助理工具调用/审查、ProseMirror 锚点映射、真实存储与权限、运行投递恢复；也没有把评论工作自动混进全局会话。生产合同与实现顺序见 spec。

图标是现有 Molis design-system（Lucide）sprite 的静态子集，浅深色/字体/边距遵循现有 Soft Workbench。没有引入第三方前端依赖。验证结果统一记录在 spec §7。
