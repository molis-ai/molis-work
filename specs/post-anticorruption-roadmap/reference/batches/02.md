## 给人讲清楚

防腐整理留下几类收尾：零散的待办和风险散在几个地方，有的没人负责；几份共用的基础代码有重复，版本号也各自涨过、没有统一；以后升级要从哪个版本算起也还没定下来。这一批把它们收干净：每件遗留的事都有主人、只记在一个地方，共用代码各留一份，所有版本回到同一个起点，并写好「从此以后改结构要怎样升级」的规则。做完之后，后面每一批都在一个干净、统一的起点上开工。需要你做的：真实 Home 的清空重建要等你说开始（旧 Home 整个搬开、不删）；版本号回到 0.1.0 之前，要先在 GitHub 上删掉旧的发布和标签，这一步只能你来；对外的许可说法和几条还没定的检查规则也要你定。

### 公共合同复位 · 开工前检查

这片把当前插件格式定为第 1 版。安装级和单条记录级连接账号仍是两个不同操作，调用方能从名字区分，动作名字里不再另写版本。在插件作者示例、已安装插件校验、工作流程绑定和 MCP 名称上核同一个结果。

原合同由 contracts 声明，解析只用 SDK，Runtime、CLI、工作台和各插件消费同一现行形状。按开发流程 §4 第 1～6、8～9、14 项核对：改声明和公开快照，同时更新全部消费者；安装身份、按项目和记录的权限、回执及否定用例要保留。第 7、10～13 项沿现行机制，本片不引入存储迁移、模型调用、成果类型、界面或错误种类。N39 只收经写入方证明总会写的字段，有真实可选场景的沿用原形状。门禁继续拒绝错误的版本与不合法声明。以两个动作快照比对前后的能力、输入输出和受众，按安装／按记录的拒绝路径分开跑；核实际安装、发现与调用。真实 Home 固定引用清理由第 ③ 项在维护窗口办理。

N39 已核到当前的真实可选场景：子任务的索引写入（`prologue-run.ts`）可不写顶层工作区模式，冻结意图仍带授权目录；Agent 输入只有 SDK 提供接收时间才落时间；无场景的判断不带场景来源，只提供文本的变更不带 Git 元数据。这些字段保留可选，Memory 沿原暂停决定。

**N29 补核（2026-11-04）。** 除 Agent 动作外，宿主动作快照还有 11 个工作区、Git、写入者和运行时动作在名字末尾带 `.v1`。正式宿主传入 `workspacesFor` 时还登记 4 个：已授权目录、设置中的目录列表，以及浏览目录的读取和选择。15 个动作一起去掉名字里的版本，均以独立的 `version: 1` 注册；插件声明、文档和 MCP 工具随之更新。验收在有目录服务的项目里查新名、拒绝旧名，并核快照其它列及各入口的调用结果。创作台的历史录制保留设计者当时看到的目录。

从产品登记生成并对照了 586 个清单动作、364 个宿主动作，三项消费场景原样保留。安装槽用 `connectors.plugin_slot.read/bind`，记录槽用 `connectors.plugin_slot.record.read/bind`，授权范围仍分别是 Home 与项目。公开快照按源码重新生成；工作区、作者和 Git 动作沿原项目合同登记，不占用 05 的 `contracts/modules/functions`。

**N26 回归补核（2026-11-04）。** R2 消费者的扩大回归发现，部分 MCP、助理脚本与目录断言仍沿用复位前的动作版本；Pages、Images 等少数用例还把现行与退役版本写成了同一个值。本合同片同步修正这些测试调用：正向调用固定使用现行 `@1`，明确检查旧 `@2`／`@3` 不可用。签名正文读取仍须实际进入读取后的撤权屏障，提示注入用例仍须取得不可信正文后验证越权拒绝；不以动作缺失代替安全拒绝。正文格式、权限、对象归属、幂等和持久化断言保留。首轮失败保留，修复后逐文件复验，不能据修改预期直接记为通过。

### 统一起点 · 开工前检查

U0 把两个日期分开。**U0-01** 真实 Home 经验证重建到第 1 版之日是库与带版本文件开始逐版升级之日，日期和构建由维护者实际填写。**U0-02** 第一个装到开发机之外的版本是公开动作、清单与宿主 API 开始过渡期的版本。在此之前原版本改形状，快照照常指出变化，固定引用按现行合同校验。**U0-03** N41 随复位与重建生效，检测登记动作、清单、提示词、角色和项目自有版本常量；N4 与 N30～34 随维护窗口执行，验收依据来自各主人真实登记与拒绝用例。

**窗口前实测（2026-11-04）。** 在公共合同候选 `11c18d736` 上，通过临时 Home 读取真实登记。动作和清单已经是 1。版本检测仍拒绝 45 项：29 个提示词、12 个角色、3 个子角色，以及 Memory 的规则常量。比如 `assistant-base` 为 31、`coding-base` 为 14、`MEMORY_GATE_VERSION` 为 3。这些值在 N31／N32 的维护窗口复位，届时须在窗口构建上重跑 `node scripts/gates/initial-versions.mjs`。这份报告不能填写真实 Home 的重建日期。

本片按开发流程 §4 核对，合同变更规则归 CONTRACT-CHANGES，数据库与文件归各自主人；统一起点是否到达只读发布检查单的实操记录。快照提示文字不改变判断与授权。维护窗口、回退和旧标签按第 3 项排期，升级实现和金样回放在第 05 批。
