# Connector 真实图标与全部官方方式接入

目标等级：功能可用。用户明确要求目录中列出的 CLI、MCP、OAuth、Key 等方式在 Molis Work 内实际接入，不能止于官方文档链接。所有当前 Connector 均需真实、居中、有留白的图标。真实第三方账号的最终验收取决于用户授权、应用配置和服务商资格，工程与协议验证不能替代真实账号验证。

现状证据：约 45 个服务目录已有官方方式清单，大部分标为 external；现有 GitHub Device Flow、Gmail/Notion OAuth、飞书 CLI 与通用令牌库。32px 容器中 SVG 同为 32px，部分品牌图标为手工替代图形。命名连接没有自己的验证入口；旧 whoami 路由只读取旧固定凭据。

范围：替换失真品牌图形，统一容器与安全区；核对全部方式的官方来源与限制；补齐 API OAuth、官方 CLI 和 MCP 的本机连接、验证与实际读取/工具发现调用路径。API 凭据继续用于现有 Feed；CLI 与 MCP 保留各自原生能力，不把协议不同的数据伪造成 Feed。每条连接独立管理凭据、配置、刷新和断开，命名连接按 ID 验证。修复复验发现的相关鉴权及状态断链。保留工作区已有修改和全部用户连接，不运行未授权的第三方写入。

方案：现有 Home 连接库与 SecretStore 继续作为唯一来源。Catalog 保存有证据的官方协议配置；Host 实现 OAuth 授权码/PKCE、刷新和提供商差异，MCP 使用官方 SDK 完成发现、授权、工具读取，CLI 只调用目录预定义的官方可执行程序和命令，通过受控进程连接。设置页按服务展示真实可用方式与所需配置，提供连接级验证和使用入口；错误必须说明缺少安装、应用注册、权限或重新授权，不得仅凭保存成功宣称远端验证通过。

边界与安全：外部服务要求的 Client ID/Secret、组织租户、实例 URL、产品资格不能由程序伪造。回调 state、PKCE、过期与重放校验；凭据只存 SecretStore，不回显、不进 URL/日志。官方 endpoint 与用户实例输入按可信边界校验，禁止跨 origin 泄漏凭据；CLI 不拼 shell。断开不撤销他人的外部 CLI 登录，停用该本机连接并保留记录。已有 OAuth/Gmail/Notion/飞书行为兼容。

模块：contracts 定义方法配置及连接类型；catalog 管官方来源和协议数据；horizontal/connector-host 管连接存储与生命周期；local-host 管 Home/SecretStore 装配、OAuth/CLI/MCP适配、路由和现有消费者；workbench 管图标、方式选择、配置及连接操作；相关 tests 调用生产路径。

验收：所有列出的方式都有对应适配及真实操作入口，不存在 external 冒充已接入；每种协议完成配置→授权/连接→验证→读取/工具发现→断开路径测试，覆盖错误 state、过期/刷新、权限失败、重启与多账号隔离；目录每个服务都有可追溯资产与官方配置；品牌图形不贴边、无重复 SVG ID/丢失图标，桌面、窄屏与暗色实际检查；运行定向回归、包构建和类型检查。真实账号验证逐服务记录已验/缺少配置/未验，缺少必要条件时不能宣称全部通过。

执行顺序：图标和现有 API 链路修复；协议配置核验；通用接入设施与各服务适配；界面贯通；定向故障与真实浏览器验证；只读审查与验收记录。全任务只保留一个实现 writer，并行代理仅调研/设计/只读审计。

并行交付对接：Connector 连接元数据归 horizontal owner；Projects、Sources、Images 各自提供只读凭据引用和状态变更接口，Host 不跨库操作业务表。为 Agent 的共同工具目录提供连接描述、工具调用、资源读取及 AbortSignal；为个人助理提供 Sources 当前授权只读检查，由助理 owner 组合材料、时间和 revision。断开/重新授权取消正在使用旧连接的请求。


最终实现决定：MCP 没有统一的稳定远端账号标识，显式新授权创建新连接，原连接的常规刷新保持自动；CLI 换号后旧连接拒绝读取。Sentry CLI 当前明确限定 sentry.io，Supabase CLI 要求至少2.118.0。UI中的OAuth、CLI及MCP不再同时保留重复旧表单，旧API端点仍兼容。

验收与未完成项见 [verification.md](verification.md)，逐服务官方配置来源及真实账号状态见 [provider-verification.md](provider-verification.md)。当前实现和受控协议/消费者验证已完成；统一包构建待总交付owner回传；真实第三方账号验收缺少指定测试连接和应用配置，已向用户询问，不能将其标为全部可用。
