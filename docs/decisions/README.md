# Architecture Decisions

这里保存已经接受、需要长期解释“为什么这样做”的架构决策记录（ADR）。当前重组决定先由 [`specs/molis-work-architecture-reorganization/spec.md`](../../specs/molis-work-architecture-reorganization/spec.md) 和 [`docs/SSOT-MATRIX.md`](../SSOT-MATRIX.md) 统一承载；当某项决定需要独立生命周期、替代关系或长期兼容说明时，再抽成单独 ADR。

ADR 只记录已经接受的决定、背景、取舍、影响和替代关系，不用来保存开放想法或实现进度。实现状态继续维护在 [`docs/system/MIGRATION.md`](../system/MIGRATION.md)。
