# 连续对话与后台任务定样

状态：三个方案待用户选（2026-11-03）。产品没有实现；整页是按剧本演的模拟，不连 Home、不调模型，任务状态全是假的。

需求出处：[`specs/proactive-assistant/spec.md`](../../../specs/proactive-assistant/spec.md) §7.5（主对话持续可用，任务在后台执行）、§12.8（后台任务的可视化与主对话联动）、PWA-127～140。§12.8 要求正式实现前先有高保真可操作切片，走通「连续交办两项任务 → 询问另一问题 → 查看并补充第一项 → 第二项需要决定 → 第一项完成 → 返回主对话」，并呈现排队、失败、停止和断线恢复，标明模拟部分。这一页就是那个切片。

## 打开

```bash
python3 -m http.server 4410 --bind 127.0.0.1 --directory docs/design
```

再打开 `http://localhost:4410/assistant-background-tasks/`。顶部斜纹条是原型控制：方案、剧本（上一步／下一步，或者直接在输入框按回车发出预填的那句）、情况（正常／排队／第一项失败／断线后恢复）、中英文、深浅、重置。

## 三个方案

三个方案只差**任务入口放在哪、详情在哪看**：

| 方案 | 入口 | 详情 | 好处 | 代价 |
| --- | --- | --- | --- | --- |
| A 对话顶上的任务条 | 助理窗格顶部一条「任务 · 进行中 1 · 等你 1」，点开在窗格里列出 | 在助理窗格里换成这项任务，顶上「← 主对话 · 2 条新」 | 入口就在对话旁边，位置稳定；看任务和回主对话都是一步 | 看详情时对话暂时让位（草稿和阅读位置保留） |
| B 底栏的任务按钮 | 底栏右侧「任务 · 进行中 1 · 等你 1」，点开一个浮起的任务面板 | 在浮起的面板里，对话一直看得见、能打字 | 对话从不让位；任务和对话可以同时看 | 面板浮在主区上，盖住正在看的文稿；入口离对话远，要在两处之间来回看 |
| C 对话里的任务卡 | 每项任务是接单那条消息里的一张卡，原地更新；输入框上方一排「在做」的小胶囊 | 在卡片里展开 | 任务和交办它的那句话放在一起，最好懂来龙去脉 | 对话一长，卡片会被顶上去，要靠胶囊跳回去；跳转会移动阅读位置 |

三个方案共用的部分（不在比较之列，也请一起看）：

- 交办以后马上有一句接单回复，写清两件事各在做什么、是在跑还是在排队（§7.5.1）；临时问的问题直接答，不开新任务（PWA-127）。
- 查看任务不改发送对象：输入框上方一直写着「发给：助理」；只有点了「对这项任务说」才换成那项任务，× 回到助理（PWA-130）。
- 补充写在任务上，回执分两步：「已收到 · 下一步开始时用上」→「已用上」，不把收到说成用上（§7.5.2）。
- 决定绑在它的任务上（「只作用于『写完发布说明』」），回答以后收成一行，可以改（PWA-135）。
- 停止和暂停先显示「正在停止」「正在暂停」，过一会儿才变成「已停止」「已暂停」，不把点击当成已经停下（PWA-134）；「停止这次回复」只停助理正在说的这句话，后台任务不停。
- 结果回到对话是一张验收卡，详细过程留在任务里；失败写明哪里没过、保留了什么（§13.3）。
- 排队写明在等什么（PWA-131）；断线时顶上一条提示，正在跑的任务变成「断线 · 待核对」，重连后先核对，不重复派出（PWA-137）。
- 新消息不把往上翻的人拉回底部（PWA-139）；离开对话期间来的消息带「新」的标记。
- 手机宽度：一屏只放一个窗格，用「文稿／助理」切换。

## 建议走一遍

1. 方案 A，一路按「下一步」走完 6 步；第 3 步会自动打开第一项并带上补充。第 4 步在对话里回答决定，第 5 步点「验收」。
2. 切到 B、C 再走一遍（「上一步」退回开头）。
3. 情况切成「排队」「第一项失败」「断线后恢复」各走一次；在任务详情里点「停止」「暂停」。
4. 换 EN、深色，窗口缩到 1024 和手机宽度。

## 模拟的部分

- 任务进度只跟着剧本走，不会自己往前；用量是写死的示例数字。
- 输入框只认剧本里预填的两句，别的话不处理。
- 「在 Coding 里接手」「再改改」「重试这一步」只弹一条提示。
- 控件是原型自己的样式，不是 `mw-*` 组件；做产品前换成组件板里的控件再核对一遍。功能验收要用真实后台任务、真实模型和原业务对象再走同一路径（§12.8、PWA-139）。
- 状态存在浏览器 localStorage（键 `molis-proto.assistant-background-tasks.v1`），「重置」清掉。
