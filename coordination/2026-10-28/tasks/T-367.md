## 3. 具体改法

在该用例自己的 `directory = await home(t)` 中，所有 secret 操作经公开 storage API 和显式 `runWithMolisWorkHome(directory, ...)`。沿用 `scripts/run-tests.mjs` 给出的 test 环境、file 后端、独立 Home 与清理，不另造环境框架。

先写一条独立 fixture sentinel，保存其可读值、sealed 值与 `readSecretsFileMeta().entryCount` 基线。由原真实 TRIGGER 触发 `pin refused`；检查 connection 和 pin 均无行，持久化 secret 数仍为基线且 sentinel 不变。不能用 spy.delete 或猜测随机 ref 代替结果。

DROP TRIGGER 后仍从原公开 Host createToken 入口创建连接；保留 pin 断言，检查返回连接实际 `credential_ref` 有 sealed entry，`resolveToken` 可读回对应 fixture token，secret 数仅增加一条且 sentinel 仍在。只加公共包入口导入，不读取私有 JSON、不混载源码和构建。
