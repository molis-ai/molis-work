## 修正与证据

一批调整：状态小字提高到 11px；移除品牌链接默认下划线；进度条改用 transform；保留已有字体命名；补齐窄屏新建入口、空白项目补充材料；取消整页反复入场动画，避免快速勾选后按钮位置在点击时变化。

`node --check` 检查 `app.js`、`data.js`、`server.mjs`。设计检测只运行一次静态扫描，记录于 `detector.json`；因解析依赖缺失，降级为正则，不能据此声称对比度或布局全面通过。Inter 属于现有产品规范；字体别名与 width 动画警告已调整，字号/圆角建议交给截图审阅判断。

截图为浏览器实际页面，不是图像生成。桌面总结、项目与连接页使用 full-page；窄屏清单和总结保留 viewport 截图，避免 full-page 将 sticky 操作条拼接到页面中间。CSS viewport 由浏览器 API 设置并读取确认；CUA 返回的部分图像为 1433px／383px 宽，窄屏 viewport 图为 383×829。文件直接保存工具返回的 bytes，没有再加工；具体转换机制未知。截图只覆盖所示状态。

独立截图审阅首轮为 `fix`，唯一 material finding 是窄屏隐藏 sidebar 后没有项目切换。修正为顶部项目名按钮 + 项目列表，浅深两套截图与以上实际操作均已回传复核。当前项目/已存项目共用既有 state，不创建第二套状态。

复核结论：`P1 resolved; disposition: ship`，仅针对窄屏项目切换这一修复项。不是对真实连接、生产应用或用户验收的结论。
