## 打开

在仓库里起一个静态服务，根目录指向 `docs/design`（页面引用同级的 `workbench-shared-paths/` 的样式和图标）：

```bash
python3 -m http.server 4410 --bind 127.0.0.1 --directory docs/design
```

再打开 `http://localhost:4410/work-mainline-switch/`。顶部带斜纹边的一条是原型控制，不是产品界面：切方案、状态（正常／还没有事项／事项很多）、中英文、深浅、重置。

## 三个方案

| 方案 | 列表菜单 | 好处 | 代价 |
| --- | --- | --- | --- |
| A 按组列出 | 现在／接下来／等别人逐组列出，固定的排在组首，已完成折叠在最后 | 和需求原文一样；一眼看全，分组本身就是优先级 | 事项一多菜单变长，要靠搜索 |
| B 带预览的两栏 | 左边同 A，右边预览悬停或键盘选中的那件：切过去会打开什么、这件事的东西 | 切之前就知道会换成什么样，少切错 | 菜单宽 700px，盖住更多主区；手机上预览去掉，退回 A |
| C 最近切过加折叠分组 | 顶上最近切过的 3 件，下面各组默认折叠，组头带数量和等你的件数 | 来回切两三件事最快，菜单短 | 不常用的事项要多点一下展开；分组的存在感弱 |

三个方案共用的部分（不在比较之列，也请一起看）：

- 切换器：状态圈（进行中／等别人／受阻／完成／轻事项虚线）、名字、等你的件数；没选事项时显示项目名。
- 切换：主区和右侧换成这件事上次的样子，第一次切到时右侧打开「这件事的东西」；提示条写「已切到…」，带「回到…」；从在跑的事项切走时说明它仍在后台跑（MLN-06）。⌘\ 回到上一件。
- 「这件事的东西」：按种类分组，每行写来源关系（就是这件事、你放进来的、Goal 资料、挂在 Goal 上）；读不到的对象显示「已不在」或「无权查看」，只能移出（MLN-11）。移出只去掉关系，对象本身还在，可撤销（MLN-10）。
- 对象页右上「放进事项」：原地列出事项，当前的排第一。
- 助理输入框前的「在：xx」，可点 × 去掉。
- 新建事项：只起个名字（轻事项），或建成 Goal／待办（由那个插件拥有）。
- 标完成：悬停出现，收进「已完成」折叠，可撤销。
- 整理主线：主区上的覆盖层，各组一列；拖动或键盘（↑↓ 移动、⌥↑↓ 换组）调顺序和换组；组名点了就能改；删组时事项并进相邻组，一件不丢（MLN-04）。

## 建议走一遍

1. 默认是已定的方案 C，点左上「网站改版」，切到「发布 v2」：看右侧「这件事的东西」里的「已不在」「无权查看」两行，点「从事项移出」再撤销。
2. 切到「首页改版」再切回「发布 v2」：提示条说 Coding 会话仍在跑，点「回到…」。
3. 在对象页点「放进事项」，放进「定价页文案」。
4. 打开菜单，悬停「法务审条款」点 ✓ 标完成，再撤销；点「整理主线」，拖一张卡到另一组，删掉「等别人」。
5. 切到 A、B 各开一次菜单对比；再把状态切成「事项很多」比较三个方案。
6. 换 EN、深色，窗口缩到 1024 和手机宽度看一遍。

## 模拟的部分

- 事项、分组、关系、对象页都是 `data.js` 里的示例；对象页只画了占位。
- 「切走再切回保留草稿、滚动、选区」只演示了标签与右侧的保留，没有真的编辑器。
- 状态存在浏览器 localStorage（键 `molis-proto.work-mainline-switch.v1`），「重置」清掉。
- 按钮、标签、分段、状态环和提示条用的是组件板实件（共用的 `docs/design/kit/`）；切换器菜单的行和分组还是原型的写法，做产品时按组件板的菜单核对一遍。
