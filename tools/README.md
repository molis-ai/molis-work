# 需求全景图的生成脚本

`index.html` 由这里生成。进展不用重新生成：页面打开时直接读 Issue #1743。

路线书的批次、依赖或交付项变了才要重新生成：

```bash
tools/rebuild.sh <molis-work 检出目录>
```

检查输出里「批次」「边」的数字，看一眼页面，再提交 `index.html` 和改过的脚本，推到 `gh-pages`。需要已登录的 `gh`。

| 文件 | 内容 |
| --- | --- |
| `data.py` | 手工录入的 151 个可独立开工单元及依赖。**依赖变了要改这里**：脚本不会从批次文件读出新依赖 |
| `build_data.py` | 读批次文件的标题和介绍，修正几条判读的依赖边，输出中间数据 |
| `build.py` | 按批次汇总，生成页面数据。`MAP` 写明拆开的单元各对应哪几个交付项 |
| `template.html` | 页面本身，含解析 #1743、计算状态的逻辑 |

依赖写法见 `data.py` 开头：无前缀是必须先做完，`~` 核出缺口才等，`^` 可先开发、合入要等，`?` 只挡其中一部分，后缀 `*` 表示由批次号判读到子项，还待核实。页面的「可领」只看硬依赖和认领状态，不看轨道占用。
