## 给人讲清楚

这一批解决**「做好的技能、插件和场景怎么安全分享给别人，以及换台电脑怎么把整个家当稳稳搬过去」**，按业务边界拆成 **2 个清晰的串行 PR** 稳步交付：

1. **单项能力包、生成插件与场景包的分享导出导入（`73-A`：含 `73-1 + 73-2`）**：
   - 把技能包、工作流、创作台做的插件（含第 `68` 批的 14 个角色样板）、场景包和保存下来的操作面打包分享；
   - 导入前先看清里面有什么内容、要什么权限、缺什么依赖插件（在默认只开「日程」的空白空间里自动提示一并开启依赖），遇到重名冲突或中途部分失败都能安全恢复；
   - **严守两条安全铁律**：导入外部插件包必须校验发布者签名信任（未信任发布者先去设置页建立信任，绝不静默跑陌生代码）；导入提示词配置包时严拒覆盖受保护的安全提示词（如 AI 低风险命令审批提示词）。
2. **整份 Home 换机导出导入（`U7`）+ 生成插件业务数据回读闭环（`73-B`：含 `73-3 + 73-4`）**：
   - **业务全带 + 大日志可选瘦身（2026-11-25 拍板）**：整份 Home 导出默认必带个人空间与全部项目分区（含推送账本与瘦身后的 Jelly 四张表）、纯平台服务数据、生成插件、记忆（**强制保留遗忘墓碑记录，严防以前彻底删掉的记忆借导入死灰复燃**）、角色与第 `71-1` 批自定义外观；**将可能高达数百 MB 的历史工作记录与本地评测账本设为可勾选项（默认不勾选给日常搬家包大幅瘦身，需要时勾选带上）**，显式排除可本地自动重建的总览索引、搜索索引与到期简表，绝不导出任何本机密码或 API 密钥；
   - **非空电脑先拍快照兜底 + 换机路径重指**：导入时做防路径穿越与防超大压缩炸弹校验，先在临时暂存目录验过全部库版本与完整性再原子切换；**如果目标电脑本来就有数据，导入前自动先拍一份本地回退快照防误盖**，导入完成后集中引导补填缺失密钥与一键重新指定换电脑后变动的本地项目／外部会话文件夹路径；
   - 同步单独验证第 `68-B` 批生成插件导出的业务数据能原样回读使用（包分享不能替代业务数据回读）。

需要你做的：开工前看一次分享范围勾选、导入预览冲突处理与非空电脑恢复确认的轻量样稿并定下。
