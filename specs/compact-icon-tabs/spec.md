# 紧凑图标标签栏

## 目标与证据
用户提供的参考图强调彩色图标、独立圆角标签、靠左的图标固定标签和明确选中态。当前标签重复显示分组名称、彩色底线、母标签，且没有固定能力；用新的标签表达替换这些视觉元素，保留已可用的工作区内容与分屏。

## 行为与范围
- 普通标签等宽、彩色语义图标、文字截断/完整标题提示；选中态使用中性色背景，不动态改变宽度。
- 右键或 Shift+F10 打开标签操作；固定后移至本窗口左侧，仅图标，取消固定恢复普通标签。固定标签不展示关闭按钮，仍可通过菜单关闭。固定、移动、复制、刷新保持状态。
- “＋”打开已有可用页面选择器并提供当前标签操作，供触屏和键盘访问；不虚构新页面、不创建领域对象。
- 分组改为用户手动创建（见 `specs/chrome-tabs-preview-groups/spec.md`）。折叠后组内标签都藏起。未分组标签没有底线；用户组用组色短线。插件色只留在图标上。
- 继续支持排序、左右上下分屏、组件内部滚动、焦点恢复；窄屏/触屏44px热区，尊重减少动态效果。

## 模块与依赖
工作台 tab-workspace-ops 管固定顺序；客户端负责图标、菜单、键盘与持久化；tab-workspace 样式负责密度和主题。复用现有 Lucide 图标、主题、原生 popover 和 localStorage，不新增依赖。普通标签旧存储没有 pinned 字段时仍为普通标签。

## 验收
1. 桌面明暗、390窄屏截图，标签/关闭/菜单可触达，根页无溢出。
2. 固定/取消固定、切换、刷新、分屏和拖动保持身份/内容/固定状态，无重复标签。
3. ＋只列已启用入口；右键、Shift+F10、菜单方向键/Escape、触屏路径可用。
4. 回归现有标签键盘、分组、关闭最后标签、Frame 与分屏。
