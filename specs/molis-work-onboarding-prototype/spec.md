# Molis Work Onboarding 高保真原型

完成等级：可交互原型。用户已要求设计高保真；依据 `docs/design/molis-work-onboarding/proposal.md` 最新清单/全选方案。此 spec 只覆盖隔离原型，不接真实文件、浏览器、邮件、IM 或模型，不改生产 Onboarding。

## 行为与范围

从一张可勾选、可全选的来源清单开始；每行显示默认范围与连接状态，范围行内调整。统一开始后已就绪来源先整理，缺失授权以原型连接队列承接，支持成功、失败、重试与跳过。来源结果与项目建议只来自本轮选中且成功读取的演示材料。总结可查证原文、修改项目名、选择采用；进入带摘要和材料的工作台。后续新建项目可从同一清单开始，也可空白创建；空白项目的「带入材料」复用清单，把采用的材料补到当前项目。

本地浏览器存储只保存该原型的演示状态与主题；刷新能继续，重置仅清理自身状态。全部内容明确标记演示。包括零选择、部分选择、全选/半选、范围调整、处理中、缺失连接、失败/跳过、无可用结果和采用状态。键盘、浅深主题与窄屏均可操作。

## 视觉与实现

沿用根 DESIGN.md 的 Molis Coss 中性灰、纸白、低饱和状态色、Inter/Noto Sans 和 Lucide。已确认单页清单结构，采用 code-led 原型；不另做视觉方向投票，不改根视觉规范。首屏两栏：左侧紧凑产品说明与流程，右侧完整来源清单和固定可见的开始操作。资料整理后转为正文主导的总结与来源阅读。窄屏单列。

允许写入：`docs/design/molis-work-onboarding/prototype/`、本 spec；按需给原方案增加原型链接。资产复用仓库字体和图标。使用独立静态服务器，仅提供明确允许的原型文件与资产。原型 UI 中不放内部架构术语。

## 验证

使用隔离 Chrome profile 对实际页面走主链及失败/重试/跳过、范围过滤、全选、零选择、引用、改名/采用、后续创建和刷新恢复。捕获桌面 1440×1000、窄屏 390×844、浅深主题关键状态；一次批量检查与一批修复，必要时一次确认。检查页面错误、横向溢出及键盘焦点。按 Impeccable 流程安排独立截图审阅，报告所覆盖原型，不声称生产集成或用户验收通过。

启动：`node docs/design/molis-work-onboarding/prototype/server.mjs`；静态检查：`node --check docs/design/molis-work-onboarding/prototype/app.js`；实际页面验证脚本与记录随原型保存。

不要求产品全量测试或发布。真实连接、读取范围 enforcement、模型调用与成本、跨来源语义分析和项目持久化接线均属于后续生产实现。
