## 场景、方案与边界

- `global-search.ts` 将最新同词同范围响应保存在搜索状态。指针瞄准结果时保留显示与点击映射，离开结果行、换词、换范围或用键盘时恢复内容在前。换词和换范围立即清理上一轮显示并作废未交付响应。键盘继续用已有选择、数字快捷键和提交逻辑。结果仍交给现行搜索打开路径校验和定位。选择暂缓整次绘制，因为只延后列表而改变上方状态的高度也会移动鼠标下的行。
- `styles/project-settings-page.ts` 保留导航链接、选中态和 Tab 顺序。窄屏标签按文字宽度显示、加现有边界色并在导航内横滚；桌面沿用侧栏。长英文名称可完整阅读，滚动只占一条导航轨道的高度。
- `project-settings-folds.ts` 用组件板已有的 `mw-btn--danger-outline` 打开既有确认框。`styles/settings.ts` 删掉该入口独有的旧链接样式。首次打开只读删除范围并在对话框中说明项目和文件选择，用户最终提交才进入现行删除路径。
- `call-row.ts`、`settings-call-diagnostics.ts`、`i18n/flow-en.ts` 将日志已有名称、结果、调用方、本机时间和已记录的失败说明显示在操作行。详情沿用能力页的折叠式样，收起机器标识、版本和错误码，短诊断编号仍可复制。已记录的动作名与来源名仍由原主人提供，固定界面文字与时间格式随页面语言，源记录内容原样保留。
- `NETWORK.md` 和 `NETWORK.en.md` 补第 1 类。对照 `connector-cli-setup.ts`、`connector-native-release.ts`、`connector-tool-source.ts`、`connector-tool-download.ts`、`connector-tool-runtime.ts`、`connector-tool-install.ts` 与 `connector-powershell.ts`，区分准备原生客户端、安装工具、连接服务各阶段，写明现有来源和请求数据。将工程核对和未走的外部联网实操分别记入清点。
