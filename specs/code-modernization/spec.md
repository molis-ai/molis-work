# 代码现代化工作流（Code Modernization）

状态：需求已整理，尚未实现（2026-10-18）。目标完成程度为**内部完整**：对一个遗留模块或代码库，用户能拿到评估、结构地图、业务规则、可审批的改造计划、增量执行与独立的行为等价证明，而不是一次不可控的“大重写”。

## 1. 问题

Coding 已覆盖会话、计划、变更集、子代理、工作树、评审与恢复，但没有一个面向“遗留代码改造”的阶段化工作流。真实现代化需要先回答：现在是什么、为什么难改、哪些业务规则不能丢、选升级/重写/重建哪条路、怎样证明新代码与旧行为等价。直接让模型“重写这个模块”会把评估、决策和证明都省掉。

## 2. 范围与非目标

**做**：

- 评估：技术栈、构建、测试、依赖、风险、可运行性。
- 地图：模块、入口、依赖、数据流、热点、测试覆盖。
- 业务规则：从代码、测试、文档中提取必须有的事实与例外，标证据与不确定项。
- 计划：升级/重写/重建的选项、成本、风险、回滚、验收；用户批准后才执行。
- 执行：增量改造、工作树隔离、每一步经审查队列、可暂停/恢复/取消。
- 验证：行为等价（测试、对照运行、独立检查）、安全加固、性能与可维护性。
- 报告：一页式状态（范围、进度、证明、风险、下一步），可持续刷新。

**不做**：

- 不自动合并、不自动推送、不绕过审查；每个写入仍经批准门。
- 不在没有用户批准计划的情况下做大规模重写。
- 不做云端执行或跨机器迁移。
- 不把业务规则提取结果直接写成 Goal/Todo；它们先作为候选，由用户确认归属。
- 不把“测试通过”当成完整的行为等价证明；要说明覆盖与未覆盖。

## 3. 阶段

### 3.1 评估（Assess）

读构建/测试/依赖/入口，跑现有检查（只读），输出：可运行性、关键风险、缺失证据、建议的改造范围。评估不修改文件。

### 3.2 地图（Map）

按模块/入口/依赖/数据流建图，标出热点、循环、跨模块契约、测试覆盖。地图是报告与计划的基础，不是新的业务事实。

### 3.3 业务规则（Extract Rules）

从代码、测试、文档提取：必须保持的行为、例外、边界、错误语义、数据约束。每条带证据（文件/行/测试）；不确定的标为待确认。规则先进入候选清单，用户确认后才成为改造验收的一部分。

### 3.4 计划与批准（Plan）

给出升级/重写/重建的选项、范围、成本、风险、回滚、验收与不做的事；推荐一项并说明理由。用户批准计划后才进入执行；计划变更需要重新批准。

### 3.5 执行（Transform）

按计划分片，每片在工作树/沙箱里做，写入与命令经审查队列；每片有完成条件与回执。可暂停、恢复、取消；取消后的迟到结果不产生新效果。

### 3.6 验证（Verify）

- 行为等价：原有测试、对照运行、关键路径的独立检查；说明覆盖与未覆盖。
- 安全：按安全评审流程检查注入、鉴权、密钥、路径、依赖。
- 性能：关键路径的前后对比；没有测量就写“未测量”。
- 可维护性：结构、重复、命名、文档；不把“更短”当唯一目标。

### 3.7 报告（Report）

一页式状态：范围、阶段、进度、已证明/未证明、风险、阻塞、下一步；可刷新并只报 delta。报告不替代源事实。

## 4. 交互与恢复

- 入口：Coding 的新工作流入口；也可由个人助理委托。
- 每一步都能看到“现在在做什么、为什么、还差什么”；长任务有进度与后台状态。
- 批准、暂停、取消、恢复都是显式操作；不自动继续到下一步。
- 失败保留已完成分片与证据；恢复不重复已发生效果。
- 计划/规则/报告都可版本化；历史版本不因新资料被暗改。

## 5. 验收标准

| 编号 | 用户可观察结果 |
| --- | --- |
| MOD-01 | 对一个真实遗留模块完成只读评估，输出可运行性、风险、缺失证据与建议范围，不修改文件 |
| MOD-02 | 地图能列出模块/入口/依赖/数据流/热点，并能从报告定位到真实文件 |
| MOD-03 | 业务规则逐条带证据；不确定项标为待确认；用户确认后才进入验收 |
| MOD-04 | 计划给出升级/重写/重建选项、成本、风险、回滚与验收；未批准不执行 |
| MOD-05 | 执行按分片进行，每片有完成条件、审查回执与可核对结果；可暂停/恢复/取消 |
| MOD-06 | 取消、撤权、停用后的迟到结果不产生新效果；恢复不重复已发生写入 |
| MOD-07 | 验证同时给出行为等价证据、覆盖范围与未覆盖项；不以测试通过冒充完整证明 |
| MOD-08 | 安全评审发现的问题进入待处理项；修复仍经审查，不自动应用 |
| MOD-09 | 报告可持续刷新并只报 delta；已证明/未证明、风险、阻塞、下一步清楚 |
| MOD-10 | `[人工]` 在一个真实遗留模块上完成一次小范围现代化，留下计划、执行回执、等价证明与报告 |
