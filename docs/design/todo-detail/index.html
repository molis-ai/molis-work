待办详情页：一件待办一页

可以直接点：标题和说明能改，状态片、右边每一行、「关联一件待办」、右上角的 ⋯ 都能点开。上面的按钮各进一个状态；右边切宽度、深浅色和语言。窗口的顶部和底部只是示意，不在这次设计里。

第一眼：是什么、怎样了、能做什么最大的字是这件事本身。标题下面一行说现在的状态和最要紧的日子。右上角是能做的事，其中只有一个实心按钮。
日期和归属退到右边它们是这件事的属性，不是主角：收进右边一块浅底，一行一件，整行可点。窗口窄了，这一块挪到标题下面。
标题和说明像文档，不像表单没有灰底输入框和小标签。直接点字就能改，停手自动保存，右上角说保存到哪一步。
状态：一枚带颜色的片蓝是在办，青是在等别人，绿是做完，灰是没开始或不做了。点开菜单换；「完成」最常用，单独是主按钮。
用到才出现「在等谁」只在等待他人时出现；「助理在办什么」只在交给助理后出现；修改记录平时收成一行。
不同的东西长得不一样来源是一张带引文的卡；关联是一组行，关系用不同底色的小标签；助理的东西是浅蓝底，等你点头时变琥珀色。
