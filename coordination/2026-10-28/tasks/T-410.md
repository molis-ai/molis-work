## 行为和公开合同

- 普通 header 为 `{title, material_id}`；固定引用仍使用原 `{title, artifact_id, version}`，ID/数字版本及正文逐字保留。保持原 data 信任边界、标题/material_id 校验与 header+正文 20,000 UTF-16 units 上限，不改 SDK。
- 来源只允许完整一对或完全不提供；半份、null、错误类型、空/超长 ID、非正安全整数版本在派发前拒绝。start 输入和 frozen 输出同样约束，不能只用 TS optional 或放宽 frozen 为任意 object。
- Assistant 的情况、目录、方法目录、普通附件、选区、回交、设置、线程上下文不再借 Work ID 占位；Coding session/question/live Page 与 Shelf envelope 同样去假来源。正文内真实 owner/revision/出处保留。
- 直接消费者只在来源存在时做固定 plan/goal 筛选。普通材料 summary 保留 material_id，以 title/material_id 显示，不能投影成空对象或输出假版本。执行计划仍要求来源双字段精确相等，普通材料不能取得固定计划资格。
- `agent.run.start.v1` version 2→3；`agent.run.read.v1`、`agent.session.read.v1`、`agent.run.wait.v1` version 3→4；ID字面量不变，当前调用方共用 agentHostCapabilities，不保旧版，不另造映射。
