33 · 底栏第十二版：三段各自向上长（对话分栏，该你的是一叠卡）

可以直接点：左边的卡和卡上的按钮、输入框上沿的事项标签、右边线上的站、输入框下面那一行、主区里的行。上面的按钮各演一条动线，「演示一遍」按顺序走完。布局用户已认可；这一稿把现在的功能、后面要来的需求、动线、状态、引导放在一起细化。顶部的页签是静态的，没有跟着换。

平常左边是一叠该你的卡，中间是输入框，上沿的标签是事项，右边一条线上是办完的、在办的、接下来的。
左边：一叠该你的卡最上面一张就是下一件该你的：哪件事、它问什么、可以怎么答。能直接在卡上答，答完这张飞走，下面一张上来。想看清楚再定，点卡片本身。它要你定的时候，那件事从右边的「在办」到这一叠里。
中间：输入框，上沿的标签只有事项和事件当前事项是一个组：事项名后面是它里面开着的事件对话，整组上沿一道墨蓝，和输入框是同一张。别的事项是右边收起的一枚，带等你的件数。组里只放你打开过、还没关的对话。换项目不在这里。
右边：一条线，办完、在办、接下来三站位置不变，每站两行小字：叫什么、几件，点名一件。实线是走过的，点线是还没到的。点名字专注到那件，点组名看这一站的全部。
对话分两栏右栏只有说过的话，和输入框一样宽。左栏在那叠卡的正上方，从上到下：该你做的（选择项、接续）、这件事现在怎样（信息卡）、到现在为止（总结）、上下文（谁来办、方式、带着什么、放在哪）。

一句话：底栏三段，各自向上长出自己的一块

底栏的一段平常向上长出来的里面放什么
左：该你一叠卡，最上面一张带回答左栏（和对话一起开合）该你做的 → 这件事现在怎样 → 到现在为止 → 上下文
中：输入框，上沿是事项标签字一行；带着什么、给谁一行对话只有说过的话，连同回执、安放、结果卡
右：一条线，办完、在办、接下来每站两行小字任务栏（自己开合）这一站的全部；在办的每件写真实步骤，能展开它派出去的子任务，在这里和子任务说话

一件事在哪，只看它的状态

失败、部分完成、中断左边卡叠哪一步没成、为什么再试一次、先放下、打开红点
结果不确定左边卡叠先核对只有「去核对」，卡上不给重试问号
