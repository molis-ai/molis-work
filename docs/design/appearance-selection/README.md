## 三个方案只差在「点了皮肤或字体之后」

| 方案 | 点一套外观或字体 | 取舍 |
| --- | --- | --- |
| A 点了就换，可撤销 | 马上换成这套，这个 Home 的所有窗口和 Mac App 一起换；提示条给「撤销」，卡片下方说已生效或出了什么问题 | 最快、和现在「改了即生效」一致；试一下也会让别的窗口跟着变，要靠撤销回去 |
| B 先在这个窗口试，再用上 | 只在这个窗口换样子，页底出现试用条：「还原」或「用上」；用上才改这个 Home 的选择 | 多点一次；试的时候能在真实页面上看效果，别的窗口不受影响；离开设置自动还原 |
| C 旁边一张样张，确认再用 | 页面不变，右侧样张卡按候选外观画（列表、表单报错、按钮、长文、数字、代码）；「用上」才换 | 页面最稳，样张把各种状态摆在一处；但看到的是样张，不是自己的页面；窄屏样张从底部升起 |

三个方案共用的规则（不随方案变）：

- **管到哪里写在每一节标题下。** 皮肤和字体是这个 Home 的一个选择，所有窗口和 Mac App 跟着；主题、密度、终端只在这台设备；界面语言只在这个浏览器，Mac App 有自己的选择。
- **字体策略。** 默认「跟随皮肤推荐」；明确选了某个字体就锁住，换皮肤也不变，并在字体下面说一句「你选定了…，Folio 推荐…」，给「改用推荐」。等宽字体单独选，换界面字体不影响它。
- **加载与失败。** 字体还没加载好时先用声明的后备字体显示，并说出来；字体加载失败、方案没通过检查，都不会换掉正在用的外观，说明原因并给出下一步（再试、换字体、交给助理修改）。
- **另一个窗口改了。** 别处刚换了外观，这里跟着换并说出来；正在试的不会悄悄盖掉别人的选择，要「仍然用上」才替换。
- **立即生效的项。** 语言、主题、密度、终端点了马上生效，不刷新整页，正在写的内容留着。
- **恢复。** 「恢复内置外观」换回 Soft Workbench 和系统字体，保留语言、自己的方案和工作内容，之后能撤销；Mac App 菜单里也有同一个入口（外观坏到设置页都看不清时用）。

## 组件板新增

定下后先补成组件板标本（交 D 轨），再写产品代码。方案 C 要补的是外观卡、样张卡和换外观的淡入（用上、撤销、恢复时整页换外观）。

| 名字 | 为什么现有的不够 |
| --- | --- |
| 外观卡 | 选外观要先看得见它的颜色、圆角和推荐字体；`mw-choice` 只放一个词。整张卡是一个按钮（`aria-pressed`），状态用 `mw-badge` 说，不只靠颜色；更多操作是卡角的独立按钮 |
| 试用条（B，已否掉，不补） | 组件板的 `mw-bar-status` 只说状态，没有「这个窗口正在临时用另一套样子」并带「还原／用上」的条；钉在设置页底部 |
| 样张卡（C） | 卡片正文跟着页面外观走；样张要在另一套外观里画，并把加载、失败、冲突说在卡脚 |
| 换外观的淡入 | 新外观和文字立即生效，旧底色在实时页面上淡去。用 `--dur-move` 和 `--ease-quint`，控件在动画中可点击，减少动态效果时直接换。 |

2026-11-10 第 16 批复验时，原定样的整页 View Transition 让鼠标约 272 毫秒无法命中语言控件。用户看过实时设置页样张后选择「实时页面淡入，控件可点」。组件板和产品共用这个动效。旧底色的淡色层不接收鼠标或焦点，快换时以后一次为准。验收见 [FSS-68](../../../specs/font-and-skin-system/spec.md#11-验收标准)。

### 组件板标本与上面定样的差异（T8b，第 14 批）

三样已经在组件板（`/__ui/catalog`）里：外观卡（`#look-card`）、样张卡（`#look-proof`）、换外观的淡入（`#look-fade`）。和定样稿不一样的地方：

- **标本是三个零件，不是一个设置页。** 原型把方案 C 画在整页里；板上每样单独摆，设置页已随 #2031 接入（设置 › 界面与语言）。
- **外观是从真实基线推出来的两套示例，不是 Folio。** Soft Workbench 用 `BASELINE_SKIN`；「蓝绿工作台」「暖色草稿」是只写「指向基线里另一个角色」的皮肤文件，经 `parseSkinFile` 和 `resolveSkin` 解析，源码里没有色值。推荐字体都写系统无衬线：Folio 的配色、圆润字体和真实的第二套外观已随 #2031 进来（`packages/design-system/resources/skins/folio.json` 与 9 份字体），多了一条外观记录，零件未改。
- **整页换外观要给 `body` 也写一遍令牌。** 页面各层把壳的令牌在 `body.settings-page` 等上又写了一遍，只给 `<html>` 写，页面纹丝不动。板上的 `lookScope` 因此同时给 `html > body`；第 16 批的产品代码已照这个办法实现，否则整页不会换。
- **淡入的开关不是 `?still`。** 用仓库已有的 `html[data-craft-still]`（自动化下由收尾层设上），再加系统的减少动态效果、标签页在后台、浏览器缺少动画 API，这四种情况都直接换。演示换的是「暖色草稿」，因为它和基线差得最多，淡入看得出来。换外观的这一刻页面和文字已经换了，淡入跟着开始，不让人等；连换两次以后一次为准。
- **按钮和代码行。** 样张里的主按钮不带键位提示；代码行折行，不截断（宽度 390 以下也读得全）；原型里的「示意」角标不做（样张是一幅有名字、不可操作的图，由读屏读出「样张：…（示意，不可操作）」）。这三条是 #1795 共审留给第 16 批的，板上先按这个写；第 16 批产品代码已按此落地（样张主按钮无键位提示、代码行折行不截断、不做「示意」角标）。
- **「更多操作」的菜单。** 复制为我的方案、导出…、移除；内置外观只有复制；在用的外观上「移除」不可用，原因写在它下面。板上那张展开着的卡带 `data-menu-held`，点别处或按 Esc 不会把它收起来，只有它自己的按钮能收。
- **词用产品已有的。** 保存、取消、更多、移除、浅色、深色、再试一次、进行中、内置、没通过检查、项目名称这些产品里已经有英文，板上不再写第二份，英文就是产品的。

## 示意（不在这次定样）

- **Folio 的配色是代替品。** 需求只定了方向（丰富协调的色彩、圆润、活泼），正式视觉已随第 16 批定（Folio「杏纸与常青」）；这里的奶油底、蓝、珊瑚、薄荷只为让「换外观」看得出来。
- **圆润字体是本机的圆体（Yuanti SC 等）。** 正式用哪款、能否随产品分发，等决策第 23 项；需求要求不能只靠某台 Mac 恰好有的字体。
- **「蓝绿工作台」** 是一份假设由助理做好的方案，只为演示「我的方案」和「没通过检查」。制作、编辑、导入导出的流程不在这次定样（第 70 批）。
